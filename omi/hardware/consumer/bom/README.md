# Bill of Materials — Omi Consumer

The BOM lists all components needed to build one Omi device (mainboard + charger + FPC + mechanical parts).

## Files

### Per-Board BOMs (use these for PCBA ordering)

| File | Board | Component Rows | Notes |
|------|-------|---------------|-------|
| `mainboard-bom.csv` | Mainboard (4-layer HDI) | 56 | 144 designators, all SMD |
| `charger-bom.csv` | Charger board (2-layer) | 6 | 8 designators |
| `fpc-bom.csv` | FPC flex (2-layer polyimide) | 2 | BTB connector + contact ring |
| `mechanical-bom.csv` | Non-electronic + off-board | 16 | Enclosure, magnets, adhesives, battery, motor |

### Original BOM

| File | Description |
|------|-------------|
| `omi-bom.csv` | Original global BOM (88 rows, all boards combined) |
| `omi-bom.xlsx` | Spreadsheet format (cleaned) |
| `omi-bom-original.xlsx` | Original manufacturer BOM |

## Columns

| Column | Description |
|--------|-------------|
| ID | Sequential component number (from original BOM) |
| SKU | Internal part SKU |
| Description | Component description with package size |
| Manufacturer | Component manufacturer |
| MPN | Manufacturer Part Number (use this to order) |
| Designator | PCB reference designator(s) for this board |
| Qty | Quantity per unit for this board |
| Board | Board assignment (mainboard/charger/fpc/mechanical) |
| Category | See [Category Legend](#category-legend) below |
| Populate | `yes` = SMT-placed on PCB by pick-and-place, `n/a` = not SMT-placed (metadata rows, mechanical, off-board electrical, manual-assembly items) |
| LCSC_PN | LCSC/JLCPCB part number (blank = not available on LCSC) |
| JLC_Status | `Extended` = JLCPCB extended library, `Basic` = basic library, `N/A` = not on LCSC |
| Stock_Note | Sourcing note: stock status, alternate sources, or procurement hint |

## ⚠ Board-Qualified Designators

Designators like C1, R1, R2, D3, U1, PP1, PP2 are **reused across boards** — each board has its own namespace. When importing into ERP or CM systems, always qualify designators as `(Board, Designator)`:

| Designator | Mainboard | Charger | FPC |
|------------|-----------|---------|-----|
| U1 | nRF5340-CLAA (WLCSP-95) | TPS25200DRVR (6-SON) | — |
| C1 | 1µF 0201 X5R | 100nF 0402 X7R | — |
| C2 | 1µF 0201 X5R | 22µF 0805 X5R | — |
| R1 | 2.2KΩ 0201 | 280KΩ 0402 | — |
| R2 | 10KΩ 0201 | 280KΩ 0402 | — |
| D3 | SDM20U40-7 Schottky | TPD1E10B06DPYR ESD | — |
| PP1/PP2 | CA02-PG07 (WH1.5mm) | CA62-PG308 (WH3.3mm) | — |
| J1 | ST-BTB-K3570606F (BTB Female) | — | Charging contact ring (custom) |
| J3 | — | — | ST-BTB-K3570606M (BTB Male) |

> **Note:** FPC designators J1 and J3 do not collide with charger designators. J1 collides with mainboard J1 (both are connectors but different parts). J3 is unique to FPC. All designators are board-scoped.

## Designator Gaps

Some designator sequences have gaps (e.g., R22, D5/D6, Q3–Q6, K1, J2 are absent). These are **design-intentional** — verified against KiCad 9 schematics (`.kicad_sch`). They reflect removed or reserved nets during board revisions, not missing BOM entries. Multi-designator rows cover components like D2/D7 (row 55, LED RGB) and U6/U11 (row 33, load switch).

## Data Source

Per-board BOMs were generated by cross-referencing the original `omi-bom.csv` against KiCad 9 PCB source files (`.kicad_pcb`). Each designator was matched to its board using embedded MPN data to resolve shared designator names. 8 components present in PCB but missing from the original BOM were identified and added (C15, C49, C50, Q1, R13, R21, R37, R47).

### Category Legend

| Category | Meaning | Purchasable? |
|----------|---------|-------------|
| `component` | Electronic part to be placed on PCB | Yes |
| `custom-part` | Custom/drawing-controlled part (no standard MPN) | By SKU/drawing |
| `accessory` | Non-electronic accessory (foot pads, etc.) | Yes |
| `pcba-reference` | Assembly service line item from original BOM | No — metadata |
| `pcb-reference` | Bare PCB line item from original BOM | No — metadata |
| `assembly-header` | Project/board header row from original BOM | No — metadata |
| `off-board-electrical` | Electrical part not placed by PCBA (battery, motor) | Yes — separate procurement |
| `cnc-part` | CNC-machined enclosure part (sourced by STEP drawing) | By drawing/RFQ |
| `injection-molding` | Injection-molded part (sourced by tooling drawing) | By drawing/RFQ |
| `consumable` | Adhesives, tapes, screws, magnets (generic, no MPN) | Yes — commodity |
| `battery` | Lithium polymer cell (see `BATTERY-SPEC.md`) | Yes — regulated |
| `motor` | Vibration motor (soldered by hand during assembly) | Yes |
| `mechanical` | Enclosure, fasteners, adhesives (general) | Yes |
