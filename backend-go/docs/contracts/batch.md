# Batch transcript-of-record contract

Python reference: `BasedHardware/omi@66b026c199463ce139d8a0658e4dc222b70a1696`. The record lane accepts custody, schedules units, commits encrypted result references to an owner log, projects text into conversations and settles the upload. Each boundary has a separate receipt. For example, a worker can successfully complete a segment while the upload still owes a sibling and Home still awaits a transcript.

For shadow comparison, feed the two implementations identical synthetic upload bytes, capture clocks, frozen policy, privacy transitions and recorded recognizer results. Compare dispositions, durable receipts, intended conversation edits, ordered identities, cumulative speech seconds and requested external operations. Normalize random tokens consistently by issuance and compare their ownership/expiry relationships. Use sandboxed stores and stub paid calls.
