## Discord

The [Omi Discord](https://discord.omi.me) is where builders, users, and the team meet. Contributors who land significant work are given the **Contributor role**.

## Code of conduct

Everyone participating in the Omi project (issues, PRs, Discord) follows the [Contributor Covenant Code of Conduct](https://github.com/BasedHardware/omi/blob/main/CODE_OF_CONDUCT.md). Enforcement contact: [team@basedhardware.com](mailto:team@basedhardware.com).

## Contacts

| Need | Contact |
|------|---------|
| Using the Omi app or device | [help.omi.me](https://help.omi.me), or [help@omi.me](mailto:help@omi.me) |
| Business, legal, licensing | [team@basedhardware.com](mailto:team@basedhardware.com) |
| Bounty claims (after release) | [team@basedhardware.com](mailto:team@basedhardware.com), see [Bounties](/doc/contribute/bounties) |
| Security disclosures | [Security policy](https://github.com/BasedHardware/omi/blob/main/SECURITY.md) |
| Code and bugs | [GitHub issues](https://github.com/BasedHardware/Omi/issues) |
