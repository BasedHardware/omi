## Overview

omiGlass is an open-source smart glasses project: a XIAO ESP32 S3 Sense with a camera, 3D-printed frame, and battery pack, paired with an open app and firmware.

<CardGroup cols={2}>
  <Card title="ESP32 S3 Sense" icon="microchip">
    XIAO microcontroller with camera
  </Card>
  <Card title="Fully open source" icon="code-branch">
    Hardware, firmware, and software in this repo
  </Card>
</CardGroup>

<Note>
omiGlass is a developer kit. Features are experimental; treat battery life and stability as unvalidated until you test your own build.
</Note>

## Using it

Pair omiGlass with the Omi app like any other Omi device: power it on, open the app, and follow the pairing flow. The camera captures first-person photos; the microphone captures audio for transcription. End-user setup help lives in the [help center](https://help.omi.me).

<Warning>
Always get consent when recording others, and be mindful of local recording laws. Respect privacy in public and private spaces.
</Warning>

## Software setup

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/BasedHardware/omi.git
    cd omi/omiGlass
    npm install
    ```

    Or with yarn:
    ```bash
    yarn install
    ```
  </Step>
  <Step title="Configure API keys">
    Copy the template and add your keys:

    ```bash
    cp .env.template .env
    ```

    Edit `.env` and add:
    - [Groq API key](https://console.groq.com/keys)
    - [OpenAI API key](https://platform.openai.com/api-keys)
    - Ollama URL (default: `http://localhost:11434/api/chat`)
  </Step>
  <Step title="Install Ollama model">
    ```bash
    ollama pull moondream:1.8b-v2-fp16
    ```
  </Step>
  <Step title="Start the application">
    ```bash
    npm start
    ```

    Or with yarn:
    ```bash
    yarn start
    ```

    <Tip>
    This is an Expo project. Open the localhost link displayed after starting to access the web version.
    </Tip>
  </Step>
</Steps>

## Firmware installation

<Steps>
  <Step title="Open the firmware">
    Open the [firmware folder](https://github.com/BasedHardware/omi/tree/main/omiGlass/firmware) and load the `.ino` file in Arduino IDE.

    <Tip>
    Alternatively, follow the [firmware readme](https://github.com/BasedHardware/omi/tree/main/omiGlass/firmware/readme.md) to build using `arduino-cli`.
    </Tip>
  </Step>
  <Step title="Configure Arduino IDE">
    Add the ESP32 board package:

    1. Go to **File → Preferences**
    2. Add to "Additional Boards Manager URLs":
       ```
       https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
       ```
    3. Go to **Tools → Board → Boards Manager**
    4. Search for `esp32` and install the latest version
  </Step>
  <Step title="Select board and port">
    1. Select port (likely COM3 or higher) at the top of Arduino IDE
    2. Search for `xiao` in the board selector
    3. Select **XIAO_ESP32S3**
  </Step>
  <Step title="Configure PSRAM">
    Go to **Tools** dropdown and set **PSRAM** to **OPI PSRAM**.

    <Frame>
      <img src="/images/docs/hardware/images/image.png" alt="PSRAM Settings" />
    </Frame>
  </Step>
  <Step title="Upload firmware">
    Click the Upload button to flash the firmware to your XIAO ESP32S3 board.
  </Step>
</Steps>

For flashing and monitoring details, see [Flash Firmware](/doc/hardware/omiglass/flash-firmware) and [Monitoring](/doc/hardware/omiglass/monitoring).
