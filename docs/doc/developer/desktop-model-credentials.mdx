---
title: "Desktop model credentials"
description: "Request-scoped authentication for the shipped macOS agent"
---

AuthService owns the managed Firebase session. The pi-mono model transport asks
Swift for current headers on every HTTP attempt, including requests after sleep
or an offline period. No refresh timer or subprocess restart maintains validity.

The interim `model_headers` Unix-pipe request is admitted by an active kernel run
capability. Swift fences its reply to the owner session; the kernel revalidates
before forwarding it. Firebase and BYOK values never enter the agent environment.
They still enter request memory and IPC until a Swift streaming relay replaces
this stepping stone.

Numeric HTTP status determines the failure code. Managed 401s receive one forced
refresh before bytes reach pi; BYOK 401s remain provider failures. A session
failure that survives recovery offers Sign in, and its journal row retains the
typed authentication classification across reload.

Hermetic checks live in the agent and extension packages, AgentModelCredentialsTests,
and AuthRefreshResilienceTests. The shared preflight runs check-agent-credentials.py.
