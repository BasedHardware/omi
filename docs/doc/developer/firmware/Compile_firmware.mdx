## Overview

Build firmware from source to customize your Omi device. If you just want to install the latest release, use the [Flash Device](/doc/get_started/Flash_device) page instead.

<CardGroup cols={2}>
  <Card title="Consumer Firmware" icon="tag">

  </Card>
  <Card title="DevKit Firmware" icon="flask">
    `omi/firmware/devkit` — SDK v2.7.0
  </Card>
</CardGroup>

## Build Steps

<Steps>
  <Step title="Install nRF Connect" icon="download">
    Install the [nRF Connect for VS Code](https://www.nordicsemi.com/Products/Development-tools/nRF-Connect-for-VS-Code) extension.

    <Accordion title="Setup video tutorial" icon="video">
      Follow this walkthrough: [How to Set Up nRF Connect](https://youtu.be/EAJdOqsL9m8)
    </Accordion>
  </Step>

  <Step title="Install the SDK Toolchain" icon="gear">
    In the nRF Connect extension, install the correct SDK + toolchain version:

    | Firmware | SDK Version | Folder |
    |----------|-------------|--------|
    | Consumer (Omi) | **2.9.0** | `omi/firmware/omi` |
    | DevKit | **2.7.0** | `omi/firmware/devkit` |

    <Warning>
    Using the wrong SDK version will cause build failures. Double-check the version before proceeding.
    </Warning>
  </Step>

  <Step title="Open the Application" icon="folder-open">
    1. Open the **nRF Connect Extension** panel in VS Code
    2. Click **Open an existing application**
    3. Navigate to `omi/firmware/omi` (consumer) or `omi/firmware/devkit` (DevKit)
  </Step>

  <Step title="Add Build Configuration" icon="sliders">
    1. In the application panel, click **Add Build Configuration**
    2. Set the board target:

    | Firmware | Board target | Build output |
    |----------|--------------|--------------|
    | Consumer (Omi) | `omi/nrf5340/cpuapp` | `dfu_application.zip` + `merged.hex` + `merged_CPUNET.hex` (sysbuild) |
    | DevKit | `xiao_ble_sense` (XIAO nRF52840 Sense) | `zephyr.uf2` |

    <Warning>
    These targets are not interchangeable. The consumer CV1 is an nRF5340 image
    built from `omi/firmware/omi` with **sysbuild** (MCUboot-signed
    `dfu_application.zip` plus `merged.hex` and `merged_CPUNET.hex`, not a UF2).
    The DevKit UF2 is built only from `omi/firmware/devkit`.

    In nRF Connect, use the `OMI` preset in `omi/firmware/omi/CMakePresets.json`
    and turn **sysbuild** on. The preset sets the board and `CONF_FILE=omi.conf`;
    it does not enable sysbuild.

    Or, from the west workspace `omi/firmware/v2.9.0`, after
    `cp ../omi/omi.conf ../omi/prj.conf`:

    ```bash
    west build -b omi/nrf5340/cpuapp ../omi --sysbuild -d build --pristine always -- -DBOARD_ROOT=..
    ```
    </Warning>

    The DevKit presets use the legacy spelling `xiao_ble_sense`. NCS 2.7.0 maps it to `xiao_ble/nrf52840/sense`, the spelling used by `omi/firmware/scripts/build-firmware-in-docker.sh`; both select the same board.

    3. Click **Build Configuration** to start the build
    4. A VS Code notification will show build progress
  </Step>

  <Step title="Locate the Firmware File" icon="file">
    After a successful build, find the outputs:

    ```text
    DevKit (UF2, drag-and-drop):
      omi/firmware/devkit/build/<your-preset>/zephyr/zephyr.uf2

    Consumer CV1, nRF Connect preset OMI with sysbuild on:
      omi/firmware/omi/build/omi/dfu_application.zip
      omi/firmware/omi/build/omi/merged.hex
      omi/firmware/omi/build/omi/merged_CPUNET.hex

    Consumer CV1, west command above (-d build inside omi/firmware/v2.9.0):
      omi/firmware/v2.9.0/build/dfu_application.zip
      omi/firmware/v2.9.0/build/merged.hex
      omi/firmware/v2.9.0/build/merged_CPUNET.hex
    ```
  </Step>

  <Step title="Flash the Device" icon="bolt">
    Follow the [Flash Device](/doc/get_started/Flash_device) guide to install the compiled firmware on your device.
  </Step>
</Steps>
