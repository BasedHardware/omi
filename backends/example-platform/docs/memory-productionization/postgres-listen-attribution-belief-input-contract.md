# PostgreSQL Listen attribution belief input contract

Status: implemented and qualified as an inert shadow-evaluation source. It has
no route, poller, production default, product read, or authoritative graph path.

## Purpose

The first noisy-modality adapter produces owner, source-local, and unknown
hypotheses from finalized Listen channel observations. This unit makes those
inputs restart-safe without retaining transcript text in the experiment plane
or treating `is_user`, grammar, or diarization as owner authority.

## Source and totality

Only an exact immutable formation input with a matching durable work acceptance
may be read. One accepted finalized session yields one or two channel inputs.
The set binds the account epoch, formation work, source snapshot, ordinal,
input count, graph-frontier digest, stage request, and content digests.

A deferred database constraint requires the complete ordinal set in the same
transaction. Partial insertion, changed bytes, a mismatched snapshot, an
unaccepted formation, or a corrupt persisted set fails closed. Exact rerun
returns the original set and makes no calibrator call.

## Privacy and authority

Persisted input JSON contains opaque coordinates, candidate kinds, directional
factor refs, independence groups, and versioned contract digests. It contains
no transcript excerpt, speaker name, asserted owner identity, calibrated
probability, threshold, or product wording.

Every read and write requires a sealed `memories.experiments.shadow` context,
then transaction-time PostgreSQL authority revalidation. Fixed
security-definer functions independently require the exact account, principal,
and capability. The application role has no direct table privileges.

The table belongs to the `staged_results` deletion surface because it is a
derived child of the sensitive formation input. It cannot write graph
revisions, identity authorization, product projections, or answers.

## Qualification evidence

- strict service and adapter tests cover total materialization, copy-safe reads,
  paired zero-call replay, cross-account/epoch/frontier drift, incomplete and
  corrupt sets, revocation, and hostile proxy/accessor rows;
- the PostgreSQL 18.4 gate exercises the real accepted-formation chain, two-row
  atomic set, exact replay, direct-table privilege denial, content-free storage,
  and transaction-time grant revocation; and
- the pinned migration corpus passes under both Bun 1.3.14 and Node 24.19.0.

## Explicit nonclaims

This unit does not select or run a calibrator, create an authoritative belief
revision, pick presentation thresholds, change owner/subject authority,
activate Listen, issue a worker credential, or set shadow retention policy.
Those remain separate measurement, composition, operations, and David-gated
rollout work.
