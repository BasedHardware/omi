# omi-cli — српски водич за брзи почетак

> Практичан водич за рад са Omi из терминала. Погодан и за људе и за AI агенте.

`omi-cli` је званични командно-линијски клијент за [Omi](https://omi.me) развојни API.
Пружа брз и скриптован приступ четири главна ресурса Omi-ја:
успомене, разговори, ставки радње и циљеви.

* **PyPI:** [pypi.org/project/omi-cli](https://pypi.org/project/omi-cli/)
* **Документација:** [docs.omi.me/doc/developer/cli/introduction](https://docs.omi.me/doc/developer/cli/introduction)
* **Изворни код:** [github.com/BasedHardware/omi/tree/main/sdks/python-cli](https://github.com/BasedHardware/omi/tree/main/sdks/python-cli)

## 1. Инсталација

Препоручена метода је `pipx`: инсталира алат у изоловано окружење,
тако да његове зависности не улазе у сукоб са вашим пројектима.

```bash
# препоручено: инсталација преко pipx
pipx install omi-cli

# или преко pip
pip install omi-cli
```

> **Важно: име пакета и име команде су различити.**
> * Пакет који се инсталира је **`omi-cli`** (одвојени пакет `omi` је други, неповезан пројекат).
> * Након инсталације извршава се команда **`omi`**.

Проверите да све ради:

```bash
omi --version
omi --help
```

## 2. Аутентификација

`omi-cli` подржава два начина пријављивања.

| Метода | Погодна за | Команда |
| :--- | :--- | :--- |
| **Развојни кључ (`omi_dev_*`)** | CI/CD, скрипте, AI агенти | `omi auth login --api-key ...` или променљива окружења |
| **Пријава преко прегледача (Google/Apple)** | Рад на сопственом рачунару | `omi auth login --browser` |

### Интерактивна пријава

Покрените без опција и питаће коју методу желите.

```bash
omi auth login
# 1) Browser — пријава преко Google или Apple (за људе)
# 2) API key — налепите развојни кључ са app.omi.me (за агенте/CI)
```

Ако изаберете кључ, унос се сакрива па кључ не остаје у историји терминала.

### Директна пријава преко прегледача

```bash
omi auth login --browser
```

### Пријава развојним кључем

Кључ добијате на [app.omi.me](https://app.omi.me) под **Developer → API Keys**.

```bash
# сачувајте кључ у конфигурацију
omi auth login --api-key omi_dev_...

# или га проследите кроз окружење — боље за CI/CD и контејнере
export OMI_API_KEY=omi_dev_...
```

Променљива окружења `OMI_API_KEY` користи се када у активном профилу није сачуван
кључ, па у контејнеру ништа не мора да се пише на диск. Ако профил већ има кључ,
он има приоритет над променљивом окружења.

### Проверите приступ

Две команде одговарају на различита питања и не треба их мешати:

* `omi auth status` — шта је сачувано **локално**: профил, маскирани кључ, датум истека.
  Ради без мреже.
* `omi auth whoami` — захтев **ка Omi серверу**: проверава да ли је кључ заиста прихваћен.
  Захтева мрежу.

```bash
omi auth status    # локална провера, ван мреже
omi auth whoami    # провера на серверу
```

Обновите токен који истиче без поновне пријаве — ова команда важи **само за сесије
преко прегледача/OAuth**. За профил аутентификован API кључем (`omi_dev_*`),
`omi auth refresh` не успева уз грешку у коришћењу (код 1): нема токена за обнову —
промените кључ у Omi веб апликацији ако је потребно:

```bash
omi auth refresh
```

Одјава:

```bash
omi auth logout
```

## 3. Основне команде

### Успомене (memories)

Чињенице и знања које је систем запамтио о вама.

```bash
# листа успомена
omi memory list

# направите нову
omi memory create "Корисник преферира тамну тему" --category lifestyle

# погледајте одређену
omi memory get <MEMORY_ID>
```

### Разговори (conversations)

Историја гласа и текста са уређаја или апликације.

```bash
# 5 најновијих разговора
omi conversation list --limit 5

# цео разговор са транскриптом
omi conversation get <CONVERSATION_ID> --include-transcript
```

### Ставке радње (action items)

Задаци које је Omi извукао из разговора.

```bash
# само отворене
omi action-item list --open

# означите као завршену
omi action-item complete <ACTION_ITEM_ID>
```

### Циљеви (goals)

```bash
# листа циљева
omi goal list

# забележите нову вредност напретка (потребна су ОБА аргумента: циљ и вредност)
omi goal progress <GOAL_ID> 25

# историја промена
omi goal history <GOAL_ID>
```

## Питање природним језиком (`ask`)

Посебна команда највишег нивоа: узима питање на природном језику,
а одговор се гради од ваших разговора.

```bash
omi ask "шта сам одлучио о селидби"
omi --json ask "које сам ставке радње обећао да завршим ове недеље"
```

## 4. JSON и скрипте (`--json`)

`omi-cli` може да изда JSON читљив машини. Опција `--json` је **глобална**
и мора бити постављена **пре** подкоманде.

```bash
# успомене: издвојите id, текст и категорију
omi --json memory list | jq '.[] | {id, content, category}'

# наслови скоријих разговора
omi --json conversation list --limit 5 | jq '.[] | {id, title: .structured.title, started_at}'

# отворене ставке радње
omi --json action-item list --open | jq '.'
```

> **Честа грешка.** `--json` долази пре подкоманде, не после.
> * Исправно: `omi --json memory list`
> * Погрешно: `omi memory list --json`

У режиму `--json` нестају поруке о напретку и спинери за људе —
stdout садржи само један валидан JSON документ. Грешке иду на stderr
у облику `{"error": "...", "detail": "..."}`.

## 5. Излазни кодови

Стабилни излазни кодови за гранање у скриптама.

| Код | Значење |
| :--- | :--- |
| `0` | Успех |
| `1` | Грешка у коришћењу (погрешна заставица, недостаје обавезни аргумент) |
| `2` | Аутентификација није успела — потребна пријава |
| `3` | Грешка сервера/мреже |
| `4` | Ограничење брзине — покушајте поново касније |
| `5` | Ресурс није пронађен |

```bash
if ! omi memory get "$MEMO_ID" --json > /tmp/m.json; then
  code=$?
  case $code in
    2) omi auth login --browser ;;
    5) echo "та успомена не постоји" ;;
    *) echo "грешка $code" ;;
  esac
fi
```

## 6. Профили и конфигурација

Ако имате више налога или окружења, раздвојите их профилима.
Подешавања се чувају у `~/.omi/config.toml`.

```bash
# пријава у лични профил
omi --profile personal auth login

# пријава у пословни профил
omi --profile work auth login

# извршите команду у одређеном профилу
omi --profile work memory list
```

Профил који се користи одређује се овим редоследом: опција `--profile` (или `-p`)
има приоритет над свим; затим променљива окружења `OMI_PROFILE`; затим активни
профил у `~/.omi/config.toml`; и на крају профил `default` као резерва.

Погледајте и измените саму конфигурацију:

```bash
# шта је тренутно подешено
omi config show

# где је конфигурациона датотека
omi config path

# промените вредност
omi config set api_base https://api.omi.me
```
