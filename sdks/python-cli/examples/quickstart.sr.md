# Почетак рада са omi-cli

Овај водич приказује првих неколико команди на српском језику. Називи команди и системске поруке остају на енглеском језику. Овде наведени примери читања неће изменити ваша сећања, разговоре, листе задатака или циљеве.

## Инсталација програма

Захтеви: Python 3.10 или новија верзија и Omi налог.

> Напомена: Назив пакета на PyPI је **`omi-cli`**, док је наредба која се покреће након инсталације **`omi`**. На PyPI постоји засебан, неповезан пакет под називом `omi` — немојте инсталирати тај пакет.

Ако је инсталиран `pipx`:

```sh
pipx install omi-cli
omi --help
```

Алтернативно, у активном Python виртуелном окружењу:

```sh
python -m pip install omi-cli
omi --help
```

Ако терминал не пронађе `omi`, проверите да ли је виртуелно окружење активно или се извршни директоријум `pipx` алата налази у вашој `PATH` променљивој.

## Повежите свој налог

Покрените интерактивног помоћника:

```sh
omi auth login
```

Изаберите пријаву путем веб прегледача, или изаберите опцију за унос Omi развојног API кључа. Интерактивни унос сакрива кључ; немојте куцати кључ у команди која остаје забележена у историји терминала.

За директну пријаву путем прегледача:

```sh
omi auth login --browser
```

Пријаву обавите на истом рачунару на којем ради терминал, јер се аутентификација враћа на локалну адресу. Пратите упутства приказана на екрану.

Након тога, проверите конфигурацију и API приступ:

```sh
omi auth status
omi auth whoami
```

`status` приказује локални статус и сакрива тајне податке, али их не проверава са сервером. `whoami` шаље ауторизовани захтев; успех значи да акредитиви исправно функционишу.

Конфигурација се подразумевано чува у `~/.omi/config.toml`. Немојте делити ову датотеку јер садржи ваше поверљиве податке.

## Прегледајте своје податке

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Празна листа може значити само да нема ставки које одговарају упиту. Да бисте сазнали филтере неке команде, погледајте помоћ:

```sh
omi memory list --help
omi action-item list --help
```

## Преузимање JSON података и пагинација

Поставите глобалну опцију `--json` **пре** групе команди:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Прва команда тражи првих 25 записа; друга тражи следећих 25. Стога једна страница није комплетна резервна копија. JSON излаз задржава пуне идентификаторе, док их табеле могу скратити.

Да бисте сачували страницу у датотеку:

```sh
omi --json memory list --limit 25 --offset 0 > secanja-strana-1.json
```

Ово преусмеравање креира или замењује локалну датотеку. Пре коришћења садржаја, проверите да ли је наредба успешно извршена. Грешке се исписују на stderr; празна датотека није доказ одсуства података. Извезена датотека може садржати личне податке: чувајте је поверљивом.

## Одјава (Log out)

```sh
omi auth logout
```

Ова наредба уклања локално сачуване акредитиве. За опозив кључа на серверу, користите управљање развојним кључевима на вашем налогу.

За остале команде и напредне опције, погледајте главни водич на енглеском:
[../README.md](../README.md) и `omi --help`.
