# omi-cli Водич за брзи почетак (Српски)

> Практични водич за интеракцију са Omi из терминала. Погодан и за људе и за AI агенте.

`omi-cli` је званични интерфејс командне линије за интеракцију са развојним API-јима [Omi](https://omi.me). Ефикасно и скриптабилно обрађује четири основна ресурса Omi — **сећања, разговоре, акционе ставке и циљеве**.

* **PyPI:** [pypi.org/project/omi-cli](https://pypi.org/project/omi-cli/)
* **Званична документација:** [docs.omi.me/doc/developer/cli/introduction](https://docs.omi.me/doc/developer/cli/introduction)
* **Изворни код:** [github.com/BasedHardware/omi/tree/main/sdks/python-cli](https://github.com/BasedHardware/omi/tree/main/sdks/python-cli)

---

## 1. Инсталација

Препоручена метода инсталације користи `pipx` за изолацију зависности.

```bash
# Препоручено: инсталирајте помоћу pipx
pipx install omi-cli

# Алтернативно: користите pip
pip install omi-cli
```

> **Важно: разлика између имена пакета и имена команде**
> * Инсталирани Python пакет се зове **`omi-cli`** (самостални пакет `omi` је други, неповезани пакет).
> * Извршна команда у терминалу након инсталације се зове **`omi`**.

Након инсталације проверите верзију и помоћ.

```bash
omi --version
omi --help
```

## 2. Аутентикација

`omi-cli` подржава два начина аутентикације.

| Начин | Препоручена употреба | Пример команде |
| :--- | :--- | :--- |
| **Развојни API кључ (`omi_dev_*`)** | CI/CD, аутоматски скриптови, AI агенти | `omi auth login --api-key ...` или променљива окружења |
| **OAuth у прегледачу (Google/Apple)** | Развојни PC / лаптоп | `omi auth login --browser` |

### Интерактивна пријава
Без опција, биће вам затражено да изаберете између пријаве у прегледачу и уноса API кључа.

```bash
omi auth login
# 1) Прегледач — пријавите се са Google или Apple налогом (за људе)
# 2) API кључ — налепите развојни кључ са app.omi.me (за агенте/CI)
```

### Директна пријава путем прегледача
```bash
omi auth login --browser
```

### Коришћење API кључа
Добијте развојни кључ из **Developer → API Keys** на [app.omi.me](https://app.omi.me), а затим га подесите.

```bash
# Подесите помоћу команде
omi auth login --api-key omi_dev_...

# Или путем променљиве окружења (идеално за CI/CD или контејнере)
export OMI_API_KEY=omi_dev_...
```

### Провера статуса аутентикације
* `omi auth status`: приказује локални профил, маскирани токен и датум истека (ради офлајн).
* `omi auth whoami`: шаље прави захтев за аутентикацију Omi серверу (потребна је мрежна веза).

```bash
omi auth status
omi auth whoami
```

За одјаву:
```bash
omi auth logout
```

## 3. Основна употреба

Можете да набројите и управљате са четири основна ресурса Omi.

### Сећања (Memories)
Управљајте чињеницама и знањем које је систем научио.

```bash
# Наведите сва сећања
omi memory list

# Креирајте ново сећање
omi memory create "Корисник преферира тамни режим" --category lifestyle

# Прикажите детаље одређеног сећања
omi memory get <MEMORY_ID>
```

### Разговори (Conversations)
Историја звука или текста разговора забележених уређајем за ношење или апликацијом.

```bash
# Преузмите последњих 5 разговора
omi conversation list --limit 5

# Прикажите детаље разговора и транскрипт
omi conversation get <CONVERSATION_ID> --include-transcript
```

### Акционе ставке (Action Items)
Задаци или пратеће ставке аутоматски извучене из разговора.

```bash
# Наведите само отворене акционе ставке
omi action-item list --open

# Означите акциону ставку као завршену
omi action-item complete <ACTION_ITEM_ID>
```

### Циљеви (Goals)
Управљајте циљевима чији се напредак прати.

```bash
# Наведите све циљеве
omi goal list
```

## 4. Обрада скриптова и JSON излаз (`--json`)

`omi-cli` изворно подржава JSON излаз. У комбинацији са `jq` или Python скриптовима, **глобална опција** `--json` мора бити постављена пре подкоманде.

```bash
# Преузмите листу сећања као JSON и извуците ID и садржај
omi --json memory list | jq '.[] | {id, content, category}'

# Преузмите наслове последњих 5 разговора
omi --json conversation list --limit 5 | jq '.[] | {id, title: .structured.title, started_at}'

# Наведите отворене акционе ставке
omi --json action-item list --open | jq '.[] | {id, description, due_at}'

# Наведите циљеве
omi --json goal list | jq '.[] | {id, title, current: .current_value, target: .target_value}'
```

## 5. Дијагностика сесије

Користите ове две команде у пару за брзо решавање проблема.

```bash
# 1) Прво проверите локалну конфигурацију
omi auth status

# 2) Потврдите са Omi сервером
omi auth whoami

# 3) Ако је потребно, поново покрените пријаву
omi auth login
```

---

## 6. Најбоље праксе

* **Користите `--json` у скриптама:** Избегавајте парсирање слободног текста; увек се ослањајте на структурирани JSON излаз.
* **Изолујте окружења помоћу `pipx`:** Избегава конфликте зависности са другим Python пакетима.
* **Не делите API кључеве:** Кључеви `omi_dev_*` дају потпун приступ налогу — чувајте их у менаџеру тајни или у променљивим окружења.
* **Одјавите се са дељених уређаја:** Користите `omi auth logout` након сесија на дељеним машинама.

## 7. Решавање проблема

| Симптом | Могући узрок | Решење |
| :--- | :--- | :--- |
| `command not found: omi` | PATH не садржи pipx bin директоријум | Покрените `pipx ensurepath` и поново покрените терминал |
| `401 Unauthorized` | API кључ је неважећи или је истекао | Генеришите нови кључ на app.omi.me и ажурирајте |
| `connection refused` | Нема мрежног приступа Omi серверу | Проверите интернет конекцију и подешавања проксија |
| `permission denied` на конфигурационим датотекама | Директоријум конфигурације се не може писати | Проверите дозволе за `~/.omi/config.toml` |
