# Брзи почетак са omi-cli

Овај водич објашњава основне команде на српском. Имена команди и поруке
програма остају на енглеском. Пример доле не мењају ваше успомене, разговоре,
ставке акција ни циљеве.

## Инсталација програма

Захтеви: Python 3.10 или новији и Omi налог.

Ако је `pipx` инсталиран:

```sh
pipx install omi-cli
omi --help
```

Као алтернатива, инсталирајте у активирано Python виртуелно окружење:

```sh
python -m pip install omi-cli
omi --help
```

Ако терминал не налази `omi`, проверите да је виртуелно окружење активно или
да је директоријум у који `pipx` инсталира извршне датотеке у `PATH`.

## Повезивање налога

Покрените интерактивни водич:

```sh
omi auth login
```

Изаберите пријаву кроз браузер или налепите Omi developer API кључ.
Интерактивни унос сакрива кључ; не уписујте га у команде које се памте у
историји терминала.

За директно коришћење браузера:

```sh
omi auth login --browser
```

Пријавите се на истом рачунару на ком је терминал, јер аутентикација користи
локалну callback адресу. Пратите упутства на екрану.

После пријаве проверите конфигурацију и приступ API-ју:

```sh
omi auth status
omi auth whoami
```

`status` приказује локално стање и маскира тајне, али не проверава њихову
важност на серверу. `whoami` шаље аутентификован захтев; ако успе, ваши
акредитиви раде — без приказивања вашег имена.

Конфигурација се подразумевано чува у `~/.omi/config.toml`. Не делите ову
датотеку јер може садржати акредитиве.

## Читање ваших података

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Празна листа може значити да ниједна ставка не одговара филтеру. Опције сваке
команде погледајте у помоћи:

```sh
omi memory list --help
omi action-item list --help
```

## JSON излаз и прелазак кроз странице

Глобалну опцију `--json` ставите **пре** групе команди:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Прва команда тражи првих 25 успомена, друга следећих 25. Једна страница није
потпуна резервна копија. JSON излаз чува целе идентификаторе, док табела може
скратити ID-еве ради приказа.

За чување странице у датотеку:

```sh
omi --json memory list --limit 25 --offset 0 > memory-stranica-1.json
```

Преусмеравање прави или преписује локалну датотеку. Пре коришћења садржаја
проверите да се команда успешно завршила. Грешке иду на stderr; празна датотека
не доказује да нема података. Извезена датотека може садржати личне податке —
чувајте је приватно.

## Коришћење профила

Стање се чува у `~/.omi/config.toml` (може се променити преко `$OMI_CONFIG`).
Сваки профил има сопствени начин аутентикације и адресу API-ја. Промена
профила — преко `--profile`:

```sh
omi config profile use посао
omi auth login
omi --profile приватни memory list
```

Честе команде конфигурације:

```sh
omi config show
omi config path
omi config profile list
```

## Излазни кодови

Ови излазни кодови су стабилни и корисни у скриптама и агентима:

| Код | Значење | Пример ситуације |
| ---: | --- | --- |
| 0 | успех | Команда завршена |
| 1 | грешка у употреби | Погрешна заставица, недостаје аргумент или неуспела валидација |
| 2 | грешка аутентикације | Нема акредитива, токен истекао или недостају дозволе |
| 3 | грешка сервера | Сервер 5xx или неуспешна веза |
| 4 | ограничење учесталости | Сервер вратио HTTP 429 |
| 5 | није пронађено | Сервер вратио HTTP 404 |

## Одјава

```sh
omi auth logout
```

Уклања локално сачуване акредитиве. За опозив кључа на серверу користите
управљање developer кључевима на свом налогу.

За више команди и опција погледајте [главни README на енглеском](../README.md)
и покрените `omi --help`.
