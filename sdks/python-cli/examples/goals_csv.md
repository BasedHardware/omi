# Export Omi Goals and Milestone Progress to CSV

Use this recipe to analyze and report on your tracked goals and habit milestones in a spreadsheet: it converts
one or more `goal list` JSON exports into a spreadsheet-safe CSV file suitable for **Microsoft Excel**,
**Google Sheets**, **Apple Numbers**, or **pandas** data pipelines. It operates completely offline, makes zero
external network requests, and protects against CSV formula injection.

---

## Prerequisites

Ensure you have the `omi` CLI installed and authenticated:

```sh
pip install omi-cli
omi auth login
```

Export your tracked goals (including inactive or achieved goals):

```sh
omi --json goal list --limit 100 --include-inactive > goals.json
```

Verify that the export file was populated before converting. If you have multiple export batches or backup
files, provide them together (e.g. `g1.json g2.json`); the converter deduplicates goals by their unique ID.

---

## Quickstart

### 1. Direct Pipeline Stream (Stdout)

Generate CSV data directly from the CLI output stream:

```sh
omi --json goal list --limit 100 --include-inactive | python goals_to_csv.py -
```

### 2. Export to a Dedicated CSV File

Generate a standalone CSV file for spreadsheet analysis:

```sh
python goals_to_csv.py goals.json -o goals.csv
```

### 3. Microsoft Excel Compatibility (UTF-8 BOM)

Prepend a UTF-8 Byte Order Mark (`\xef\xbb\xbf`) so Excel on Windows automatically detects character encoding:

```sh
python goals_to_csv.py goals.json -o goals.csv --excel-bom
```

### 4. Filter by Goal Status

Export only currently active goals, or filter to completed/achieved milestones:

```sh
python goals_to_csv.py goals.json --status active -o active_goals.csv
```

### 5. Filter by Goal Type

Filter by metric category (`numeric`, `scale`, `boolean`, or `qualitative`):

```sh
python goals_to_csv.py goals.json --type numeric -o numeric_goals.csv
```

## CLI Options

| Option | Flag | Description | Default |
| :--- | :--- | :--- | :--- |
| `inputs` | Positional | One or more JSON export files, or `-` for stdin | *(Required)* |
| `--output` | `-o` | Destination CSV file path | `stdout` |
| `--status` | `--status` | Filter status: `all`, `active`, `completed`, `inactive` | `all` |
| `--type` | `--type` | Filter goal type: `all`, `numeric`, `scale`, `boolean`, `qualitative` | `all` |
| `--excel-bom` | `--excel-bom`| Prepend UTF-8 BOM for Microsoft Excel on Windows | `False` |
| `--overwrite` | `--overwrite` | Allow overwriting existing destination files | `False` |

## Formula Injection Defense

Spreadsheet programs (Microsoft Excel, LibreOffice Calc, Google Sheets) interpret cells starting with `=`, `+`,
`-`, `@`, `\t`, or `\r` as executable formula syntax or Dynamic Data Exchange (DDE) commands. To prevent
malicious formula execution or accidental calculation syntax errors from user-defined titles or units, the
converter automatically prefixes affected text cells with a leading single quote (`'`), neutralizing formula
execution while leaving pure numeric data intact.

---

## Design Principles

- **Zero Third-Party Dependencies**: Pure Python 3.10+ standard library (`csv`, `io`, `json`, `datetime`, `pathlib`).
- **Spreadsheet Security**: Strict formula injection neutralization across all user-generated text fields.
- **Safe POSIX File Permissions**: Creates destination files using standard umask modes (`0644`).
- **Atomic File Operations**: Uses temporary file replacement when `--overwrite` is specified.
- **Piped Stream Hygiene**: Native `BrokenPipeError` signal handling for commands like `| head`.
