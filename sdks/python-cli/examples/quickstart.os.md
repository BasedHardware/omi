# omi-cli — ирон рарстог хъавдан

> Omi-имæ терминалæй куыст кæныны практикон хъавдан. Адæмæн æмæ AI-агенттæн.

`omi-cli` у [Omi](https://omi.me) разработчикты API-йы официалон командон хæттæн клиент.
Йæ фæрцы Omi-йы цыппар сæйраг ресурсмæ — фæлтæрæн, ныхæстæгæн, кусæгты æмæ нысæнттæн — тагъд æмæ скриптон адæймад бар дæтты.

* **PyPI:** [pypi.org/project/omi-cli](https://pypi.org/project/omi-cli/)
* **Документаци:** [docs.omi.me/doc/developer/cli/introduction](https://docs.omi.me/doc/developer/cli/introduction)
* **Рæвда код:** [github.com/BasedHardware/omi/tree/main/sdks/python-cli](https://github.com/BasedHardware/omi/tree/main/sdks/python-cli)

## 1. Æркæсын

Рекомендацигонд метод у `pipx`: уый инструменты дисциплинæй иунæг мидæгты æркæсы,
цæмæй йæ зависимостытæ дæ проекттимæ нæ æмбæлы.

```bash
# рекомендаци: pipx-æй æркæс
pipx install omi-cli

# кæнæ pip-æй
pip install omi-cli
```

> **Ахсджиаг: пакеты ном æмæ командæйы ном æндæр сты.**
> * Æркæст пакет у **`omi-cli`** (æндæр пакет `omi` у æндæр, æнæбастæн проект).
> * Æркæсты фæстæ кæсын командæ у **`omi`**.

Æмбæрзт кæн, æмæ æппæт дзуары:

```bash
omi --version
omi --help
```

## 2. Авторизаци

`omi-cli` дыууæ адæймад рагъы руаджы.

| Метод | Уæлмæ | Командæ |
| :--- | :--- | :--- |
| **Разработчикты ключ (`omi_dev_*`)** | CI/CD, скрипттæ, AI-агенттæ | `omi auth login --api-key ...` кæнæ мидæгты переменной |
| **Браузеры авторизаци (Google/Apple)** | Дæ компьютерыл куыст | `omi auth login --browser` |

### Интерактивон авторизаци

Куыскæн æнæ опцитæ — уый фæстæдæр фæстындз кæй методы фæрцы бацын кæнын.

```bash
omi auth login
# 1) Browser — Google кæнæ Apple-æй бац (адæмæн)
# 2) API key — app.omi.me-æй разработчикты ключ дæтт (агенттæн/CI)
```

Кæд ключы равзардзæ, уæд вводы цаут фæстæ æркæсдзæн, цæмæй ключ терминалы историйы нæ уа.

### Браузерæй равзæрст бац

```bash
omi auth login --browser
```

### Разработчикты ключы бац

Ключы ратт [app.omi.me](https://app.omi.me)-ыл **Developer → API Keys**-ы.

```bash
# ключы конфигурацийы æмбæрзт
omi auth login --api-key omi_dev_...

# кæнæ мидæгты фæрцы рад — CI/CD æмæ контейнертæн хуыздæр
export OMI_API_KEY=omi_dev_...
```

Мидæгты переменной `OMI_API_KEY` фæрцы кæд активон профилы никæй ключ æмбæрзт нæ у,
уæд æй фæрцы кæны, цæмæй контейнерс дискмæ ницы фыссын уæй. Кæд профилы разæй ключ ис,
уæд уый ключ мидæгты переменойæй размæ у.

### Адæймады æмбæрзт кæн

Дыууæ командæйы æндæр фæрстытæн хъуамæ æркад — æнæ æмбæрзтæг:

* `omi auth status` — цы у **бынæй** æмбæрзт: профиль, фæстæ æркæст ключ, цæттæдзинады датæ.
  Торфы æнæ дзуары.
* `omi auth whoami` — **Omi-сервермæ** домæн: æмбæрзт кæны, кæй ключ сæ цынд æй равзарынц.
  Торф хъæуы.

```bash
omi auth status    # бынæй æмбæрзт, оффлайн
omi auth whoami    # серверон æмбæрзт
```

Цæттæдзинаг токены ногæй ссæй, нæ бацæй — ацы командæ æрмæст **браузер/OAuth-сесситæн**.
API-ключы (`omi_dev_*`) авторизæт профилæн `omi auth refresh` фæрцы кæныны рæвыдæн
(код 1) фæстæ уæй: токен нæй, цы ног кæны — хъæуæ, Omi-вебæппы ключ аив:

```bash
omi auth refresh
```

Расуын:

```bash
omi auth logout
```

## 3. Бындурон командæтæ

### Фæлтæрæн (memories)

Факттæ æмæ зонинæдтæ, кæдæр æмбæрзт у дæ фæдæг.

```bash
# фæлтæрæнты номхыгъд
omi memory list

# ногæй скæн
omi memory create "Пайдагæнæг æрхъуылын дæрæг темæ уарзы" --category lifestyle

# исæрæг æй равзар
omi memory get <MEMORY_ID>
```

### Ныхæстæгæ (conversations)

Девайс кæнæ æппликацийы хъæлæс æмæ фæснам истори.

```bash
# фæстаг 5 ныхæстæг
omi conversation list --limit 5

# æгъдæудæг ныхæстæг транскрипцимæ
omi conversation get <CONVERSATION_ID> --include-transcript
```

### Кусæгтæ (action items)

Omi-ы ныхæстæгæй скæнд куыстытæ.

```bash
# æрмæст гомæнтæ
omi action-item list --open

# æмбæрзт кæн куыд æндæргонд
omi action-item complete <ACTION_ITEM_ID>
```

### Нысæнттæ (goals)

```bash
# нысæнтты номхыгъд
omi goal list

# ног прогрессы нымæц фысс (хъæуы ДЫУУÆ аргументы: нысæн æмæ нымæц)
omi goal progress <GOAL_ID> 25

# ивдзинады истори
omi goal history <GOAL_ID>
```

## 4. JSON æмæ скрипттæ (`--json`)

`omi-cli` машинæйæ рæвда JSON фæрцы кæнын æй уæлдзæ. `--json` опци **глобалон**
у æмæ уый субкомандæйæ **размæ** æвдисын хъæуы.

```bash
# фæлтæрæнтæ: id, фæснам æмæ категори ратт
omi --json memory list | jq '.[] | {id, content, category}'

# фæстаг ныхæстæгты сæргæндтæ
omi --json conversation list --limit 5 | jq '.[] | {id, title: .structured.title, started_at}'

# гомæн кусæгтæ
omi --json action-item list --open | jq '.'
```

> **Æхсæн рæвыд.** `--json` субкомандæйæ размæ цæуын æй хъæуы, нæ фæстæ.
> * Æцæг: `omi --json memory list`
> * Рæвыд: `omi memory list --json`

`--json`-режимы адæмæн прогрессы хъусинæгтæ æмæ спиннертæ фæстæ уынц —
stdout æрмæст иу æцæг JSON-документ дæтты. Рæвыдтæ stderr-мæ
`{"error": "...", "detail": "..."}` формы цæуынц.

## 5. Расуыны кодтæ

Скриптты æркæсæн стабилон расуыны кодтæ.

| Код | Æмæнæ |
| :--- | :--- |
| `0` | Цынд |
| `1` | Фæрцы кæныны рæвыд (рæвыд флаг, хъæугæ аргумент нæй) |
| `2` | Авторизаци фæстæ — бац хъæуы |
| `3` | Сервер/торфы рæвыд |
| `4` | Рæстæджы равзар — фæстæдæр ногæй фæст |
| `5` | Ресурс нæ ратт |

```bash
if ! omi memory get "$MEMO_ID" --json > /tmp/m.json; then
  code=$?
  case $code in
    2) omi auth login --browser ;;
    5) echo "уыдон фæлтæрæн нæй" ;;
    *) echo "рæвыд $code" ;;
  esac
fi
```

## 6. Профилтæ æмæ конфигураци

Кæд дæ бирæ аккаунт кæнæ мидæг ис, профилтæй æрхæс.
Æркæстытæ `~/.omi/config.toml`-ы æмбæрзт уынц.

```bash
# персоналон профилмæ бац
omi --profile personal auth login

# куысты профилмæ бац
omi --profile work auth login

# исæрæг профилы командæ кæс
omi --profile work memory list
```

Фæрцы кæст профиль ацы равзæрстæй æмбæрзт у: `--profile` опци (кæнæ `-p`)
æппæтæй размæ у; фæстæ `OMI_PROFILE` мидæгты переменной; фæстæ `~/.omi/config.toml`-ы
активон профиль; æмæ фæстæ `default` профиль резервæй.

Æмбæрзт кæн æмæ дæ конфигураци сæхæдæг ив:

```bash
# цы ныртæккæ æркæст у
omi config show

# конфигурацийы файл цæм и
omi config path

# нымæц ив
omi config set api_base https://api.omi.me
```
