# omi-cli-имæ ænхъом райдай

Ацы гæрæн æвæрдæй базонæг командæтæ Iron æвзагыл зæгъы. Командæтæн нæмттæ
æмæ программæйæн фæстæгтæ англис æвзагыл æрцæуынц. Дæлдæр æвдисæн командæтæ
дæ æнцоңдæтæн, ныхастæн, кусæн элементтæн кæнæ нысæнттæн фæивыд нæ кæнынц.

## Программæ æрлæууынын

Хъæугæ: Python 3.10 кæнæ ногдæр æмæ Omi-аккаунт.

`pipx` æрлæууынгæйæ уый уæв:

```sh
pipx install omi-cli
omi --help
```

Кæнæ æрлæууй активгонд Python виртуалон сфæлмæнон уæлей:

```sh
python -m pip install omi-cli
omi --help
```

Терминал `omi` куы нæ ссæуа, фæлдæс у виртуалон сфæлмæнон активон у, кæнæ
`pipx` executables æрæвæрæ каталог `PATH`-мæ ис.

## Дæ аккаунт бандæ æрлæууынын

Интерактивон гæрæн фæцæй:

```sh
omi auth login
```

Фæлварæн браузер æхсæдæр логин кæнæ æрлæуу Omi гæнæнг API-ключ.
Интерактивон баххæст ключ æмбæхсы; æрцайы командæтæн æй ма ныффысс,
кæддæры терминалон историйыл хæссы.

Браузер рæстæгылæн архайын:

```sh
omi auth login --browser
```

Уый терминалимæ иу компьютерыл логин кæн, кæнцыл автентификаци локалон
callback адрис архайы. Экраныл æвдисæйнаг инструкцитæ фæстæ фæхæс.

Логин куыд уыд, сæхæрæн конфигураци æмæ API-бабæхт æхсызгон кæн:

```sh
omi auth status
omi auth whoami
```

`status` локалон уæвæн уынæг æмæ æмбæхсы тайаг, фæлæ серверыл сæ бæрæггæнæн
нæ æхсызгон кæны. `whoami` автентификацигонд дæттын æрбамбæхсы; сæйраг æрцыд,
дæ credentials кусынц — дæ ном æвдисæйнаг нæ.

Конфигураци æмбæхстыгыл `~/.omi/config.toml`-мæ хæссы. Ацы файл ма бæрæг
кæн — уый credentials хъуамæ ис.

## Дæ рарæфæн æркæсын

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Афтæмæнæй список зæгъы мæнæ æй филтримæ айсай æрцыд. Алы командæн дæр
опцитæ æхсæдæр ныссехсæдæр:

```sh
omi memory list --help
omi action-item list --help
```

## JSON райсын æмæ фарстæ æрбахæццæ

Глобалон `--json` опци командæтæн группæйы **размæ** æрæвæр:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Фыццаг командæ фыццаг 25 æнцоңдæтæ домы; дыккæг — фæстæмæвæг 25. Иу фарс
нæ у æппæт резерв. JSON-баххæст æппæт ID-æтæ хæсы, фæлæ таблицæ æвдисæйнаг
ID-æтæ цъхъхъ кæны.

Фарс файлмæ хæсын:

```sh
omi --json memory list --limit 25 --offset 0 > memory-fars-1.json
```

Редирект локалон файл сæвæры кæнæ фæивы. Мидис æхсæдæр архайынæн фыццаг
фæлдæс у командæ сæфæн сæхæрæн фæци. Рæдыдæтæ stderr-мæ фыссынц; афтæмæнæй
файл рарæфæн нæ у æвдисæйнаг. Экспортон файл персоналон информаци хъуамæ
æмбæлæ — æй рæстæгылæн æмбæхс.

## Профилтæ архайын

State `~/.omi/config.toml`-мæ хæссы (`$OMI_CONFIG`-æй ивдæргонд). Алы профил
æхсæдæр автентификаци метод æмæ API-адрисæн ис. `--profile`-æй ив:

```sh
omi config profile use kus
omi auth login
omi --profile persian memory list
```

Æппæт конфигурацийон командæтæ:

```sh
omi config show
omi config path
omi config profile list
```

## Æрбалæг кодтæ

Ацы æрбалæг кодтæ стабилон сты æмæ скрипттæ кæнæ агенттæн пайда сты:

| Код | Мæнæ | Зæгъæн уæвæн |
| ---: | --- | --- |
| 0 | сæйраг | Командæ фæци |
| 1 | архайы радыд | Рæдыд flag, æрæхсай аргумент кæнæ фæти validation |
| 2 | автентификацийы радыд | credentials нæй, token æмбæхст кæнæ бар нæ фæу |
| 3 | серверон радыд | Сервер 5xx кæнæ бамбæхс фæти |
| 4 | уæвæн лимит | Сервер HTTP 429 æрæмбæхсы |
| 5 | нæ ссæугæ | Сервер HTTP 404 æрæмбæхсы |

## Логаут

```sh
omi auth logout
```

Локалон æмбæхст credentials бахиуын кæны. Серверыл key рацыдæр кæнынæн, дæ
аккаунты developer key идарæг архай.

Фылдæр командæтæ æмæ опцитæ [англис сæйраг README](../README.md) æмæ `omi
--help` фæцæй.
