# omi-cli баййафын

Ацы хъуыдыхæдтæ æвдисынц omi-cli-ы фыццаг командæтæ ирон æвзагыл. Командæты нæмттæ æмæ программæйы фыстытæ баззайынц англисаг æвзагыл. Ацы æзмæлд мысылæнтæ дæ æнусбардзинæдтæ (memories), дзурдзытæ (conversations), архайдты иууæлтæ (action items) кæнæ нысантæ (goals) нæ ивдзысты.

## Байгом кæнын

Дæхи хъæуы: Python 3.10 кæнæ ногæй, æмæ Omi аккаунт.

pipx байгом уæвæн:

```sh
pipx install omi-cli
omi --help
```

Кæнæ активацигонд Python виртуалон мохъы:

```sh
python -m pip install omi-cli
omi --help
```

Ныффыссæн: `omi` командæ гæнæн уа PATH-ы æддæмæ æрмæст нæ — фен, виртуалон мохъ активон уа, кæнæ pipx-ы папкæ `$PATH`-ы уа.

## Бахизын

Фыццагæй бахиз:

```sh
omi auth login
```

Браузерæй кæнæ Omi developer API æвзæрстæй бахизæн бон у. Æвзæрстæ æфст — терминалы историйæн нæ фыссæй.

Ацы компьютерæй браузерæй бахизын тыххæй:

```sh
omi auth login --browser
```

Терминалæй æрмæстгонд машинæтæн: авторизаци локалон адрисæй æххæыссы. Экранæйæ уалдзæгæй нымад кæн.

Айваргъонд конфигураци æмæ API æвзæрстæ фен:

```sh
omi auth status
omi auth whoami
```

`status` æвдисы локалон хабæрттæ, æмбæхсы секреттæ, æмæ серверæн нæ æрбафсидзæн. `whoami` рарвысы аутентификацигонд запрос; кæд æххæыссы, уæд дæ credentials æмбарзонд.

Конфигураци хæццæ у `~/.omi/config.toml`-ы. Ацы файл къухæй нæ ив — æвзæрстыты секреттæ йæхимæ ис.

## Æнусбардзинæдты æмæ дзурдзыты номылæг

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Номылæг ком уæвæн, уый æвдисы, æмæ ныртæккæ дæрæн ницы ис. Алы командæйы фильтртæ феныны тыххæй:

```sh
omi memory list --help
omi action-item list --help
```

## JSON æмæ экспорттæ

Глобалон `--json` опци хъуамæ æрцæуа командæты къорды РАЗÆЙ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Фыццаг командæ райсы фыццаг 25 æнусбардзинæдтæ; дыккаг — иннæ 25. JSON рахизы æххæст идентификатортæ ис, фæлæ таблицæйы æвдисæн сæ æфсымæр кæны.

Файлы схæццæ кæнын:

```sh
omi --json memory list --limit 25 --offset 0 > æнусбардзинæдтæ-фарс-1.json
```

Ацы redirect ног локалон файл саразы кæнæ зæрондæй фыссæй. Фыццаг командæйы рахиз фен. Рæдыдтæ цæуынц stderr-æн; ком файл нæ ныффыссы, æмæ даннойтæ нæй. Экспорты файлты æнцонæй хабæрттæ гæнæн æвæрд уа — сæ хъуамæ хæццæ кæнай.

## Рахизын

```sh
omi auth logout
```

Ацы командæ локалон credentials æфсайвæй. Серверæй саразгæ æвзæрстæтæ developer key management-ы бын ис.

Фылдæр: [англисаг хъуыдыхæдтæ](../README.md) æмæ `omi --help`.
