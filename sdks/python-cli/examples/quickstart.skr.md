# omi-cli سانگے تکھا راہنما (Quickstart)

ایہ راہنما سرائیکی (Saraiki) زبان وچ `omi-cli` دے مُڈھلے کمانڈاں دی وضاحت کریندا ہے۔ کمانڈ دے ناں اتے پروگرام دے سنیہے انگریزی وچ ہی رہسن۔ ایتھاں ڈتے ڳئے معائنہ دے مثالاں تہاݙیاں یاداں (memories)، گالھ مُہاڑ (conversations)، کرن آلے کم (action items)، یا مقاصد (goals) وچ کوئی تبدیلی نئیں کریندے۔

## پروگرام دی تنصیب (Installation)

لوڑیندیاں چیزاں: Python 3.10 یا نواں ورژن اتے ہک Omi کھاتہ۔

جے تہاݙے کول `pipx` انسٹال ہے:

```sh
pipx install omi-cli
omi --help
```

تساں اینکوں کہیں چالو Python ورچوئل ماحول (virtual environment) وچ وی انسٹال کر سڳدے ہو:

```sh
python -m pip install omi-cli
omi --help
```

جے ٹرمینل وچ `omi` کمانڈ نہ لبھے، تاں چیک کرو کہ ورچوئل ماحول چالو ہے یا `pipx` دی راہ تہاݙے `$PATH` وچ شامل ہے۔

## اپݨاں کھاتہ جوڑݨ (Authentication)

ڳالھ مُہاڑ آلا مددگار شروع کرو:

```sh
omi auth login
```

براؤزر دے ذریعے لاگ ان تھیوݨ یا اپݨی Omi developer API key درج کرݨ دا طریقہ چݨو۔ ایہ طریقہ کنجی کوں لُکا گھندے؛ ٹرمینل دی تاریخ وچ رہ ونڄݨ آلے کمانڈز وچ کنجی مت لکھو۔

سدھا براؤزر تے ونڄݨ سانگے:

```sh
omi auth login --browser
```

اوں کمپیوٹر تے لاگ ان تھیوو جتھاں ٹرمینل چلدا پئے: تصدیقی جواب مقامی پتہ استعمال کریندے۔ سکرین تے ݙتے ڳئے ہدایات تے عمل کرو۔

اون٘دے بعد، ترتیبات اتے API رسائی دی تصدیق کرو:

```sh
omi auth status
omi auth whoami
```

`status` مقامی حالت ݙکھیندا ہے اتے راز کوں لُکیندا ہے، پر سرور تے اون٘دی درستی دی جانچ نئیں کریندا۔ `whoami` ہک تصدیق شدہ درخواست بھیڄیندے؛ جے کامیاب تھیوے، تاں تہاݙا ناں ݙکھائے بغیر تصدیق کریندے کہ دستاویزاں کم کریندیاں پئین۔

ترتیبات عام طور تے `~/.omi/config.toml` وچ محفوظ ہوندیاں ہن۔ ایہ فائل کہیں نال سانجھی مت کرو: ایندے وچ خفیہ دستاویزاں تھی سڳدیاں ہن۔

## اپݨے ڈیٹا دا معائنہ کرو (Inspection)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

خالی فہرِست دا مطلب صرف ایہ تھی سڳدے کہ ڳول دے مطابق کجھ نئیں لبھیا۔ ہر کمانڈ وچ فلٹر لبھݨ سانگے مدد استعمال کرو:

```sh
omi memory list --help
omi action-item list --help
```

## JSON حاصل کرݨ اتے ورقہ گردانی (Pagination)

کمانڈ گروپ توں **پہلے** گلوبل `--json` آپشن لاؤ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

پہلا کمانڈ پہلیاں 25 یاداں منگسی؛ ݙوجھا کمانڈ اڳلیاں 25 یاداں منگسی۔ ہک ورقہ پورا بیک اپ نئیں ہوندا۔ JSON آؤٹ پٹ سارے شناختی کوڈ محفوظ رکھدے، جݙاں جو سکرین دا ٹیبل اینکوں ݙکھاوݨ سانگے چھوٹا کر سڳدے۔

ہک ورقہ فائل وچ محفوظ کرݨ سانگے:

```sh
omi --json memory list --limit 25 --offset 0 > یاداں-ورقہ-1.json
```

ایہ طریقہ مقامی فائل بݨیندا ہے یا بدلیندا ہے۔ اندر دی معلومات استعمال کرݨ توں پہلے چیک کرو کہ کمانڈ ٹھیک ختم تھیا۔ خرابیاں ایرر آؤٹ پٹ (stderr) وچ لکھیاں ویندین؛ خالی فائل دا مطلب ایہ نئیں کہ ڈیٹا نئیں ہے۔ کڈھئی ڳئی فائل وچ ذاتی معلومات تھی سڳدی ہے: اینکوں سنبھال کے رکھو۔

## کھاتے توں ٻاہر نکلݨ (Logout)

```sh
omi auth logout
```

ایہ کمانڈ مقامی طور تے محفوظ دستاویزاں ہٹا ݙیندے۔ سرور توں کنجی ختم کرݨ سانگے، اپݨے کھاتے وچ developer key دا انتظام استعمال کرو۔

ٻئے کمانڈز اتے ودھیک آپشنز سانگے، [انگریزی دا وݙا راہنما](../README.md) اتے `omi --help` ݙیکھو۔
