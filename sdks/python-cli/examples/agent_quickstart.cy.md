# Canllaw Cyflym Asiant (Welsh)

## Crynodeb
Mae'r canllaw hwn yn dangos sut i ddefnyddio **omi-cli** i redeg asiant AI gan ddefnyddio'r SDK Python CLI. Mae'r camau yn union yr un pethau a welir yn y fersiwn Saesneg, ond wedi'u cyfieithu i'r Gymraeg.

## Cynofodion
- **Python 3.9+** wedi'i osod.
- **omi-cli** wedi'i osod (gweler adran Gosod OMI CLI isod).
- Allwedd API OMI (gallwch gael un yn [https://omi.example.com/dashboard](https://omi.example.com/dashboard)).
