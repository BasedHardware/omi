# Export Omi Conversations to Markdown (Obsidian / Notion / Second Brain)

Use this recipe to export your Omi conversation transcripts and summaries into clean, structured Markdown files. The resulting files are pre-configured with YAML frontmatter, action item checklists, and timestamped transcripts, ready to drop directly into an **Obsidian** vault, **Notion**, **Logseq**, or a personal archive.

## Requirements

- Python 3.10+
- An authenticated `omi-cli` (`omi auth login`)

## Quickstart

### Option 1: Direct Pipeline via Stdin (Recommended)

Fetch your recent conversations (including full audio transcript segments) and export them directly into your Obsidian vault:

```bash
omi --json conversation list --include-transcript --limit 50 | python conversations_to_markdown.py - --output-dir ~/Documents/ObsidianVault/Omi/
```

### Option 2: Export from a Saved JSON File

1. Export conversations to a local JSON file:
   ```bash
   omi --json conversation list --include-transcript --limit 100 > conversations.json
   ```

2. Convert the JSON export into individual Markdown notes:
   ```bash
   python conversations_to_markdown.py conversations.json --output-dir ./notes/
   ```

### Option 3: Export a Single Specific Conversation

```bash
omi --json conversation get <CONVERSATION_ID> --include-transcript > conversation.json
python conversations_to_markdown.py conversation.json --output-dir ./notes/
```

## Output Structure

Each exported file is named using the pattern `YYYY-MM-DD_slugified_title_shortid.md` (e.g. `2026-09-13_ai_wearables_architecture_review_conva1b2.md`).

## Features

- **Obsidian / Notion Ready:** Includes YAML frontmatter with tags (`#omi`, `#conversation`, `#<category>`) for automatic indexing and filtering in graph views.
- **Interactive Checklists:** Action items generated by Omi are converted into standard Markdown checkboxes (`- [ ]` and `- [x]`).
- **Timestamped Transcripts:** Dialogue turns are formatted as readable blockquotes with speaker attribution and formatted `[MM:SS]` timestamps (`[HH:MM:SS]` for conversations longer than an hour).
- **Pure Standard Library:** Requires zero third-party dependencies (`pip` install not needed).
- **Safe Handling:** Handles missing fields, special characters, UTF-8 BOM encoding, and avoids file collisions or directory traversal.
