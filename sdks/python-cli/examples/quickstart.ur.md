# omi-cli کے ساتھ آغاز

یہ رہنما اردو میں ابتدائی چند کمانڈز کا طریقہ کار پیش کرتا ہے۔ کمانڈز کے نام اور سسٹم کے پیغامات انگریزی میں رہیں گے۔ یہاں دی گئی پڑھنے کی مثالیں آپ کی یادداشتوں، گفتگوؤں، کاموں کی فہرست یا اہداف میں کوئی تبدیلی نہیں کرتیں۔

## پروگرام انسٹال کریں

ضروریات: Python 3.10 یا نیا ورژن اور ایک Omi اکاؤنٹ۔

> توجہ فرمائیں: PyPI پر پیکیج کا نام **`omi-cli`** ہے، جبکہ انسٹال کے بعد استعمال ہونے والی کمانڈ کا نام **`omi`** ہے۔ PyPI پر `omi` نام کا ایک غیر متعلقہ پیکیج بھی موجود ہے — اسے انسٹال نہ کریں۔

اگر `pipx` انسٹال ہے:

```sh
pipx install omi-cli
omi --help
```

متبادل طور پر، کسی فعال Python ورچوئل ماحول میں:

```sh
python -m pip install omi-cli
omi --help
```

اگر ٹرمینل `omi` کمانڈ کو تلاش نہ کر سکے، تو یقینی بنائیں کہ ورچوئل ماحول فعال ہے یا `pipx` کی ڈائریکٹری آپ کے `PATH` میں شامل ہے۔

## اپنا اکاؤنٹ منسلک کریں

انٹرایکٹو لاگ ان شروع کریں:

```sh
omi auth login
```

براؤزر کے ذریعے لاگ ان کریں یا Omi ڈیولپر API key چسپاں کرنے کا طریقہ منتخب کریں۔ انٹرایکٹو ان پٹ کلید کو پوشیدہ رکھتا ہے؛ ایسی کمانڈ میں کلید نہ لکھیں جو شیل کی تاریخ میں محفوظ ہو جائے۔

براہ راست براؤزر کے لیے:

```sh
omi auth login --browser
```

لاگ ان اسی کمپیوٹر پر مکمل کریں جہاں ٹرمینل چل رہا ہے، کیونکہ تصدیقی عمل مقامی ایڈریس پر واپس آتا ہے۔ اسکرین پر ظاہر ہونے والی ہدایات پر عمل کریں۔

اس کے بعد کنفیگریشن اور API رسائی کی جانچ کریں:

```sh
omi auth status
omi auth whoami
```

`status` مقامی حالت دکھاتا ہے اور رازوں کو چھپاتا ہے، لیکن سرور پر توثیق نہیں کرتا۔ `whoami` ایک تصدیق شدہ درخواست بھیجتا ہے؛ کامیابی کا مطلب ہے کہ اسناد درست کام کر رہی ہیں۔

کنفیگریشن فائیل طے شدہ طور پر `~/.omi/config.toml` میں محفوظ ہوتی ہے۔ یہ فائل کسی کے ساتھ شیئر نہ کریں کیونکہ اس میں آپ کی حساس معلومات ہو سکتی ہیں۔

## اپنا ڈیٹا دیکھیں

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

خالی فہرست کا مطلب یہ ہو سکتا ہے کہ تلاش سے مطابقت رکھنے والا کوئی آئٹم موجود نہیں۔ کسی کمانڈ کے فلٹرز جاننے کے لیے help دیکھیں:

```sh
omi memory list --help
omi action-item list --help
```

## JSON آؤٹ پٹ اور صفحات کی تقسیم (Pagination)

عالمی آپشن `--json` کو کمانڈ گروپ سے **پہلے** رکھیں:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

پہلی کمانڈ ابتدائی 25 ریکارڈز اور دوسری اگلے 25 ریکارڈز لاتی ہے۔ مکمل بیک اپ کے لیے ایک سے زائد صفحات کی ضرورت ہوتی ہے۔ JSON آؤٹ پٹ مکمل شناخت کنندگان کو محفوظ رکھتا ہے۔

کسی صفحے کو فائل میں محفوظ کرنے کے لیے:

```sh
omi --json memory list --limit 25 --offset 0 > yaadein-page-1.json
```

یہ ری ڈائریکشن مقامی فائل بناتی یا تبدیل کرتی ہے۔ مواد استعمال کرنے سے پہلے تصدیق کریں کہ کمانڈ کامیاب رہی۔ غلطیاں stderr پر لکھی جاتی ہیں؛ خالی فائل ڈیٹا کی عدم موجودگی کا حتمی ثبوت نہیں ہے۔ برآمد شدہ فائل میں نجی معلومات ہو سکتی ہیں، اسے محفوظ رکھیں۔

## لاگ آؤٹ کریں

```sh
omi auth logout
```

یہ کمانڈ مقامی طور پر محفوظ شدہ اسناد کو حذف کر دیتی ہے۔ سرور پر کلید منسوخ کرنے کے لیے اپنے اکاؤنٹ کا ڈیولپر پورٹل استعمال کریں۔

دیگر کمانڈز اور جدید آپشنز کے لیے انگریزی کی بنیادی گائیڈ دیکھیں:
[../README.md](../README.md) اور `omi --help`.
