# omi-cli کے ساتھ فوری آغاز

یہ رہنمائی بنیادی کمانڈز اردو میں بیان کرتی ہے۔ کمانڈ کے نام اور پروگرام کے
پیغامات انگریزی ہی رہتے ہیں۔ نیچے دی گئی مثال کمانڈیں آپ کی یادیں، گفتگوئیں،
عملی اشیاء یا مقاصد تبدیل نہیں کرتیں۔

## پروگرام انسٹال کرنا

ضروریات: Python 3.10 یا نیا ورژن اور Omi اکاؤنٹ۔

اگر `pipx` انسٹال ہے:

```sh
pipx install omi-cli
omi --help
```

متبادل طور پر، فعال Python virtual environment میں انسٹال کریں:

```sh
python -m pip install omi-cli
omi --help
```

اگر ٹرمینل `omi` نہ پائے تو دیکھیں کہ virtual environment فعال ہے یا `pipx`
جس ڈائریکٹری میں executable رکھتا ہے وہ `PATH` میں ہے۔

## اکاؤنٹ جوڑنا

انٹرایکٹو رہنمائی چلائیں:

```sh
omi auth login
```

براؤزر لاگ اِن منتخب کریں یا Omi ڈیولپر API key چسپاں کریں۔ انٹرایکٹو اندراج
key چھپاتا ہے؛ اسے ایسی کمانڈز میں نہ لکھیں جو ٹرمینل ہسٹری میں محفوظ ہوتی ہیں۔

براؤزر براہِ راست استعمال کرنے کے لیے:

```sh
omi auth login --browser
```

اسی کمپیوٹر پر لاگ اِن کریں جہاں ٹرمینل ہے، کیونکہ تصدیق مقامی callback
پتہ استعمال کرتی ہے۔ اسکرین پر ظاہر ہدایات پر عمل کریں۔

لاگ اِن کے بعد کنفیگریشن اور API رسائی جانچیں:

```sh
omi auth status
omi auth whoami
```

`status` مقامی حالت دکھاتا ہے اور رازوں کو ماسک کرتا ہے، مگر ان کی سرور پر
درستگی کی تصدیق نہیں کرتا۔ `whoami` تصدیق شدہ درخواست بھیجتا ہے؛ اگر کامیاب ہو
تو آپ کی credentials کام کر رہی ہیں — بغیر آپ کا نام دکھائے۔

کنفیگریشن بطور ڈیفالٹ `~/.omi/config.toml` میں محفوظ ہوتی ہے۔ یہ فائل شیئر نہ
کریں کیونکہ اس میں credentials ہو سکتی ہیں۔

## اپنا ڈیٹا پڑھنا

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

خالی فہرست کا مطلب ہو سکتا ہے کہ فلٹر سے کوئی آئٹم نہیں ملا۔ ہر کمانڈ کے
اختیارات help میں دیکھیں:

```sh
omi memory list --help
omi action-item list --help
```

## JSON حاصل کرنا اور صفحات پر جانا

گلوبل `--json` آپشن کمانڈ گروپ سے **پہلے** رکھیں:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

پہلی کمانڈ پہلی 25 یادیں مانگتی ہے، دوسری اگلی 25۔ ایک صفحہ مکمل بیک اپ نہیں۔
JSON آؤٹ پٹ مکمل ID رکھتا ہے، جبکہ ٹیبل ڈسپلے کے لیے ID مختصر کر سکتی ہے۔

کوئی صفحہ فائل میں محفوظ کرنے کے لیے:

```sh
omi --json memory list --limit 25 --offset 0 > memory-safha-1.json
```

ری ڈائریکٹ مقامی فائل بناتا یا اسے اوور رائٹ کرتا ہے۔ مواد استعمال کرنے سے پہلے
یقینی کریں کہ کمانڈ کامیابی سے مکمل ہوئی۔ غلطیاں stderr پر آتی ہیں؛ خالی فائل
ڈیٹا نہ ہونے کا ثبوت نہیں۔ ایکسپورٹ شدہ فائل میں ذاتی معلومات ہو سکتی ہیں — اسے
نجی رکھیں۔

## پروفائلز استعمال کرنا

اسٹیٹ `~/.omi/config.toml` میں محفوظ ہوتی ہے (`$OMI_CONFIG` سے بدلی جا سکتی
ہے)۔ ہر پروفائل کا اپنا تصدیقی طریقہ اور API پتہ ہوتا ہے۔ `--profile` سے
تبدیل کریں:

```sh
omi config profile use kaam
omi auth login
omi --profile niji memory list
```

عام کنفیگریشن کمانڈز:

```sh
omi config show
omi config path
omi config profile list
```

## ایگزٹ کوڈز

یہ ایگزٹ کوڈز مستحکم ہیں اور اسکرپٹس یا ایجنٹس کے لیے مفید ہیں:

| کوڈ | مطلب | مثالی صورت |
| ---: | --- | --- |
| 0 | کامیاب | کمانڈ مکمل ہوئی |
| 1 | استعمال کی غلطی | غلط فلیگ، کمی والا آرگومنٹ یا ناکام validation |
| 2 | تصدیقی غلطی | credentials موجود نہیں، token میعاد ختم یا اجازت ناکافی |
| 3 | سرور غلطی | سرور 5xx یا کنکشن ناکام |
| 4 | rate limit | سرور نے HTTP 429 لوٹایا |
| 5 | نہیں ملا | سرور نے HTTP 404 لوٹایا |

## لاگ آؤٹ

```sh
omi auth logout
```

مقامی طور پر محفوظ credentials ہٹاتا ہے۔ سرور پر key منسوخ کرنے کے لیے اپنے
اکاؤنٹ کا developer key انتظام استعمال کریں۔

مزید کمانڈز اور اختیارات کے لیے [انگریزی مین README](../README.md) دیکھیں اور
`omi --help` چلائیں۔
