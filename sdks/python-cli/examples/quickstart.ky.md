# omi-cli — кыргызча тез баштауу колдонмосу

> Omi менен терминалдан иштөөнүн практикалык колдонмосу. Адамдарга да, AI-агенттерге да ылайыктуу.

`omi-cli` — [Omi](https://omi.me) иштеп чыгуучу APIсынын расмий буйрук-сап клиенти.
Ал Omi'нин төрт негизги объектисине тез жана скрипттерге ыңгайлуу жетүү берет:
эстутумдар, баарлашуулар, тапшырмактар жана максаттар.

* **PyPI:** [pypi.org/project/omi-cli](https://pypi.org/project/omi-cli/)
* **Документация:** [docs.omi.me/doc/developer/cli/introduction](https://docs.omi.me/doc/developer/cli/introduction)
* **Булак коду:** [github.com/BasedHardware/omi/tree/main/sdks/python-cli](https://github.com/BasedHardware/omi/tree/main/sdks/python-cli)

## 1. Орнотуу

Сунушталган ыкма — `pipx`: ал куралды өзүнчө бөлүнгөн чөйрөгө орнотот,
ошондуктан анын көз карандылыктары сиздин долбоорлоруңуз менен кагышпайт.

```bash
# сунушталат: pipx аркылуу орнотуу
pipx install omi-cli

# же pip аркылуу
pip install omi-cli
```

> **Маанилүү: пакеттин аты менен буйруктун аты ар башка.**
> * Орнотулуучу пакет — **`omi-cli`** (башка `omi` пакети — таптакыр башка, байланышы жок долбоор).
> * Орнотулгандан кийин сиз **`omi`** буйругун иштетесиз.

Баары иштей турганын текшериңиз:

```bash
omi --version
omi --help
```

## 2. Аутентификация

`omi-cli` эки кирүү ыкмасын колдойт.

| Ыкма | Качан ылайыктуу | Буйрук |
| :--- | :--- | :--- |
| **Иштеп чыгуучу ачкычы (`omi_dev_*`)** | CI/CD, скрипттер, AI-агенттер | `omi auth login --api-key ...` же чөйрө өзгөрмөсү |
| **Браузер аркылуу кирүү (Google/Apple)** | Өз компьютериңизде иштөө | `omi auth login --browser` |

### Интерактивдүү кирүү

Флагсыз буйрук кайсы ыкманы колдонгуңуз келерин өзү сурайт:

```bash
omi auth login
# 1) Browser — Google же Apple аркылуу кирүү (адамга ыңгайлуу)
# 2) API key — app.omi.me сайтынан иштеп чыгуучу ачкычын коюу (агенттерге жана CI'га ыңгайлуу)
```

Ачкычты тандаганда киргизүү жашырылат — ачкыч терминал тарыхында калбайт.

### Браузер аркылуу түздөн-түз

```bash
omi auth login --browser
```

### Иштеп чыгуучу ачкычы аркылуу

Ачкыч [app.omi.me](https://app.omi.me) сайтында **Developer → API Keys** бөлүмүнөн алынат.

```bash
# ачкычты конфигурацияга сактоо
omi auth login --api-key omi_dev_...

# же аны чөйрө аркылуу берүү — CI/CD жана контейнерлер үчүн артык
export OMI_API_KEY=omi_dev_...
```

`OMI_API_KEY` чөйрө өзгөрмөсү активдүү профильде сакталган ачкыч жок болгондо колдонулат,
ошондуктан контейнерде дискке эч нерсе жазуунун кереги жок. Эгер профильде ачкыч
буга чейин сакталган болсо, ал чөйрө өзгөрмөсүнөн жогору турат.

### Кирүүнү текшерүү

Эки буйрук ар башка суроолорго жооп берет, аларды чатааштырбаңыз:

* `omi auth status` — **жергиликтүү** эмне сакталганы: профиль, жашырылган ачкыч, мөөнөтү.
  Тармаксыз иштейт.
* `omi auth whoami` — **Omi серверине** кайрылуу: ачкыч чыныгы кабыл
  алынарын текшерет. Тармак талап кылынат.

```bash
omi auth status    # жергиликтүү текшерүү, оффлайн
omi auth whoami    # сервердеги текшерүү
```

Мөөнөтү бүтүүгө жакындаган OAuth сессиясын кайра кирбестен жаңылоо — бул браузер аркылуу кирүүгө (OAuth) гана тиешелүү. `omi_dev_*` ачкычтары үчүн бул буйрук эч кандай жаңыртуу жүргүзбөйт; ачкычты веб-тиркемедеги `Developer → API Keys` бөлүмүнөн алмаштырыңыз:

```bash
omi auth refresh
```

Чыгуу:

```bash
omi auth logout
```

## 3. Негизги буйруктар

### Эстутумдар (memories)

Система сиз жөнүндө эстеп калган фактылар жана билим.

```bash
# эстутумдардын тизмеси
omi memory list

# жаңысын түзүү
omi memory create "Колдонуучу караңгы теманы жактырат" --category lifestyle

# белгилүү бирин көрүү
omi memory get <MEMORY_ID>
```

### Баарлашуулар (conversations)

Түзмөктөн же тиркемеден алынган үн жана текст тарыхы.

```bash
# акыркы 5 баарлашуу
omi conversation list --limit 5

# транскрипция менен толук баарлашуу
omi conversation get <CONVERSATION_ID> --include-transcript
```

### Тапшырмактар (action items)

Omi баарлашуулардан чыгарган иштер.

```bash
# ачык болгондору гана
omi action-item list --open

# аткарылды деп белгилөө
omi action-item complete <ACTION_ITEM_ID>
```

### Максаттар (goals)

```bash
# максаттардын тизмеси
omi goal list

# жаңы прогресс маанисин каттоо (ЭКИ аргумент тең талап кылынат: максат жана маани)
omi goal progress <GOAL_ID> 25

# өзгөрүү тарыхы
omi goal history <GOAL_ID>
```

## Өз сөздөрүңүз менен суроо бериңиз (`ask`)

Баштапкы деңгээлдеги өзүнчө буйрук: кадимки тилде суроо берет,
жооп болсо сиздин өз баарлашууларыңыздан түзүлөт.

```bash
omi ask "көчүү жөнүндө эмне чечкенмин"
omi --json ask "бул жумада кайсы иштерди бүтүрөм деп убада кылганмын"
```

## 4. JSON жана скрипттер (`--json`)

`omi-cli` машина окыга турган JSON чыгара алат. `--json` флагы **глобалдуу**,
ошондуктан ал кошумча буйруктун **алдына** коюлат.

```bash
# эстутумдар: id, текст жана категорияны алуу
omi --json memory list | jq '.[] | {id, content, category}'

# акыркы баарлашуулардын аталыштары
omi --json conversation list --limit 5 | jq '.[] | {id, title: .structured.title, started_at}'

# ачык тапшырмактар
omi --json action-item list --open | jq '.'
```

> **Кеңири таралган ката.** `--json` кошумча буйруктан мурун келет, андан кийин эмес.
> * Туура: `omi --json memory list`
> * Туура эмес: `omi memory list --json`

`--json` режиминде stdout'ка JSON'ден башка эч нерсе чыкпайт —
скрипттер ушунга ишене алышат.

## 5. Чыгуу коддору

Коддор туруктуу, ошондуктан скрипттер менен CI логикасы аларга жараша бөлүнө алат.

| Код | Мааниси | Качан |
| :---: | :--- | :--- |
| `0` | Ийгилик | Буйрук аткарылды |
| `1` | Чакыруу катасы | omi-cli'нин өз текшерүүсү (мисалы, `--browser` жана `--api-key` бирге, жараксыз кирүү тандоосу, бош stdin) |
| `2` | Жеткиликтүүлүк же аргумент катасы | Кирилген эмес, ачкыч жараксыз же мөөнөтү бүткөн — ошондой эле талдоочунун каталары (белгисиз флаг, жетишпеген аргумент) |
| `3` | Сервер катасы | 5xx жооп, убакыт ашып кетүү, байланыш жок |
| `4` | Өтө көп сурамдар | 429 Too Many Requests |
| `5` | Табылган жок | 404, id жок |

Bash'та текшерүү үлгүсү:

```bash
if omi --json auth whoami > /dev/null 2>&1; then
  echo "ачкыч иштейт"
else
  code=$?
  [ "$code" -eq 2 ] && echo "кайра кириңиз"
  [ "$code" -eq 3 ] && echo "сервер иштебейт, кийинчерээк аракет кылыңыз"
fi
```

## 6. Чөйрө өзгөрмөлөрү

### Bash / Zsh (Linux, macOS)

```bash
export OMI_API_KEY="omi_dev_ачкычыңыз"

omi --json memory list --limit 10
```

Ачкыч жаңы сессияларда жүктөлүшү үчүн сапты `~/.bashrc` же `~/.zshrc` файлына кошуңуз.

### PowerShell (Windows)

```powershell
$env:OMI_API_KEY = "omi_dev_ачкычыңыз"

# PowerShell менен JSON талдоо
(omi --json memory list | ConvertFrom-Json) | Select-Object id, content
```

Туруктуу орнотуу үчүн:

```powershell
[Environment]::SetEnvironmentVariable("OMI_API_KEY", "omi_dev_ачкычыңыз", "User")
```

## 7. Жергиликтүү Omi Desktop тиркемеси

Эгер Omi десктоп тиркемеси иштеп жатса, маалыматтын бир бөлүгүнө
булутту айланып өтпөй түздөн-түз жетүүгө болот.

```bash
# жергиликтүү API'нын дарегин көрсөтүү
omi local configure --url http://127.0.0.1:47778 --token ТОКЕНИҢИЗ

# жооп берерин текшерүү
omi --json local status

# экран тарыхында издөө
omi --json local search-screen "баалар" --days 7 --app Safari

# id боюнча экран сүрөтү
omi --json local screenshot 123 --output /tmp/omi-shot.jpg

# жергиликтүү маалымат базасына каалаган SQL
omi --json local sql "SELECT appName, COUNT(*) FROM screenshots GROUP BY appName"
```

Иш тартиби: адегенде `local status`, анан `local tools` — жеткиликтүү
куралдарды жана алардын параметрлерин көрүү үчүн, андан кийин гана чакыруулар.

## 8. Профилдер

Эгер бир нече каттоо эсебиңиз же чөйрөңүз болсо, аларды профилдер менен бөлүңүз.
Жөндөөлөр `~/.omi/config.toml` файлында сакталат.

```bash
# жеке профилге кирүү
omi --profile personal auth login

# жумуш профилине кирүү
omi --profile work auth login

# белгилүү профилде буйрук иштетүү
omi --profile work memory list
```

Эгер профильди көрсөтпөсөңүз, CLI адегенде `OMI_PROFILE` чөйрө өзгөрмөсүнүн маанисин колдонот, анан конфигурация файлынын активдүү профилин, анан `default`. Приоритет тартиби: `--profile`, анан `OMI_PROFILE`, анан `~/.omi/config.toml` ичиндеги активдүү профиль, анан `default`.

Конфигурациянын өзүн көрүү жана өзгөртүү:

```bash
# азыр эмне жөндөлгөнү
omi config show

# конфигурация файлы кайда жайгашканы
omi config path

# маанини өзгөртүү
omi config set api_base https://api.omi.me
```
