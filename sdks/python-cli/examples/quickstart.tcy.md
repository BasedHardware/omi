# omi-cli ಒಟ್ಟಿಗೆ ಸುರುತ ಪಟ್ಟೊ

ಈ ಮಾರ್ಗದರ್ಶಿ omi-cli ತ ಸುರುತ ಆಜ್ಞೆಲೆನ್ (commands) ತುಳುಟ್ ವಿವರಿಸುಂಡು. ಆಜ್ಞೆಲೆನ ಪುದರ್ಲು ಬೊಕ್ಕ ಪ್ರೋಗ್ರಾಂ ತ ಸಂದೇಶೊಲು ಇಂಗ್ಲಿಷ್ಡೇ ಉಪ್ಪುವ. ಇಡೆ ತೋಜಾಯಿನ ಪರಿಶೀಲನೆ ಉದಾಹರಣೆಲು ಈರೆನ ನೆನಪುಲೆನ್ (memories), ಸಂಭಾಷಣೆಲೆನ್ (conversations), ಕೆಲಸೊಲೆನ್ (action items) ಅತ್ತಂಡ ಗುರಿಕುಲೆನ್ (goals) ಬದಲ್ ಮಲ್ಪುಜಿ.

## ಇನ್ಸ್ಟಾಲ್ ಮಲ್ಪುನೆ

ಬೋಡಾಯಿನ: Python 3.10 ಅತ್ತಂಡ ಅಯಿಡ್ದ್ ಪೊಸ, ಬೊಕ್ಕ Omi ಖಾತೆ.

ಈರೆಗ್ `pipx` ಇತ್ತ್ಂಡ:

```sh
pipx install omi-cli
omi --help
```

Python ವರ್ಚುವಲ್ ಎನ್ವಿರಾನ್ಮೆಂಟ್ಡ್ ಲಾ ಇನ್ಸ್ಟಾಲ್ ಮಲ್ಪೊಲಿ:

```sh
python -m pip install omi-cli
omi --help
```

ಟರ್ಮಿನಲ್ಗ್ `omi` ತಿಕ್ಕಂದ್ಂಡ, ವರ್ಚುವಲ್ ಎನ್ವಿರಾನ್ಮೆಂಟ್ ಸಕ್ರಿಯ ಉಂಡು ಅತ್ತಂಡ `pipx` ಫೋಲ್ಡರ್ `$PATH` ಡ್ ಉಂಡು ಪಂದ್ ಖಚಿತ ಮಲ್ಪುಲೆ.

## ಖಾತೆನ್ ಜೋಡಿಪುನೆ

ಇಂಟರಾಕ್ಟಿವ್ ಸಹಾಯಕನ್ ಸುರು ಮಲ್ಪುಲೆ:

```sh
omi auth login
```

ಬ್ರೌಸರ್ ಮೂಲಕ ಲಾಗಿನ್ ಆವೊಡು ಅತ್ತಂಡ Omi ಡೆವಲಪರ್ API ಕೀಲಿ ಅಂಟಿಸಾವೊಡು ಪಂದ್ ಆಯ್ಕೆ ಮಲ್ಪುಲೆ. ಇಂಟರಾಕ್ಟಿವ್ ಇನ್ಪುಟ್ ಕೀಲಿನ್ ಮುಚ್ಚುಂಡು; ಟರ್ಮಿನಲ್ ಇತಿಹಾಸೊಡ್ ಉಪ್ಪುನ ಆಜ್ಞೆಡ್ ಕೀಲಿನ್ ಬರೆಪುಜಿ.

ನೇರವಾದ್ ಬ್ರೌಸರ್ಗ್ ಪೋಯೆರೆ:

```sh
omi auth login --browser
```

ಟರ್ಮಿನಲ್ ಇತ್ತಿನ ಅದೇ ಕಂಪ್ಯೂಟರ್ಡ್ ಲಾಗಿನ್ ಆಲೆ: ದೃಢೀಕರಣದ ಉತ್ತರ ಸ್ಥಳೀಯ ವಿಳಾಸೊಗು ಪೋಪುಂಡು. ಸ್ಕ್ರೀನ್ಡ್ ಉಪ್ಪುನ ಸೂಚನೆಲೆನ್ ಅನುಸರಿಸಲೆ.

ಅವೆಡ್ದ್ ಬೊಕ್ಕ, ಸಂರಚನೆ ಬೊಕ್ಕ API ಪ್ರವೇಶೊನು ಪರಿಶೀಲಿಸಲೆ:

```sh
omi auth status
omi auth whoami
```

`status` ಸ್ಥಳೀಯ ಸ್ಥಿತಿನ್ ತೋಜಾವುಂಡು ಬೊಕ್ಕ ರಹಸ್ಯೊನು ಮುಚ್ಚುಂಡು, ಆಂಡ ಸರ್ವರ್ನಲ್ಲಿ ಸಿಂಧುತ್ವೊನು ಪರಿಶೀಲಿಸುಜಿ. `whoami` ದೃಢೀಕೃತ ವಿನಂತಿ ಮಲ್ಪುಂಡು; ಯಶಸ್ವಿ ಆಂಡ, ರುಜುವಾತುಲು ಕೆಲಸ ಮಲ್ಪುಂಡು ಪಂದ್ ಸ್ಪಷ್ಟ, ಈರೆನ ಪುದರ್ನ್ ತೋಜಾಂದೆ.

ಸಂರಚನೆ ಡಿಫಾಲ್ಟ್ ಆದ್ `~/.omi/config.toml` ಡ್ ಒರಿಪುಂಡು. ಈ ಫೈಲ್ನ್ ಹಂಚುಜಿ: ಅಯಿಟ್ ಖಾಸಗಿ ರುಜುವಾತುಲು ಉಪ್ಪೊಲಿ.

## ಡೇಟಾನ್ ತೂಪುನೆ

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ಖಾಲಿ ಪಟ್ಟಿ ಪಂಡ ಸಾಮಾನ್ಯವಾದ್ ಪರಿಶೀಲನೆಗ್ ಏನೂ ಹೊಂದುಜಿ ಪಂದ್ ಅರ್ಥ. ಪ್ರತಿ ಆಜ್ಞೆದ ಫಿಲ್ಟರ್ಲೆನ್ ತೋಜೆರೆ ಸಹಾಯೊನು ಗಳಸುಲೆ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ಬೊಕ್ಕ ಪುಟೊಕುಲು

ಜಾಗತಿಕ ಆಯ್ಕೆ `--json` ನ್ ಆಜ್ಞೆ ಗುಂಪುದ **ದುಂಬು** ದೀಲೆ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ಸುರುತ ಆಜ್ಞೆ ಸುರುತ 25 ನೆನಪುಲೆನ್ ಕೇನುಂಡು; ರಡ್ಡನೆದಿ ಮುಂದುದ 25 ನ್. ಒಂಜಿ ಪುಟ ಸಂಪೂರ್ಣ ಪ್ರತಿ ಅತ್ತ್. JSON ಔಟ್ಪುಟ್ ಪೂರ್ಣ ಸಂಖ್ಯೆಲೆನ್ ಒರಿಪುಂಡು, ಆಂಡ ಸ್ಕ್ರೀನ್ದ ಕೋಷ್ಟಕೊಲು ಅವೆನ್ ಕಿರು ಮಲ್ಪೊಲಿ.

ಪುಟೊನು ಫೈಲ್ಡ್ ಒರಿಪೆರೆ:

```sh
omi --json memory list --limit 25 --offset 0 > nenapu-puta-1.json
```

ಈ ರೀಡೈರೆಕ್ಟ್ ಸ್ಥಳೀಯ ಫೈಲ್ನ್ ಉಂಡು ಮಲ್ಪುಂಡು ಅತ್ತಂಡ ಮಿತ್ತ್ ಬರೆಪುಂಡು. ಒಳಪಟ್ಟಿನ್ ಗಳಸೆರೆ ದುಂಬು ಆಜ್ಞೆ ಮುಗಿಂಡ್ ಪಂದ್ ಖಚಿತ ಮಲ್ಪುಲೆ. ತಪ್ಪುಲು ತಪ್ಪು ಔಟ್ಪುಟ್ಗ್ (stderr) ಬರೆಪುವ. ಖಾಲಿ ಫೈಲ್ ಡೇಟಾ ಇಜ್ಜಿ ಪಂದ್ ಸಾಕ್ಷಿ ಅತ್ತ್. ರಫ್ತು ಮಲ್ತಿನ ಫೈಲ್ಡ್ ಖಾಸಗಿ ಮಾಹಿತಿ ಉಪ್ಪೊಲಿ: ಅವೆನ್ ಖಾಸಗಿಯಾದ್ ಒರಿಪುಲೆ.

## ಲಾಗ್ ಔಟ್

```sh
omi auth logout
```

ಈ ಆಜ್ಞೆ ಸ್ಥಳೀಯವಾದ್ ಒರಿಪಾಯಿನ ರುಜುವಾತುಲೆನ್ ಅಳಿಸುಂಡು. ಸರ್ವರ್ನಲ್ಲಿ ಕೀಲಿನ್ ರದ್ದು ಮಲ್ಪೆರೆ, ಈರೆನ ಖಾತೆಡ್ ಡೆವಲಪರ್ ಕೀ ನಿರ್ವಹಣೆನ್ ಗಳಸುಲೆ.

ಹೆಚ್ಚ ಆಜ್ಞೆಲು ಬೊಕ್ಕ ಆಯ್ಕೆಲೆಗ್, [ಇಂಗ್ಲಿಷ್ ಮುಖ್ಯ ಮಾರ್ಗದರ್ಶಿ](../README.md) ಬೊಕ್ಕ `omi --help` ನ್ ತೂಲೆ.
