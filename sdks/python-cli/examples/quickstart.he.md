# צעדים ראשונים עם omi-cli

מדריך זה מסביר את הפקודות הראשונות בעברית. שמות הפקודות וההודעות של התוכנה
נשארים באנגלית. דוגמאות השאילתות המופיעות כאן אינן משנות את הזיכרונות, השיחות,
המשימות או היעדים שלך.

## התקנת התוכנה

דרישות קדם: Python 3.10 ומעלה וחשבון Omi.

אם מותקן אצלך `pipx`:

```sh
pipx install omi-cli
omi --help
```

לחלופין, ניתן להתקין בתוך סביבה וירטואלית פעילה של Python:

```sh
python -m pip install omi-cli
omi --help
```

אם הטרמינל אינו מזהה את הפקודה `omi`, יש לוודא שהסביבה הווירטואלית מופעלת או
שנתיב ההתקנה של `pipx` נמצא במשתנה ה-`PATH` שלך.

## חיבור החשבון שלך

הפעלת אשף ההתחברות האינטראקטיבי:

```sh
omi auth login
```

בחר בין התחברות דרך הדפדפן לבין הדבקת מפתח API למפתחים של Omi. הקלט
האינטראקטיבי מסתיר את המפתח; הימנע מלכתוב אותו בפקודה שתישמר בהיסטוריית הטרמינל.

למעבר ישיר לדפדפן:

```sh
omi auth login --browser
```

התחבר מאותו מחשב שבו פועל הטרמינל: תגובת האימות משתמשת בכתובת מקומית.
פעל לפי ההנחיות שמופיעות על המסך.

לאחר מכן, אמת את התצורה והגישה ל-API:

```sh
omi auth status
omi auth whoami
```

הפקודה `status` מציגה את המצב המקומי ומסתירה את המפתח הסודי, אך אינה בודקת
תוקף מול השרת. הפקודה `whoami` מבצעת בקשה מאומתת לשרת; אם היא מצליחה, היא
מאשרת שפרטי ההתחברות פועלים כשורה, ללא צורך בהצגת שמך.

ההגדרות נשמרות כברירת מחדל בנתיב `~/.omi/config.toml`. אין לשתף קובץ זה: הוא
עשוי להכיל את פרטי האימות הסודיים שלך.

## צפייה בנתונים שלך

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

רשימה ריקה עשויה להעיד פשוט על כך שאין פריטים התואמים לשאילתה. השתמש בעזרה כדי
לגלות את אפשרויות הסינון של כל פקודה:

```sh
omi memory list --help
omi action-item list --help
```

## קבלת פלט בפורמט JSON ומעבר בין עמודים

יש למקם את הדגל הכללי `--json` **לפני** קבוצת הפקודות:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

הפקודה הראשונה מבקשת את 25 הזיכרונות הראשונים; השנייה מבקשת את 25 הבאים.
עמוד בודד אינו מהווה גיבוי מלא. פלט ה-JSON שומר על מזהים מלאים, בעוד שטבלאות
עשויות לקצר אותם לצורך תצוגה.

לשמירת עמוד לקובץ מקומי:

```sh
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
```

הפניה זו יוצרת או מחליפה את הקובץ המקומי. ודא שהפקודה הסתיימה בהצלחה לפני
השימוש בתוכן. הודעות שגיאה נכתבות לערוץ השגיאות הסטנדרטי (stderr); קובץ ריק
אינו מבטיח שאין נתונים. הקובץ המיוצא עשוי להכיל מידע אישי: שמור עליו מאובטח.

## התנתקות מהחשבון (Logout)

```sh
omi auth logout
```

פקודה זו מוחקת את פרטי האימות השמורים מקומית במחשב. לביטול מפתח API בשרת,
השתמש בממשק ניהול מפתחות המפתחים בחשבונך.

לשאר הפקודות ואפשרויות מתקדמות, עיין ב-[מדריך הראשי באנגלית](../README.md) וב-`omi --help`.
