# omi-cli સાથે ઝડપી શરૂઆત

આ માર્ગદર્શિકા મૂળભૂત કમાન્ડો ગુજરાતીમાં સમજાવે છે. કમાન્ડના નામ અને પ્રોગ્રામ
સંદેશાઓ અંગ્રેજીમાં જ રહે છે. નીચેની ઉદાહરણ કમાન્ડો તમારી યાદો, વાતચીત, ક્રિયા
વસ્તુઓ કે લક્ષ્યોને બદલતી નથી.

## પ્રોગ્રામ ઇન્સ્ટોલ કરવો

જરૂરિયાતો: Python 3.10 કે નવું અને Omi એકાઉન્ટ.

જો `pipx` ઇન્સ્ટોલ થયેલ હોય:

```sh
pipx install omi-cli
omi --help
```

અથવા સક્રિય કરેલ Python virtual environment માં ઇન્સ્ટોલ કરો:

```sh
python -m pip install omi-cli
omi --help
```

જો ટર્મિનલ `omi` શોધી ન શકે, તો તપાસો કે virtual environment સક્રિય છે કે
`pipx` જે ફોલ્ડરમાં executable મૂકે છે તે `PATH` માં છે.

## તમારું એકાઉન્ટ જોડવું

ઇંટરેક્ટિવ માર્ગદર્શક ચલાવો:

```sh
omi auth login
```

બ્રાઉઝર લોગિન પસંદ કરો અથવા Omi ડેવલપર API key પેસ્ટ કરો. ઇંટરેક્ટિવ ઇનપુટ
key છુપાવે છે; ટર્મિનલ ઇતિહાસમાં સાચવાતી કમાન્ડોમાં તે સીધી ન લખો.

બ્રાઉઝર સીધુ વાપરવા માટે:

```sh
omi auth login --browser
```

ટર્મિનલ હોય ત્યાં જ કમ્પ્યુટર પર લોગિન કરો, કારણ કે ઓથન્ટિકેશન સ્થાનિક callback
એડ્રેસ વાપરે છે. સ્ક્રીન પર દેખાતી સૂચનાઓનું પાલન કરો.

લોગિન પછી કૉન્ફિગરેશન અને API ઍક્સેસ તપાસો:

```sh
omi auth status
omi auth whoami
```

`status` સ્થાનિક સ્થિતિ બતાવે છે અને રહસ્યો છુપાવે છે, પરંતુ સર્વર પર તેમની
માન્યતા તપાસતું નથી. `whoami` ઓથન્ટિકેટેડ વિનંતી મોકલે છે; સફળ થાય તો તમારા
credentials કામ કરે છે — તમારું નામ બતાવ્યા વિના.

કૉન્ફિગરેશન ડિફૉલ્ટ રીતે `~/.omi/config.toml` માં સાચવાય છે. આ ફાઇલ શેર કરશો
નહીં કારણ કે તેમાં credentials હોઈ શકે.

## તમારો ડેટા વાંચવો

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ખાલી યાદીનો અર્થ થઈ શકે કે ફિલ્ટર સાથે કોઈ આઇટમ મેળ ખાતી નથી. દરેક કમાન્ડના
વિકલ્પો help માં જુઓ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON મેળવવું અને પાનાં ફરવું

ગ્લોબલ `--json` વિકલ્પ કમાન્ડ ગ્રુપ **પહેલાં** મૂકો:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

પહેલી કમાન્ડ પહેલી 25 યાદો માંગે છે; બીજી આગળની 25. એક પાનું સંપૂર્ણ બેકઅપ
નથી. JSON આઉટપુટ સંપૂર્ણ ID રાખે છે, જ્યારે કોષ્ટક દેખાવ માટે ID ટૂંકી કરી
શકે છે.

પાનું ફાઇલમાં સાચવવા:

```sh
omi --json memory list --limit 25 --offset 0 > memory-panu-1.json
```

રીડાયરેક્શન સ્થાનિક ફાઇલ બનાવે છે કે ઓવરરાઇટ કરે છે. સામગ્રી વાપરતા પહેલાં
ખાતરી કરો કે કમાન્ડ સફળતાથી પૂરી થઈ. ભૂલો stderr પર લખાય છે; ખાલી ફાઇલ ડેટા
ન હોવાનો પુરાવો નથી. એક્સપોર્ટ ફાઇલમાં અંગત માહિતી હોઈ શકે — તેને ખાનગી રાખો.

## પ્રોફાઇલ વાપરવી

સ્ટેટ `~/.omi/config.toml` માં સાચવાય છે (`$OMI_CONFIG` વડે બદલી શકાય). દરેક
પ્રોફાઇલની પોતાની ઓથન્ટિકેશન રીત અને API એડ્રેસ હોય છે. `--profile` થી
બદલો:

```sh
omi config profile use કામ
omi auth login
omi --profile અંગત memory list
```

સામાન્ય કૉન્ફિગરેશન કમાન્ડો:

```sh
omi config show
omi config path
omi config profile list
```

## એક્ઝિટ કોડ્સ

આ એક્ઝિટ કોડ્સ સ્થિર છે અને સ્ક્રિપ્ટ અથવા એજન્ટ માટે ઉપયોગી છે:

| કોડ | અર્થ | ઉદાહરણ સ્થિતિ |
| ---: | --- | --- |
| 0 | સફળ | કમાન્ડ પૂર્ણ થઈ |
| 1 | ઉપયોગ-ભૂલ | ખોટો ફ્લેગ, ઓછો આર્ગ્યુમેન્ટ કે નિષ્ફળ માન્યતા |
| 2 | ઓથન્ટિકેશન-ભૂલ | credentials નથી, ટોકન સમાપ્ત કે પરવાનગી ઓછી |
| 3 | સર્વર-ભૂલ | સર્વર 5xx કે કનેક્શન નિષ્ફળ |
| 4 | દર-મર્યાદા | સર્વરે HTTP 429 પરત આપ્યો |
| 5 | મળ્યું નહીં | સર્વરે HTTP 404 પરત આપ્યો |

## લૉગઆઉટ

```sh
omi auth logout
```

સ્થાનિક રીતે સાચવેલ credentials દૂર કરે છે. સર્વર પર key રદ કરવા માટે તમારા
એકાઉન્ટનું developer key મેનેજમેન્ટ વાપરો.

વધુ કમાન્ડ અને વિકલ્પો માટે [અંગ્રેજી મુખ્ય README](../README.md) જુઓ અને
`omi --help` ચલાવો.
