# omi-cli સાથે શરૂઆત

આ માર્ગદર્શિકા ગુજરાતીમાં પ્રારંભિક આદેશોનો ઉપયોગ કેવી રીતે કરવો તે સમજાવે છે. આદેશોના નામ અને સિસ્ટમના સંદેશાઓ અંગ્રેજીમાં રહેશે. અહીં આપેલા વાંચવાના ઉદાહરણો તમારી યાદો, વાતચીત, કાર્યો અથવા લક્ષ્યોમાં કોઈ ફેરફાર કરતા નથી.

## પ્રોગ્રામ ઇન્સ્ટોલ કરો

જરૂરિયાતો: Python 3.10 કે તેથી નવું સંસ્કરણ અને એક Omi એકાઉન્ટ.

> નોંધ: PyPI પર પેકેજનું નામ **`omi-cli`** છે, જ્યારે ઇન્સ્ટોલ કર્યા પછી ચાલતા આદેશનું નામ **`omi`** છે. PyPI પર `omi` નામનું એક અસંબંધિત પેકેજ પણ છે — તેને ઇન્સ્ટોલ ન કરશો.

જો `pipx` ઇન્સ્ટોલ કરેલું હોય:

```sh
pipx install omi-cli
omi --help
```

વૈકલ્પિક રીતે, સક્રિય Python વર્ચ્યુઅલ એન્વાયર્નમેન્ટમાં:

```sh
python -m pip install omi-cli
omi --help
```

જો ટર્મિનલને `omi` આદેશ ન મળે, તો વર્ચ્યુઅલ એન્વાયર્નમેન્ટ સક્રિય છે કે નહીં અથવા `pipx` ડિરેક્ટરી તમારા `PATH` માં છે કે નહીં તેની ખાતરી કરો.

## તમારું એકાઉન્ટ જોડો

ઇન્ટરેક્ટિવ લોગિન શરૂ કરો:

```sh
omi auth login
```

બ્રાઉઝર દ્વારા લોગિન કરો અથવા Omi ડેવલપર API key પેસ્ટ કરવાનો વિકલ્પ પસંદ કરો. ઇન્ટરેક્ટિવ ઇનપુટ કીને છુપાવે છે; ટર્મિનલ ઇતિહાસમાં રહી જાય તેવા આદેશમાં કી લખશો નહીં.

સીધા બ્રાઉઝર માટે:

```sh
omi auth login --browser
```

જે કમ્પ્યુટર પર ટર્મિનલ ચાલી રહ્યું છે તેના પર જ બ્રાઉઝર લોગિન પૂર્ણ કરો, કારણ કે પ્રમાણીકરણ સ્થાનિક સરનામાં પર પરત ફરે છે. સ્ક્રીન પરની સૂચનાઓનું પાલન કરો.

ત્યારબાદ રૂપરેખાંકન અને API ઍક્સેસ તપાસો:

```sh
omi auth status
omi auth whoami
```

`status` સ્થાનિક સ્થિતિ દર્શાવે છે અને ગુપ્ત વિગતો છુપાવે છે, પરંતુ સર્વર પર ચકાસણી કરતું નથી. `whoami` સર્વર પર પ્રમાણિત વિનંતી મોકલે છે; સફળ થવાનો અર્થ છે કે વિગતો યોગ્ય રીતે કાર્ય કરી રહી છે.

રૂપરેખાંકન ફાઇલ ડિફોલ્ટ રૂપે `~/.omi/config.toml` માં સાચવવામાં આવે છે. આ ફાઇલ કોઈની સાથે શેર ન કરો: તેમાં સંવેદનશીલ માહિતી હોઈ શકે છે.

## તમારો ડેટા જુઓ

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ખાલી સૂચિનો અર્થ ફક્ત એટલો જ હોઈ શકે કે ક્વેરી સાથે મેળ ખાતી કોઈ એન્ટ્રી નથી. ફિલ્ટરિંગ વિકલ્પો જાણવા help જુઓ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON આઉટપુટ અને પૃષ્ઠ ક્રમાંકન (Pagination)

વૈશ્વિક વિકલ્પ `--json` આદેશ જૂથની **પહેલાં** મૂકો:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

પ્રથમ આદેશ પ્રથમ ૨૫ રેકોર્ડ્સ અને બીજો આગામી ૨૫ રેકોર્ડ્સ મેળવે છે. સંપૂર્ણ બેકઅપ માટે બહુવિધ પૃષ્ઠોની જરૂર પડી શકે છે. JSON આઉટપુટમાં સંપૂર્ણ ઓળખકર્તાઓ સચવાય છે.

કોઈ પૃષ્ઠ ફાઇલમાં સાચવવા માટે:

```sh
omi --json memory list --limit 25 --offset 0 > yado-page-1.json
```

આ રીડાયરેક્શન સ્થાનિક ફાઇલ બનાવે છે અથવા બદલે છે. ભૂલો stderr પર લખવામાં આવે છે; ખાલી ફાઇલ ડેટા ન હોવાનો ચોક્કસ પુરાવો નથી. નિકાસ કરેલી ફાઇલમાં ખાનગી માહિતી હોઈ શકે છે, તેથી તેને સુરક્ષિત રાખો.

## લોગ આઉટ કરો

```sh
omi auth logout
```

આ આદેશ સ્થાનિક રીતે સંગ્રહિત ઓળખપત્રો દૂર કરે છે. સર્વર પર કી રદ કરવા માટે તમારા એકાઉન્ટના ડેવલપર પોર્ટલનો ઉપયોગ કરો.

અન્ય આદેશો અને અદ્યતન વિકલ્પો માટે મુખ્ય અંગ્રેજી માર્ગદર્શિકા જુઓ:
[../README.md](../README.md) અને `omi --help`.
