# omi-cli સાથે ઝડપી પ્રારંભ (Quickstart)

આ માર્ગદર્શિકા ગુજરાતીમાં `omi-cli` ના મૂળભૂત આદેશો (commands) દર્શાવે છે. આદેશોના નામ અને ટર્મિનલ સંદેશાઓ અંગ્રેજીમાં રહેશે. અહીં આપેલા વાંચવાના ઉદાહરણો ફક્ત તમારો ડેટા દર્શાવે છે અને તમારી યાદો (memories), વાતચીત (conversations), કાર્ય-સૂચિ (action items) અથવા લક્ષ્યો (goals) માં કોઈ ફેરફાર કરતા નથી.

## પ્રોગ્રામ ઇન્સ્ટોલ કરો

જરૂરિયાતો: Python 3.10 કે તેથી નવું સંસ્કરણ અને એક Omi ખાતું.

> **મહત્વપૂર્ણ નોંધ:** PyPI પર પેકેજનું નામ **`omi-cli`** છે, જ્યારે ઇન્સ્ટોલેશન પછી ચાલતા આદેશનું નામ **`omi`** છે. PyPI પર `omi` નામનું એક અલગ, અસંબંધિત પેકેજ પણ ઉપલબ્ધ છે — તેને ઇન્સ્ટોલ કરશો નહીં.

જો તમારી પાસે `pipx` ઇન્સ્ટોલ કરેલ હોય (ભલામણ કરેલ):

```sh
pipx install omi-cli
omi --help
```

વૈકલ્પિક રીતે, તમારા સક્રિય Python વર્ચ્યુઅલ એન્વાયર્નમેન્ટ (virtual environment) માં:

```sh
python -m pip install omi-cli
omi --help
```

જો ટર્મિનલ `omi` કમાન્ડ ન ઓળખે, તો ખાતરી કરો કે તમારું વર્ચ્યુઅલ એન્વાયર્નમેન્ટ સક્રિય છે અથવા `pipx` ની ડિરેક્ટરી તમારા સિસ્ટમ `PATH` માં ઉમેરાયેલી છે.

## તમારું ખાતું જોડો (Login)

ઇન્ટરેક્ટિવ લોગિન પ્રક્રિયા શરૂ કરો:

```sh
omi auth login
```

બ્રાઉઝર દ્વારા લૉગિન પસંદ કરો અથવા Omi ડેવલપર API Key પેસ્ટ કરવાનો વિકલ્પ પસંદ કરો. ઇન્ટરેક્ટિવ ઇનપુટ તમારી API Key ને સ્ક્રીન પર છુપાવે છે; આદેશમાં સીધી Key લખશો નહીં જેથી તે ટર્મિનલ હિસ્ટ્રીમાં સંગ્રહિત ન થાય.

સીધા બ્રાઉઝર લૉગિન માટે:

```sh
omi auth login --browser
```

લૉગિન એ જ કમ્પ્યુટર પર કરો જ્યાં ટર્મિનલ ચાલી રહ્યું છે, કારણ કે પ્રમાણીકરણ (authentication) સ્થાનિક સરનામાં (localhost) પર પરત આવે છે. સ્ક્રીન પર દેખાતા સરળ નિર્દેશોનું પાલન કરો.

ત્યારબાદ રૂપરેખાંકન (configuration) અને API કનેક્ટિવિટી ચકાસો:

```sh
omi auth status
omi auth whoami
```

- `omi auth status`: સ્થાનિક ફાઇલ સ્થિતિ બતાવે છે અને સિક્રેટ્સ છુપાવે છે.
- `omi auth whoami`: સર્વર પર પ્રમાણિત વિનંતી મોકલે છે; સફળ થવા પર તમારો વપરાશકર્તા ID દર્શાવે છે.

રૂપરેખાંકન ડિફૉલ્ટ રૂપે `~/.omi/config.toml` માં સંગ્રહિત થાય છે. આ ફાઇલ કોઈની સાથે શેર કરશો નહીં કારણ કે તેમાં તમારી લોગિન ક્રેડેન્શિયલ્સ હોઈ શકે છે.

## તમારો ડેટા જુઓ

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

જો પરિણામ ખાલી દેખાય, તો તેનો અર્થ એ છે કે શોધ સાથે મેળ ખાતો કોઈ ડેટા નથી. વધારાના ફિલ્ટર્સ જાણવા માટે `--help` વાપરો:

```sh
omi memory list --help
omi conversation list --help
omi action-item list --help
```

## JSON આઉટપુટ અને પેજિનેશન (Pagination)

પ્રોગ્રામમેટિક વપરાશ અથવા ઑટોમેશન માટે ગ્લોબલ ફ્લેગ `--json` નો ઉપયોગ આદેશ જૂથની **પહેલાં** કરો:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

પ્રથમ આદેશ શરૂઆતના 25 રેકોર્ડ્સ લાવે છે; બીજો આદેશ પછીના 25 રેકોર્ડ્સ લાવે છે. JSON આઉટપુટ સંપૂર્ણ ઓળખકર્તા (IDs) દર્શાવે છે.

ડેટાને JSON ફાઇલમાં સેવ કરવા માટે:

```sh
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
```

## વિશિષ્ટ રેકોર્ડ વિગતો મેળવો

```sh
omi memory get <memory-id>
omi conversation get <conversation-id>
```

વાતચીતના સંપૂર્ણ ટ્રાન્સક્રિપ્ટ સેગમેન્ટ્સ સાથે જોવા માટે:

```sh
omi conversation get <conversation-id> --segments
```

## મુશ્કેલીનિવારણ (Troubleshooting)

- **કમાન્ડ મળતી નથી (`command not found: omi`)**: ખાતરી કરો કે તમારું Python વર્ચ્યુઅલ એન્વાયર્નમેન્ટ સક્રિય છે અથવા `~/.local/bin` તમારા `PATH` પર્યાવરણ ચલમાં સામેલ છે.
- **પ્રમાણીકરણ નિષ્ફળતા (`Authentication failed`)**: `omi auth login` ફરીથી ચલાવીને નવું સત્ર શરૂ કરો અથવા `omi auth status` દ્વારા ચકાસો.
- **સહાય મેળવો**: કોઈપણ આદેશ વિશે વધુ માહિતી માટે `omi <command> --help` ચલાવો.
