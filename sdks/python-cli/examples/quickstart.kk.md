# omi-cli көмегімен алғашқы қадамдар

Бұл нұсқаулық бастапқы командаларды қазақ тілінде түсіндіреді. Командалардың
атаулары мен бағдарлама хабарламалары ағылшын тілінде қалады. Мұнда көрсетілген
сұрау мысалдары естеліктеріңізді, сөйлесулеріңізді, тапсырмаларыңызды немесе
мақсаттарыңызды өзгертпейді.

## Бағдарламаны орнату

Талаптар: Python 3.10 немесе жаңа нұсқасы және Omi тіркелгісі.

Егер сізде `pipx` орнатылған болса:

```sh
pipx install omi-cli
omi --help
```

Балама ретінде, оны белсендірілген Python виртуалды ортасында (virtual environment)
орнатуға болады:

```sh
python -m pip install omi-cli
omi --help
```

Егер терминал `omi` командасын таппаса, виртуалды ортаның белсендірілгенін
немесе `pipx` орындалатын файлдарды орнататын бума `PATH` айнымалыңызда бар екенін тексеріңіз.

## Тіркелгіңізді байланыстыру

Интерактивті көмекшіні іске қосыңыз:

```sh
omi auth login
```

Браузер арқылы кіруді немесе Omi әзірлеушісінің API кілтін қою опциясын таңдаңыз.
Интерактивті енгізу кілтті жасырады; оны терминал тарихында қалатын командада жазбаңыз.

Тікелей браузерге өту үшін:

```sh
omi auth login --browser
```

Терминал жұмыс істеп тұрған компьютерде кіріңіз: аутентификация жауабы жергілікті
мекенжайды пайдаланады. Экрандағы нұсқауларды орындаңыз.

Осыдан кейін конфигурацияны және API қолжетімділігін тексеріңіз:

```sh
omi auth status
omi auth whoami
```

`status` жергілікті күйді көрсетеді және құпияны жасырады, бірақ сервердегі
жарамдылығын тексермейді. `whoami` аутентификацияланған сұрау жібереді; егер ол
сәтті болса, атыңызды міндетті түрде көрсетпей, тіркелгі деректерінің жұмыс істейтінін растайды.

Конфигурация әдепкі бойынша `~/.omi/config.toml` файлында сақталады. Бұл файлды
басқалармен бөліспеңіз: оның ішінде құпия кіру деректері болуы мүмкін.

## Деректеріңізді қарау

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Бос тізім жай ғана сұрауға сәйкес келетін элементтер жоқ дегенді білдіруі мүмкін.
Әрбір команданың сүзгілерін білу үшін анықтаманы пайдаланыңыз:

```sh
omi memory list --help
omi action-item list --help
```

## JSON алу және беттерді шарлау

Ғаламдық `--json` опциясын командалар тобының **алдына** қойыңыз:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Бірінші команда алғашқы 25 естелікті, екіншісі — келесі 25-ті сұрайды. Сондықтан
бір бет толық резервтік көшірме (backup) емес. JSON шығысы толық идентификаторларды
сақтайды, ал экрандағы кестелер көрсету үшін оларды қысқартуы мүмкін.

Бетті файлға сақтау үшін:

```sh
omi --json memory list --limit 25 --offset 0 > estelikter-bet-1.json
```

Бұл қайта бағыттау жергілікті файлды жасайды немесе ауыстырады. Мазмұнды
пайдаланбас бұрын команданың сәтті аяқталғанына көз жеткізіңіз. Қателер қателер
шығысына (stderr) жазылады; бос файл деректер жоқ екеніне кепілдік бермейді.
Экспортталған файлда жеке ақпарат болуы мүмкін: оны құпия сақтаңыз.

## Жүйеден шығу (Logout)

```sh
omi auth logout
```

Бұл команда жергілікті сақталған тіркелгі деректерін жояды. Сервердегі кілтті
қайтарып алу үшін тіркелгіңіздегі әзірлеуші кілттерін басқаруды пайдаланыңыз.

Басқа командалар мен кеңейтілген опциялар үшін [ағылшын тіліндегі негізгі нұсқаулықты](../README.md)
және `omi --help` қараңыз.
