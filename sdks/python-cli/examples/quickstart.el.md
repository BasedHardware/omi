# Πρώτα βήματα με το omi-cli

Αυτός ο οδηγός εξηγεί τις πρώτες εντολές στα ελληνικά. Τα ονόματα των εντολών
και τα μηνύματα του προγράμματος παραμένουν στα αγγλικά. Τα παραδείγματα
ερωτημάτων που εμφανίζονται εδώ δεν τροποποιούν τις αναμνήσεις, τις συνομιλίες,
τις εργασίες ή τους στόχους σας.

## Εγκατάσταση του προγράμματος

Απαιτήσεις: Python 3.10 ή νεότερη έκδοση και ένας λογαριασμός Omi.

Εάν έχετε εγκατεστημένο το `pipx`:

```sh
pipx install omi-cli
omi --help
```

Εναλλακτικά, μπορείτε να το εγκαταστήσετε μέσα σε ένα ενεργοποιημένο εικονικό
περιβάλλον Python (virtual environment):

```sh
python -m pip install omi-cli
omi --help
```

Εάν το τερματικό δεν βρίσκει το `omi`, βεβαιωθείτε ότι το εικονικό περιβάλλον
είναι ενεργοποιημένο ή ότι ο κατάλογος όπου το `pipx` εγκαθιστά τα εκτελέσιμα
αρχεία βρίσκεται στο `PATH` σας.

## Σύνδεση του λογαριασμού σας

Ξεκινήστε τον διαδραστικό οδηγό:

```sh
omi auth login
```

Επιλέξτε σύνδεση μέσω προγράμματος περιήγησης (browser) ή την επιλογή επικόλλησης
ενός κλειδιού API προγραμματιστή Omi. Η διαδραστική εισαγωγή αποκρύπτει το κλειδί.
Αποφύγετε να το γράψετε σε μια εντολή που θα παραμείνει στο ιστορικό του τερματικού.

Για να μεταβείτε απευθείας στο πρόγραμμα περιήγησης:

```sh
omi auth login --browser
```

Συνδεθείτε στον ίδιο υπολογιστή όπου εκτελείται το τερματικό: η απάντηση
πιστοποίησης χρησιμοποιεί μια τοπική διεύθυνση. Ακολουθήστε τις οδηγίες στην οθόνη.

Στη συνέχεια, επαληθεύστε τη διαμόρφωση και την πρόσβαση στο API:

```sh
omi auth status
omi auth whoami
```

Το `status` δείχνει την τοπική κατάσταση και αποκρύπτει το μυστικό, αλλά δεν
ελέγχει την εγκυρότητα στον διακομιστή. Το `whoami` πραγματοποιεί ένα πιστοποιημένο
αίτημα. Εάν επιτύχει, επιβεβαιώνει ότι τα διαπιστευτήρια λειτουργούν, χωρίς απαραίτητα
να εμφανίζει το όνομά σας.

Η διαμόρφωση αποθηκεύεται από προεπιλογή στο `~/.omi/config.toml`. Μην μοιράζεστε
αυτό το αρχείο: μπορεί να περιέχει τα εμπιστευτικά σας διαπιστευτήρια.

## Προβολή των δεδομένων σας

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Μια κενή λίστα μπορεί απλώς να σημαίνει ότι δεν υπάρχουν στοιχεία που αντιστοιχούν
στο ερώτημα. Χρησιμοποιήστε τη βοήθεια για να ανακαλύψετε τα φίλτρα κάθε εντολής:

```sh
omi memory list --help
omi action-item list --help
```

## Λήψη JSON και πλοήγηση σε σελίδες

Τοποθετήστε την καθολική επιλογή `--json` **πριν** από την ομάδα εντολών:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Η πρώτη εντολή ζητά τις πρώτες 25 αναμνήσεις, ενώ η δεύτερη τις επόμενες 25.
Μία μόνο σελίδα δεν αποτελεί συνεπώς πλήρες αντίγραφο ασφαλείας (backup).
Η έξοδος JSON διατηρεί τα πλήρη αναγνωριστικά, ενώ οι πίνακες στην οθόνη μπορεί
να τα συντομεύσουν για προβολή.

Για να αποθηκεύσετε μια σελίδα σε αρχείο:

```sh
omi --json memory list --limit 25 --offset 0 > anamnhseis-selida-1.json
```

Αυτή η ανακατεύθυνση δημιουργεί ή αντικαθιστά το τοπικό αρχείο. Βεβαιωθείτε ότι
η εντολή ολοκληρώθηκε με επιτυχία πριν χρησιμοποιήσετε το περιεχόμενό της. Τα σφάλματα
γράφονται στην έξοδο σφαλμάτων (stderr). Ένα κενό αρχείο δεν εγγυάται ότι δεν υπάρχουν
δεδομένα. Το εξαγόμενο αρχείο μπορεί να περιέχει προσωπικές πληροφορίες: κρατήστε το ιδιωτικό.

## Αποσύνδεση (Logout)

```sh
omi auth logout
```

Αυτή η εντολή διαγράφει τα τοπικά αποθηκευμένα διαπιστευτήρια. Για να ανακαλέσετε
ένα κλειδί στον διακομιστή, χρησιμοποιήστε τη διαχείριση κλειδιών προγραμματιστή
στον λογαριασμό σας.

Για τις υπόλοιπες εντολές και προηγμένες επιλογές, δείτε τον
[κύριο οδηγό στα αγγλικά](../README.md) και `omi --help`.
