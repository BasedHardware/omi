# Οδηγός γρήγορης εκκίνησης omi-cli (Greek Quickstart)

> Πρακτικός οδηγός για άμεση αλληλεπίδραση με το Omi από το τερματικό — σχεδιασμένος για προγραμματιστές και αυτόνομους πράκτορες τεχνητής νοημοσύνης (AI agents).

Το `omi-cli` είναι η επίσημη διεπαφή γραμμής εντολών για το API ανάπτυξης του [Omi](https://omi.me). Σας επιτρέπει να διαχειρίζεστε και να αυτοματοποιείτε τους 4 βασικούς πόρους του συστήματος με δομημένο και αξιόπιστο τρόπο: αναμνήσεις (memories), συνομιλίες (conversations), στοιχεία ενεργειών / εργασίες (action items) και στόχους (goals).

* **PyPI:** [pypi.org/project/omi-cli](https://pypi.org/project/omi-cli/)
* **Επίσημη τεκμηρίωση:** [docs.omi.me/doc/developer/cli/introduction](https://docs.omi.me/doc/developer/cli/introduction)
* **Πηγαίος κώδικας:** [github.com/BasedHardware/omi/tree/main/sdks/python-cli](https://github.com/BasedHardware/omi/tree/main/sdks/python-cli)

---

## 1. Εγκατάσταση

Για να αποφύγετε διενέξεις εξαρτήσεων και να εκτελείτε το εργαλείο CLI σε απομονωμένο περιβάλλον, συνιστάται η χρήση του `pipx`:

```bash
# Συνιστάται: απομονωμένη εγκατάσταση μέσω pipx
pipx install omi-cli

# Εναλλακτική εγκατάσταση με τυπικό pip (π.χ. σε ενεργοποιημένο virtualenv)
pip install omi-cli
```

> **Σημαντική διευκρίνιση: Όνομα πακέτου vs. Όνομα εντολής**
> * Το επίσημο όνομα του πακέτου στο PyPI είναι **`omi-cli`** (το όνομα `omi` ανήκει σε άλλο, άσχετο πακέτο).
> * Η εντολή που εκτελείτε στο τερματικό είναι απευθείας **`omi`**.

Επαληθεύστε την επιτυχή εγκατάσταση ελέγχοντας την έκδοση και το μενού βοήθειας:

```bash
omi --version
omi --help
```

## 2. Έλεγχος ταυτότητας (Authentication)

Το `omi-cli` υποστηρίζει δύο βασικές μεθόδους ταυτοποίησης:

| Μέθοδος | Πεδίο χρήσης | Παράδειγμα εντολής |
| :--- | :--- | :--- |
| **Κλειδί API προγραμματιστή (`omi_dev_*`)** | Αυτοματισμοί, CI/CD, servers χωρίς οθόνη, πράκτορες AI | `omi auth login --api-key ...` ή `OMI_API_KEY` |
| **Σύνδεση OAuth μέσω περιηγητή (Google/Apple)** | Τοπικοί σταθμοί εργασίας και προσωπική χρήση | `omi auth login --browser` (Google) / `--provider apple` |

### Διαδραστική σύνδεση
Εάν εκτελέσετε την εντολή χωρίς παραμέτρους, θα εμφανιστεί μενού επιλογής:

```bash
omi auth login
# 1) Browser — Σύνδεση Google μέσω προγράμματος περιήγησης (για Apple χρησιμοποιήστε `--provider apple`)
# 2) API key — Επικόλληση κλειδιού API που δημιουργήθηκε στο app.omi.me
```

### Απευθείας σύνδεση μέσω περιηγητή
```bash
# Προεπιλεγμένη σύνδεση Google
omi auth login --browser

# Εναλλακτική σύνδεση με λογαριασμό Apple
omi auth login --browser --provider apple
```

### Χρήση κλειδιού API προγραμματιστή
Δημιουργήστε το κλειδί API από τον πίνακα ελέγχου [app.omi.me](https://app.omi.me) στην ενότητα **Developer → API Keys**:

```bash
# Αποθήκευση του κλειδιού στο τοπικό προφίλ
omi auth login --api-key omi_dev_...

# Ή ορισμός ως μεταβλητή περιβάλλοντος (ιδανικό για containers και CI/CD)
# Σημείωση: Εάν υπάρχει ήδη αποθηκευμένο κλειδί στο ενεργό προφίλ, εκτελέστε πρώτα `omi auth logout`.
export OMI_API_KEY="omi_dev_to_diko_sas_kleidi_edo"
```

### Έλεγχος κατάστασης ταυτοποίησης
* `omi auth status`: Εμφανίζει το ενεργό προφίλ και το καλυμμένο διαπιστευτήριο χωρίς δικτυακή κλήση (λειτουργεί εκτός σύνδεσης).
* `omi auth whoami`: Στέλνει ένα πιστοποιημένο αίτημα στον διακομιστή Omi για επιβεβαίωση της εγκυρότητας των διαπιστευτηρίων (απαιτεί σύνδεση στο διαδίκτυο).

```bash
omi auth status
omi auth whoami
```

### Αποσύνδεση (Logout)
```bash
omi auth logout
# Εάν χρησιμοποιείτε τη μεταβλητή OMI_API_KEY, καταργήστε την επίσης από τη συνεδρία (Bash/Zsh: `unset OMI_API_KEY`).
```

## 3. Βασικές εντολές

### Αναμνήσεις (Memories)
Ατομικές πληροφορίες περιβάλλοντος και συμπεράσματα που καταγράφονται από το Omi:

```bash
# Προβολή αποθηκευμένων αναμνήσεων
omi memory list

# Δημιουργία νέας ανάμνησης
omi memory create "Προτιμά τεχνικές και περιεκτικές απαντήσεις με παραδείγματα Python" --category work

# Ανάκτηση στοιχείων συγκεκριμένης ανάμνησης
omi memory get <MEMORY_ID>
```

### Συνομιλίες (Conversations)
Ηχογραφημένες συνομιλίες και απομαγνητοφωνήσεις από συσκευές Omi:

```bash
# Προβολή των 5 πιο πρόσφατων συνομιλιών
omi conversation list --limit 5

# Ανάκτηση λεπτομερειών συνομιλίας και πλήρους απομαγνητοφώνησης
omi conversation get <CONVERSATION_ID> --include-transcript
```

### Στοιχεία ενεργειών και εργασίες (Action Items)
Εργασίες που εντοπίζονται αυτόματα από το περιεχόμενο των διαλόγων:

```bash
# Προβολή εκκρεμών εργασιών
omi action-item list --open

# Ολοκλήρωση μιας εργασίας
omi action-item complete <ACTION_ITEM_ID>
```

### Στόχοι (Goals)
Μακροπρόθεσμοι στόχοι και μετρήσεις προόδου:

```bash
# Προβολή ενεργών στόχων
omi goal list

# Δημιουργία νέου αριθμητικού στόχου
omi goal create "Πίνε 2 λίτρα νερό καθημερινά" --type numeric --target 2 --unit liters
```

## 4. Δομημένος αυτοματισμός και έξοδος JSON (`--json`)

Το `omi-cli` υποστηρίζει πλήρως τη δημιουργία σεναρίων αυτοματισμού. Η γενική παράμετρος `--json` μορφοποιεί τα αποτελέσματα σε έγκυρη δομή JSON:

```bash
# Ανάκτηση αναμνήσεων σε JSON και εξαγωγή πεδίων με το jq
omi --json memory list | jq '.[] | {id, content, category}'

# Ανάκτηση τίτλων των πιο πρόσφατων συνομιλιών
omi --json conversation list --limit 5 | jq '.[] | {id, title: .structured.title, started_at}'

# Προβολή εκκρεμών ενεργειών σε ακατέργαστη μορφή JSON
omi --json action-item list --open | jq '.'
```

> **Κρίσιμος συντακτικός κανόνας:**
> Η επιλογή `--json` είναι **γενική παράμετρος** και πρέπει να τοποθετείται **πριν** από την υποεντολή:
> * Σωστό: `omi --json memory list`
> * Λάθος: `omi memory list --json`

### Σελιδοποίηση και εξαγωγή σε αρχείο
Χρησιμοποιήστε τις παραμέτρους `--limit` και `--offset` για περιήγηση σε μεγάλο όγκο δεδομένων:

```bash
# Σελιδοποίηση αποτελεσμάτων
omi --json memory list --limit 25 --offset 0 > anamnhseis-selida-1.json
omi --json memory list --limit 25 --offset 25 > anamnhseis-selida-2.json
```

Η ανακατεύθυνση δημιουργεί ή αντικαθιστά το τοπικό αρχείο. Επαληθεύετε πάντα την επιτυχή εκτέλεση της εντολής μέσω του κωδικού εξόδου. Τα σφάλματα καταγράφονται στη ροή τυπικού σφάλματος (stderr), επομένως ένα κενό αρχείο δεν εγγυάται απουσία δεδομένων. Τα εξαγόμενα αρχεία ενδέχεται να περιέχουν ευαίσθητα προσωπικά δεδομένα — διατηρήστε τα ασφαλή.

## 5. Κωδικοί εξόδου (Exit Codes)

Αξιόπιστη διαχείριση σφαλμάτων σε σενάρια κελύφους και ροές CI/CD:

| Κωδικός | Σημασία | Επεξήγηση |
| :---: | :--- | :--- |
| `0` | **Επιτυχία (`EXIT_OK`)** | Η λειτουργία ολοκληρώθηκε χωρίς σφάλματα. |
| `1` | **Σφάλμα χρήσης / Σύνταξη (`EXIT_USAGE`)** | Μη έγκυρες τιμές, άγνωστες επιλογές Click ή ελλιπή ορίσματα εντολής. |
| `2` | **Σφάλμα ταυτοποίησης (`EXIT_AUTH`)** | Μη επικυρωμένα διαπιστευτήρια, ληγμένο κλειδί ή ανεπαρκή δικαιώματα πρόσβασης. |
| `3` | **Σφάλμα διακομιστή (`EXIT_SERVER`)** | Απόκριση HTTP 5xx, λήξη χρονικού ορίου ή αδυναμία σύνδεσης στον διακομιστή. |
| `4` | **Όριο ρυθμού αιτημάτων (`EXIT_RATE_LIMITED`)** | Απόκριση HTTP 429 — υπερβολικός αριθμός αιτημάτων σε σύντομο διάστημα. |
| `5` | **Δεν βρέθηκε (`EXIT_NOT_FOUND`)** | Απόκριση HTTP 404 — ο ζητούμενος πόρος δεν υπάρχει. |

## 6. Παραδείγματα για διάφορα περιβάλλοντα κελύφους

### Bash / Zsh (Linux / macOS)
```bash
export OMI_API_KEY="omi_dev_to_diko_sas_kleidi_edo"

# Εκτέλεση εντολής και έλεγχος κωδικού εξόδου
omi --json memory list --limit 10
if [ $? -ne 0 ]; then
    echo "Παρουσιάστηκε σφάλμα κατά την ανάκτηση των αναμνήσεων." >&2
fi
```

### PowerShell (Windows)
```powershell
$env:OMI_API_KEY = "omi_dev_to_diko_sas_kleidi_edo"

# Μετατροπή της εξόδου JSON απευθείας σε αντικείμενο PowerShell
$memories = omi --json memory list | ConvertFrom-Json
$memories | Select-Object id, content, category

# Έλεγχος σφάλματος μέσω της μεταβλητής $LASTEXITCODE
if ($LASTEXITCODE -ne 0) {
    Write-Error "Η εντολή Omi απέτυχε με κωδικό $LASTEXITCODE."
}
```

## 7. Ενσωμάτωση τοπικού API εφαρμογής υπολογιστή (Local Desktop API)

Όταν η εφαρμογή Omi Desktop εκτελείται στον υπολογιστή σας, μπορείτε να εκτελείτε αναζητήσεις στο τοπικό ιστορικό οθόνης και περιβάλλοντος χωρίς κλήσεις στο cloud:

```bash
# Ρύθμιση τοπικού τελικού σημείου και ορισμός διαπιστευτηρίου
export OMI_LOCAL_API_URL="http://127.0.0.1:47778"
read -r -s -p "Desktop token: " OMI_LOCAL_TOKEN; echo
export OMI_LOCAL_TOKEN

# Έλεγχος κατάστασης τοπικής υπηρεσίας
omi --json local status

# Αναζήτηση στην πρόσφατη οπτική γραμμή χρόνου
omi --json local search-screen "Τριμηνιαία αναφορά" --days 7 --app Safari
```

## 8. Διαχείριση πολλαπλών προφίλ (Profiles)

Μπορείτε να διαχωρίσετε προσωπικούς λογαριασμούς, λογαριασμούς εργασίας ή περιβάλλοντα δοκιμών χρησιμοποιώντας την παράμετρο `--profile`. Οι ρυθμίσεις αποθηκεύονται στο αρχείο `~/.omi/config.toml`:

```bash
# Δημιουργία προσωπικού προφίλ και σύνδεση
omi --profile personal auth login

# Δημιουργία προφίλ εργασίας και σύνδεση
omi --profile work auth login

# Εκτέλεση εντολών με συγκεκριμένο προφίλ
omi --profile work memory list

# Χρήση προσαρμοσμένου περιβάλλοντος δοκιμών (staging)
omi --profile staging --api-base https://api.staging.omi.me memory list
```

## 9. Ασφάλεια και βέλτιστες πρακτικές

* **Μην καταχωρείτε κλειδιά στο Git:** Μην αποθηκεύετε ποτέ κλειδιά API σε δημόσια αποθετήρια. Χρησιμοποιήστε διαχειριστές μυστικών ή αρχεία περιβάλλοντος που καλύπτονται από το `.gitignore`.
* **Προστασία ιστορικού κελύφους:** Αποφύγετε την εισαγωγή κλειδιών ως απευθείας ορίσματα γραμμής εντολών σε κοινόχρηστα μηχανήματα. Προτιμήστε τη διαδραστική είσοδο ή τη μεταβλητή περιβάλλοντος `OMI_API_KEY`.
* **Δικαιώματα καταλόγου:** Σε συστήματα τύπου Unix, περιορίστε τα δικαιώματα πρόσβασης του καταλόγου `~/.omi/` αποκλειστικά στον χρήστη σας (`chmod 700 ~/.omi`).
