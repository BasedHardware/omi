# omi-cli सँ शुरुआत (Maithili Quickstart)

ई मार्गदर्शिका मैथिलीमे प्रारंभिक कमांडक विवरण दैत अछि। कमांडक नाम आ प्रोग्राम संदेश अंग्रेजीमे रहत। एतय देल गेल उदाहरण सभ अहाँक याद (memories), बातचीत (conversations), काज (action items) वा लक्ष्य (goals) मे कोनो बदलाव नहि करैत अछि।

## प्रोग्राम इंस्टॉल करब

आवश्यकता: Python 3.10 वा ओकर बादक संस्करण आ एकटा Omi खाता।

जँ अहाँक सिस्टममे `pipx` इंस्टॉल अछि:

```sh
pipx install omi-cli
omi --help
```

वा सक्रिय Python वर्चुअल एनवायरनमेंटक भीतर:

```sh
python -m pip install omi-cli
omi --help
```

जँ टर्मिनल `omi` नहि भेटबए, तँ जाँच करू जे वर्चुअल एनवायरनमेंट सक्रिय अछि वा `pipx` क डायरेक्टरी अहाँक `PATH` मे शामिल अछि।

## अपन खाता कनेक्ट करब

इंटरएक्टिव लॉगिन शुरू करू:

```sh
omi auth login
```

ब्राउज़रक माध्यम सँ लॉगिन चुनू वा अपन Omi डेवलपर API कुंजी (API key) पेस्ट करू। इंटरएक्टिव इनपुट कुंजीकेँ नुका क' रखैत अछि; टर्मिनल हिस्ट्रीमे कुंजी लिखबा सँ बचू।

सोझे ब्राउज़र सँ लॉगिन करबाक लेल:

```sh
omi auth login --browser
```

ओही कंप्यूटर पर लॉगिन करू जतय टर्मिनल खुलल अछि: प्रमाणीकरण एकटा स्थानीय पताक उपयोग करैत अछि। स्क्रीन पर देल गेल निर्देश सभक पालन करू।

एकर बाद, कॉन्फ़िगरेशन आ API पहुँचक पुष्टि करू:

```sh
omi auth status
omi auth whoami
```

`status` स्थानीय स्थितिकेँ देखाबैत अछि आ गोपनीय जानकारीकेँ नुकाबैत अछि, मुदा सर्वर पर एकर जाँच नहि करैत अछि। `whoami` एकटा प्रमाणित अनुरोध करैत अछि; सफल भेला पर, ई पुष्टि करैत अछि जे क्रेडेंशियल सही ढंग सँ काज क' रहल अछि।

कॉन्फ़िगरेशन डिफ़ॉल्ट रूप सँ `~/.omi/config.toml` मे सहेज क' राखल जाइत अछि। ई फ़ाइल ककरो संग साझा नहि करू: एहिमे अहाँक क्रेडेंशियल भ' सकैत अछि।

## अपन डेटा देखब (Querying Data)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

एकटा खाली सूचीक अर्थ भ' सकैत अछि जे अनुरोध सँ मेल खएनिहार कोनो डेटा नहि अछि। प्रत्येक कमांडक फ़िल्टरक बारेमे जनबाक लेल सहायता देखू:

```sh
omi memory list --help
omi action-item list --help
```

## JSON प्राप्त करब आ पन्ना बदलब (Pagination)

ग्लोबल `--json` विकल्पकेँ कमांड ग्रुप सँ **पहिले** लगाऊ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

पहिल कमांड पहिल २५ टा याद लानैत अछि; दोसर कमांड अगिला २५ टा लानैत अछि। एकर माने एकटा पन्ना पूरा बैकअप नहि अछि। JSON आउटपुट पूरा आईडी रखैत अछि, जखन कि टेबल ओकरा छोट क' क' देखा सकैत अछि।

कोनो पन्नाकेँ फ़ाइलमे सहेजबाक लेल:

```sh
omi --json memory list --limit 25 --offset 0 > yaadan-page-1.json
```

ई रीडायरेक्शन स्थानीय फ़ाइल बनबैत अछि वा बदलि दैत अछि। उपयोग सँ पहिने जाँच करू जे कमांड सफलतापूर्वक पूरा भेल कि नहि। निर्यात कएल फ़ाइलमे व्यक्तिगत डेटा भ' सकैत अछि: एकरा सुरक्षित राखू।

## लॉगआउट करब

```sh
omi auth logout
```

ई कमांड स्थानीय रूप सँ सहेजल क्रेडेंशियल हटा दैत अछि। सर्वर पर कुंजी रद्द करबाक लेल, अपन खातात डेवलपर पोर्टलक उपयोग करू।

आन कमांड आ उन्नत विकल्पक लेल, [मुख्य अंग्रेजी मार्गदर्शिका](../README.md) आ `omi --help` देखू।
