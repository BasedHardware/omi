# omi-cli त्वरित मार्गदर्शिका (Maithili Quickstart)

> टर्मिनल सँ सोझे Omi क उपयोग करवाक लेल व्यावहारिक मार्गदर्शिका — डेवलपर्स आ स्वायत्त AI एजेंट्स लेल निर्मित।

`omi-cli` [Omi](https://omi.me) डेवलपर API लेल आधिकारिक कमांड-लाइन इंटरफ़ेस (CLI) अछि। ई Omi क 4 मुख्य संसाधन सभ धरि संरचित पहुँच प्रदान करैत अछि: स्मृति (memories), बातचीत (conversations), कार्य बिंदु (action items), आ लक्ष्य (goals)।

* **PyPI:** [pypi.org/project/omi-cli](https://pypi.org/project/omi-cli/)
* **आधिकारिक दस्तावेज़ीकरण:** [docs.omi.me/doc/developer/cli/introduction](https://docs.omi.me/doc/developer/cli/introduction)
* **स्रोत कोड:** [github.com/BasedHardware/omi/tree/main/sdks/python-cli](https://github.com/BasedHardware/omi/tree/main/sdks/python-cli)

## 1. संस्थापन (Installation)

सिस्टम निर्भरता सभक बीच टकराव सँ बचबाक लेल आ एकटा पृथक वातावरण बनएने रखबाक लेल, `pipx` क उपयोग करवाक दृढ़ अनुशंसा कएल जाइत अछि:

```bash
# अनुशंसित विधि: pipx द्वारा पृथक संस्थापन
pipx install omi-cli

# वैकल्पिक विधि: मानक pip द्वारा संस्थापन (उदा. वर्चुअल वातावरण मे)
pip install omi-cli
```

> **महत्वपूर्ण स्पष्टीकरण: पैकेज नाम बनाम कमांड नाम**
> * PyPI पर आधिकारिक पैकेजक नाम **`omi-cli`** अछि (ध्यान राखू जे `omi` नाम क पैकेज एकटा भिन्न आ असंबद्ध प्रोजेक्ट अछि)।
> * टर्मिनल मे चलाओल जाए वाला वास्तविक कमांड मात्र **`omi`** अछि।

संस्थापन सफल भेल कि नहि, एकर पुष्टि संस्करण आ सहायता मेनू देखि कए करू:

```bash
omi --version
omi --help
```

## 2. प्रमाणीकरण (Authentication)

`omi-cli` प्रमाणीकरणक दू मुख्य विधियक समर्थन करैत अछि:

| विधि | प्रयोजन | कमांडक उदाहरण |
| :--- | :--- | :--- |
| **डेवलपर API कुंजी (`omi_dev_*`)** | स्वचालन, CI/CD, हेडलेस सर्वर, AI एजेंट्स | `omi auth login --api-key ...` अथवा `OMI_API_KEY` |
| **ब्राउज़र OAuth लॉगिन (Google/Apple)** | व्यक्तिगत कंप्यूटर पर स्थानीय विकास | `omi auth login --browser` (Google) / `--provider apple` |

### इंटरैक्टिव लॉगिन
बिना कोनो अतिरिक्त पैरामीटर क कमांड चलएला पर एकटा इंटरैक्टिव प्रॉम्प्ट शुरू होइत अछि, जे इनपुट समय अहाँक कुंजी कए सुरक्षित रूप सँ नुका कए राखैत अछि:

```bash
omi auth login
# 1) Browser — ब्राउज़रक माध्यम सँ Google द्वारा लॉगिन करू (Apple लेल `--provider apple` फ्लैग जोड़ू)
# 2) API key — app.omi.me सँ प्राप्त डेवलपर API कुंजी पेस्ट करू
```

### सोझे ब्राउज़र लॉगिन
```bash
# मानक Google खाता सँ लॉगिन
omi auth login --browser

# Apple खाता सँ लॉगिन
omi auth login --browser --provider apple
```

### API कुंजी द्वारा गैर-इंटरैक्टिव लॉगिन
हेडलेस वातावरण आ स्वचालित स्क्रिप्ट्स लेल, अहाँ सोझे कमांड-लाइन फ्लैग अथवा पर्यावरण चरक उपयोग कए सकैत छी:

```bash
# फ्लैग द्वारा सोझे कुंजी प्रदान करू
omi auth login --api-key "omi_dev_xxxxxxxxxxxxxxxxxxxxxxxx"

# अथवा पर्यावरण चर सेट करू (सत्र भरि स्वतः पहिचान लेल जाइत अछि)
export OMI_API_KEY="omi_dev_xxxxxxxxxxxxxxxxxxxxxxxx"
```

### प्रमाणीकरण स्थितिक सत्यापन
```bash
# स्थानीय क्रेडेंशियल क स्थिति, प्रदाता आ प्रोफ़ाइल जाँचू (ऑफलाइन सेहो काज करैत अछि)
omi auth status

# सक्रिय टोकन अथवा API कुंजी क सर्वर पर सत्यापन करू आ उपयोगकर्ता विवरण प्राप्त करू
omi auth whoami

# सुरक्षित रूप सँ लॉगआउट करू आ स्थानीय टोकन हटाउ
omi auth logout
```

## 3. मुख्य संसाधन आ कमांड्स

`omi-cli` ओहि 4 मुख्य संरचना सभक प्रबंधन करैत अछि जाहि पर Omi पारिस्थितिकी तंत्र निर्भर अछि:

### क) स्मृतियाँ (Memories)
स्मृतियाँ बातचीत सँ स्वचालित रूप सँ निकालल गेल मुख्य तथ्य आ संदर्भ अछि।

```bash
# सभ स्मृतियक सूची देखू
omi memory list

# पृष्ठ सीमा निर्धारित कए सूची देखू
omi memory list --limit 10

# कोनो विशिष्ट स्मृतिक विस्तृत विवरण आईडी द्वारा प्राप्त करू
omi memory get <memory-id>
```

### ख) बातचीत (Conversations)
Omi हार्डवेयर अथवा ऐप्स द्वारा रिकॉर्ड कएल गेल संपूर्ण संवाद।

```bash
# हालक बातचीत सभक सूची प्राप्त करू
omi conversation list

# कोनो विशिष्ट बातचीत क संपूर्ण विवरण आ ट्रांसक्रिप्ट देखू
omi conversation get <conversation-id>
```

### ग) कार्य बिंदु (Action Items)
बातचीत सँ पहिचान कएल गेल कार्य, दायित्व आ आगामी कार्य बिंदु।

```bash
# सभ लंबित आ पूर्ण कार्य बिंदु देखू
omi action-item list

# कोनो विशिष्ट कार्य बिन्दुक विवरण देखू
omi action-item get <item-id>
```

### घ) लक्ष्य (Goals)
उपयोगकर्ताक दीर्घकालिक लक्ष्य आ योजना।

```bash
# निर्धारित लक्ष्य सभक सूची प्राप्त करू
omi goal list

# कोनो विशिष्ट लक्ष्यक प्रगति आ विवरण देखू
omi goal get <goal-id>
```

## 4. स्वचालन आ JSON स्क्रिप्टिंग (JSON & jq)

AI एजेंट्स, पाइपलाइन, आ शेल स्क्रिप्ट्स मे एकीकरण लेल, `omi-cli` संपूर्ण आउटपुट मशीन-पठनीय JSON प्रारूप मे प्रदान करैत अछि।

### स्वर्ण नियम: `--json` क स्थान
> **अत्यंत महत्वपूर्ण:** `--json` फ्लैग केँ मुख्य कमांड `omi` क तुरंत बाद, उप-कमांड सँ पहिने राखल अनिवार्य अछि:

```bash
# सही प्रारूप:
omi --json memory list
omi --json conversation list

# अमान्य प्रारूप (त्रुटि उत्पन्न कए सकैत अछि):
omi memory list --json
```

### व्यावहारिक `jq` पाइपलाइन उदाहरण

```bash
# 1. सभ स्मृति सभक संक्षिप्त सामग्री आ समय निकालू
omi --json memory list | jq '.[] | {id: .id, content: .content, created_at: .created_at}'

# 2. सबसँ हालक बातचीत क पहिचान (आईडी) प्राप्त करू
RECENT_ID=$(omi --json conversation list --limit 1 | jq -r '.[0].id')
echo "हालक बातचीत आईडी: $RECENT_ID"

# 3. लंबित कार्य बिंदु सभक मात्र विवरण फिल्टर करू
omi --json action-item list | jq -r '.[] | select(.completed == false) | .description'
```

### पृष्ठकरण (Pagination)
पैघ डेटासेट लेल, `--limit` आ `--offset` पैरामीटरक उपयोग करू:

```bash
# पहिल 20 टा परिणाम प्राप्त करू
omi --json memory list --limit 20 --offset 0

# अगिला 20 टा परिणाम प्राप्त करू
omi --json memory list --limit 20 --offset 20
```

## 5. निकास कोड अनुबंध (Exit Codes Contract)

`omi-cli` [omi_cli/errors.py](https://github.com/BasedHardware/omi/blob/main/sdks/python-cli/omi_cli/errors.py) मे परिभाषित मानक निकास कोड क पालन करैत अछि, जाहि सँ स्क्रिप्ट्स मे त्रुटि प्रबंधन सरल भऽ जाइत अछि:

| निकास कोड | प्रतीकात्मक नाम | अर्थ आ निवारण |
| :---: | :--- | :--- |
| **0** | `EXIT_OK` | ऑपरेशन पूर्णतः सफल रहल। |
| **1** | `EXIT_USAGE` | अमान्य कमांड सिंटैक्स, अज्ञात तर्क, अथवा अनुपलब्ध आवश्यक फ्लैग। |
| **2** | `EXIT_AUTH` | क्रेडेंशियल अनुपलब्ध, अमान्य API कुंजी, अथवा समाप्त भेल सत्र। |
| **3** | `EXIT_SERVER` | सर्वर त्रुटि (5xx) अथवा कनेक्शन विफलता। |
| **4** | `EXIT_RATE_LIMITED` | अनुरोध दर सीमा (Rate Limit 429) पार भेल। |
| **5** | `EXIT_NOT_FOUND` | अनुरोध कएल गेल संसाधन (आईडी) अस्तित्व मे नहि अछि (404)। |

### बैश स्क्रिप्ट मे त्रुटि प्रबंधन उदाहरण:
```bash
if ! omi --json memory list > /dev/null 2>&1; then
  EXIT_CODE=$?
  case $EXIT_CODE in
    1) echo "त्रुटि: अमान्य उपयोग अथवा फ्लैग।" ;;
    2) echo "त्रुटि: प्रमाणीकरण विफल भेल। कृपया 'omi auth login' चलबाक प्रयास करू।" ;;
    3) echo "त्रुटि: सर्वर त्रुटि अथवा कनेक्शन विफलता भेल।" ;;
    4) echo "त्रुटि: दर सीमा (Rate limit) पार भेल। किछु समय बाद पुनः प्रयास करू।" ;;
    5) echo "त्रुटि: संसाधन नहि भेटल।" ;;
    *) echo "त्रुटि: कोड $EXIT_CODE क संग अप्रत्याशित समस्या भेल।" ;;
  esac
  exit $EXIT_CODE
fi
```

## 6. उन्नत उपयोग: स्थानीय API आ बहु-प्रोफ़ाइल

### स्थानीय डेस्कटॉप API एकीकरण
जखन Omi डेस्कटॉप ऐप अहाँक कंप्यूटर पर चलि रहल होइ, तखन अहाँ बाह्य क्लाउड क बदला स्थानीय इंस्टेंस सँ कनेक्ट कए सकैत छी:

```bash
# स्थानीय डेस्कटॉप API एंडपॉइंट निर्धारित करू
export OMI_LOCAL_API_URL="http://127.0.0.1:47778"

# स्थानीय टोकन सेट करू
export OMI_LOCAL_TOKEN="your_local_desktop_token"

# स्थानीय सर्वर सँ स्थिति जाँचू
omi auth status
```

### एकाधिक प्रोफ़ाइल प्रबंधन
अहाँ विभिन्न वातावरण (उदा. व्यक्तिगत, कार्य, स्टेजिंग) लेल भिन्न-भिन्न प्रोफ़ाइल सुरक्षित रखि सकैत छी:

```bash
# स्टेजिंग प्रोफ़ाइल मे लॉगिन करू
omi --profile staging auth login --api-key "omi_dev_staging_key"

# स्टेजिंग प्रोफ़ाइल सँ कमांड चलाउ
omi --profile staging memory list
```
