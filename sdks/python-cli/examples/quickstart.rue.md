# Першы крокы з omi-cli

Тот провідник описує першы команды з omi-cli по русиньскы. Назвы командох і повідомліня програму зістають по анґліцькы. Приклады в тім провіднику не міняють твої памяті (memories), розговоры (conversations), акційны пункты (action items) ани цілі (goals).

## Установлїня

Потребуєте: Python 3.10 або новшый і конто Omi.

Як `pipx` є установленый:

```sh
pipx install omi-cli
omi --help
```

Алтернатівно можете установити го в актівнім віртуалнім середовищи Pythona:

```sh
python -m pip install omi-cli
omi --help
```

Як термінал не найтить `omi`, провірьте, ці віртуалне середовище є актівне або ці каталог pipx є в `$PATH`.

## Звязати ся з контом

Зачніть інтерактівный помічник логованя:

```sh
omi auth login
```

Выберьте логованя через браузер або вложывші API-ключ од Omi розвояра. Інтерактівне логованя укриває ваш ключ; не лишайте го в історії термінала.

Про логованя прямо через браузер:

```sh
omi auth login --browser
```

Логуйте ся на тім самім компютрі, де біжыть термінал: одповідь авторизації хоснує локалну адресу. Поступайте подля інструкцій на екрані.

Пак провірьте конфіґурацію і API-ключ:

```sh
omi auth status
omi auth whoami
```

`status` показує локалный стан і укриває секреты, але не провірює дійсность на сервері. `whoami` чинить пожаданя з авторизаційов; як ся удасть, потвердить, же вашы даны логованя працують, не показуючі ваше імя.

Конфіґурація є звычайно зазначена в `~/.omi/config.toml`. Не давайте того файла дале: може в собі містити секреты логованя.

## Огляданя даных

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Порожній список може просто значити, же ніт даных одповідаючіх пожаданю. Про пізнаня доступных філтрів каждой команды погляньте до помочі:

```sh
omi memory list --help
omi action-item list --help
```

## JSON вывод і сторінкованя

Дайте ґлобалну опцію `--json` **перед** ґрупов команд:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Перша команда пожадать о першых 25 памятёх; друга о наступных 25. Една сторінка не є повным забеспечінём. JSON вывод заховає вшыткы ідентіфікаторы, а таблиці на екрані годны їх скорчити про огляд.

Жебы захранити єдну сторінку до файлу:

```sh
omi --json memory list --limit 25 --offset 0 > память-сторінка-1.json
```

То переадресованя створить або перепише локалный файл. Перед хоснованём обсягу провірьте, ці команда ся успішно докінчіла. Хыбы записують ся до stderr; порожній файл не дає ґаранції, же даных ніт. Експортованы файлы можуть містити пріватны даны: хороните їх.

## Выход (Logout)

```sh
omi auth logout
```

Тота команда выдалить локално захованы даны логованя. Про одкликаня ключа на сервері хоснуйте управліня ключами розвояра в своїм конті.

Про далшы команды і росшырены опції погляньте до [анґліцького головного провідника](../README.md) і `omi --help`.
