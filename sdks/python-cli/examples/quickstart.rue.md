# Першы крокы з omi-cli

Тота навчанка обяснює першы приказы (commands) omi-cli по русиньскы. Назвы приказох і повідомліня програму зіставають по анґліцькы. Приклады гляданя, котры сься тука представлены, не міняють твої памяті (memories), розговоры (conversations), задачи (action items) ани твої цілі (goals).

## Іншталація

Потрібне: Python 3.10 або новшый, і конто Omi.

Кедь маєш `pipx`:

```sh
pipx install omi-cli
omi --help
```

Можеш го тыж іншталовати в актівнім Python-віртуалнім середовищу:

```sh
python -m pip install omi-cli
omi --help
```

Кедь термінал не находить `omi`, пересвідч ся, же віртуалне середовище робить або же тека `pipx` є в `$PATH`.

## Злучиня конта

Зачни інтерактівного помічника:

```sh
omi auth login
```

Выберь приголошіня через браузер або вложіня ключа Omi developer API. Інтерактівне вложіня скрывать ключ; не пиши го до приказу, котрый зістане в історії термінала.

Жебы ити просто до браузера:

```sh
omi auth login --browser
```

Приголош ся на тім самім компютерї як термінал: одповідь автентифікації йде до локалной адресы. Слідуй інштрукціям на екранї.

Потім перевірь конфіґурацію і приступ API:

```sh
omi auth status
omi auth whoami
```

`status` показує локалный стан і скрывать секрет, але не перевірять платность на серверї. `whoami` робить автентифікованый жадость; кедь ся подарить, є ясно, же приступовы даны роблять, без показованя твого імена.

Конфіґурація ся уложыть по дефаулту в `~/.omi/config.toml`. Не діли ся тот файл: може обсяговати пріватны приступовы даны.

## Огляданя твоїх даных

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Порожный список звычайно значіть лем тото, же нич не одповідать гляданю. Хоснуй поміч, жебы найти філтры каждого приказу:

```sh
omi memory list --help
omi action-item list --help
```

## JSON і стороны

Постав ґлоґалну опцію `--json` **перед** ґрупов приказох:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Першый приказ просить першых 25 памяті; другый просить наступных 25. Една сторона не є цілковита копія. JSON усховає цілы чісла, а табліцї на екранї можуть їх скорчіти.

Жебы усховати сторону до файлу:

```sh
omi --json memory list --limit 25 --offset 0 > память-сторона-1.json
```

Тото переменованя створить або перепише локалный файл. Пересвідч ся, же приказ є уж закінченый, перед тым як хосновати його обсяг. Хыбы ся пишуть до хыбового выхода (stderr); порожный файл не є доказом, же нит даных. Експортованый файл може обсяговати пріватны інформації: держ го в тайні.

## Выход

```sh
omi auth logout
```

Тот приказ знічтожать локално усхованы приступовы даны. Жебы значінчіти ключ на серверї, хоснуй керованя developer-ключами во властнім контї.

По веце приказів і опцій поглянь на [головну навчанку по анґліцькы](../README.md) і `omi --help`.
