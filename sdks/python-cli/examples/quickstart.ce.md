# omi-cli сиха куьйгалла

ХӀокху куьйгалло `omi-cli` юьхьанцара омранаш нохчийн маттахь (Chechen) кхетадо. Омранийн цӀераш а, программийн хаамаш а ингалсан маттахь дуьсур ду. Кхузахь далийна талламан масалша хьан дагалецамаш (memories), къамелаш (conversations), дан деза гӀуллакхаш (action items), я Ӏалашонаш (goals) хийцар дац.

## Программа хӀоттор (Installation)

Оьшуш дерг: Python 3.10 я керлачух верси а, Omi аккаунт а.

Нагахь хьан `pipx` хӀоттийна ялахь:

```sh
pipx install omi-cli
omi --help
```

Иштта хьоьга иза болх беш йолчу Python виртуальни гуонехь (virtual environment) хӀотто а тарло:

```sh
python -m pip install omi-cli
omi --help
```

Нагахь терминалехь `omi` омра ца карахь, виртуальни гуо жигар буй я `pipx` некъ хьан `$PATH` юкъахь буй хьажа.

## Хьан аккаунт дӀахоттор (Authentication)

Къамелан гӀоьнча волавала:

```sh
omi auth login
```

Браузер чухула чугӀо я хьан Omi developer API key чуязъе. ХӀокху гӀоьнчас догӀа къайладоккхур ду; терминалан исторехь дуьсучу омранашкахь догӀа ма язде.

Браузер чу нийсса ваха:

```sh
omi auth login --browser
```

Терминал болх беш йолчу компьютеран тӀехь чугӀо: тешаллин жоьпо меттигера адрес леладо. Экранан тӀерачу тӀедилламашца гӀо.

Цул тӀаьхьа нисдарш а, API тӀекхачар а талла:

```sh
omi auth status
omi auth whoami
```

`status` меттигера хьал гойту а, къайле ларйо а, амма серверехь цуьнан нийсалла ца толлу. `whoami` тешаллин дехар дохьуьйту; нагахь иза кхиаме хилахь, хьан цӀе ца гойтуш тешаллаш болх беш хилар тӀечӀагӀдо.

Нисдарш дукха хьолахь `~/.omi/config.toml` чохь Ӏалашдо. ХӀара файл нахана ма дӀасаяхьита: цунна чохь къайлаха тешаллаш хила тарло.

## Хьан хаамаш таллар (Inspection)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Еса исписка лахарца цхьа а хаам ца карийна хилар бен кхин хӀумма а дац. ХӀора омран чохь гӀирсаш каро гӀо леладе:

```sh
omi memory list --help
omi action-item list --help
```

## JSON схьаэцар а, агӀонаш дӀасаяхар а (Pagination)

Омранийн тобанал **хьалха** глобальни `--json` харжам хӀоттабе:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Хьалхарчу омрано дуьххьарлера 25 дагалецам доьху; шолгӀачо — тӀаьхьадогӀу 25 дагалецам. Цхьа агӀо юьззина резервни копи (backup) яц. JSON жамӀаша берриге билгалдахарш Ӏалашдо, ткъа экранан таблицаша уьш гайта кегийра дан а тарло.

АгӀо файлан чу Ӏалашъян:

```sh
omi --json memory list --limit 25 --offset 0 > дагалецамаш-агӀо-1.json
```

ХӀокху некъо меттигера файл кхуллу я хийца тарло. Чулацам лелоле хьалха омра кхиаме чекхдаьлла хилар хьажа. ГӀалаташ гӀалатийн агӀон тӀехь (stderr) яздо; есачу файло хаамаш бац бохург дац. Экспорт йиначу файлехь хьан шайн долара хаамаш хила тарло: уьш ларде.

## Аккаунт чуьра араялар (Logout)

```sh
omi auth logout
```

ХӀокху омрано меттигехь Ӏалашдина тешаллаш дӀадоху. Серверан тӀера догӀа дӀадаккха, хьан аккаунтехь developer key урхалла леладе.

Кхечу омранашна а, тӀехьажаршна а, [ингалсан маттахь коьрта куьйгалла](../README.md) а, `omi --help` а хьажа.
