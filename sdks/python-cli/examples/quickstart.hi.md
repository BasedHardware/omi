# omi-cli के साथ शुरुआत

यह गाइड हिंदी में पहले कुछ कमांड दिखाती है। कमांड के नाम और प्रोग्राम के संदेश
अंग्रेज़ी में रहते हैं। यहाँ दिए गए पढ़ने के उदाहरण आपकी यादें, बातचीत,
कार्य-सूची या लक्ष्य नहीं बदलते।

## प्रोग्राम इंस्टॉल करें

आवश्यकताएँ: Python 3.10 या उससे नया संस्करण और एक Omi खाता।

> ध्यान दें: PyPI पर पैकेज का नाम **`omi-cli`** है, जबकि इंस्टॉल के बाद चलने वाली
> कमांड का नाम **`omi`** है। PyPI पर `omi` नाम का एक अलग, असंबंधित पैकेज भी है —
> उसे इंस्टॉल न करें।

यदि `pipx` इंस्टॉल है:

```sh
pipx install omi-cli
omi --help
```

वैकल्पिक रूप से, सक्रिय Python वर्चुअल एनवायरनमेंट में:

```sh
python -m pip install omi-cli
omi --help
```

अगर टर्मिनल को `omi` नहीं मिलता, तो जाँचें कि वर्चुअल एनवायरनमेंट सक्रिय है या
`pipx` की executable डायरेक्टरी आपके `PATH` में है।

## अपना खाता जोड़ें

इंटरैक्टिव सहायक शुरू करें:

```sh
omi auth login
```

ब्राउज़र से लॉगिन चुनें, या Omi का डेवलपर API key चिपकाने का विकल्प चुनें।
इंटरैक्टिव इनपुट key को छिपाता है; ऐसी कमांड में key न लिखें जो टर्मिनल
इतिहास में रह जाए।

सीधे ब्राउज़र के लिए:

```sh
omi auth login --browser
```

लॉगिन उसी कंप्यूटर पर करें जिस पर टर्मिनल चल रहा है, क्योंकि प्रमाणीकरण
स्थानीय पते पर लौटता है। स्क्रीन पर दिखने वाले निर्देशों का पालन करें।

इसके बाद कॉन्फ़िगरेशन और API पहुँच जाँचें:

```sh
omi auth status
omi auth whoami
```

`status` स्थानीय स्थिति दिखाता है और secret छिपाता है, पर सर्वर पर उसकी
वैधता की जाँच नहीं करता। `whoami` एक प्रमाणित अनुरोध भेजता है; सफल होने का
अर्थ है कि क्रेडेंशियल काम कर रहे हैं।

कॉन्फ़िगरेशन डिफ़ॉल्ट रूप से `~/.omi/config.toml` में सहेजा जाता है। यह फ़ाइल
साझा न करें: इसमें आपके क्रेडेंशियल हो सकते हैं।

## अपना डेटा देखें

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

खाली सूची का अर्थ केवल यह हो सकता है कि क्वेरी से मेल खाता कोई आइटम नहीं है।
किसी कमांड के फ़िल्टर जानने के लिए help देखें:

```sh
omi memory list --help
omi action-item list --help
```

## JSON प्राप्त करें और पेज बदलें

वैश्विक विकल्प `--json` को कमांड समूह से **पहले** रखें:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

पहली कमांड पहले 25 रिकॉर्ड माँगती है; दूसरी अगले 25। इसलिए एक पेज पूरा
बैकअप नहीं है। JSON आउटपुट पूरे आइडेंटिफ़ायर रखता है, जबकि टेबल उन्हें छोटा
कर सकती हैं।

किसी पेज को फ़ाइल में सहेजने के लिए:

```sh
omi --json memory list --limit 25 --offset 0 > yaadein-page-1.json
```

यह रीडायरेक्शन स्थानीय फ़ाइल बनाता या बदलता है। सामग्री उपयोग करने से पहले
जाँचें कि कमांड सफल रही। त्रुटियाँ stderr पर लिखी जाती हैं; खाली फ़ाइल डेटा न
होने का प्रमाण नहीं है। निर्यात की गई फ़ाइल में व्यक्तिगत जानकारी हो सकती है:
इसे निजी रखें।

## लॉग आउट करें

```sh
omi auth logout
```

यह कमांड स्थानीय रूप से सहेजे गए क्रेडेंशियल हटाता है। सर्वर पर key रद्द करने
के लिए अपने खाते के डेवलपर key प्रबंधन का उपयोग करें।

अन्य कमांड और उन्नत विकल्पों के लिए अंग्रेज़ी मुख्य गाइड देखें:
[../README.md](../README.md) और `omi --help`.
