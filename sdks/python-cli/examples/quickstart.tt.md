# omi-cli буенча кыскача кулланма

Бу кулланма `omi-cli` өчен беренче боерыкларны татар телендә (Татарча) аңлата. Боерык исемнәре һәм программа хәбәрләре инглиз телендә кала. Монда китерелгән карап чыгу мисаллары сезнең истәлекләрегезне (memories), сөйләшүләрегезне (conversations), эш пунктларыгызны (action items) яки максатларыгызны (goals) үзгәртми.

## Программаны урнаштыру

Таләпләр: Python 3.10 яки яңарак юрама һәм Omi аккаунты.

Әгәр сездә `pipx` урнаштырылган булса:

```sh
pipx install omi-cli
omi --help
```

Шулай ук аны актив Python виртуаль мохитенә (virtual environment) урнаштырырга мөмкин:

```sh
python -m pip install omi-cli
omi --help
```

Әгәр терминалда `omi` боерыгы табылмаса, виртуаль мохитнең актив булуын яисә `pipx` урнаштыру директориясенең `$PATH` үзгәрүчесендә булуын тикшерегез.

## Аккаунтыгызны тоташтыру

Интерактив ярдәмчене башлау:

```sh
omi auth login
```

Браузер аша керү яки Omi developer API ачкычын кую вариантын сайлагыз. Интерактив кертү ачкычны яшерә; терминал тарихында кала торган боерыкларда аны язмагыз.

Браузерга турыдан-туры күчү өчен:

```sh
omi auth login --browser
```

Терминал эшләгән санакның үзендә үк керегез: аутентификация җавабы локаль адрес куллана. Экрандагы күрсәтмәләрне үтәгез.

Аннан соң көйләүләрне һәм API-га керү мөмкинлеген тикшерегез:

```sh
omi auth status
omi auth whoami
```

`status` локаль халәтне күрсәтә һәм серне яшерә, ләкин сервердагы гамәлдә булуын тикшерми. `whoami` аутентификацияләнгән сорау җибәрә; әгәр уңышлы булса, исемегезне күрсәтмичә генә таныклыкларның эшләвен раслый.

Конфигурация гадәттә `~/.omi/config.toml` файлында саклана. Бу файл белән уртаклашмагыз: анда яшерен таныклыклар булырга мөмкин.

## Мәгълүматларыгызны карап чыгу

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Буш исемлек бары тик эзләүгә туры килгән мәгълүмат булмавын аңлатырга мөмкин. Һәр боерыктагы фильтрларны табу өчен ярдәм бүлеген кулланыгыз:

```sh
omi memory list --help
omi action-item list --help
```

## JSON алу һәм битләү (Pagination)

Глобаль `--json` опциясен боерыклар төркеме **алдыннан** куегыз:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Беренче боерык беренче 25 истәлекне сорый; икенчесе — чираттагы 25 истәлекне. Бер бит тулы резерв күчермә (backup) түгел. JSON чыгышы тулы идентификаторларны саклый, ә экрандагы таблицалар аларны кыскартып күрсәтергә мөмкин.

Битне файлга саклау өчен:

```sh
omi --json memory list --limit 25 --offset 0 > истәлекләр-бит-1.json
```

Бу юнәлтү локаль файлны төзи яки алмаштыра. Эчтәлеген кулланыр алдыннан боерыкның уңышлы тәмамлануын тикшерегез. Хаталар хата агымына (stderr) языла; буш файл мәгълүмат юк дигәнне аңлатмый. Экспортланган файлда шәхси мәгълүмат булырга мөмкин: аны саклагыз.

## Аккаунттан чыгу

```sh
omi auth logout
```

Бу боерык локаль сакланган таныклыкларны бетерә. Сервердагы ачкычны юкка чыгару өчен шәхси аккаунтыгызда developer key идарәсен кулланыгыз.

Башка боерыклар һәм өстәмә көйләүләр өчен [төп инглизчә кулланманы](../README.md) һәм `omi --help` боерыгын карагыз.
