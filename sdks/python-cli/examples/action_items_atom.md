# Publish Omi Action Items as an Atom Syndication Feed (.atom)

Use this recipe to follow your Omi task backlog in any standard feed reader: it converts one or more
`action-item list` JSON exports into a valid Atom 1.0 syndication feed (RFC 4287). Applications like
**NetNewsWire**, **Thunderbird**, **Feedly**, or Slack RSS integrations can subscribe to the generated feed
over a `file://` URL or local web server. Each action item becomes a feed entry with completion status, due
dates, timestamps, and an HTML content card.

---

## Prerequisites

You need Python 3.10+ and an authenticated `omi-cli` installed:

```sh
pip install omi-cli
omi auth login
```

Export your action items (up to 200 items per batch):

```sh
omi --json action-item list --limit 200 > tasks.json
```

Verify that the export file was populated before running the converter. This is one page; to retrieve more,
re-run with `--offset 200` (and so on) into separate files (e.g. `p1.json p2.json`) and pass them together.
The converter deduplicates items by their ID.

---

## Quickstart

### 1. Direct Pipeline Stream (Stdout)

Generate the Atom feed directly from the CLI output stream into stdout:

```sh
set -o pipefail
omi --json action-item list --limit 200 | python action_items_to_atom.py -
```

### 2. Export to a Feed File

Write the Atom XML feed to a standalone file:

```sh
python action_items_to_atom.py tasks.json -o ~/Feeds/omi_tasks.atom
```

### 3. Filter to Open Tasks Only

Generate a feed containing only open, uncompleted action items:

```sh
python action_items_to_atom.py tasks.json --status open -o ~/Feeds/pending_tasks.atom
```

### 4. Custom Feed Title

Set a custom feed title for your reader:

```sh
python action_items_to_atom.py tasks.json --title "Work Backlog" -o ~/Feeds/work.atom
```

---

## CLI Options

| Option | Flag | Description | Default |
| :--- | :--- | :--- | :--- |
| `inputs` | Positional | One or more JSON export files, or `-` for stdin | *(Required)* |
| `--output` | `-o` | Destination Atom XML file path | `stdout` |
| `--status` | `--status` | Filter items: `all`, `open`, or `completed` | `all` |
| `--title` | `--title` | Custom Atom feed title | `"Omi Action Items"` |
| `--overwrite` | `--overwrite` | Allow overwriting existing destination files | `False` |

## Integration Workflows

### NetNewsWire / Feedly Local Subscription

1. Generate your feed into a local folder:
   ```sh
   python action_items_to_atom.py tasks.json --overwrite -o ~/.local/share/feeds/omi_tasks.atom
   ```
2. In NetNewsWire or your desktop feed reader, choose **File > New Web Feed...** and enter:
   `file:///home/user/.local/share/feeds/omi_tasks.atom`
3. Whenever you re-run the export, your feed reader will highlight new tasks and completed items.

### Slack / Discord Webhook Notification

Pipe your Atom feed into automated feed webhooks or RSS bots to notify team channels of new pending action
items captured by Omi.

## Design Principles

- **Zero Third-Party Dependencies**: Pure Python standard library (`xml.sax.saxutils`, `json`, `datetime`, `pathlib`).
- **RFC 4287 & RFC 3339 Compliant**: Full XML syndication conformance with normalized UTC timestamps.
- **Control Character Filtering**: Automatically drops unencodable C0 control codes and lone surrogates.
- **Safe POSIX Permissions**: Creates files using default umask (`0644`) rather than restricted tempfile modes.
- **Atomic File Operations**: Uses temporary file replacement when `--overwrite` is specified.
- **Piped Stream Hygiene**: Native `BrokenPipeError` signal handling for commands like `| head`.
