# omi-cli ᱞᱟᱹᱜᱤᱫ ᱩᱥᱟᱹᱨᱟ ᱩᱫᱩᱜ-ᱥᱚᱫᱚᱨ

ᱱᱚᱶᱟ ᱩᱫᱩᱜ-ᱥᱚᱫᱚᱨ ᱫᱚ ᱥᱟᱱᱛᱟᱲᱤ (Santali) ᱛᱮ `omi-cli` ᱨᱮᱱᱟᱜ ᱮᱛᱚᱦᱚᱵ ᱠᱚᱢᱟᱱᱰ ᱠᱚ ᱵᱩᱡᱷᱟᱹᱣ ᱚᱪᱚᱭᱟ᱾ ᱠᱚᱢᱟᱱᱰ ᱧᱩᱛᱩᱢ ᱟᱨ ᱯᱨᱚᱜᱨᱟᱢ ᱨᱮᱱᱟᱜ ᱠᱷᱚᱵᱚᱨ ᱠᱚᱫᱚ ᱤᱝᱞᱤᱥ ᱛᱮᱜᱮ ᱛᱟᱦᱮᱸᱱᱟ᱾ ᱱᱚᱸᱰᱮ ᱮᱢ ᱟᱠᱟᱱ ᱧᱮᱞ-ᱵᱤᱰᱟᱹᱣ ᱨᱮᱱᱟᱜ ᱫᱟᱹᱭᱠᱟᱹ ᱠᱚᱫᱚ ᱟᱢᱟᱜ ᱩᱭᱦᱟᱹᱨ (memories), ᱨᱚᱯᱚᱲ (conversations), ᱠᱟᱹᱢᱤ ᱦᱚᱨᱟ (action items), ᱟᱨᱵᱟᱝ ᱡᱚᱥ (goals) ᱨᱮ ᱪᱮᱫ ᱦᱚᱸ ᱵᱟᱭ ᱵᱚᱫᱚᱞᱟ᱾

## ᱯᱨᱚᱜᱨᱟᱢ ᱤᱱᱥᱴᱚᱞ ᱢᱮ (Installation)

ᱞᱟᱹᱠᱛᱤᱭᱟᱱ ᱡᱤᱱᱤᱥ: Python 3.10 ᱟᱨᱵᱟᱝ ᱱᱟᱶᱟ ᱵᱷᱚᱨᱥᱚᱱ ᱟᱨ ᱢᱤᱫ Omi ᱠᱷᱟᱛᱟ (account)᱾

ᱡᱩᱫᱤ ᱟᱢ ᱴᱷᱮᱱ `pipx` ᱤᱱᱥᱴᱚᱞ ᱢᱮᱱᱟᱜ-ᱟ:

```sh
pipx install omi-cli
omi --help
```

ᱟᱢ ᱱᱚᱶᱟ ᱢᱤᱫ ᱮᱠᱴᱤᱵᱷ Python ᱵᱷᱟᱨᱪᱩᱣᱟᱞ ᱮᱱᱵᱷᱟᱭᱨᱚᱱᱢᱮᱱᱴ (virtual environment) ᱨᱮᱦᱚᱸ ᱤᱱᱥᱴᱚᱞ ᱫᱟᱲᱮᱭᱟᱜ-ᱟᱢ:

```sh
python -m pip install omi-cli
omi --help
```

ᱡᱩᱫᱤ ᱴᱟᱨᱢᱤᱱᱟᱞ ᱨᱮ `omi` ᱠᱚᱢᱟᱱᱰ ᱵᱟᱭ ᱧᱟᱢᱚᱜ-ᱟ, ᱮᱱᱠᱷᱟᱱ ᱵᱷᱟᱨᱪᱩᱣᱟᱞ ᱮᱱᱵᱷᱟᱭᱨᱚᱱᱢᱮᱱᱴ ᱪᱟᱹᱞᱩ ᱢᱮᱱᱟᱜ-ᱟ ᱥᱮ ᱵᱟᱝ ᱟᱨᱵᱟᱝ `pipx` ᱰᱟᱦᱟᱨ ᱟᱢᱟᱜ `$PATH` ᱨᱮ ᱢᱮᱱᱟᱜ-ᱟ ᱥᱮ ᱵᱟᱝ ᱚᱱᱟ ᱧᱮᱞ ᱵᱤᱰᱟᱹᱣ ᱢᱮ᱾

## ᱟᱢᱟᱜ ᱠᱷᱟᱛᱟ ᱡᱚᱲᱟᱣ ᱢᱮ (Authentication)

ᱨᱚᱯᱚᱲ ᱜᱚᱲᱚᱭᱤᱡ ᱮᱛᱚᱦᱚᱵ ᱢᱮ:

```sh
omi auth login
```

ᱵᱽᱨᱟᱣᱡᱚᱨ ᱛᱮ ᱵᱚᱞᱚᱱ ᱟᱨᱵᱟᱝ Omi developer API key ᱞᱟᱜᱟᱣ ᱵᱟᱪᱷᱟᱣ ᱢᱮ᱾ ᱜᱚᱲᱚᱭᱤᱡ ᱤᱱᱯᱩᱴ ᱫᱚ ᱪᱟᱹᱵᱷᱤ ᱩᱠᱩ ᱫᱚᱦᱚᱭᱟ; ᱴᱟᱨᱢᱤᱱᱟᱞ ᱨᱮ ᱛᱟᱦᱮᱸᱱ ᱠᱟᱱ ᱠᱚᱢᱟᱱᱰ ᱠᱚᱨᱮ ᱪᱟᱹᱵᱷᱤ ᱟᱞᱚᱢ ᱚᱞᱟ᱾

ᱥᱚᱡᱷᱮ ᱵᱽᱨᱟᱣᱡᱚᱨ ᱛᱮ ᱪᱟᱞᱟᱜ ᱞᱟᱹᱜᱤᱫ:

```sh
omi auth login --browser
```

ᱚᱱᱟ ᱠᱚᱢᱯᱤᱭᱩᱴᱚᱨ ᱨᱮᱜᱮ ᱵᱚᱞᱚᱱ ᱢᱮ ᱡᱟᱦᱟᱸ ᱨᱮ ᱴᱟᱨᱢᱤᱱᱟᱞ ᱪᱟᱞᱟᱜ ᱠᱟᱱᱟ: ᱯᱟᱹᱛᱭᱟᱹᱣ ᱛᱮᱞᱟ ᱫᱚ ᱚᱲᱟᱜ ᱴᱷᱟᱶ (local address) ᱵᱮᱵᱷᱟᱨᱟ᱾ ᱥᱠᱨᱤᱱ ᱨᱮ ᱮᱢ ᱟᱠᱟᱱ ᱱᱤᱨᱫᱮᱥ ᱠᱚ ᱯᱟᱸᱡᱟᱭ ᱢᱮ᱾

ᱤᱱᱟᱹ ᱛᱟᱭᱚᱢ, ᱥᱟᱡᱟᱣ ᱟᱨ API ᱥᱮᱴᱮᱨ ᱵᱤᱰᱟᱹᱣ ᱢᱮ:

```sh
omi auth status
omi auth whoami
```

`status` ᱫᱚ ᱞᱚᱠᱟᱞ ᱚᱵᱚᱥᱛᱟ ᱩᱫᱩᱜᱟ ᱟᱨ ᱩᱠᱩ ᱠᱟᱛᱷᱟ ᱫᱚᱦᱚᱭᱟ, ᱢᱮᱱᱠᱷᱟᱱ ᱥᱟᱨᱵᱷᱟᱨ ᱨᱮ ᱠᱟᱹᱢᱤ ᱠᱟᱱᱟ ᱥᱮ ᱵᱟᱝ ᱚᱱᱟ ᱵᱟᱭ ᱧᱮᱞᱟ᱾ `whoami` ᱫᱚ ᱢᱤᱫ ᱯᱟᱹᱛᱭᱟᱹᱣ ᱱᱮᱦᱚᱸᱨ ᱠᱩᱞᱟ; ᱡᱩᱫᱤ ᱴᱷᱤᱠ ᱛᱟᱦᱮᱸᱱᱟ, ᱮᱱᱠᱷᱟᱱ ᱟᱢᱟᱜ ᱧᱩᱛᱩᱢ ᱵᱟᱝ ᱩᱫᱩᱜ ᱠᱟᱛᱮ ᱪᱟᱹᱵᱷᱤ ᱠᱟᱹᱢᱤ ᱠᱟᱱᱟ ᱢᱮᱱᱛᱮ ᱯᱟᱹᱛᱭᱟᱹᱣ ᱮᱢᱚᱜ-ᱟ᱾

ᱥᱟᱡᱟᱣ ᱫᱚ ᱥᱟᱫᱷᱟᱨᱚᱱ ᱞᱮᱠᱟᱛᱮ `~/.omi/config.toml` ᱨᱮ ᱥᱟᱧᱪᱟᱣ ᱛᱟᱦᱮᱸᱱᱟ᱾ ᱱᱚᱶᱟ ᱯᱷᱟᱭᱤᱞ ᱮᱴᱟᱜ ᱦᱚᱲ ᱥᱟᱶ ᱟᱞᱚᱢ ᱦᱟᱹᱴᱤᱧᱟ: ᱱᱚᱸᱰᱮ ᱩᱠᱩ ᱠᱟᱛᱷᱟ ᱛᱟᱦᱮᱸ ᱫᱟᱲᱮᱭᱟᱜ-ᱟ᱾

## ᱟᱢᱟᱜ ᱰᱮᱴᱟ ᱧᱮᱞ-ᱵᱤᱰᱟᱹᱣ ᱢᱮ (Inspection)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ᱠᱷᱟᱹᱞᱤ ᱛᱟᱹᱞᱠᱟᱹ ᱨᱮᱱᱟᱜ ᱢᱮᱱᱮᱛ ᱫᱚ ᱱᱤᱭᱟᱹ ᱜᱮ ᱦᱩᱭ ᱫᱟᱲᱮᱭᱟᱜ-ᱟ ᱡᱮ ᱥᱮᱸᱫᱽᱨᱟ ᱞᱮᱠᱟᱛᱮ ᱪᱮᱫ ᱦᱚᱸ ᱰᱮᱴᱟ ᱵᱟᱹᱱᱩᱜ-ᱟ᱾ ᱡᱚᱛᱚ ᱠᱚᱢᱟᱱᱰ ᱨᱮ ᱯᱷᱤᱞᱴᱟᱨ ᱧᱟᱢ ᱞᱟᱹᱜᱤᱫ ᱜᱚᱲᱚ (help) ᱵᱮᱵᱷᱟᱨ ᱢᱮ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ᱦᱟᱛᱟᱣ ᱟᱨ ᱥᱟᱠᱟᱢ ᱯᱟᱨᱚᱢ (Pagination)

ᱠᱚᱢᱟᱱᱰ ᱜᱩᱴ ᱠᱷᱚᱱ **ᱢᱟᱬᱟᱝ** ᱨᱮ ᱡᱮᱜᱮᱛᱟᱹᱨᱤ `--json` ᱵᱟᱪᱷᱟᱣ ᱞᱟᱜᱟᱣ ᱢᱮ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ᱯᱩᱭᱞᱩ ᱠᱚᱢᱟᱱᱰ ᱫᱚ ᱯᱩᱭᱞᱩ ᱒᱕ ᱩᱭᱦᱟᱹᱨ ᱠᱚᱡᱚᱜ-ᱟ; ᱫᱚᱥᱟᱨ ᱠᱚᱢᱟᱱᱰ ᱫᱚ ᱤᱱᱟᱹ ᱛᱟᱭᱚᱢ ᱨᱮᱱᱟᱜ ᱒᱕ ᱩᱭᱦᱟᱹᱨ ᱠᱚᱡᱚᱜ-ᱟ᱾ ᱢᱤᱫ ᱥᱟᱠᱟᱢ ᱫᱚ ᱯᱩᱨᱟᱹ ᱵᱮᱠ-ᱟᱯ ᱫᱚ ᱵᱟᱝ ᱠᱟᱱᱟ᱾ JSON ᱚᱣᱩᱴᱯᱩᱴ ᱫᱚ ᱡᱚᱛᱚ ᱩᱯᱨᱩᱢ ᱠᱳᱰ ᱥᱟᱧᱪᱟᱣ ᱫᱚᱦᱚᱭᱟ, ᱡᱚᱠᱷᱚᱱ ᱥᱠᱨᱤᱱ ᱨᱮᱱᱟᱜ ᱴᱮᱵᱩᱞ ᱫᱚ ᱩᱫᱩᱜ ᱞᱟᱹᱜᱤᱫ ᱠᱷᱟᱴᱚ ᱫᱟᱲᱮᱭᱟᱜ-ᱟ᱾

ᱢᱤᱫ ᱥᱟᱠᱟᱢ ᱯᱷᱟᱭᱤᱞ ᱨᱮ ᱥᱟᱧᱪᱟᱣ ᱞᱟᱹᱜᱤᱫ:

```sh
omi --json memory list --limit 25 --offset 0 > ᱩᱭᱦᱟᱹᱨ-ᱥᱟᱠᱟᱢ-1.json
```

ᱱᱚᱶᱟ ᱰᱟᱦᱟᱨ ᱫᱚ ᱞᱚᱠᱟᱞ ᱯᱷᱟᱭᱤᱞ ᱵᱮᱱᱟᱣᱟ ᱟᱨᱵᱟᱝ ᱵᱚᱫᱚᱞᱟ᱾ ᱵᱷᱤᱛᱨᱤ ᱨᱮᱱᱟᱜ ᱠᱟᱛᱷᱟ ᱵᱮᱵᱷᱟᱨ ᱢᱟᱬᱟᱝ ᱨᱮ ᱧᱮᱞ ᱢᱮ ᱡᱮ ᱠᱚᱢᱟᱱᱰ ᱴᱷᱤᱠ ᱛᱮ ᱪᱟᱵᱟ ᱟᱠᱟᱱᱟ ᱥᱮ ᱵᱟᱝ᱾ ᱵᱷᱩᱞ ᱠᱚᱫᱚ ᱮᱨᱚᱨ ᱚᱣᱩᱴᱯᱩᱴ (stderr) ᱨᱮ ᱚᱞᱚᱜ-ᱟ; ᱠᱷᱟᱹᱞᱤ ᱯᱷᱟᱭᱤᱞ ᱢᱮᱱᱮᱛ ᱫᱚ ᱰᱮᱴᱟ ᱵᱟᱹᱱᱩᱜ-ᱟ ᱢᱮᱱᱛᱮ ᱵᱟᱝ ᱵᱩᱡᱷᱟᱹᱣᱜ-ᱟ᱾ ᱚᱰᱚᱠ ᱟᱠᱟᱱ ᱯᱷᱟᱭᱤᱞ ᱨᱮ ᱱᱤᱡᱮᱨᱟᱜ ᱠᱟᱛᱷᱟ ᱛᱟᱦᱮᱸ ᱫᱟᱲᱮᱭᱟᱜ-ᱟ: ᱱᱚᱶᱟ ᱡᱚᱛᱚᱱ ᱠᱟᱛᱮ ᱫᱚᱦᱚᱭ ᱢᱮ᱾

## ᱠᱷᱟᱛᱟ ᱠᱷᱚᱱ ᱚᱰᱚᱠᱚᱜ ᱢᱮ (Logout)

```sh
omi auth logout
```

ᱱᱚᱶᱟ ᱠᱚᱢᱟᱱᱰ ᱫᱚ ᱞᱚᱠᱟᱞ ᱨᱮ ᱥᱟᱧᱪᱟᱣ ᱟᱠᱟᱱ ᱪᱟᱹᱵᱷᱤ ᱠᱚ ᱚᱪᱚᱜᱟ᱾ ᱥᱟᱨᱵᱷᱟᱨ ᱠᱷᱚᱱ ᱪᱟᱹᱵᱷᱤ ᱵᱚᱱᱫᱚ ᱞᱟᱹᱜᱤᱫ, ᱟᱢᱟᱜ ᱠᱷᱟᱛᱟ ᱨᱮ developer key ᱵᱮᱵᱚᱥᱛᱷᱟ ᱵᱮᱵᱷᱟᱨ ᱢᱮ᱾

ᱮᱴᱟᱜ ᱠᱚᱢᱟᱱᱰ ᱠᱚ ᱟᱨ ᱵᱟᱹᱲᱛᱤ ᱵᱟᱪᱷᱟᱣ ᱠᱚ ᱞᱟᱹᱜᱤᱫ, [ᱤᱝᱞᱤᱥ ᱢᱩᱬᱩᱛ ᱩᱫᱩᱜ-ᱥᱚᱫᱚᱨ](../README.md) ᱟᱨ `omi --help` ᱧᱮᱞ ᱢᱮ᱾
