# ڕێبەری خێرا: omi-cli (کوردیی سۆرانی)

`omi-cli` ئینتەرفەیسی فەرمیی هێڵی فەرمانە (CLI) بۆ پەیوەندی لەگەڵ ئێکۆسیستەمی Omi: دەستڕاگەیشتن بە بیرگەکان (memories)، گفتوگۆکان (conversations)، بڕگە چالاکییەکان (action items) و ئامانجەکان (goals) دابین دەکات. ئەم ڕێبەرییە بە تەواوی بە سۆرانی نووسراوە، بۆ ژینگەکانی ئۆتۆمەیشەن، بەکارهێنەرانی تێرمیناڵ و گەشەپێدەران.

---

## 1. دامەزراندن (Installation)

پاکێجەکە لە کۆگای PyPI بە ناوی `omi-cli` بڵاودەکرێتەوە. دوای دامەزراندن، فەرمانی `omi` لە `$PATH` بەردەست دەبێت:
```bash
# شێوازی پێشنیارکراو: ژینگەی جیاکراوە بە pipx
pipx install omi-cli

# یان بە pip ی ئاسایی:
pip install omi-cli
```

دڵنیابە لە دامەزراندنەکە بە پشکنینی وەشان و نامەی یارمەتی:
```bash
omi --version
omi --help
```

> **تێبینی:** ناوی پاکێجی PyPI بریتییە لە `omi-cli` (چونکە پاکێجێکی تر ناوی پوختی `omi` بەکاردەهێنێت)، بەڵام فەرمانی تێرمیناڵ هەمیشە `omi` یە.

---

## 2. چوونەژوورەوە (Authentication)

`omi-cli` هەردوو چوونەژوورەوەی ئینتەراکتیڤی براوسەر و کلیلەکانی API ی گەشەپێدەر پشتگیری دەکات:
```bash
omi auth login
# 1) براوسەر — چوونەژوورەوە بە براوسەر (Google یان Apple)
# 2) کلیلە API — دانانی کلیلە گەشەپێدەر لە پانێڵی app.omi.me
```

### چوونەژوورەوە بە براوسەر
```bash
# چوونەژوورەوە بە هەژماری Google (بنەڕەت)
omi auth login --browser

# چوونەژوورەوە بە هەژماری Apple
omi auth login --browser --provider apple
```

### چوونەژوورەوە بە کلیلە API ی گەشەپێدەر

کلیلێکی API لە داشبۆردی [app.omi.me](https://app.omi.me) دروست بکە لە بەشی **Developer → API Keys**:
```bash
# پاشەکەوتکردنی کلیلەکە لە پرۆفایلی چالاکی ئێستا
omi auth login --api-key omi_dev_zure_gakoa_hemen

# یان دانانی وەک گۆڕاوی ژینگە (پێشنیارکراو بۆ Docker و پرۆسەکانی CI/CD):
export OMI_API_KEY="omi_dev_zure_gakoa_hemen"
```

> **تێبینی ئاسایش و پێشینەیی:**
> * ئەگەر `--api-key` ڕاستەوخۆ لە هێڵی فەرمان بەکاربهێنیت، کلیلەکە لە مێژووی تێرمیناڵ (`shell history`) و لیستی پرۆسەکانی سیستەم دەردەکەوێت. لەسەر مەکینەی هاوبەش، مۆدی ئینتەراکتیڤ (`omi auth login`) یان گۆڕاوی ژینگەی `OMI_API_KEY` بەکاربهێنە.
> * ئەگەر پرۆفایلی چالاک پێشتر کلیلێکی لە ڕێکخستنەکان پاشەکەوت کردبێت، پێشینەیی هەیە بەسەر گۆڕاوی ژینگەدا. بۆ بەکارهێنانی `OMI_API_KEY`، پێشتر لە هەژمارەکە بچۆ دەرەوە بە `omi auth logout` یان پرۆفایلێکی نوێ بەکاربهێنە.

### پشکنینی دۆخی دانیشتن

* `omi auth status`: پرۆفایلی چالاک و ناسنامە شاراوەکەی پاشەکەوتکراوی لوکاڵی نیشان دەدات (بەبێ ئینتەرنێت کاردەکات).
* `omi auth whoami`: داواکارییەکی تۆڕ دەنێرێت بۆ سێرڤەرەکانی Omi بۆ دڵنیابوون لە دروستبوونی دانیشتنەکە.
```bash
omi auth status
omi auth whoami
```

### چوونەدەرەوە (Logout)

بۆ سڕینەوەی ئەو بڕوانامانەی لە لوکاڵ پاشەکەوتکراون:
```bash
omi auth logout
# ئەگەر گۆڕاوی ژینگەی OMI_API_KEY ت بەکارهێنابێت، لە دانیشتنەکە بیسڕەوە:
unset OMI_API_KEY
```

> **تێبینی ئاسایشی فایل:** ڕێکخستنەکان لە فایلی `~/.omi/config.toml` پاشەکەوت دەکرێن. لە سیستەمەکانی Unix/Linux، پێشنیار دەکرێت مۆڵەتەکان سنووردار بکەیت: `chmod 700 ~/.omi && chmod 600 ~/.omi/config.toml`.

## 3. فەرمانە بنەڕەتییەکان

### بیرگەکان (Memories)

پاشەکەوتکردن و گەڕان لە تێبینییەکانی کۆنتێکستی درێژخایەن، ڕووداوەکان و تێبینییەکان:
```bash
# لیستی بیرگە پاشەکەوتکراوەکان
omi memory list

# دروستکردنی بیرگەیەکی نوێ
omi memory create "بەکارهێنەر وەڵامی تەکنیکی بە نموونەی Python پێ باشە" --category work

# وەرگرتنی بیرگەیەکی دیاریکراو بە ناسنامە
omi memory get <OROITZAPEN_ID>
```

### گفتوگۆکان (Conversations)

تۆمارە دەنگییەکان و دەقە وەرگێڕاوەکانی ئامێرەکانی Omi:
```bash
# لیستی 5 گفتوگۆی کۆتایی
omi conversation list --limit 5

# وەرگرتنی گفتوگۆیەک لەگەڵ دەقە تەواوەکەی
omi conversation get <ELKARRIZKETA_ID> --include-transcript
```

### بڕگە چالاکییەکان و ئەرکەکان (Action Items)

ئەو ئەرک و چالاکییانەی بە ئۆتۆماتیکی لە گفتوگۆکان دەدۆزرێنەوە:
```bash
# لیستی ئەرکە کراوەکان
omi action-item list --open

# نیشانکردنی ئەرکێک وەک تەواوبوو
omi action-item complete <ZEREGIN_ID>
```

### ئامانجەکان (Goals)

بەدواداچوونی ئامانجە درێژخایەنەکان و پێشکەوتن:
```bash
# لیستی ئامانجە چالاکەکان
omi goal list

# دروستکردنی ئامانجێکی ژمارەیی نوێ (ناونیشان وەک ئارگیومەنتی شوێنی دەدرێت)
omi goal create "بڕی ئاوی ڕۆژانە" --type numeric --target 2500 --unit "ml"
```

## 4. ئۆتۆمەیشەنی پێکهاتەیی و دەرچووی JSON (`--json`)

`omi-cli` بە تایبەتی بۆ تێکەڵبوون لە سکریپتەکان و هەڵسەنگاندنی ئۆتۆماتیکی AI داڕێژراوە. ئاڵای جیهانی `--json` دەرچووی JSON ی پاک دابین دەکات، کە بۆ پرۆسێسکردن لەگەڵ ئامرازەکانی وەک `jq` زۆر گونجاوە:
```bash
# وەرگرتنی بیرگەکان بە فۆرماتی JSON و فلتەرکردن بە jq
omi --json memory list | jq '.[] | {id, content, category}'

# دەرهێنانی ناونیشانەکانی 5 گفتوگۆی کۆتایی
omi --json conversation list --limit 5 | jq '.[] | {id, title: .structured.title, started_at}'

# لیستی ئەرکە کراوەکان
omi --json action-item list --open | jq '.'
```

> **یاسای سەرەکی سینتاکس:**
> هەڵبژاردەی `--json` جیهانییە و هەمیشە دەبێت **پێش** ژێرفەرمانەکە دابنرێت:
> * ڕاستە: `omi --json memory list`
> * هەڵەیە: `omi memory list --json`

### پەڕەبەندیکردن و هەناردەکردنی داتا

کاتێک لەگەڵ قەبارەی گەورەتری داتا کاردەکەیت `--limit` و `--offset` بەکاربهێنە:
```bash
# دابەزاندنی داتا پەڕە بە پەڕە
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
omi --json memory list --limit 25 --offset 25 > memories-page-2.json
```

ڕیدایرێکتکردن بۆ فایل فایلێکی لوکاڵی دروست دەکات یان دەیگۆڕێت. هەمیشە کۆدی دەرچووی فەرمانەکە بپشکنە پێش پرۆسێسکردنی داتا. نامە هەڵەکان دەچنە هەڵەی ستاندەرد (`stderr`)، بۆیە فایلێکی بەتاڵ گەرەنتی نادات کە داتا بوونی نییە. فایلە هەناردەکراوەکان لەوانەیە داتای نهێنییان تێدابێت — بەپێی یاسا ئاسایشییەکانت بیانپارێزە.

## 5. کۆدەکانی دەرچوون (Exit Codes Contract)

`omi-cli` گرێبەستێکی جێگیری کۆدەکانی دەرچوون بەکاردەهێنێت، کە بۆ ئۆتۆمەیشەن و بریکارەکانی AI داڕێژراوە. سفر (0) واتە سەرکەوتن؛ هەر ژمارەیەکی ناسفر واتە هەڵەیەک بە مانای دیاریکراو.

| کۆد | ناو | مانا و ڕوونکردنەوە |
| :---: | :--- | :--- |
| `0` | **سەرکەوتن (`EXIT_OK`)** | فەرمانەکە بەبێ هەڵە جێبەجێ کرا. |
| `1` | **هەڵەی بەکارهێنان / پشتڕاستکردنەوەی بەرنامە (`EXIT_USAGE`)** | هەڵەی پشتڕاستکردنەوەی ئاستی بەرنامە (`UsageError`، بۆ نموونە `--browser` و `--api-key` پێکەوە ناگونجێن). |
| `2` | **هەڵەی ڕەسەنایەتی / شیکردنەوە (`EXIT_AUTH`)** | بڕوانامەکان نین، کلیلەکە بەسەرچووە یان مۆڵەت بەش نییە. هەڵە سینتاکسییەکانی Click/Typer و نرخە نادروستەکان هەروەها کۆدی 2 دەگەڕێننەوە. |
| `3` | **هەڵەی سێرڤەر یان تۆڕ (`EXIT_SERVER`)** | وەڵامی HTTP 5xx ی سێرڤەری Omi یان پچڕانی پەیوەندی تۆڕ. |
| `4` | **سنووری داواکاری تێپەڕێندرا (`EXIT_RATE_LIMITED`)** | وەڵامی HTTP 429 — لە ماوەیەکی کورتدا داواکاری زۆر نێردراوە. |
| `5` | **سەرچاوەکە نەدۆزرایەوە (`EXIT_NOT_FOUND`)** | وەڵامی HTTP 404 — سەرچاوە داواکراوەکە بوونی نییە.

## 6. نموونە بۆ ژینگە جیاوازەکانی تێرمیناڵ

بۆ سکریپتەکانی ئۆتۆمەیشەن، باشترە هەمیشە کۆدی دەرچوون بپشکنیت پێش پرۆسێسکردنی هەر داتایەک. سینتاکسی وردەکە پەیوەستە بەو تێرمیناڵەی بەکاری دەهێنیت:

### Bash / Zsh (Linux و macOS)
```bash
#!/usr/bin/env bash
set -euo pipefail

if omi --json memory list --limit 5 > /tmp/memories.json; then
    echo "بە سەرکەوتوویی $(jq 'length' /tmp/memories.json) بیرگە وەرگیرا."
else
    code=$?
    echo "هەڵە لە وەرگرتنی بیرگەکان (کۆدی دەرچوون: $code)" >&2
    exit "$code"
fi
```

### PowerShell (Windows / macOS / Linux)
```powershell
$ErrorActionPreference = "Continue"

omi --json memory list --limit 5 | Out-File -FilePath "$env:TEMP\memories.json" -Encoding utf8
if ($LASTEXITCODE -ne 0) {
    Write-Error "فەرمانەکە شکستی هێنا بە کۆدی دەرچوونی $LASTEXITCODE"
    exit $LASTEXITCODE
}
Write-Host "داتاکە بە باشی پاشەکەوت کرا."
```

### Windows Command Prompt (`cmd.exe`)
```cmd
omi --json memory list --limit 5 > "%TEMP%\memories.json"
if %ERRORLEVEL% NEQ 0 (
    echo هەڵەیەک ڕوویدا بە کۆدی دەرچوونی %ERRORLEVEL%
    exit /b %ERRORLEVEL%
)
echo کردارەکە بە سەرکەوتوویی تەواو بوو.
```

## 7. بەڕێوەبردنی پرۆفایل و ژینگەی تاقیکردنەوە (Staging)

هەڵبژاردەی `--profile` ڕێگە دەدات چەند ڕێکخستنێکی سەربەخۆ بهێڵیتەوە (بۆ نموونە تایبەتی، کار یان تاقیکردنەوە). بۆ ژینگەکانی تاقیکردنەوە (staging)، دەتوانیت URL ی بنەڕەت بە هەمیشەیی لە پرۆفایلەکە دابنێیت:

> **تێبینی گرنگ دەربارەی هەڵبژاردەی `--api-base`:** ئاڵای `--api-base` تەنها وەک جێگرەوەیەکی کاتی بۆ ئەو فەرمانە تایبەتە کاردەکات و بە ئۆتۆماتیکی لە ڕێکخستنەکان پاشەکەوت نابێت. بۆ بەکارهێنانی هەمیشەیی `config set api_base <url>` بەکاربهێنە.
```bash
# دانانی هەمیشەیی URL ی بنەڕەت بۆ پرۆفایلی staging
omi --profile staging config set api_base https://api.staging.omi.me

# چوونەژوورەوە لە پرۆفایلی تاقیکردنەوەی staging
omi --profile staging auth login --api-key omi_dev_staging_gakoa

# جێبەجێکردنی فەرمانەکان لە پرۆفایلی staging (بە هەمیشەیی ئاڕاستەکراوە بۆ ژینگەی staging)
omi --profile staging memory list

# یان جێگرەوەی کاتی بۆ یەک فەرمان:
# omi --profile staging --api-base https://api.staging.omi.me memory list
```

## 8. تێکەڵبوون لەگەڵ API ی لوکاڵی دێسکتۆپ (Local Desktop API)

ئەگەر ئەپی Omi Desktop لەسەر هەمان کۆمپیوتەر کاردەکات، دەتوانیت ڕاستەوخۆ لەگەڵ سێرڤەری لوکاڵ قسە بکەیت بەبێ ناردنی داتا بۆ هەور. پێش جێبەجێکردنی `omi local status` یان گەڕانەکان، دڵنیابە ناونیشان و تۆکنی ئاسایش دانراون:
```bash
# 1. دانانی ناونیشانی لوکاڵ (پۆرتی بنەڕەت 47778) و تۆکن:
export OMI_LOCAL_API_URL="http://127.0.0.1:47778"
export OMI_LOCAL_TOKEN="your_local_token"

# یان پاشەکەوتکردنی هەمیشەیی لە پرۆفایل:
# omi local configure --url http://127.0.0.1:47778 --token "your_local_token"

# 2. پشکنینی دۆخی خزمەتگوزاری لوکاڵ (پێویستی بە پارامێترە پێشوەخت دانراوەکانە)
omi local status

# 3. گەڕان لە مێژووی شاشە بە پرسیار و ئەپ
omi local search-screen "asteroko bilera" --days 1 --app "Slack"
```

## 9. ئاسایش و باشترین پراکتیزەکان

1. **شوێنی ئاڵای `--json`:** هەمیشە پێش ژێرفەرمانەکە دابنێ (`omi --json memory list`).
2. **مامەڵە لەگەڵ کۆدەکانی دەرچوون:** لە سکریپتەکانی ئۆتۆمەیشەن هەمیشە کۆدەکانی 1 بۆ 5 بپشکنە و مامەڵەیان لەگەڵ بکە.
3. **پاراستنی بڕوانامەکان:** هەرگیز کلیلەکانی API بەرز مەکە بۆ کۆگاکانی کۆدی گشتی. لە بەرهەمهێنان و ژینگەکانی CI/CD هەمیشە گۆڕاوی `OMI_API_KEY` بەکاربهێنە.
