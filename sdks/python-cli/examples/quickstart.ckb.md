# دەستپێکردنی خێرا بە omi-cli

ئەم ڕێنماییە بە کوردیی ناوەندی (سۆرانی) یەکەم فەرمانەکانی omi-cli ڕوون دەکاتەوە. ناوی فەرمانەکان و نامەکانی پرۆگرام بە ئینگلیزی دەمێننەوە. نموونە پرسیارەکانی لێرە هیچ شتێک لە memories، conversations، action items، یان goalsـەکەت ناگۆڕن.

## دامەزراندن

پێویستییەکان: Python 3.10 یان نوێتر، و هەژمارێکی Omi.

ئەگەر pipxـت دامەزراندووە:

```sh
pipx install omi-cli
omi --help
```

یان بییدامەزرێنە لە Python virtual environmentـێکی چالاککراودا:

```sh
python -m pip install omi-cli
omi --help
```

تێبینی: لەوانەیە فەرمانی `omi` لە سەرەتادا لە PATHـەکەت نەبێت — دڵنیا بە کە virtual environment چالاکە یان بوخچەی pipx لە `$PATH` دان.

## چوونەژوورەوە

پێش بەکارهێنانی CLI، بچۆ ژوورەوە:

```sh
omi auth login
```

دەتوانیت بە وێبگەڕ بچیتە ژوورەوە یان بە Omi developer API key. کلیلەکە دادەلکێنرێت — ناچێتە مێژووی تێرمیناڵەوە.

لەم کۆمپیوتەرە بە وێبگەڕ بچۆ ژوورەوە:

```sh
omi auth login --browser
```

بۆ ئامێرە تەنیا-تێرمیناڵەکان: ڕێگەپێدان لە ناونیشانێکی لوکاڵ تەواو دەبێت. ڕێنمایییەکانی شاشەکە بەدواداچوونەوە بکە.

ڕێکخستن و API keyـی ئێستا بپشکنە:

```sh
omi auth status
omi auth whoami
```

`status` زانیاری لوکاڵ پیشان دەدات و نهێنییەکان دادەشارێت، بێ ئەوەی پرسیار لە سێرڤەر بکات. `whoami` داوایەکی ڕەسەنێت نارد دەنێرێت؛ ئەگەر سەرکەوتوو بوو، واتە کریدێنشاڵەکانت کاردەکەن.

ڕێکخستن لە `~/.omi/config.toml` هەڵدەگیرێت. ئەم پەڕگەیە بە دەست مەگۆڕە — نهێنییەکانی کلیل تێدایە.

## لیستکردنی memories و conversations

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ئەگەر لیستەکە بەتاڵ بوو، تەنیا واتە هێشتا هیچ ناوێکی تێدا نییە. بۆ بینینی ئەو فلتەرانەی هەر فەرمانێک پشتیوانی دەکات:

```sh
omi memory list --help
omi action-item list --help
```

## JSON و هەناردەکردن

هەڵبژاردەی گشتی `--json` دەبێت پێش گروپی فەرمان دابنرێت:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

یەکەم فەرمان یەکەم 25 memories دەهێنێت؛ دووەم 25ـی داهاتوو دەهێنێت. دەرچوونی JSON ناسنامە تەواوەکان دەگرێتەوە، بەڵام خشتەکە کورتان دەکات.

پاشەکەوتکردنی بۆ پەڕگە:

```sh
omi --json memory list --limit 25 --offset 0 > memories-lapare-1.json
```

ئەم redirectـە پەڕگەیەکی لوکاڵ دروست دەکات یان لەسەری دەنووسێت. سەرەتا دەرچوونی فەرمانەکە بپشکنە. هەڵەکان دەچنە stderr؛ پەڕگەی بەتاڵ واتە داتا نییە ناکات. پەڕگەکانی هەناردە لەوانەیە زانیاری کەسیان تێدابێت — بەبەهێز پارێزیان بکە.

## چوونەدەرەوە

```sh
omi auth logout
```

ئەم فەرمانە کریدێنشاڵە لوکاڵەکان دەسڕێتەوە. کلیلەکانی لای سێرڤەر لە developer key management بەڕێوە دەبرێن.

بۆ فەرمان و هەڵبژاردەی زیاتر: [بەڵگەنامەی ئینگلیزی](../README.md) و `omi --help`.
