# دەستپێکی خێرا لەگەڵ omi-cli

ئەم ڕێنماییە فەرمانە بنەڕەتییەکان بە کوردیی سۆرانی ڕووندەکاتەوە. ناوی فەرمانەکان
و پەیامەکانی پڕۆگرام بە ئینگلیزی دەمێننەوە. فەرمانە نموونەییەکانی خوارەوە
بیرەوەرییەکانت، گفتوگۆکانت، دانە کردارەکان یان ئامانجەکانت نانۆمەزن.

## دامەزراندنی پڕۆگرامەکە

پێویستییەکان: Python 3.10 یان نوێتر و هەژمارێکی Omi.

ئەگەر `pipx` دامەزراوە:

```sh
pipx install omi-cli
omi --help
```

یان لە ژوورەوە virtual environment ـی چالاککراوی Python دایمەزرێنە:

```sh
python -m pip install omi-cli
omi --help
```

ئەگەر تێرمیناڵ `omi` نەدۆزییەوە، دڵنیابە virtual environment ـەکە چالاکە یان
ئەو بوخچەیەی `pipx` تێیدا executable دادەنێت لە `PATH` ـدایە.

## پەیوەندیکردنی هەژمارەکەت

ڕێنماییی گونجاوە interactive بەکاربهێنە:

```sh
omi auth login
```

چوونەژوورەوە بە وێبگەڕ هەڵبژێرە یان کلیلی API ـی گەشەپێدەری Omi لکێنە. داخڵکردنی
interactive کلیلەکە دەشارێتەوە; مەینوسە لە فەرمانەکاندا کە لە مێژووی تێرمیناڵ
پاشەکەوت دەبن.

بۆ بەکارهێنانی ڕاستەوخۆی وێبگەڕ:

```sh
omi auth login --browser
```

لە هەمان کۆمپیوتەری تێرمیناڵ بچۆ ژوورەوە چونکە ڕەوانکردن ناونیشانی callback ـی
ناوخۆیی بەکاردەهێنێت. ڕێنمایییەکانی سەر شاشە جێبەجێ بکە.

دوای چوونەژوورەوە، ڕێکخستن و دەستڕاگەیشتی API بپشکنە:

```sh
omi auth status
omi auth whoami
```

`status` دۆخی ناوخۆیی نیشان دەدات و نهێنییەکان دەشارێتەوە، بەڵام دروستییان لە
سێرڤەر ناپشکنێت. `whoami` داواکاری ڕەوانکراو دەنێرێت; ئەگەر سەرکەوتوو بوو،
باڵەکانت کار دەکەن بەبێ نیشاندانی ناوت.

ڕێکخستن بە شێوەی بنەڕەتی لە `~/.omi/config.toml` هەڵدەگیرێت. ئەم فایلە
بەشداری مەکە چونکە لەوانەیە بالەکان تێدا بێت.

## خوێندنەوەی زانیارییەکانت

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

لیستەی بەتاڵ لەوانەیە واتە هیچ دانەیەک لەگەڵ فلتەر نەیهاتەوە. هەڵبژاردەکانی هەر
فەرمانێک لە یارمەتیدا ببینە:

```sh
omi memory list --help
omi action-item list --help
```

## وەرگرتنی JSON و گەڕان بە پەڕەکان

هەڵبژاردەی گشتی `--json` **پێش** گروپی فەرمان دانێ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

یەکەم فەرمان یەکەم ٢٥ بیرەوەری داوا دەکات; دووەم فەرمان ٢٥ ی داهاتوو. یەک پەڕە
پاکچەری تەواو نییە. دەرچووی JSON ناسنامە تەواوەکان دەپارێزێت، بەڵام خشتە لەوانەیە
بۆ پیشاندان ناسنامەکان کەم بکاتەوە.

بۆ هەڵگرتنی پەڕەیەک بۆ فایل:

```sh
omi --json memory list --limit 25 --offset 0 > memory-pel-1.json
```

ڕەوانکردنەوە فایلێکی ناوخۆیی دروست دەکات یان لەسەری دەنووسێت. پێش بەکارهێنانی
ناوەڕۆکەکە دڵنیابە فەرمانەکە بە سەرکەوتوویی تەواو بووە. هەڵەکان بۆ stderr
دەنووسرێن; فایلی بەتاڵ بەڵگەی نەبوونی داتا نییە. فایلی هەناردەکراو لەوانەیە
زانیاری کەسی تێدا بێت — بە تایبەتی بیپارێزە.

## بەکارهێنانی پڕۆفایلەکان

دۆخ لە `~/.omi/config.toml` هەڵدەگیرێت (بە `$OMI_CONFIG` دەگۆڕدرێت). هەر
پڕۆفایلێک ڕێگای ڕەوانکردن و ناونیشانی API ـی خۆی هەیە. بە `--profile`
بیگۆڕە:

```sh
omi config profile use کار
omi auth login
omi --profile کەسی memory list
```

فەرمانە بەرباوەکانی ڕێکخستن:

```sh
omi config show
omi config path
omi config profile list
```

## کۆدەکانی دەرچوون

ئەم کۆدانە جێگیرن و بۆ سکریپتەکان یان ئەجینتەکان بەکاردێن:

| کۆد | مانا | نموونەی بارودۆخ |
| ---: | --- | --- |
| 0 | سەرکەوتن | فەرمان تەواو بوو |
| 1 | هەڵەی بەکارهێنان | فلاجی هەڵە، ئارگیومێنتی کەم، یان پشکنین شکستی هێنا |
| 2 | هەڵەی ڕەوانکردن | بالەکان نیین، تۆکن بەسەرچووە، یان مۆڵەت کەمە |
| 3 | هەڵەی سێرڤەر | سێرڤەر 5xx یان پەیوەندی شکستی هێنا |
| 4 | سنووردارکرانی رێژە | سێرڤەر HTTP 429 گێڕایەوە |
| 5 | نەدۆزرایەوە | سێرڤەر HTTP 404 گێڕایەوە |

## دەرچوون

```sh
omi auth logout
```

بالە هەڵگیراوە ناوخۆییەکان لادەبات. بۆ پاشگەزبوونەوەی کلیلەکە لە سێرڤەر،
بەڕێوەبردنی کلیلی گەشەپێدەر لە هەژمارەکەت بەکاربهێنە.

بۆ فەرمان و هەڵبژاردەی زیاتر، [README ـی سەرەکی ئینگلیزی](../README.md) ببینە
و `omi --help` بەکاربهێنە.
