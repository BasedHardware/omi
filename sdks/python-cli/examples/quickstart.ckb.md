# omi-cli — ڕێنووسیی دەستپێکی خێرا بە کوردیی سۆرانی

> ڕێنووسییەکی کارامە بۆ کارکردن لەگەڵ Omi لە تێرمیناڵەوە. بۆ مرۆڤ و بۆ بریکارە AIییەکانە.

`omi-cli` کلایەنتە فەرمییەکەی هێڵی فەرمانییە بۆ APIی گەشەپێدەری [Omi](https://omi.me).
دەسەڵاتێکی خێرا و سکرێپتکراو دەدات بۆ چوار سەرچاوەی بنەڕەتیی Omi:
بیرەوەرییەکان، گفتوگۆکان، کارەکان، و ئامانجەکان.

* **PyPI:** [pypi.org/project/omi-cli](https://pypi.org/project/omi-cli/)
* **بەڵگەنامە:** [docs.omi.me/doc/developer/cli/introduction](https://docs.omi.me/doc/developer/cli/introduction)
* **کۆدی سەرچاوە:** [github.com/BasedHardware/omi/tree/main/sdks/python-cli](https://github.com/BasedHardware/omi/tree/main/sdks/python-cli)

---

## 1. دامەزراندن

شێوازی پێشنیازکراو `pipx`ە: ئامرازەکە لە ژوورێکی جیاوازدا دادەنێزێت،
کە بەپێچەوانەی پڕۆژەکانت نایەکە ڕکۆڵەکیان لەسەر هاوکێشەکان.

```bash
# پێشنیازکراو: بە pipx دادەمەزرێنە
pipx install omi-cli

# یان بە pip
pip install omi-cli
```

> **گرنگ: ناوی پاکێج و ناوی فەرمان جیاوازن.**
> * پاکێجەکەی دادەنێزرێت **`omi-cli`**یە (پاکێجی جیاوازی `omi` پڕۆژەیەکی تر و پەیوەندیدار نییە).
> * دوای دامەزراندن فەرمانی جێبەجێکراو **`omi`**یە.

دڵنیابە لەوەی هەمووشتێک کار دەکات:

```bash
omi --version
omi --help
```

## 2. ڕەسەنایەت

`omi-cli` دوو شێوازی چوونەژوورەوە پشتگیری دەکات.

| شێواز | گونجاو بۆ | فەرمان |
| :--- | :--- | :--- |
| **کلیلی گەشەپێدەر (`omi_dev_*`)** | CI/CD، سکرێپت، بریکارە AIییەکان | `omi auth login --api-key ...` یان گۆڕاوەی ژوور |
| **چوونەژووری وێبگە (Google/Apple)** | کارکردن لەسەر کۆمپیوتەری خۆت | `omi auth login --browser` |

### چوونەژووری کارلێکەرانە

بەبێ هیچ هەڵبژاردەیەک بیکوژە — دەتەوێت پێت بڵێت کام شێواز بەکاربهێنیت.

```bash
omi auth login
# 1) Browser — بە Google یان Apple بچۆژوورەوە (بۆ مرۆڤ)
# 2) API key — کلیلی گەشەپێدەر لە app.omi.me دابنێ (بۆ بریکار/CI)
```

ئەگەر کلیلەکە هەڵدەبژێریت، نووسینەکە شاردراوە دەبێت بۆ ئەوەی کلیلەکە لە مێژووی تێرمیناڵدا نەمێنێت.

### ڕاستەوخۆ لە وێبگەوە بچۆژوورەوە

```bash
omi auth login --browser
```

### بە کلیلی گەشەپێدەر بچۆژوورەوە

کلیلەکە لە [app.omi.me](https://app.omi.me) لە ژێر **Developer → API Keys** بەدەست بهێنە.

```bash
# کلیلەکە لە ڕێکخستنەکەدا پاشەکەوت بکە
omi auth login --api-key omi_dev_...

# یان لە ڕێگەی ژوورەوە بگوازە — باشترە بۆ CI/CD و کۆنتەینەر
export OMI_API_KEY=omi_dev_...
```

گۆڕاوەی ژووری `OMI_API_KEY` ئەوکاتە بەکاردێت کە هیچ کلیلێک لە پرۆفایلە کارگێڕەکەدا
پاشەکەوت نەکرابێت، بۆیە لە کۆنتەینەردا هیچ شتێک نابێتە دیسکدا بنووسرێت. ئەگەر پرۆفایلەکە
پێشوتر کلیلی هەیە، ئەو کلیلە لەسەر گۆڕاوەی ژوور پێشەکی دەگرێت.

### دەستپێشەکردنەکە پشتڕاست بکەرەوە

دوو فەرمان بۆ پرسیارە جیاوازەکان وەڵام دەدەنەوە — لەیان تەقڵیب مەکە:

* `omi auth status` — ئەوەی **ناوخۆ** پاشەکەوت کراوە: پرۆفایل، کلیلی شاراوە، بەرواری بەسەرچوون.
  بەبێ تۆڕ کار دەکات.
* `omi auth whoami` — داواکارییەک **بۆ سێرڤەری Omi**: پشتڕاست دەکات کە کلیلەکە بەڕاستی قبوڵ دەکرێت.
  پێویستە بە تۆڕ.

```bash
omi auth status    # پشکنینی ناوخۆ، ئۆفلاین
omi auth whoami    # پشکنینی سێرڤەر
```

تۆکنێکی نزیکەی بەسەربچوو ڕینوو بکە بەبێ دووبارە چوونەژوورەوە — ئەم فەرمانە تەنھا بۆ
**دانیشتنی وێبگە/OAuth**ە. بۆ پرۆفایلێک کە بە کلیلی API (`omi_dev_*`) ڕەسەنایەت کراوە،
`omi auth refresh` بە هەڵەی بەکارهێنانەوە (کۆدی 1) سەرکەوتوو نابێت: هیچ تۆکنێک نییە بۆ ڕینوو —
ئەگەر پێویست بوو کلیلەکە لە وێبئەپی Omi بگۆڕە:

```bash
omi auth refresh
```

چوونەدەرەوە:

```bash
omi auth logout
```

## 3. فەرمانە بنەڕەتییەکان

### بیرەوەرییەکان (memories)

ڕاستییەکان و زانیارییەکانی کە سیستەم لەسەر تۆ لەبیر کردوون.

```bash
# لیستەی بیرەوەرییەکان
omi memory list

# یەکێکی نوێ دروست بکە
omi memory create "بەکارهێنەر ڕەنگی تاریک پێدەخوازێت" --category lifestyle

# یەکێکی دیاریکراو ببینە
omi memory get <MEMORY_ID>
```

### گفتوگۆکان (conversations)

مێژووی دەنگ و دەق لە ئامێر یان ئەپ.

```bash
# دوایین 5 گفتوگۆ
omi conversation list --limit 5

# گفتوگۆی تەواو لەگەڵ تێبینی
omi conversation get <CONVERSATION_ID> --include-transcript
```

### کارەکان (action items)

ئەرکەکانی کە Omi لە گفتوگۆکانەوە دەرهێناون.

```bash
# تەنھا کراوەکان
omi action-item list --open

# وەک تەواوکراو نیشان بکە
omi action-item complete <ACTION_ITEM_ID>
```

### ئامانجەکان (goals)

```bash
# لیستەی ئامانجەکان
omi goal list

# بەهای پێشکەوتنی نوێ تۆمار بکە (هەردوو ئارگیومێنت پێویستن: ئامانج و بەها)
omi goal progress <GOAL_ID> 25

# مێژووی گۆڕانکارییەکان
omi goal history <GOAL_ID>
```

## بە زمانی سروشتی بپرسە (`ask`)

فەرمانێکی جیاوازی ئاستی بەرز: پرسیارێکی زمانی سروشتی وەردەگرێت،
و وەڵامەکە لە گفتوگۆکانتەوە دروست دەبێت.

```bash
omi ask "لەسەر گواستنەوە چیم بڕیاردا"
omi --json ask "کام کارەکانم بەڵێن دا ئەم هەفتەیە تەواو بکەم"
```

## 4. JSON و سکرێپت (`--json`)

`omi-cli` دەتوانێت JSONی ئامراز-خوێنەوار بەرهەم بهێنێت. هەڵبژاردەی `--json`
**گشتی**یە بۆیە دەبێت **پێش** ژێرفەرمان دانرێت.

```bash
# بیرەوەرییەکان: id، دەق و بەش دەربهێنە
omi --json memory list | jq '.[] | {id, content, category}'

# سەردێڕی گفتوگۆی دوایی
omi --json conversation list --limit 5 | jq '.[] | {id, title: .structured.title, started_at}'

# کارە کراوەکان
omi --json action-item list --open | jq '.'
```

> **هەڵەی باو.** `--json` پێش ژێرفەرمان دێت، نەک دوای.
> * ڕاست: `omi --json memory list`
> * هەڵە: `omi memory list --json`

لە مۆدی `--json`دا، پەیامەکانی پێشکەوتن و سپینەری مرۆڤ نادەماون —
stdout تەنھا یەک بەڵگەی JSONی دروست لەخۆدەگرێت. هەڵەکان بۆ stderr
بە شێوەی `{"error": "...", "detail": "..."}` دەچن.

## 5. کۆدەکانی دەرچوون

کۆدەکانی دەرچوونی جێگیر بۆ لێککردن لە سکرێپتدا.

| کۆد | واتا |
| :--- | :--- |
| `0` | سەرکەوتوو |
| `1` | هەڵەی بەکارهێنان (اڵای هەڵە، ئارگیومێنتی پێویست نەمابێت) |
| `2` | ڕەسەنایەت سەرکەوتوو نەبوو — چوونەژوورەوە پێویستە |
| `3` | هەڵەی سێرڤەر/تۆڕ |
| `4` | سنووری خێرایی — دواتر دووبارە هەوڵبدە |
| `5` | سەرچاوە نەدۆزرایەوە |

```bash
if ! omi memory get "$MEMO_ID" --json > /tmp/m.json; then
  code=$?
  case $code in
    2) omi auth login --browser ;;
    5) echo "ئەو بیرەوەرییە نییە" ;;
    *) echo "هەڵە $code" ;;
  esac
fi
```

## 6. پرۆفایلەکان و ڕێکخستن

ئەگەر چەند هەژمار یان ژوورت هەیە، بە پرۆفایل جیایان بکەرەوە.
ڕێکخستنەکان لە `~/.omi/config.toml` پاشەکەوت دەکرێن.

```bash
# بچۆژوورەوە بۆ پرۆفایلی کەسی
omi --profile personal auth login

# بچۆژوورەوە بۆ پرۆفایلی کار
omi --profile work auth login

# فەرمانێک لە پرۆفایلێکی دیاریکراو جێبەجێ بکە
omi --profile work memory list
```

پرۆفایلی بەکارهێنراو بەم ڕیزبەندییەوە دیاری دەکرێت: هەڵبژاردەی `--profile` (یان `-p`)
لەسەر هەمووش پێشەکی دەگرێت; پاشان گۆڕاوەی ژووری `OMI_PROFILE`; پاشان پرۆفایلی
کارگێڕی `~/.omi/config.toml`; و لە کۆتاییدا پرۆفایلی `default` وەک یەدەگ.

خودی ڕێکخستنەکە ببینە و بگۆڕە:

```bash
# ئێستا چی ڕێکخراوە
omi config show

# فایلە ڕێکخستنەکە لە كوێیە
omi config path

# بەهایەک بگۆڕە
omi config set api_base https://api.omi.me
```
