# د omi-cli سره لومړي ګامونه

دا لارښود په پښتو ژبه لومړني امرونه تشریح کوي. د امرونو نومونه او د پروګرام
پیغامونه په انګلیسي پاتې کیږي. دلته ورکړل شوي د پوښتنو مثالونه ستاسو یادونه،
خبرې اترې، دندې یا اهداف نه بدلوي.

## د پروګرام لګول (انسټالول)

اړتیاوې: Python 3.10 یا نوې بڼه او د Omi یو ګڼون (اکاونټ).

که تاسو `pipx` لګولی وي:

```sh
pipx install omi-cli
omi --help
```

په بل ډول، تاسو کولی شئ دا په یو فعال شوي Python مجازي چاپیریال (virtual environment) کې ولګوئ:

```sh
python -m pip install omi-cli
omi --help
```

که ټرمینل `omi` امر ونه موند، وګورئ چې مجازي چاپیریال فعال دی یا هغه پوښۍ چیرې چې `pipx` فایلونه لګوي ستاسو په `PATH` کې شتون لري.

## د خپل ګڼون نښلول

متقابل مرستیال پیل کړئ:

```sh
omi auth login
```

د براوزر له لارې ننوتل یا د Omi پرمخ وړونکي API کیلي د پیسټ کولو اختیار وټاکئ.
متقابل داخلول کیلي پټوي؛ په داسې امر کې د هغې له لیکلو ډډه وکړئ چې د ټرمینل په تاریخ کې پاتې شي.

مستقیماً براوزر ته د تګ لپاره:

```sh
omi auth login --browser
```

په ورته کمپیوټر کې ننوځئ چیرې چې ټرمینل چلیږي: د تصدیق ځواب محلي پته کاروي.
په سکرین کې لارښوونې تعقیب کړئ.

له هغې وروسته، ترتیب او API ته لاسرسی تایید کړئ:

```sh
omi auth status
omi auth whoami
```

`status` محلي حالت ښیې او راز پټوي، مګر په سرور کې اعتبار نه ګوري.
`whoami` یو تصدیق شوی غوښتنه لیږي؛ که بریالۍ شي، دا تاییدوي چې اسناد کار کوي، پرته له دې چې ستاسو نوم ښکاره کړي.

ترتیب په ډیفالټ ډول په `~/.omi/config.toml` کې خوندي کیږي. دا فایل له نورو سره مه شریکوئ: دا ممکن ستاسو محرم اسناد ولري.

## د خپلو معلوماتو لیدل

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

خالي لیست پدې مانا کیدی شي چې هیڅ توکي د پوښتنې سره سمون نه خوري. د هر امر د فلټرونو موندلو لپاره له مرستې څخه کار واخلئ:

```sh
omi memory list --help
omi action-item list --help
```

## د JSON ترلاسه کول او په پاڼو کې ګرځېدل

نړیوال اختیار `--json` د امر ګروپ څخه **مخکې** کیږدئ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

لومړی امر لومړني ۲۵ یادونه غواړي؛ دوهم، راتلونکي ۲۵. نو یوه پاڼه بشپړ بیک اپ نه دی.
د JSON محصول بشپړ پیژندونکي ساتي، پداسې حال کې چې د سکرین جدولونه ممکن د ښودلو لپاره لنډ کړي.

په فایل کې د یوې پاڼې خوندي کولو لپاره:

```sh
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
```

دا لارښوونه محلي فایل جوړوي یا بدلوي. د مینځپانګې کارولو دمخه ډاډ ترلاسه کړئ چې امر په بریالیتوب سره پای ته رسیدلی.
تېروتنې په stderr کې لیکل کیږي؛ خالي فایل دا تضمین نه کوي چې معلومات نشته. صادر شوی فایل ممکن شخصي معلومات ولري: دا محرم وساتئ.

## له ګڼون څخه وتل (Logout)

```sh
omi auth logout
```

دا امر په محلي ډول خوندي شوي اسناد پاکوي. په سرور کې د کیلي لغوه کولو لپاره، په خپل ګڼون کې د پراختیا کونکي کیلي مدیریت وکاروئ.

د نورو امرونو او پرمختللو اختیارونو لپاره، [اصلي انګلیسي لارښود](../README.md) او `omi --help` وګورئ.
