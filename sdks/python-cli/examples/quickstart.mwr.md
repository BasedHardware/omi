# omi-cli सारू छोटो मार्गदर्शन

ओ मार्गदर्शन मारवाड़ी (Marwari) भाषा में `omi-cli` रा सुरुआती कमाण्ड्स रे बारे में समझावे है। कमाण्ड्स रा नांव अर प्रोग्राम रा सन्देस अंग्रेजी में ही रेवेला। अठीने दिया ग्योड़ा उदाहरण थारी यादां (memories), बातां (conversations), करबा जोग काम (action items), या ध्येय (goals) में कोई फेरबदल कोनी करेला।

## प्रोग्राम इन्स्टॉल करबो (Installation)

जरूरी चीजां: Python 3.10 या नयो संस्करण अर एक Omi खातो।

जे थारे कनै `pipx` इन्स्टॉल है:

```sh
pipx install omi-cli
omi --help
```

थे इणने चालू Python वर्चुअल एनवायरनमेंट (virtual environment) में भी इन्स्टॉल कर सको हो:

```sh
python -m pip install omi-cli
omi --help
```

जे टर्मिनल में `omi` कमाण्ड नी मिले, तो जाचो कि वर्चुअल एनवायरनमेंट चालू है या `pipx` वाळो रस्तो थारे `$PATH` में है।

## आपरो खातो जोड़बो (Authentication)

बातचीत वाळो सहायक सुरू करो:

```sh
omi auth login
```

ब्राउजर सूं लॉगिन करबो या आपरी Omi developer API key पेस्ट करबो चुणो। सहायक इनपुट चाबी ने छुपा लेवेला; टर्मिनल रे इतिहास में रेवण वाळे कमाण्ड्स में चाबी मत लिखो।

सीधे ब्राउजर पर जाबा सारू:

```sh
omi auth login --browser
```

उणीज कम्प्यूटर पर लॉगिन करो जीण पर टर्मिनल चाल रह्यो है: पुष्टि वाळो जबाब लोकल पतो इस्तेमाल करे है। स्क्रीन पर दीखता निर्देशां रो पाळण करो।

उणरे बाद, सेटिंग्स अर API पहुँच री जाच करो:

```sh
omi auth status
omi auth whoami
```

`status` लोकल हाल दिखावे है अर गुपत चीजां ने छुपावे है, पण सर्वर पर उणरे चालबा री जाच कोनी करे। `whoami` एक जांचीजी बिनती भेजे है; जे सफल हुयी, तो नांव दिखाए बिना पक्को करे है कि क्रेडेंशियल्स काम कर रह्या है।

सेटिंग्स आमतौर पर `~/.omi/config.toml` में सुरक्षित रेवे है। आ फाइल कींने भी शेयर मत करो: इणमें गुपत क्रेडेंशियल्स हो सके है।

## आपरो डेटा देखबो (Inspection)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

खाली सूची रो मतलब ओ हीज हो सके है कि खोज रे मुजब कोई डेटा कोनी मिल्यो। हर कमाण्ड में फ़िल्टर खोजबा सारू मदद रो इस्तेमाल करो:

```sh
omi memory list --help
omi action-item list --help
```

## JSON लेबो अर पन्ना पलटबो (Pagination)

कमाण्ड समूह सूं **पैली** ग्लोबळ `--json` विकल्प लगावो:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

पैलो कमाण्ड पैली 25 यादां माँगेला; दूजो कमाण्ड आगली 25 यादां माँगेला। एक पन्नो पूरो बैकअप कोनी होवे। JSON आउटपुट पूरा पहचानी कोड सुरक्षित राखे है, जबके स्क्रीन री टेबल इणने छोटो कर सके है।

एक पन्नो फाइल में सहेजबा सारू:

```sh
omi --json memory list --limit 25 --offset 0 > यादां-पन्नो-1.json
```

ओ तरीको लोकल फाइल बणावे है या बदले है। सामग्री इस्तेमाल करबा सूं पैली देखल्यो कि कमाण्ड पूरो हुयो या कोनी। खोट एरर आउटपुट (stderr) में लिखीजे है; खाली फाइल रो मतलब ओ कोनी कि डेटा कोनी है। निकाल्योड़ी फाइल में निजी जानकारी हो सके है: इणने सम्भाळ'र राखो।

## खाते सूं बारै निकलबो (Logout)

```sh
omi auth logout
```

ओ कमाण्ड लोकल रूप सूं सहेज्योड़ा क्रेडेंशियल्स हटावे है। सर्वर सूं चाबी रद्द करबा सारू, आपरे खाते में developer key प्रबन्धन रो उपयोग करो।

दूजा कमाण्ड्स अर घणी सुविधावां सारू, [अंग्रेजी रो मुख्य मार्गदर्शन](../README.md) अर `omi --help` देखो।
