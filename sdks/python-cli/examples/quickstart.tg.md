# omi-cli Дастури оғози сареъ (Tajik Quickstart)

> Дастури амалӣ барои истифодаи Omi мустақиман аз сатри фармон — махсус барои таҳиягарон ва агентҳои мустақили зеҳни сунъӣ (AI).

`omi-cli` — интерфейси расмии сатри фармон (CLI) барои API-и таҳиягарони [Omi](https://omi.me) мебошад. Он дастрасии сохториро ба 4 манбаи асосии Omi таъмин мекунад: хотираҳо (memories), гуфтугӯҳо (conversations), вазифаҳо / амалҳо (action items) ва ҳадафҳо (goals).

* **PyPI:** [pypi.org/project/omi-cli](https://pypi.org/project/omi-cli/)
* **Ҳуҷҷатҳои расмӣ:** [docs.omi.me/doc/developer/cli/introduction](https://docs.omi.me/doc/developer/cli/introduction)
* **Рамзи ибтидоӣ:** [github.com/BasedHardware/omi/tree/main/sdks/python-cli](https://github.com/BasedHardware/omi/tree/main/sdks/python-cli)

---

## 1. Насб (Installation)

Барои пешгирӣ аз ихтилофи бастаҳои системавӣ ва нигоҳдории муҳити ҷудогона, истифодаи `pipx` қатъиян тавсия дода мешавад:

```bash
# Усули тавсияшаванда: насби ҷудогона тавассути pipx
pipx install omi-cli

# Усули алтернативӣ тавассути pip-и муқаррарӣ (масалан, дар муҳити маҷозӣ)
pip install omi-cli
```

> **Эзоҳи муҳим: Номи баста ва номи фармон**
> * Номи расмии баста дар PyPI — **`omi-cli`** аст (бастаи `omi` лоиҳаи дигар буда, ба ин иртибот надорад).
> * Фармоне, ки дар терминал иҷро мешавад, танҳо иборат аст аз: **`omi`**.

Бо санҷиши версия ва менюи кӯмак дурустии насбро муайян кунед:

```bash
omi --version
omi --help
```

## 2. Воридшавӣ ва тасдиқи ҳуввият (Authentication)

`omi-cli` ду усули асосии тасдиқи ҳуввиятро дастгирӣ мекунад:

| Усул | Мақсад | Намунаи фармон |
| :--- | :--- | :--- |
| **Калиди API барои таҳиягарон (`omi_dev_*`)** | Автоматикунонӣ, CI/CD, серверҳои headless, агентҳои AI | `omi auth login --api-key ...` ё `OMI_API_KEY` |
| **Воридшавии OAuth тавассути браузер (Google/Apple)** | Таҳияи маҳаллӣ дар компютери шахсӣ | `omi auth login --browser` (Google) / `--provider apple` |

### Воридшавии интерактивӣ
Иҷрои фармон бидуни параметрҳои иловагӣ менюи интихобро мекушояд:

```bash
omi auth login
# 1) Browser — Воридшавӣ тавассути Google дар браузер (барои Apple парчами `--provider apple`-ро истифода баред)
# 2) API key — Гузоштани калиди API аз app.omi.me
```

### Воридшавии мустақим тавассути браузер
```bash
# Воридшавии стандартӣ бо ҳисоби Google
omi auth login --browser

# Воридшавии алтернативӣ бо профили Apple
omi auth login --browser --provider apple
```

### Воридшавӣ бо калиди API-и таҳиягар
Калиди API-ро аз саҳифаи идоракунии [app.omi.me](https://app.omi.me) дар қисмати **Developer → API Keys** эҷод намоед:

```bash
# Нигоҳ доштани калид дар профили фаъоли маҳаллӣ
omi auth login --api-key omi_dev_...

# Ё ба воситаи тағйирёбандаи муҳит (барои Docker ва CI/CD мувофиқ аст):
# Эзоҳ: Агар дар профил калиди пешина сабт шуда бошад, аввал `omi auth logout`-ро иҷро кунед.
export OMI_API_KEY="omi_dev_калиди_шумо_дар_инҷо"
```

### Санҷиши вазъияти воридшавӣ
* `omi auth status`: Профили фаъол ва нишонаи пӯшидаро бидуни дархости шабакавӣ нишон медиҳад (офлайн кор мекунад).
* `omi auth whoami`: Барои тасдиқи эътибори сессия ба сервери Omi дархост мефиристад (пайвастшавӣ ба интернет лозим аст).

```bash
omi auth status
omi auth whoami
```

### Баромад аз система (Logout)
```bash
omi auth logout
# Агар тағйирёбандаи муҳити OMI_API_KEY-ро истифода карда бошед, онро нест кунед (Bash/Zsh: `unset OMI_API_KEY`).
```

## 3. Фармонҳои асосӣ

### Хотираҳо (Memories)
Ёддоштҳо ва мушоҳидаҳои контекстӣ, ки Omi сабт кардааст:

```bash
# Намоиши рӯйхати хотираҳо
omi memory list

# Эҷоди хотираи нав
omi memory create "Ҷавобҳои мухтасар ва дақиқи техникиро бо намунаҳои Python авлотар медонад" --category work

# Дарёфти хотираи мушаххас аз рӯи ID
omi memory get <MEMORY_ID>
```

### Гуфтугӯҳо (Conversations)
Муколамаҳо ва матнҳои сабтшуда аз дастгоҳҳои Omi:

```bash
# Рӯйхати 5 гуфтугӯи охирин
omi conversation list --limit 5

# Дарёфти гуфтугӯ бо матни пурраи он
omi conversation get <CONVERSATION_ID> --include-transcript
```

### Амалҳо ва вазифаҳо (Action Items)
Вазифаҳое, ки ба таври худкор аз гуфтугӯҳо муайян шудаанд:

```bash
# Рӯйхати вазифаҳои кушода
omi action-item list --open

# Қайд кардани вазифа ҳамчун иҷрошуда
omi action-item complete <ACTION_ITEM_ID>
```

### Ҳадафҳо (Goals)
Ҳадафҳои дарозмуддат ва назорати пешрафт:

```bash
# Рӯйхати ҳадафҳои фаъол
omi goal list

# Эҷоди ҳадафи ададӣ
omi goal create "Ҳар рӯз 2 литр об нӯшидан" --type numeric --target 2 --unit liters
```

## 4. Автоматикунонии сохторӣ ва баромади JSON (`--json`)

`omi-cli` барои скриптҳо ва ҳамгироӣ бо агентҳои AI тарҳрезӣ шудааст. Парчами умумии `--json` маълумотро дар шакли дурусти JSON бармегардонад, ки онро метавон бо утилитҳо ба мисли `jq` коркард кард:

```bash
# Намоиши хотираҳо дар шакли JSON ва филтр кардан бо jq
omi --json memory list | jq '.[] | {id, content, category}'

# Гирифтани сарлавҳаҳои гуфтугӯҳои охирин
omi --json conversation list --limit 5 | jq '.[] | {id, title: .structured.title, started_at}'

# Намоиши вазифаҳои кушода дар формати хоми JSON
omi --json action-item list --open | jq '.'
```

> **Қоидаи муҳими наҳвӣ:**
> Парчами `--json` **опсияи умумӣ** мебошад ва бояд **пеш аз** зеринтихобҳо навишта шавад:
> * Дуруст: `omi --json memory list`
> * Нодуруст: `omi memory list --json`

### Саҳифабандӣ ва содирот ба файлҳо
Барои пайдарпай гирифтани ҳаҷми калони иттилоот аз параметрҳои `--limit` ва `--offset` истифода кунед:

```bash
# Саҳифабандии натиҷаҳо
omi --json memory list --limit 25 --offset 0 > khotiroho-sahifa-1.json
omi --json memory list --limit 25 --offset 25 > khotiroho-sahifa-2.json
```

Равонакунии маълумот ба файл онро дар диск эҷод ё нав мекунад. Ҳамеша рамзи бозгашти фармонро пеш аз коркард санҷед. Паёмҳои хато ба ҷараёни стандартии хатоҳо (stderr) фиристода мешаванд, аз ин рӯ холӣ будани файл нишонаи набудани хато нест. Маълумоти содиротшуда метавонад дорои иттилооти шахсӣ бошад — онҳоро боэҳтиёт нигоҳ доред.

## 5. Рамзҳои бозгашт (Exit Codes)

Пешгирӣ ва идоракунии боэътимоди хатогиҳо дар скриптҳо ва CI/CD:

| Рамз | Мафҳум | Тавсиф |
| :---: | :--- | :--- |
| `0` | **Муваффақият (`EXIT_OK`)** | Фармон бидуни хатогӣ бомуваффақият иҷро шуд. |
| `1` | **Хатогии истифода / наҳвӣ (`EXIT_USAGE`)** | Қиматҳои нодуруст, парчамҳои ношиноси Click ё набудани далелҳои зарурӣ. |
| `2` | **Хатогии тасдиқи ҳуввият (`EXIT_AUTH`)** | Маълумоти нодуруст, калиди беэътибор ё набудани дастрасӣ. |
| `3` | **Хатогии сервер ё шабака (`EXIT_SERVER`)** | Посухи HTTP 5xx, қатъи пайваст ё тамом шудани вақти интизории дархост. |
| `4` | **Маҳдудияти дархостҳо (`EXIT_RATE_LIMITED`)** | Посухи HTTP 429 — шумораи аз ҳад зиёди дархостҳо дар фосилаи кӯтоҳи вақт. |
| `5` | **Сарчашма ёфт нашуд (`EXIT_NOT_FOUND`)** | Посухи HTTP 404 — объекти дархостшуда вуҷуд надорад. |

## 6. Намунаҳо барои муҳитҳои гуногуни сатри фармон

### Bash / Zsh (Linux / macOS)
```bash
export OMI_API_KEY="omi_dev_калиди_шумо_дар_инҷо"

# Иҷрои фармон ва санҷиши рамзи бозгашт
omi --json memory list --limit 10
if [ $? -ne 0 ]; then
    echo "Ҳангоми гирифтани хотираҳо хатогӣ рух дод." >&2
fi
```

### PowerShell (Windows)
```powershell
$env:OMI_API_KEY = "omi_dev_калиди_шумо_дар_инҷо"

# Табдили мустақими баромади JSON ба объекти PowerShell
$memories = omi --json memory list | ConvertFrom-Json
$memories | Select-Object id, content, category

# Санҷиши рамзи бозгашт тавассути $LASTEXITCODE
if ($LASTEXITCODE -ne 0) {
    Write-Error "Фармони Omi бо рамзи хатогӣ анҷом ёфт: $LASTEXITCODE."
}
```

## 7. Ҳамгироӣ бо барномаи маҳаллии мизи корӣ (Local Desktop API)

Агар барномаи мизи кории Omi дар ҳамон компютер кор кунад, шумо метавонед бидуни муроҷиат ба абр мустақиман бо таърихи маҳаллии экран кор кунед:

```bash
# Танзими нишонии маҳаллӣ ва токени дастрасӣ
export OMI_LOCAL_API_URL="http://127.0.0.1:47778"
read -r -s -p "Токени барномаро ворид кунед: " OMI_LOCAL_TOKEN; echo
export OMI_LOCAL_TOKEN

# Санҷиши вазъияти хидмати маҳаллӣ
omi --json local status

# Ҷустуҷӯ дар таърихи экран
omi --json local search-screen "Ҳисоботи семоҳа" --days 7 --app Safari
```

## 8. Кор бо якчанд профилҳо (Profiles)

Парчами `--profile` имкон медиҳад, ки ҳисобҳои корӣ, шахсӣ ё муҳитҳои санҷиширо ҷудо нигоҳ доред. Танзимот дар файли `~/.omi/config.toml` сабт мешавад:

```bash
# Эҷод ва воридшавӣ ба профили шахсӣ
omi --profile personal auth login

# Эҷод ва воридшавӣ ба профили корӣ
omi --profile work auth login

# Иҷрои фармон бо профили мушаххас
omi --profile work memory list

# Истифодаи муҳити озмоишӣ (staging)
omi --profile staging --api-base https://api.staging.omi.me memory list
```

## 9. Амният ва таҷрибаҳои беҳтарин

* **Калидҳоро дар Git нигоҳ надоред:** Ҳеҷ гоҳ калидҳои API-ро ба анборҳои умумӣ илова накунед; аз менеҷерҳои махфӣ ё файлҳои муҳити дар `.gitignore` сабтшуда истифода баред.
* **Муҳофизати таърихи сатри фармон:** Дар компютерҳои умумӣ калидҳоро ба сифати далели фармонҳо нафиристед; аз воридшавии интерактивӣ ё тағйирёбандаи `OMI_API_KEY` истифода намоед.
* **Ҳуқуқҳои дастрасии файлҳо:** Дар системаҳои Unix ба папкаи танзимоти `~/.omi/` маҳдудияти қатъӣ гузоред (`chmod 700 ~/.omi`).
