# omi-cli — дастури зуд оғоз ба кор ба забони тоҷикӣ

> Дастури амалӣ барои кор бо Omi аз терминал. Барои одамон ва агентҳои зеҳни сунъӣ мувофиқ аст.

`omi-cli` — мижози расмии сатри фармон барои API-и барномасозии [Omi](https://omi.me).
Он дастрасии зуд ва скриптшавандаро ба чаҳор воҳиди асосии Omi медиҳад:
хотираҳо, гуфтугӯҳо, вазифаҳо ва ҳадафҳо.

* **PyPI:** [pypi.org/project/omi-cli](https://pypi.org/project/omi-cli/)
* **Ҳуҷҷатҳо:** [docs.omi.me/doc/developer/cli/introduction](https://docs.omi.me/doc/developer/cli/introduction)
* **Сарчашма:** [github.com/BasedHardware/omi/tree/main/sdks/python-cli](https://github.com/BasedHardware/omi/tree/main/sdks/python-cli)

---

## 1. Насб

Усули тавсияшуда `pipx` аст: он асбобро дар муҳити алоҳида насб мекунад,
то вобастагиҳояш бо лоиҳаҳои шумо мухолифат накунанд.

```bash
# тавсияшаванда: насб тавассути pipx
pipx install omi-cli

# ё тавассути pip
pip install omi-cli
```

> **Муҳим: номи баста ва номи фармон фарқ мекунанд.**
> * Бастаи насбшаванда **`omi-cli`** аст (бастаи алоҳидаи `omi` лоиҳаи дигар аст, бе иртибот).
> * Пас аз насб, шумо фармони **`omi`**-ро иҷро мекунед.

Боварӣ ҳосил кунед, ки ҳама чиз кор мекунад:

```bash
omi --version
omi --help
```

## 2. Аутентификатсия

`omi-cli` ду роҳи воридшавиро дастгирӣ мекунад.

| Усул | Барои кӣ мувофиқ аст | Фармон |
| :--- | :--- | :--- |
| **Калиди барномасоз (`omi_dev_*`)** | CI/CD, скриптҳо, агентҳои зеҳни сунъӣ | `omi auth login --api-key ...` ё тағйирёбандаи муҳит |
| **Воридшавӣ тавассути браузер (Google/Apple)** | Кор дар компютери худ | `omi auth login --browser` |

### Воридшавии интерактивӣ

Бе параметр, фармон худаш мепурсад, ки кадом усулро истифода баред:

```bash
omi auth login
# 1) Browser — воридшавӣ бо Google ё Apple (барои одамон қулай)
# 2) API key — гузоштани калиди барномасоз аз app.omi.me (барои агентҳо ва CI қулай)
```

Агар шумо калидро интихоб кунед, воридот пинҳон мешавад, то калид дар таърихи терминал боқӣ намонад.

### Мустақиман тавассути браузер

```bash
omi auth login --browser
```

### Тавассути калиди барномасоз

Калидро дар [app.omi.me](https://app.omi.me) дар **Developer → API Keys** гирифтан мумкин аст.

```bash
# калидро дар танзимот нигоҳ доред
omi auth login --api-key omi_dev_...

# ё онро тавассути муҳит диҳед — барои CI/CD ва контейнерҳо афзалтар аст
export OMI_API_KEY=omi_dev_...
```

Тағйирёбандаи муҳити `OMI_API_KEY` вақте истифода мешавад, ки дар профили фаъол калид сабт нашудааст;
дар контейнер чизе ба диск навиштан лозим нест.
Агар профил аллакай калид дошта бошад, он бар тағйирёбандаи муҳит афзалият дорад.

### Санҷиши пайвастшавӣ

Ду фармон ба ду саволи гуногун ҷавоб медиҳанд ва набояд омехта шаванд:

* `omi auth status` — он чизе ки **дар маҳаллӣ** сабт шудааст: профил, калиди пинҳоншуда, санаи анҷом.
  Бе шабака кор мекунад.
* `omi auth whoami` — дархост **ба сервери Omi**: тафтиш мекунад, ки калид воқеан қабул шудааст.
  Шабака лозим аст.

```bash
omi auth status    # тафтиши маҳаллӣ, офлайн
omi auth whoami    # тафтиш дар тарафи сервер
```

Нав кардани токене, ки мӯҳлаташ наздик аст, бидуни воридшавии дубора — ин фармон
**танҳо ба сессияҳои браузер/OAuth** татбиқ мешавад. Барои профили аутентификатсияшуда
тавассути калиди API (`omi_dev_*`), `omi auth refresh` бо хатои истифода (код 1) ноком мешавад:
токене барои нав кардан нест — калидро дар барномаи веби Omi давр занед, агар лозим бошад:

```bash
omi auth refresh
```

Баромадан:

```bash
omi auth logout
```

## 3. Фармонҳои асосӣ

### Хотираҳо (memories)

Фактҳо ва донише, ки система дар бораи шумо ба ёд гирифтааст.

```bash
# рӯйхати хотираҳо
omi memory list

# сохтани хотираи нав
omi memory create "Корбар мавзӯи торикро мехоҳад" --category lifestyle

# дидани як хотираи мушаххас
omi memory get <MEMORY_ID>
```

### Гуфтугӯҳо (conversations)

Таърихи овозӣ ва матнӣ аз дастгоҳ ё барнома.

```bash
# 5 гуфтугӯи охирин
omi conversation list --limit 5

# гуфтугӯи пурра бо транскриптсия
omi conversation get <CONVERSATION_ID> --include-transcript
```

### Вазифаҳо (action items)

Вазифаҳое, ки Omi аз гуфтугӯҳо баровардааст.

```bash
# танҳо вазифаҳои кушода
omi action-item list --open

# ҳамчун иҷрошуда қайд кардан
omi action-item complete <ACTION_ITEM_ID>
```

### Ҳадафҳо (goals)

```bash
# рӯйхати ҳадафҳо
omi goal list

# сабти арзиши нави пешрафт (ҲАР ДУ аргумент лозим аст: ҳадаф ва арзиш)
omi goal progress <GOAL_ID> 25

# таърихи тағйирот
omi goal history <GOAL_ID>
```

## Савол додан бо суханони худ (`ask`)

Фармони алоҳидаи сатҳи боло: саволро бо забони табиӣ мепурсад,
ва ҷавоб аз гуфтугӯҳои худи шумо сохта мешавад.

```bash
omi ask "ман дар бораи кӯчидан чӣ қарор кардам"
omi --json ask "кадом вазифаҳоро ваъда додам, ки ин ҳафта анҷом диҳам"
```

## 4. JSON ва скриптҳо (`--json`)

`omi-cli` метавонад JSON-и барои мошин хондан мувофиқ тавлид кунад. Параметри `--json` **глобалӣ** аст
ва бинобар ин **пеш аз** зерфармон ҷойгир мешавад.

```bash
# хотираҳо: гирифтани id, матн ва категория
omi --json memory list | jq '.[] | {id, content, category}'

# унвонҳои гуфтугӯҳои охирин
omi --json conversation list --limit 5 | jq '.[] | {id, title: .structured.title, started_at}'

# вазифаҳои кушода
omi --json action-item list --open | jq '.'
```

> **Хатои маъмули.** `--json` пеш аз зерфармон меояд, на пас аз он.
> * Дуруст: `omi --json memory list`
> * Нодуруст: `omi memory list --json`

Дар ҳолати `--json`, ба ҷуз худи JSON, чизи дигаре ба stdout навишта намешавад —
скриптҳо метавонанд ба он такя кунанд.

## 5. Кодҳои баромад

Кодҳо устуворанд: мантиқи скриптҳо ва CI метавонад ба онҳо пайваст шавад.

| Код | Маъно | Кай |
| :---: | :--- | :--- |
| `0` | Муваффақият | Фармон иҷро шуд |
| `1` | Хатои муроҷиат | Валидатсияи хоси omi-cli (масалан `--browser` ва `--api-key` якҷоя, интихоби нодурусти воридшавӣ, stdin холӣ) |
| `2` | Хатои дастрасӣ | Ворид нашудааст, калид нодуруст ё мӯҳлаташ гузаштааст |
| `3` | Хатои сервер | Ҷавоби 5xx, гузаштани вақт, бе пайвастшавӣ |
| `4` | Дархостҳо аз ҳад зиёд | 429 Too Many Requests |
| `5` | Ёфт нашуд | 404, идентификатор вуҷуд надорад |

> **Эзоҳ.** Параметрҳои номаълум ва аргументҳои гумшуда аз ҷониби Click қатъ мешаванд ва код `2` медиҳанд.

Мисоли санҷиш дар Bash:

```bash
if omi --json auth whoami > /dev/null 2>&1; then
  echo "калид кор мекунад"
else
  code=$?
  [ "$code" -eq 2 ] && echo "аз нав ворид шавед"
  [ "$code" -eq 3 ] && echo "сервер кор намекунад, баъдтар кӯшиш кунед"
fi
```

## 6. Тағйирёбандаҳои муҳит

### Bash / Zsh (Linux, macOS)

```bash
export OMI_API_KEY="omi_dev_калиди_шумо"

omi --json memory list --limit 10
```

Барои он ки калид дар сессияҳои нав бор карда шавад, сатрро ба `~/.bashrc` ё `~/.zshrc` илова кунед.

### PowerShell (Windows)

```powershell
$env:OMI_API_KEY = "omi_dev_калиди_шумо"

# таҳлили JSON бо PowerShell
(omi --json memory list | ConvertFrom-Json) | Select-Object id, content
```

Барои танзими доимӣ:

```powershell
[Environment]::SetEnvironmentVariable("OMI_API_KEY", "omi_dev_калиди_шумо", "User")
```

## 7. Барномаи Omi Desktop дар маҳал

Агар барномаи мизи кории Omi дар ҳоли иҷро бошад, як қисми маълумот
мустақиман, бидуни гузаштан аз абр дастрас аст.

```bash
# нишон додани суроғаи API-и маҳаллӣ
omi local configure --url http://127.0.0.1:47778 --token ТОКЕНИ_ШУМО

# тафтиш, ки ҷавоб медиҳад
omi --json local status

# ҷустуҷӯ дар таърихи экран
omi --json local search-screen "нархҳо" --days 7 --app Safari

# гирифтани скриншот бо идентификатор
omi --json local screenshot 123 --output /tmp/omi-shot.jpg

# SQL-и дилхоҳ ба пойгоҳи маҳаллӣ
omi --json local sql "SELECT appName, COUNT(*) FROM screenshots GROUP BY appName"
```

Тартиби тавсияшаванда: аввал `local status`, баъд `local tools` — барои дидани
асбобҳои дастрас ва параметрҳояшон — ва танҳо баъд муроҷиатҳо.

## 8. Профилҳо

Агар шумо якчанд ҳисоб ё муҳит дошта бошед, онҳоро бо профилҳо ҷудо кунед.
Танзимот дар `~/.omi/config.toml` нигоҳ дошта мешаванд.

```bash
# воридшавӣ ба профили шахсӣ
omi --profile personal auth login

# воридшавӣ ба профили корӣ
omi --profile work auth login

# иҷрои фармон дар профили мушаххас
omi --profile work memory list
```

Профили истифодашаванда бо ин тартиб муайян мешавад: параметри `--profile` (ё `-p`) бар ҳама чиз
афзалият дорад; баъд тағйирёбандаи муҳити `OMI_PROFILE`; баъд профили фаъоли дар
`~/.omi/config.toml` муайяншуда; ва дар охир профили `default`.

Дидан ва тағйир додани худи танзимот:

```bash
# он чизе ки ҳозир танзим шудааст
omi config show

# файли танзимот дар куҷост
omi config path

# тағйир додани як арзиш
omi config set api_base https://api.omi.me
```
