# Први чекори со omi-cli

Овој водич ги објаснува првите команди на македонски јазик. Имињата на
командите и пораките на програмата остануваат на англиски јазик. Примерите за
пребарување прикажани овде не ги менуваат вашите спомени, разговори, задачи
или цели.

## Инсталација на програмата

Барања: Python 3.10 или понова верзија и Omi сметка.

Ако имате инсталирано `pipx`:

```sh
pipx install omi-cli
omi --help
```

Алтернативно, можете да ја инсталирате во рамките на активирана виртуелна
средина на Python (virtual environment):

```sh
python -m pip install omi-cli
omi --help
```

Ако терминалот не ја пронајде `omi`, проверете дали виртуелната средина е
активирана или дали директориумот каде `pipx` ги инсталира извршните датотеки
е во вашиот `PATH`.

## Поврзување на вашата сметка

Стартувајте го интерактивниот асистент:

```sh
omi auth login
```

Изберете најавување преку прелистувач или опција за лепење на развоен API клуч
од Omi. Интерактивниот внес го крие клучот; избегнувајте да го пишувате во
команда што ќе остане во историјата на терминалот.

За директно отворање на прелистувачот:

```sh
omi auth login --browser
```

Најавете се на истиот компјутер каде што работи терминалот: одговорот за
автентикација користи локална адреса. Следете ги упатствата на екранот.

Потоа, потврдете ја конфигурацијата и пристапот до API:

```sh
omi auth status
omi auth whoami
```

`status` ја прикажува локалната состојба и ја крие тајната, но не ја проверува
валидноста на серверот. `whoami` испраќа автентицирано барање; ако успее,
потврдува дека акредитивите работат, без нужно да го прикажува вашето име.

Конфигурацијата стандардно се зачувува во `~/.omi/config.toml`. Не ја споделувајте
оваа датотека: таа може да ги содржи вашите доверливи акредитиви.

## Преглед на вашите податоци

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Празна листа може едноставно да значи дека нема ставки што одговараат на
барањето. Користете помош за да ги откриете филтрите за секоја команда:

```sh
omi memory list --help
omi action-item list --help
```

## Добивање JSON и навигација низ страници

Поставете ја глобалната опција `--json` **пред** групата команди:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Првата команда ги бара првите 25 спомени; втората, следните 25. Една страница
затоа не е целосна резервна копија (backup). JSON излезот ги задржува целосните
идентификатори, додека табелите на екранот може да ги скратат за приказ.

За зачувување на страница во датотека:

```sh
omi --json memory list --limit 25 --offset 0 > spomeni-stranica-1.json
```

Ова пренасочување ја креира или заменува локалната датотека. Проверете дали
командата завршила успешно пред да ја користите нејзината содржина. Грешките се
запишуваат на излезот за грешки (stderr); празна датотека не гарантира дека
нема податоци. Извезената датотека може да содржи лични информации: чувајте ја приватна.

## Одјавување од сметката (Logout)

```sh
omi auth logout
```

Оваа команда ги брише локално зачуваните акредитиви. За да отповикате клуч на
серверот, користете го управувањето со развојни клучеви на вашата сметка.

За останатите команди и напредни опции, погледнете го
[главниот водич на англиски](../README.md) и `omi --help`.
