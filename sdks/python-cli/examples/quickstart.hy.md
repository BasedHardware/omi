# Առաջին քայլերը omi-cli-ով

Այս ուղեցույցը բացատրում է առաջին հրամանները հայերենով: Հրամանների անունները
և ծրագրի հաղորդագրությունները մնում են անգլերեն: Այստեղ ներկայացված հարցումների
օրինակները չեն փոփոխում ձեր հիշողությունները, խոսակցությունները, առաջադրանքները
կամ նպատակները:

## Ծրագրի տեղադրում

Պահանջներ՝ Python 3.10 կամ ավելի նոր տարբերակ և Omi հաշիվ:

Եթե ունեք տեղադրված `pipx`՝

```sh
pipx install omi-cli
omi --help
```

Որպես այլընտրանք, կարող եք տեղադրել այն ակտիվացված Python վիրտուալ միջավայրում
(virtual environment)՝

```sh
python -m pip install omi-cli
omi --help
```

Եթե տերմինալը չի գտնում `omi`-ն, համոզվեք, որ վիրտուալ միջավայրն ակտիվացված է,
կամ այն թղթապանակը, որտեղ `pipx`-ը տեղադրում է գործարկվող ֆայլերը, գտնվում է
ձեր `PATH`-ում:

## Ձեր հաշվի միացումը

Գործարկեք ինտերակտիվ օգնականը՝

```sh
omi auth login
```

Ընտրեք մուտք գործել բրաուզերի միջոցով կամ Omi մշակողի API բանալին տեղադրելու
տարբերակը: Ինտերակտիվ մուտքագրումը թաքցնում է բանալին. խուսափեք այն գրել
հրամանում, որը կմնա տերմինալի պատմության մեջ:

Անմիջապես բրաուզեր անցնելու համար՝

```sh
omi auth login --browser
```

Մուտք գործեք նույն համակարգչով, որտեղ աշխատում է տերմինալը. նույնականացման
պատասխանն օգտագործում է տեղական հասցե: Հետևեք էկրանին հայտնվող հրահանգներին:

Դրանից հետո ստուգեք կազմաձևումը և API հասանելիությունը՝

```sh
omi auth status
omi auth whoami
```

`status`-ը ցույց է տալիս տեղական վիճակը և թաքցնում է գաղտնիքը, բայց չի
ստուգում վավերականությունը սերվերի վրա: `whoami`-ն կատարում է նույնականացված
հարցում. հաջողության դեպքում այն հաստատում է, որ հավատարմագրերն աշխատում են՝
առանց անպայման ձեր անունը ցուցադրելու:

Կազմաձևումը լռելյայն պահվում է `~/.omi/config.toml` ֆայլում: Մի տարածեք այս
ֆայլը. այն կարող է պարունակել ձեր գաղտնի տվյալները:

## Ձեր տվյալների դիտումը

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Դատարկ ցուցակը կարող է պարզապես նշանակել, որ հարցմանը համապատասխանող տարրեր չկան:
Օգտագործեք օգնությունը՝ յուրաքանչյուր հրամանի զտիչները բացահայտելու համար՝

```sh
omi memory list --help
omi action-item list --help
```

## JSON-ի ստացում և էջերի նավարկում

Տեղադրեք գլոբալ ընտրանքը `--json` հրամանների խմբից **առաջ**՝

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Առաջին հրամանը հարցնում է առաջին 25 հիշողությունները, երկրորդը՝ հաջորդ 25-ը:
Հետևաբար, մեկ էջը ամբողջական պահուստային պատճեն չէ (backup): JSON ելքը պահպանում է
ամբողջական նույնացուցիչները, մինչդեռ էկրանի աղյուսակները կարող են կրճատել դրանք ցուցադրման համար:

Էջը ֆայլում պահելու համար՝

```sh
omi --json memory list --limit 25 --offset 0 > hishoxutyunner-ej-1.json
```

Այս վերահասցեավորումը ստեղծում կամ փոխարինում է տեղական ֆայլը: Համոզվեք, որ հրամանը
հաջողությամբ ավարտվել է նախքան դրա բովանդակությունն օգտագործելը: Սխալները գրվում են
սխալների ելքում (stderr). դատարկ ֆայլը չի երաշխավորում, որ տվյալներ չկան: Արտահանված
ֆայլը կարող է պարունակել անձնական տեղեկություններ. պահեք այն գաղտնի:

## Հաշվից դուրս գալ (Logout)

```sh
omi auth logout
```

Այս հրամանը ջնջում է տեղական մակարդակով պահպանված հավատարմագրերը: Սերվերում բանալին
չեղարկելու համար օգտագործեք ձեր հաշվում մշակողի բանալիների կառավարումը:

Մնացած հրամանների և առաջադեմ ընտրանքների համար տես
[անգլերեն հիմնական ուղեցույցը](../README.md) և `omi --help`:
