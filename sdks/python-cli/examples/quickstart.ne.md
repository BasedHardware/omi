# omi-cli सँग सुरुवात (Nepali Quickstart)

यो मार्गदर्शिकाले नेपालीमा प्रारम्भिक आदेशहरू (commands) बारे व्याख्या गर्दछ। कमाण्डका नामहरू र प्रोग्राम सन्देशहरू अंग्रेजीमै रहनेछन्। यहाँ दिइएका उदाहरणहरूले तपाईंका सम्झनाहरू (memories), कुराकानीहरू (conversations), कार्यहरू (action items) वा लक्ष्यहरू (goals) मा कुनै परिवर्तन गर्दैनन्।

## प्रोग्राम स्थापना (Installation)

आवश्यकताहरू: Python 3.10 वा सोभन्दा नयाँ संस्करण र एउटा Omi खाता।

यदि तपाईंसँग `pipx` इन्स्टल छ भने:

```sh
pipx install omi-cli
omi --help
```

वा सक्रिय गरिएको Python भर्चुअल वातावरण (virtual environment) भित्र:

```sh
python -m pip install omi-cli
omi --help
```

यदि टर्मिनलले `omi` फेला पार्न सकेन भने, भर्चुअल वातावरण सक्रिय छ कि छैन वा `pipx` को डाइरेक्टरी तपाईंको `PATH` मा समावेश छ कि छैन जाँच गर्नुहोस्।

## आफ्नो खाता जडान गर्ने (Connecting Your Account)

अन्तर्क्रियात्मक लगइन सुरु गर्नुहोस्:

```sh
omi auth login
```

ब्राउजर मार्फत लगइन छनौट गर्नुहोस् वा आफ्नो Omi विकासकर्ता API कुञ्जी (API key) पेस्ट गर्नुहोस्। अन्तर्क्रियात्मक इनपुटले कुञ्जी लुकाउँछ; टर्मिनलको इतिहासमा कुञ्जी लेख्नबाट बच्नुहोस्।

सिधै ब्राउजर प्रयोग गर्न:

```sh
omi auth login --browser
```

टर्मिनल खुला भएकै कम्प्युटरमा लगइन गर्नुहोस्: प्रमाणीकरणले स्थानीय ठेगाना प्रयोग गर्दछ। स्क्रिनमा दिइएका निर्देशनहरू पालना गर्नुहोस्।

त्यसपछि, कन्फिगरेसन र API पहुँच प्रमाणित गर्नुहोस्:

```sh
omi auth status
omi auth whoami
```

`status` ले स्थानीय स्थिति देखाउँछ र गोप्य जानकारी लुकाउँछ, तर सर्भरमा यसको वैधता जाँच गर्दैन। `whoami` ले एउटा प्रमाणित अनुरोध गर्दछ; यदि सफल भयो भने, यसले प्रमाणहरूले सही रूपमा काम गरिरहेको पुष्टि गर्दछ।

कन्फिगरेसन पूर्वनिर्धारित रूपमा `~/.omi/config.toml` मा सुरक्षित गरिन्छ। यो फाइल कसैसँग साझेदारी नगर्नुहोस्: यसमा तपाईंका प्रमाणहरू हुन सक्छन्।

## आफ्नो डेटा हेर्ने (Querying Data)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

खाली सूचीको अर्थ अनुरोधसँग मेल खाने कुनै डेटा नभएको हुन सक्छ। प्रत्येक कमाण्डका फिल्टरहरू बारे जान्न मद्दत हेर्नुहोस्:

```sh
omi memory list --help
omi action-item list --help
```

## JSON प्राप्त गर्ने र पृष्ठहरू सञ्चालन गर्ने (Pagination)

विश्वव्यापी `--json` विकल्पलाई कमाण्ड समूहभन्दा **अगाडि** राख्नुहोस्:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

पहिलो कमाण्डले पहिलो २५ वटा सम्झनाहरू ल्याउँछ; दोस्रोले त्यसपछिका २५ वटा ल्याउँछ। त्यसैले एउटा पृष्ठ पूर्ण ब्याकअप होइन। JSON आउटपुटले पूर्ण आईडीहरू राख्दछ, जबकि तालिकाहरूले प्रदर्शनका लागि यसलाई छोटो बनाउन सक्छन्।

कुनै पृष्ठलाई फाइलमा सुरक्षित गर्न:

```sh
omi --json memory list --limit 25 --offset 0 > yaadan-page-1.json
```

यो रिडिरेक्सनले स्थानीय फाइल सिर्जना गर्छ वा प्रतिस्थापन गर्छ। प्रयोग गर्नु अघि कमाण्ड सफलतापूर्वक सम्पन्न भएको जाँच गर्नुहोस्। निर्यात गरिएको फाइलमा व्यक्तिगत डेटा हुन सक्छ: यसलाई सुरक्षित राख्नुहोस्।

## लगआउट गर्ने

```sh
omi auth logout
```

यो कमाण्डले स्थानीय रूपमा सुरक्षित गरिएका प्रमाणहरू हटाउँछ। सर्भरमा कुञ्जी रद्द गर्न, आफ्नो खाताको विकासकर्ता पोर्टल प्रयोग गर्नुहोस्।

अन्य कमाण्डहरू र उन्नत विकल्पहरूका लागि, [मुख्य अंग्रेजी मार्गदर्शिका](../README.md) र `omi --help` हेर्नुहोस्।
