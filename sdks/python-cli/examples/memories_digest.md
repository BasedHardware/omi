# Build a Memories Digest (Category Breakdown, Knowledge Clusters, Capture Timeline)

Use this recipe to explore trends, category distributions, and top knowledge clusters in your captured
memories without reading raw JSON files: it turns one or more `memory list` JSON exports into a concise
Markdown digest with category breakdowns, top tag frequencies, monthly capture cadence, and recent highlights.
It operates completely offline, makes zero external network requests, and writes to stdout or standalone
Markdown files.

---

## Prerequisites

Ensure you have the `omi` CLI installed and authenticated:

```sh
pip install omi-cli
omi auth login
```

Export your memories (up to 200 items per batch):

```sh
omi --json memory list --limit 200 > memories.json
```

Verify that the export file was populated before running the recipe. If you have multiple export batches or
backups, provide them together (e.g. `batch1.json batch2.json`); the converter deduplicates items by their ID.

---

## Quickstart

### 1. Direct Pipeline Stream (Stdout)

Generate a digest directly from the CLI output stream into your terminal:

```sh
omi --json memory list --limit 200 | python memories_to_digest.py -
```

### 2. Export to a Dedicated Markdown Report

Generate a standalone digest file:

```sh
python memories_to_digest.py memories.json -o digest.md
```

### 3. Apply Local Timezone Offsets

Convert UTC timestamps to your local timezone (e.g. `+09:00` for JST or `-05:00` for EST):

```sh
python memories_to_digest.py memories.json -o digest.md --utc-offset +09:00
```

### 4. Filter by Category

Generate a focused digest of a specific memory category (e.g. `work`, `skills`, or `learnings`):

```sh
python memories_to_digest.py memories.json --category work -o work_digest.md
```

## CLI Options

| Option | Flag | Description | Default |
| :--- | :--- | :--- | :--- |
| `inputs` | Positional | One or more JSON export files, or `-` for stdin | *(Required)* |
| `--output` | `-o` | Destination Markdown file path | `stdout` |
| `--category` | `--category` | Filter memories by category (e.g. `work`, `skills`) | `None` (All) |
| `--utc-offset` | `--utc-offset`| Timezone offset in `±HH:MM` format (e.g. `+09:00`, `-05:00`)| UTC (`+00:00`) |
| `--overwrite` | `--overwrite` | Allow overwriting existing destination files | `False` |

## Digest Sections

1. **Executive Summary**: High-level totals, category diversity, tagging ratios, and privacy counts.
2. **Summary Metrics Table**: Structured tabular breakdown of capture metrics.
3. **Categories Breakdown**: Frequency table sorted by popularity with emoji badges and top tags.
4. **Top Knowledge Tags**: Top 10 identified tags sorted by mention frequency and portfolio share.
5. **Monthly Capture Cadence**: Chronological monthly breakdown of capture volumes.
6. **Recent Memory Highlights**: Chronological list of recent memories with truncated preview text.

## Design Principles

- **Zero Third-Party Dependencies**: Pure Python 3.10+ standard library (`argparse`, `datetime`, `json`, `pathlib`).
- **Safe POSIX File Permissions**: Uses standard umask creation modes (`0644`) rather than restrictive tempfile modes.
- **Atomic File Operations**: Writes to a temporary file before renaming when `--overwrite` is specified.
- **Markdown Metacharacter Escaping**: Automatically sanitizes table and list metacharacters to
  prevent syntax corruption.
- **Pipeline Ready**: Supports piped stdin (`-`) and clean `BrokenPipeError` signal handling for commands like `| head`.
