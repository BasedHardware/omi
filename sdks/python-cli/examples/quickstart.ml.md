# omi-cli മലയാളം ദ്രുത ആരംഭ സഹായി (Malayalam Quickstart Guide)

> ടെർമിനലിൽ നിന്ന് Omi-യുമായി സംവദിക്കുന്നതിനുള്ള പ്രായോഗിക വഴികാട്ടി. ഡെവലപ്പർമാർക്കും AI ഏജന്റുകൾക്കും ഒരുപോലെ ഉപയോഗപ്രദമാണ്.

`omi-cli` എന്നത് [Omi](https://omi.me) ഡെവലപ്പർ API ഉപയോഗിക്കുന്നതിനുള്ള ഔദ്യോഗിക കമാൻഡ്-ലൈൻ ഇന്റർഫേസ് (CLI) ആണ്. Omi-യിലെ നാല് പ്രധാന വിഭവങ്ങൾ (ഓർമ്മകൾ, സംഭാഷണങ്ങൾ, ചെയ്യേണ്ട കാര്യങ്ങൾ, ലക്ഷ്യങ്ങൾ) കാര്യക്ഷമമായി കൈകാര്യം ചെയ്യാനും സ്ക്രിപ്റ്റുകൾ വഴി ഓട്ടോമേറ്റ് ചെയ്യാനും ഇത് സഹായിക്കുന്നു.

* **PyPI:** [pypi.org/project/omi-cli](https://pypi.org/project/omi-cli/)
* **ഔദ്യോഗിക ഡോക്യുമെന്റേഷൻ:** [docs.omi.me/doc/developer/cli/introduction](https://docs.omi.me/doc/developer/cli/introduction)
* **സോഴ്സ് കോഡ്:** [github.com/BasedHardware/omi/tree/main/sdks/python-cli](https://github.com/BasedHardware/omi/tree/main/sdks/python-cli)

## 1. ഇൻസ്റ്റാളേഷൻ (Installation)

മറ്റ് പൈത്തൺ പാക്കേജുകളിൽ നിന്ന് വേറിട്ടുനിൽക്കാൻ `pipx` വഴി ഇൻസ്റ്റാൾ ചെയ്യുന്നതാണ് ഏറ്റവും നല്ല മാർഗ്ഗം:

```bash
# ശുപാർശ ചെയ്യുന്ന രീതി: pipx വഴി ഇൻസ്റ്റാൾ ചെയ്യുക
pipx install omi-cli

# അല്ലെങ്കിൽ pip ഉപയോഗിച്ച്
pip install omi-cli
```

> **പ്രധാനപ്പെട്ട കുറിപ്പ്: പാക്കേജ് നാമവും കമാൻഡ് നാമവും തമ്മിലുള്ള വ്യത്യാസം**
> * പൈത്തൺ പാക്കേജിന്റെ പേര് **`omi-cli`** എന്നാണ് (PyPI-യിലെ `omi` എന്നത് ബന്ധമില്ലാത്ത മറ്റൊരു പാക്കേജാണ്, അത് ഇൻസ്റ്റാൾ ചെയ്യരുത്).
> * ഇൻസ്റ്റാൾ ചെയ്ത ശേഷം ടെർമിനലിൽ റൺ ചെയ്യേണ്ട കമാൻഡിന്റെ പേര് **`omi`** എന്നാണ്.

ഇൻസ്റ്റാളേഷൻ പൂർത്തിയായ ശേഷം പതിപ്പും സഹായവും പരിശോധിക്കുക:

```bash
omi --version
omi --help
```

## 2. പ്രാമാണീകരണം (Authentication)

`omi-cli` രണ്ട് പ്രാമാണീകരണ രീതികളെ പിന്തുണയ്ക്കുന്നു:

| രീതി | പ്രധാന ഉപയോഗം | ഉദാഹരണ കമാൻഡ് |
| :--- | :--- | :--- |
| **ഡെവലപ്പർ API കീ (`omi_dev_*`)** | CI/CD, ഓട്ടോമേഷൻ സ്ക്രിപ്റ്റുകൾ, AI ഏജന്റുകൾ | `omi auth login --api-key ...` അല്ലെങ്കിൽ എൻവയോൺമെന്റ് വേരിയബിളുകൾ |
| **ബ്രൗസർ OAuth (Google/Apple)** | ഡെവലപ്പറുടെ സ്വകാര്യ ലാപ്‌ടോപ്പ് / കമ്പ്യൂട്ടർ | `omi auth login --browser` |

### ഇന്ററാക്ടീവ് ലോഗിൻ (Interactive Login)
ഫ്ലാഗുകളൊന്നുമില്ലാതെ കമാൻഡ് റൺ ചെയ്താൽ ബ്രൗസർ അല്ലെങ്കിൽ API കീ തിരഞ്ഞെടുക്കാനുള്ള ഓപ്ഷൻ ലഭിക്കും:

```bash
omi auth login
# 1) Browser — Google അല്ലെങ്കിൽ Apple അക്കൗണ്ട് വഴി ലോഗിൻ ചെയ്യുക (വ്യക്തികൾക്കായി)
# 2) API key — app.omi.me-ൽ നിന്ന് ഡെവലപ്പർ കീ നൽകുക (ഏജന്റുകൾ/CI-ക്കായി)
```

### നേരിട്ട് ബ്രൗസർ വഴി ലോഗിൻ ചെയ്യുക
```bash
omi auth login --browser
```

### API കീ ഉപയോഗിക്കുക
[app.omi.me](https://app.omi.me)-ലെ "Developer → API Keys" വിഭാഗത്തിൽ നിന്ന് കീ എടുത്ത് സെറ്റ് ചെയ്യുക:

```bash
# കമാൻഡ് വഴി സെറ്റ് ചെയ്യുക
omi auth login --api-key omi_dev_...

# അല്ലെങ്കിൽ എൻവയോൺമെന്റ് വേരിയബിൾ വഴി സെറ്റ് ചെയ്യുക (CI/CD-ക്ക് ഉചിതം)
export OMI_API_KEY=omi_dev_...
```

### പ്രാമാണീകരണ നില പരിശോധിക്കുക
* `omi auth status`: പ്രാദേശിക പ്രൊഫൈൽ, മറച്ച ടോക്കൺ, കാലാവധി തീരുന്ന സമയം എന്നിവ കാണിക്കുന്നു (ഓഫ്‌ലൈനായി പ്രവർത്തിക്കും).
* `omi auth whoami`: സെർവറിലേക്ക് അഭ്യർത്ഥന അയച്ച് കീ സാധുവാണോ എന്ന് സ്ഥിരീകരിക്കുന്നു (ഇന്റർനെറ്റ് ആവശ്യമാണ്).

```bash
omi auth status
omi auth whoami
```

വിവരങ്ങൾ നീക്കംചെയ്യാൻ ലോഗ്ഔട്ട് ചെയ്യുക:
```bash
omi auth logout
```

ക്രമീകരണ ഫയൽ സ്വതവേ `~/.omi/config.toml` എന്നതിൽ സുരക്ഷിതമായി സൂക്ഷിക്കുന്നു. ഇത് ആരുമായും പങ്കിടരുത്.

## 3. അടിസ്ഥാന ഉപയോഗം (Basic Usage)

Omi-യുടെ നാല് പ്രധാന വിഭവങ്ങൾ കൈകാര്യം ചെയ്യൽ:

### ഓർമ്മകൾ (Memories)
സിസ്റ്റം പഠിച്ച വസ്തുതകളും വിവരങ്ങളും കൈകാര്യം ചെയ്യുക:

```bash
# ഓർമ്മകളുടെ പട്ടിക കാണുക
omi memory list

# പുതിയ ഓർമ്മ ചേർക്കുക
omi memory create "ഉപയോക്താവ് ഡാർക്ക് മോഡ് ഇഷ്ടപ്പെടുന്നു" --category lifestyle

# നിർദ്ദിഷ്ട ഓർമ്മയുടെ വിശദാംശങ്ങൾ കാണുക
omi memory get <MEMORY_ID>
```

### സംഭാഷണങ്ങൾ (Conversations)
ഉപകരണത്തിൽ നിന്നോ ആപ്പിൽ നിന്നോ റെക്കോർഡ് ചെയ്ത ഓഡിയോയും ട്രാൻസ്ക്രിപ്റ്റുകളും:

```bash
# സമീപകാലത്തെ 5 സംഭാഷണങ്ങൾ കാണുക
omi conversation list --limit 5

# സംഭാഷണത്തിന്റെ പൂർണ്ണ വിവരങ്ങളും ട്രാൻസ്ക്രിപ്റ്റും കാണുക
omi conversation get <CONVERSATION_ID> --include-transcript
```

### ചെയ്യേണ്ട കാര്യങ്ങൾ (Action Items)
സംഭാഷണങ്ങളിൽ നിന്ന് സ്വയമേവ വേർതിരിച്ചെടുത്ത ജോലികൾ:

```bash
# പൂർത്തിയാകാത്ത ജോലികളുടെ പട്ടിക മാത്രം കാണുക
omi action-item list --open

# ജോലി പൂർത്തിയായതായി അടയാളപ്പെടുത്തുക
omi action-item complete <ACTION_ITEM_ID>
```

### ലക്ഷ്യങ്ങൾ (Goals)
ട്രാക്ക് ചെയ്യുന്ന ലക്ഷ്യങ്ങൾ പരിശോധിക്കുക:

```bash
# ലക്ഷ്യങ്ങളുടെ പട്ടിക കാണുക
omi goal list
```

## 4. സ്ക്രിപ്റ്റിംഗും JSON ഔട്ട്പുട്ടും (`--json`)

`omi-cli` നേരിട്ട് JSON ഔട്ട്പുട്ടിനെ പിന്തുണയ്ക്കുന്നു. `jq` അല്ലെങ്കിൽ മറ്റ് പ്രോഗ്രാമുകളുമായി ഉപയോഗിക്കുമ്പോൾ `--json` ആഗോള ഓപ്ഷൻ **സബ്-കമാൻഡിന് മുമ്പിൽ** നൽകണം:

```bash
# ഓർമ്മകളെ JSON രൂപത്തിൽ നേടി ID-യും ഉള്ളടക്കവും വേർതിരിക്കുക
omi --json memory list | jq '.[] | {id, content, category}'

# സമീപകാല സംഭാഷണങ്ങളുടെ തലക്കെട്ടുകൾ കാണുക
omi --json conversation list --limit 5 | jq '.[] | {id, title: .structured.title, started_at}'

# ശേഷിക്കുന്ന ജോലികൾ JSON-ൽ കാണുക
omi --json action-item list --open | jq '.'
```

> **പ്രധാന നിയമം:** `--json` ഫ്ലാഗ് എപ്പോഴും സബ്-കമാൻഡിന് **മുമ്പിൽ** വെയ്ക്കുക:
> * ശരി: `omi --json memory list`
> * തെറ്റ്: `omi memory list --json`

### ഫയലിലേക്ക് സൂക്ഷിക്കലും പേജിനേഷനും (Pagination)

```bash
# ആദ്യത്തെ 25 രേഖകൾ ഫയലിൽ സൂക്ഷിക്കുക
omi --json memory list --limit 25 --offset 0 > ormmakal-page-1.json

# അടുത്ത 25 രേഖകൾ ലഭ്യമാക്കുക
omi --json memory list --limit 25 --offset 25 > ormmakal-page-2.json
```

## 5. എക്സിറ്റ് കോഡുകൾ (Exit Codes)

ഓട്ടോമേഷൻ സ്ക്രിപ്റ്റുകളിൽ പിശകുകൾ തിരിച്ചറിയാൻ താഴെ പറയുന്ന എക്സിറ്റ് കോഡുകൾ സഹായിക്കുന്നു:

| കോഡ് | തരം | വിവരണം |
| :---: | :--- | :--- |
| `0` | Success | കമാൻഡ് വിജയകരമായി പൂർത്തിയായി |
| `1` | Usage Error | തെറ്റായ ഫ്ലാഗുകൾ അല്ലെങ്കിൽ അപൂർണ്ണമായ വിവരങ്ങൾ |
| `2` | Auth Error | ലോഗിൻ ചെയ്തിട്ടില്ല, അസാധുവായ API കീ അല്ലെങ്കിൽ കാലാവധി കഴിഞ്ഞ ടോക്കൺ |
| `3` | Server Error | സെർവർ പിശക് (5xx), നെറ്റ്‌വർക്ക് തകരാർ അല്ലെങ്കിൽ ടൈംഔട്ട് |
| `4` | Rate Limited | റിക്വസ്റ്റ് പരിധി കവിഞ്ഞു (429 Too Many Requests) |
| `5` | Not Found | അഭ്യർത്ഥിച്ച വിഭവം കണ്ടെത്താനായില്ല (404 Not Found) |

## 6. ഷെൽ എൻവയോൺമെന്റ് ഉദാഹരണങ്ങൾ

### Bash / Zsh (Linux / macOS)
```bash
# API കീ സജ്ജീകരിക്കുക
export OMI_API_KEY="omi_dev_your_actual_key_here"

# കമാൻഡ് പ്രവർത്തിപ്പിക്കുക
omi --json memory list --limit 10
```

### PowerShell (Windows)
```powershell
# API കീ സജ്ജീകരിക്കുക
$env:OMI_API_KEY = "omi_dev_your_actual_key_here"

# PowerShell-ൽ JSON പാർസിംഗ്
(omi --json memory list | ConvertFrom-Json) | Select-Object id, content
```

## 7. ലോക്കൽ ഡെസ്ക്ടോപ്പ് API സംയോജനം (Local Desktop API)

Omi Desktop ആപ്പ് പ്രവർത്തിക്കുമ്പോൾ, ക്ലൗഡിന്റെ ആവശ്യമില്ലാതെ കമ്പ്യൂട്ടറിലെ വിവരങ്ങൾ നേരിട്ട് തിരയാവുന്നതാണ്:

```bash
# ലോക്കൽ API വിലാസവും ടോക്കണും കോൺഫിഗർ ചെയ്യുക
omi local configure --url http://127.0.0.1:47778 --token YOUR_DESKTOP_TOKEN

# ലോക്കൽ നില പരിശോധിക്കുക
omi --json local status

# സ്ക്രീൻ ചരിത്രത്തിൽ തിരയുക
omi --json local search-screen "പ്രോജക്ട് പ്ലാൻ" --days 7 --app Safari
```

## 8. പ്രൊഫൈലുകൾ കൈകാര്യം ചെയ്യൽ (Profiles)

ഒന്നിലധികം അക്കൗണ്ടുകൾ അല്ലെങ്കിൽ ടെസ്റ്റിംഗ് സാഹചര്യങ്ങൾ കൈകാര്യം ചെയ്യാൻ `--profile` ഓപ്ഷൻ ഉപയോഗിക്കുക:

```bash
# വ്യക്തിഗത പ്രൊഫൈലിൽ ലോഗിൻ ചെയ്യുക
omi --profile personal auth login

# ജോലി പ്രൊഫൈലിൽ ലോഗിನ್ ചെയ്യുക
omi --profile work auth login

# ഇഷ്ടമുള്ള പ്രൊഫൈലിന് കീഴിൽ കമാൻഡുകൾ റൺ ചെയ്യുക
omi --profile work memory list
```
