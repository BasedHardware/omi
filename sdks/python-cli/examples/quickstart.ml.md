# omi-cli ഉപയോഗിച്ച് വേഗത്തിലുള്ള തുടക്കം

ഈ ഗൈഡ് അടിസ്ഥാന കമാൻഡുകൾ മലയാളത്തിൽ വിശദീകരിക്കുന്നു. കമാൻഡുകളുടെ പേരുകളും
പ്രോഗ്രാം സന്ദേശങ്ങളും ഇംഗ്ലീഷിൽ തന്നെയിരിക്കും. താഴെയുള്ള ഉദാഹരണ കമാൻഡുകൾ
നിങ്ങളുടെ ഓർമ്മകൾ, സംഭാഷണങ്ങൾ, പ്രവർത്തന ഇനങ്ങൾ അല്ലെങ്കിൽ ലക്ഷ്യങ്ങളെ
മാറ്റുന്നില്ല.

## പ്രോഗ്രാം ഇൻസ്റ്റാൾ ചെയ്യൽ

ആവശ്യകതകൾ: Python 3.10 അല്ലെങ്കിൽ പുതിയതും Omi അക്കൗണ്ടും.

`pipx` ഇൻസ്റ്റാൾ ചെയ്തിട്ടുണ്ടെങ്കിൽ:

```sh
pipx install omi-cli
omi --help
```

അല്ലെങ്കിൽ സജ്ജമാക്കിയ Python വർച്വൽ എൻവയോൺമെന്റിൽ ഇൻസ്റ്റാൾ ചെയ്യുക:

```sh
python -m pip install omi-cli
omi --help
```

ടെർമിനലിന് `omi` കാണാതായാൽ, വർച്വൽ എൻവയോൺമെന്റ് സജീവമാണോ അല്ലെങ്കിൽ `pipx`
executable ഇടുന്ന ഡയറക്ടറി `PATH`-ൽ ഉണ്ടോ എന്ന് പരിശോധിക്കുക.

## നിങ്ങളുടെ അക്കൗണ്ട് ബന്ധിപ്പിക്കൽ

ഇന്ററാക്ടീവ് ഗൈഡ് റൺ ചെയ്യുക:

```sh
omi auth login
```

ബ്രൗസർ ലോഗിൻ തിരഞ്ഞെടുക്കുക അല്ലെങ്കിൽ Omi ഡെവലപ്പർ API key ഒട്ടിക്കുക.
ഇന്ററാക്ടീവ് ഇൻപുട്ട് key മറയ്ക്കുന്നു; ടെർമിനൽ ചരിത്രത്തിൽ സൂക്ഷിക്കുന്ന
കമാൻഡുകളിൽ അത് നേരിട്ടെഴുതരുത്.

ബ്രൗസർ നേരിട്ട് ഉപയോഗിക്കാൻ:

```sh
omi auth login --browser
```

ടെർമിനൽ ഉള്ള അതേ കമ്പ്യൂട്ടറിൽ ലോഗിൻ ചെയ്യുക — പ്രാമാണീകരണം പ്രാദേശിക
callback വിലാസം ഉപയോഗിക്കുന്നു. സ്ക്രീനിലെ നിർദ്ദേശങ്ങൾ പാലിക്കുക.

ലോഗിൻ കഴിഞ്ഞ് കോൺഫിഗറേഷനും API ആക്‌സസും പരിശോധിക്കുക:

```sh
omi auth status
omi auth whoami
```

`status` പ്രാദേശിക അവസ്ഥ കാണിച്ച് രഹസ്യങ്ങൾ മറയ്ക്കുന്നു, പക്ഷേ അവ സർവറിൽ
സാധുതയുള്ളതാണോ എന്ന് പരിശോധിക്കില്ല. `whoami` പ്രാമാണീകൃത അപേക്ഷ അയയ്ക്കുന്നു;
വിജയിച്ചാൽ നിങ്ങളുടെ പേര് കാണിക്കാതെ തന്നെ credentials പ്രവർത്തിക്കുന്നു.

കോൺഫിഗറേഷൻ സ്ഥിരസ്ഥിതിയായി `~/.omi/config.toml`-ൽ സൂക്ഷിക്കുന്നു. ഈ ഫയലിൽ
credentials ഉണ്ടായേക്കാമെന്നതിനാൽ പങ്കിടരുത്.

## നിങ്ങളുടെ ഡാറ്റ വായിക്കൽ

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ശൂന്യമായ ലിസ്റ്റ് എന്നാൽ ഫിൽട്ടറുമായി പൊരുത്തപ്പെടുന്ന ഇനങ്ങളില്ല എന്നും
അർത്ഥമാക്കാം. ഓരോ കമാൻഡിന്റെയും ഓപ്ഷനുകൾ help-ൽ കാണുക:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ലഭ്യമാക്കലും പേജുകൾ മാറ്റലും

ഗ്ലോബൽ `--json` ഓപ്ഷൻ കമാൻഡ് ഗ്രൂപ്പിന് **മുമ്പ്** ഇടുക:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ആദ്യ കമാൻഡ് ആദ്യത്തെ 25 ഓർമ്മകൾ ചോദിക്കുന്നു; രണ്ടാമത്തേത് അടുത്ത 25. ഒരു പേജ്
പൂർണ്ണ ബാക്കപ്പല്ല. JSON ഔട്ട്പുട്ട് മുഴുവൻ ID-കളും സൂക്ഷിക്കുന്നു, എന്നാൽ
ടേബിൾ പ്രദർശനത്തിനായി ID-കൾ ചുരുക്കാം.

ഒരു പേജ് ഫയലിലേക്ക് സൂക്ഷിക്കാൻ:

```sh
omi --json memory list --limit 25 --offset 0 > memory-page-1.json
```

റീഡയറക്ഷൻ പ്രാദേശിക ഫയൽ സൃഷ്ടിക്കുകയോ തിരുത്തിയെഴുതുകയോ ചെയ്യുന്നു. ഉള്ളടക്കം
ഉപയോഗിക്കുന്നതിന് മുമ്പ് കമാൻഡ് വിജയകരമായി പൂർത്തിയായെന്ന് ഉറപ്പാക്കുക. പിശകുകൾ
stderr-ലേക്ക് എഴുതപ്പെടുന്നു; ശൂന്യ ഫയൽ ഡാറ്റയില്ലെന്ന് തെളിയിക്കുന്നില്ല.
എക്സ്പോർട്ട് ഫയലിൽ സ്വകാര്യ വിവരങ്ങൾ ഉണ്ടായേക്കാം — അത് സ്വകാര്യമായി സൂക്ഷിക്കുക.

## പ്രൊഫൈലുകൾ ഉപയോഗിക്കൽ

സ്റ്റേറ്റ് `~/.omi/config.toml`-ൽ സൂക്ഷിക്കുന്നു (`$OMI_CONFIG` കൊണ്ട്
മാറ്റാവുന്നതാണ്). ഓരോ പ്രൊഫൈലിനും സ്വന്തം പ്രാമാണീകരണ രീതിയും API വിലാസവും
ഉണ്ട്. `--profile` കൊണ്ട് മാറ്റുക:

```sh
omi config profile use ജോലി
omi auth login
omi --profile സ്വകാര്യം memory list
```

സാധാരണ കോൺഫിഗറേഷൻ കമാൻഡുകൾ:

```sh
omi config show
omi config path
omi config profile list
```

## എക്സിറ്റ് കോഡുകൾ

ഈ എക്സിറ്റ് കോഡുകൾ സ്ഥിരവും സ്ക്രിപ്റ്റുകൾക്കും ഏജന്റുകൾക്കും ഉപയോഗപ്രദവുമാണ്:

| കോഡ് | അർത്ഥം | ഉദാഹരണ സാഹചര്യം |
| ---: | --- | --- |
| 0 | വിജയം | കമാൻഡ് പൂർത്തിയായി |
| 1 | ഉപയോഗ പിശക് | തെറ്റായ flag, കുറഞ്ഞ ആർഗ്യുമെന്റ് അല്ലെങ്കിൽ പരാജയപ്പെട്ട validation |
| 2 | പ്രാമാണീകരണ പിശക് | credentials ഇല്ല, ടോക്കൺ കാലഹരണപ്പെട്ടു അല്ലെങ്കിൽ അനുമതി കുറവ് |
| 3 | സർവർ പിശക് | സർവർ 5xx അല്ലെങ്കിൽ കണക്ഷൻ പരാജയം |
| 4 | നിരക്ക് പരിമിതി | സർവർ HTTP 429 തിരിച്ചയച്ചു |
| 5 | കണ്ടെത്തിയില്ല | സർവർ HTTP 404 തിരിച്ചയച്ചു |

## ലോഗൗട്ട്

```sh
omi auth logout
```

പ്രാദേശികമായി സൂക്ഷിച്ച credentials നീക്കം ചെയ്യുന്നു. സർവറിൽ key റിവോക്ക്
ചെയ്യാൻ നിങ്ങളുടെ അക്കൗണ്ടിലെ developer key മാനേജ്‌മെന്റ് ഉപയോഗിക്കുക.

കൂടുതൽ കമാൻഡുകൾക്കും ഓപ്ഷനുകൾക്കും [ഇംഗ്ലീഷ് പ്രധാന README](../README.md)
കാണുക, `omi --help` റൺ ചെയ്യുക.
