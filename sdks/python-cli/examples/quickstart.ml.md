# omi-cli ആരംഭിക്കുക

ഈ ഗൈഡ് മലയാളത്തിൽ ആദ്യ കമാൻഡുകൾ എങ്ങനെ ഉപയോഗിക്കാമെന്ന് വിശദീകരിക്കുന്നു. കമാൻഡുകളുടെ പേരുകളും സിസ്റ്റം സന്ദേശങ്ങളും ഇംഗ്ലീഷിൽ തന്നെയായിരിക്കും. ഇവിടെ നൽകിയിട്ടുള്ള വായനാ ഉദാഹരണങ്ങൾ നിങ്ങളുടെ ഓർമ്മകൾ, സംഭാഷണങ്ങൾ, ചെയ്യേണ്ട കാര്യങ്ങൾ അല്ലെങ്കിൽ ലക്ഷ്യങ്ങൾ എന്നിവയിൽ മാറ്റം വരുത്തില്ല.

## പ്രോഗ്രാം ഇൻസ്റ്റാൾ ചെയ്യുക

ആവശ്യകതകൾ: Python 3.10 അല്ലെങ്കിൽ പുതിയ പതിപ്പും ഒരു Omi അക്കൗണ്ടും.

> ശ്രദ്ധിക്കുക: PyPI-ൽ പാക്കേജിന്റെ പേര് **`omi-cli`** എന്നാണ്, എന്നാൽ ഇൻസ്റ്റാളേഷന് ശേഷം പ്രവർത്തിക്കുന്ന കമാൻഡ് **`omi`** ആണ്. PyPI-ൽ `omi` എന്ന പേരിൽ മറ്റൊരു പാക്കേജ് ഉണ്ട് — അത് ഇൻസ്റ്റാൾ ചെയ്യരുത്.

`pipx` ഇൻസ്റ്റാൾ ചെയ്തിട്ടുണ്ടെങ്കിൽ:

```sh
pipx install omi-cli
omi --help
```

പകരമായി, സജീവമായ ഒരു Python വെർച്വൽ എൻവയോൺമെന്റിൽ:

```sh
python -m pip install omi-cli
omi --help
```

ടെർമിനലിന് `omi` കമാൻഡ് കണ്ടെത്താൻ കഴിയുന്നില്ലെങ്കിൽ, വെർച്വൽ എൻവയോൺമെന്റ് സജീവമാണോ അല്ലെങ്കിൽ `pipx` ഡയറക്ടറി നിങ്ങളുടെ `PATH`-ൽ ഉണ്ടോ എന്ന് പരിശോധിക്കുക.

## അക്കൗണ്ട് ബന്ധിപ്പിക്കുക

സംവേദനാത്മക ലോഗിൻ ആരംഭിക്കുക:

```sh
omi auth login
```

ബ്രൗസർ വഴി ലോഗിൻ ചെയ്യുക അല്ലെങ്കിൽ Omi ഡെവലപ്പർ API key ഒട്ടിക്കുന്ന വഴി തിരഞ്ഞെടുക്കുക. സംവേദനാത്മക ഇൻപുട്ട് കീ മറച്ചുവെക്കുന്നു; ടെർമിനൽ ചരിത്രത്തിൽ അവശേഷിക്കുന്ന രീതിയിൽ കീ ടൈപ്പ് ചെയ്യരുത്.

നേരിട്ട് ബ്രൗസർ വഴി:

```sh
omi auth login --browser
```

ടെർമിനൽ പ്രവർത്തിക്കുന്ന കമ്പ്യൂട്ടറിൽ തന്നെ ബ്രൗസർ ലോഗിൻ പൂർത്തിയാക്കുക, കാരണം പ്രാമാണീകരണം പ്രാദേശിക വിലാസത്തിലേക്ക് മടങ്ങുന്നു. സ്ക്രീനിലെ നിർദ്ദേശങ്ങൾ പാലിക്കുക.

തുടർന്ന് കോൺഫിഗറേഷനും API കണക്റ്റിവിറ്റിയും പരിശോധിക്കുക:

```sh
omi auth status
omi auth whoami
```

`status` പ്രാദേശിക അവസ്ഥ കാണിക്കുകയും രഹസ്യങ്ങൾ മറയ്ക്കുകയും ചെയ്യുന്നു, എന്നാൽ സെർവറിൽ സാധുത പരിശോധിക്കുന്നില്ല. `whoami` സെർവറിലേക്ക് ഒരു പ്രാമാണീകരിച്ച അഭ്യർത്ഥന അയയ്ക്കുന്നു; വിജയിച്ചാൽ ക്രെഡൻഷ്യലുകൾ ശരിയായി പ്രവർത്തിക്കുന്നു എന്ന് അർത്ഥമാക്കുന്നു.

കോൺഫിഗറേഷൻ ഫയൽ സാധാരണയായി `~/.omi/config.toml` എന്നതിൽ സംരക്ഷിക്കപ്പെടുന്നു. ഇത് ആരുമായും പങ്കിടരുത്: ഇതിൽ നിങ്ങളുടെ പ്രധാന വിവരങ്ങൾ അടങ്ങിയിരിക്കാം.

## നിങ്ങളുടെ വിവരങ്ങൾ കാണുക

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ശൂന്യമായ ലിസ്റ്റ് അന്വേഷണവുമായി പൊരുത്തപ്പെടുന്ന വിവരങ്ങൾ ഇല്ലെന്ന് മാത്രമേ അർത്ഥമാക്കുന്നുള്ളൂ. ഫിൽട്ടറിംഗ് ഓപ്ഷനുകൾ അറിയാൻ help നോക്കുക:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ഔട്ട്പുട്ടും പേജിനേഷനും (Pagination)

ആഗോള ഓപ്ഷനായ `--json` കമാൻഡ് ഗ്രൂപ്പിന് **മുമ്പായി** നൽകുക:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ആദ്യത്തെ കമാൻഡ് ആദ്യത്തെ 25 റെക്കോർഡുകളും രണ്ടാമത്തേത് അടുത്ത 25 റെക്കോർഡുകളും നൽകുന്നു. പൂർണ്ണ ബാക്കപ്പിനായി ഒന്നിലധികം പേജുകൾ ആവശ്യമായി വന്നേക്കാം. JSON ഔട്ട്പുട്ടിൽ പൂർണ്ണ ഐഡന്റിഫയറുകൾ സുരക്ഷിതമായിരിക്കും.

ഒരു പേജ് ഫയലിലേക്ക് സംരക്ഷിക്കാൻ:

```sh
omi --json memory list --limit 25 --offset 0 > ormakal-page-1.json
```

ഈ റീഡയറക്ഷൻ ഒരു പ്രാദേശിക ഫയൽ സൃഷ്ടിക്കുകയോ മാറ്റുകയോ ചെയ്യുന്നു. പിശകുകൾ stderr-ലേക്ക് എഴുതപ്പെടുന്നു; ശൂന്യമായ ഫയൽ ഡാറ്റ ഇല്ലെന്നതിന് തെളിവല്ല. കയറ്റുമതി ചെയ്ത ഫയലിൽ സ്വകാര്യ വിവരങ്ങൾ ഉണ്ടായേക്കാം, അതിനാൽ ഇത് സുരക്ഷിതമായി സൂക്ഷിക്കുക.

## ലോഗ് ഔട്ട് ചെയ്യുക

```sh
omi auth logout
```

ഈ കമാൻഡ് പ്രാദേശികമായി സൂക്ഷിച്ച ക്രെഡൻഷ്യലുകൾ നീക്കംചെയ്യുന്നു. സെർവറിൽ കീ റദ്ദാക്കാൻ അക്കൗണ്ടിന്റെ ഡെവലപ്പർ പോർട്ടൽ ഉപയോഗിക്കുക.

മറ്റ് കമാൻഡുകൾക്കും വിപുലമായ ഓപ്ഷനുകൾക്കുമായി പ്രധാന ഇംഗ്ലീഷ് ഗൈഡ് കാണുക:
[../README.md](../README.md), `omi --help`.
