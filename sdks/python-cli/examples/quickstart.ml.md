# omi-cli ഉപയോഗിച്ചുള്ള തുടക്ക വഴികാട്ടി (Malayalam Quickstart)

ഈ വഴികാട്ടി `omi-cli`-ന്റെ അടിസ്ഥാന കമാൻഡുകൾ മലയാളത്തിൽ ലളിതമായി വിശദീകരിക്കുന്നു. കമാൻഡുകളുടെ പേരുകളും കമ്പ്യൂട്ടർ സന്ദേശങ്ങളും ഇംഗ്ലീഷിൽ തന്നെയായിരിക്കും. ഇവിടെ നൽകിയിരിക്കുന്ന ഉദാഹരണങ്ങൾ നിങ്ങളുടെ ഓർമ്മകൾ, സംഭാഷണങ്ങൾ, ചെയ്യേണ്ട കാര്യങ്ങൾ അല്ലെങ്കിൽ ലക്ഷ്യങ്ങൾ എന്നിവയിൽ മാറ്റം വരുത്താതെ വിവരങ്ങൾ വായിക്കുക മാത്രമേ ചെയ്യുന്നുള്ളൂ.

## 1. പ്രോഗ്രാം ഇൻസ്റ്റാൾ ചെയ്യുക (Installation)

**ആവശ്യകതകൾ:** Python 3.10 അല്ലെങ്കിൽ പുതിയ പതിപ്പും ഒരു Omi അക്കൗണ്ടും.

> **പ്രധാന കുറിപ്പ്:** PyPI-ൽ പാക്കേജിന്റെ പേര് **`omi-cli`** എന്നാണ്, എന്നാൽ ഇൻസ്റ്റാളേഷന് ശേഷം ടെർമിനലിൽ പ്രവർത്തിപ്പിക്കുന്ന കമാൻഡിന്റെ പേര് **`omi`** എന്നാണ്. PyPI-ൽ `omi` എന്ന പേരിൽ മറ്റൊരു പാക്കേജുമുണ്ട് — അത് ഇൻസ്റ്റാൾ ചെയ്യരുത്.

`pipx` ലഭ്യമാണെങ്കിൽ:

```sh
pipx install omi-cli
omi --help
```

അല്ലെങ്കിൽ, ഒരു സജീവ Python വെർച്വൽ എൻവയോൺമെന്റിൽ (virtualenv):

```sh
python -m pip install omi-cli
omi --help
```

ടെർമിനലിൽ `omi` കമാൻഡ് ലഭ്യമല്ലെങ്കിൽ, വെർച്വൽ എൻവയോൺമെന്റ് സജീവമാണോ അല്ലെങ്കിൽ `pipx` ഡയറക്ടറി നിങ്ങളുടെ `PATH`-ൽ ഉണ്ടോ എന്ന് പരിശോധിക്കുക.

## 2. നിങ്ങളുടെ അക്കൗണ്ട് ബന്ധിപ്പിക്കുക (Authentication)

ലോഗിൻ പ്രക്രിയ ആരംഭിക്കുക:

```sh
omi auth login
```

ബ്രൗസർ വഴി ലോഗിൻ ചെയ്യുകയോ നിങ്ങളുടെ Omi ഡെവലപ്പർ API കീ നൽകുകയോ ചെയ്യാം. നേരിട്ടുള്ള ബ്രൗസർ ലോഗിനായി:

```sh
omi auth login --browser
```

ടെർമിനൽ പ്രവർത്തിക്കുന്ന കമ്പ്യൂട്ടറിൽ തന്നെ ലോഗിൻ ചെയ്യുക, കാരണം പ്രാമാണീകരണം ലോക്കൽ വിലാസത്തിലേക്ക് (localhost) തിരികെ ലഭിക്കുന്നു.

തുടർന്ന് കണക്ഷൻ നിലയും API ആക്‌സസ്സും പരിശോധിക്കുക:

```sh
omi auth status
omi auth whoami
```

`status` ലോക്കൽ അവസ്ഥ കാണിക്കുകയും രഹസ്യങ്ങൾ മറയ്ക്കുകയും ചെയ്യുന്നു. `whoami` സെർവറിലേക്ക് അഭ്യർത്ഥന അയച്ച് ക്രെഡൻഷ്യലുകൾ ശരിയായി പ്രവർത്തിക്കുന്നുവെന്ന് ഉറപ്പാക്കുന്നു.

കോൺഫിഗറേഷൻ സ്ഥിരസ്ഥിതിയായി `~/.omi/config.toml`-ൽ സൂക്ഷിക്കുന്നു. ഇതിൽ നിങ്ങളുടെ അക്കൗണ്ട് വിവരങ്ങൾ ഉള്ളതിനാൽ ഇത് സുരക്ഷിതമായി സൂക്ഷിക്കുക.

## 3. നിങ്ങളുടെ വിവരങ്ങൾ കാണുക

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ഒരു നിർദ്ദിഷ്ട സംഭാഷണത്തിന്റെ മുഴുവൻ ട്രാൻസ്ക്രിപ്റ്റും ലഭിക്കാൻ:

```sh
omi conversation get <CONVERSATION_ID> --include-transcript
```

ഏതെങ്കിലും കമാൻഡിന്റെ കൂടുതൽ ഓപ്ഷനുകൾ മനസ്സിലാക്കാൻ `--help` ഉപയോഗിക്കുക:

```sh
omi memory list --help
omi conversation list --help
omi goal list --help
```

## 4. JSON ഫോർമാറ്റും പേജിനേഷനും (Pagination)

ഗ്ലോബൽ ഓപ്ഷനായ `--json` എപ്പോഴും കമാൻഡ് ഗ്രൂപ്പിന് **മുമ്പിൽ** നൽകുക:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ആദ്യ കമാൻഡ് ആദ്യത്തെ 25 രേഖകൾ ആവശ്യപ്പെടുന്നു; രണ്ടാമത്തേത് അടുത്ത 25 രേഖകൾ ആവശ്യപ്പെടുന്നു.

വിവരങ്ങൾ ഒരു ഫയലിലേക്ക് സംരക്ഷിക്കാൻ (Export):

```sh
omi --json memory list --limit 25 --offset 0 > ormmakal-page-1.json
```

## 5. ലോഗ് ഔട്ട് ചെയ്യുക (Logout)

ലോക്കൽ കമ്പ്യൂട്ടറിൽ നിന്ന് ക്രെഡൻഷ്യലുകൾ നീക്കം ചെയ്യാൻ:

```sh
omi auth logout
```

ഇത് കമ്പ്യൂട്ടറിൽ നിന്ന് മാത്രമേ ലോഗിൻ വിവരങ്ങൾ നീക്കം ചെയ്യുകയുള്ളൂ. സെർവറിൽ നിന്ന് കീ പൂർണ്ണമായി റദ്ദാക്കാൻ Omi ഡെവലപ്പർ ഡാഷ്‌ബോർഡ് ഉപയോഗിക്കുക.

കൂടുതൽ വിവരങ്ങൾക്കും വിപുലമായ നിർദ്ദേശങ്ങൾക്കുമായി പ്രധാന ഇംഗ്ലീഷ് ഗൈഡ് കാണുക: [../README.md](../README.md) ഒപ്പം [agent_quickstart.md](agent_quickstart.md).
