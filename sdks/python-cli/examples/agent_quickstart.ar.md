# دليل البدء السريع للوكيل (omi-cli)

هذا الدليل يوضح كيفية إنشاء وتشغيل سير عمل معتمد على الوكيل باستخدام أداة `omi-cli`.  
يحتوي على أمثلة على الأوامر التي يمكن تنفيذها في سطر الأوامر، مع شرح مختصر لكل خطوة.

> ⚠️ **ملاحظة**: جميع الأوامر المذكورة هنا تعمل على نظام Linux أو macOS.  
> إذا كنت تستخدم Windows، يرجى تشغيلها داخل بيئة WSL أو استخدام PowerShell مع التعديلات اللازمة.
