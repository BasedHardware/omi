# omi-cli खातिर संक्षेप गाइड

ई गाइड मगही (Magahi) भाषा में `omi-cli` के सुरुआती कमांड के बारे में बतबैत हे। कमांड के नाम आ प्रोग्राम के संदेस अंग्रेजी में ही रहतै। इहाँ देल गेल उदाहरण राउर याद (memories), बातचीत (conversations), करे वाला काम (action items), चाहे लच्छ (goals) में कउनो फेरबदल नइ करतै।

## प्रोग्राम इनस्टॉल करब (Installation)

जरूरी चीजन: Python 3.10 या नया संस्करण आ एगो Omi खाता।

अगर राउर पास `pipx` इनस्टॉल हे:

```sh
pipx install omi-cli
omi --help
```

रउवा एकरा एगो एक्टिव Python वर्चुअल एनवायरनमेंट (virtual environment) में भी इनस्टॉल कर सकही:

```sh
python -m pip install omi-cli
omi --help
```

अगर टर्मिनल में `omi` कमांड नइ मिलइत हे, त देख लेब कि वर्चुअल एनवायरनमेंट एक्टिव हे कि नइ या `pipx` के रस्ता राउर `$PATH` में हे कि नइ।

## अपन खाता जोड़ब (Authentication)

बातचीत करे वाला सहायक सुरू करब:

```sh
omi auth login
```

ब्राउजर से लॉगिन करब या अपन Omi developer API key पेस्ट करब चुनब। सहायक इनपुट चाबी के नुका देतै; टर्मिनल के इतिहास में रहे वाला कउनो कमांड में चाबी मत लिखब।

सीधे ब्राउजर पर जाय खातिर:

```sh
omi auth login --browser
```

उहे कंप्यूटर पर लॉगिन करब जेकरा पर टर्मिनल चल रहल हे: परमानित जबाब लोकल पता के उपयोग करइत हे। स्क्रीन पर देल निर्देश के पालन करब।

ओकरा बाद, सेटिंग्स आ API पहुँच के जाँच करब:

```sh
omi auth status
omi auth whoami
```

`status` लोकल हाल देखाबैत हे आ भेद के नुकाबैत हे, बाकिर सर्वर पर ओकरा चले के जाँच नइ करइत हे। `whoami` एगो जाँचल बिनती भेजइत हे; अगर सब ठीक रहल, त नाम देखैले बिना बताबैत हे कि क्रेडेंशियल्स काम कर रहल हे।

सेटिंग्स बहुधा `~/.omi/config.toml` में सुरक्षित रहइत हे। ई फाइल केहू से साझा मत करब: एहमें गुप्त क्रेडेंशियल्स हो सकइत हे।

## अपन डेटा देखब (Inspection)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

खाली सूची के मतलब सिर्फ ई हो सकइत हे कि खोज के मुताबिक कउनो डेटा नइ मिलल। हर कमांड में फ़िल्टर खोजे खातिर मदद के उपयोग करब:

```sh
omi memory list --help
omi action-item list --help
```

## JSON लेब आ पन्ना पलटब (Pagination)

कमांड समूह से **पहिले** पूरा सिस्टम वाला `--json` विकल्प लगाब:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

पहिला कमांड पहिला 25 याद मँगतै; दूसर कमांड अगिला 25 याद मँगतै। एगो पन्ना पूरा बैकअप नइ होबैत हे। JSON आउटपुट पूरा पहचानी कोड के सुरक्षित राखइत हे, जबकि स्क्रीन के तालिका ओकरा छोट कर सकइत हे।

एगो पन्ना फाइल में सहेजे खातिर:

```sh
omi --json memory list --limit 25 --offset 0 > याद-पन्ना-1.json
```

ई तरीका लोकल फाइल बनाबैत हे या बदलइत हे। सामग्री उपयोग करे से पहिले देख लेब कि कमांड ठीक से पूरा भेल कि नइ। खराबी एरर आउटपुट (stderr) में लिखल जाइत हे; खाली फाइल के मतलब ई नइ हे कि डेटा नइ हे। निकालल फाइल में निजी जानकारी हो सकइत हे: ओकरा संभाल के राखब।

## खाता से बाहर निकलना (Logout)

```sh
omi auth logout
```

ई कमांड लोकल रूप से सहेजल क्रेडेंशियल्स हटा देतै। सर्वर से चाबी रद्द करे खातिर, अपन खाता में developer key प्रबंधन के उपयोग करब।

आउर कमांड आ जादा विकल्प खातिर, [अंग्रेजी के मुख्य गाइड](../README.md) आ `omi --help` देखब।
