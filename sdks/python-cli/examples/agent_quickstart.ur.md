# ایجنٹ کوئیک سٹارٹ گائیڈ (Urdu)

یہ گائیڈ آپ کو `omi-cli` کے ذریعے ایجنٹ‑چلانے والے ورک فلو کو جلدی سے سیٹ اپ کرنے میں مدد دیتی ہے۔ تمام کوڈ بلاکس اور کمانڈ لائن آرگیومنٹس اصل انگریزی ورژن کے جیسے ہی رہتے ہیں؛ صرف وضاحتی متن اردو میں ترجمہ کیا گیا ہے۔

## 📖 تعارف

`omi-cli` ایک کمانڈ‑ لائن ٹول ہے جو آپ کو LLM‑بیسڈ ایجنٹس بنانے، ٹیسٹ کرنے اور ڈپلائے کرنے کی سہولت دیتا ہے۔ اس مثال میں ہم ایک سادہ ایجنٹ بنائیں گے جو یوزر کے سوالات کا جواب دے گا۔

## ✅ پیشگی ضروریات

- **Python 3.9+** انسٹال ہو
- **Node.js 18+** (اگر آپ `omi-cli` کے JavaScript ورژن استعمال کرنا چاہتے ہیں)
- **omi-cli** (Python پیکج) – اسے اگلے سیکشن میں انسٹال کریں
- ایک **OpenAI API key** (یا کوئی بھی سپورٹڈ LLM پرووائیڈر)
