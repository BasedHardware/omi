# omi-cli ସହିତ ଆରମ୍ଭ କରନ୍ତୁ

ଏହି ମାର୍ଗଦର୍ଶିକା ଓଡ଼ିଆରେ ପ୍ରାରମ୍ଭିକ କମାଣ୍ଡ ବ୍ୟବହାର କରିବାର ପ୍ରଣାଳୀ ଦର୍ଶାଏ। କମାଣ୍ଡର ନାମ ଏବଂ ସିଷ୍ଟମ୍ ବାର୍ତ୍ତାଗୁଡ଼ିକ ଇଂରାଜୀରେ ରହିବ। ଏଠାରେ ଦିଆଯାଇଥିବା ପଢ଼ିବା ଉଦାହରଣ ଆପଣଙ୍କ ସ୍ମୃତି, ବାର୍ତ୍ତାଳାପ, କାର୍ଯ୍ୟତାଲିକା କିମ୍ବା ଲକ୍ଷ୍ୟକୁ ପରିବର୍ତ୍ତନ କରିବ ନାହିଁ।

## ପ୍ରୋଗ୍ରାମ ଇନଷ୍ଟଲ୍ କରନ୍ତୁ

ଆବଶ୍ୟକତା: Python 3.10 ବା ତଦୁର୍ଦ୍ଧ୍ୱ ସଂସ୍କରଣ ଏବଂ ଏକ Omi ଆକାଉଣ୍ଟ।

> ଧ୍ୟାନ ଦିଅନ୍ତୁ: PyPI ରେ ପ୍ୟାକେଜ୍ ନାମ **`omi-cli`**, କିନ୍ତୁ ଇନଷ୍ଟଲ୍ ପରେ ଚାଲୁଥିବା କମାଣ୍ଡ୍ ହେଉଛି **`omi`**। PyPI ରେ `omi` ନାମକ ଅନ୍ୟ ଏକ ପ୍ୟାକେଜ୍ ଅଛି — ତାହାକୁ ଇନଷ୍ଟଲ୍ କରନ୍ତୁ ନାହିଁ।

ଯଦି `pipx` ଇନଷ୍ଟଲ୍ ଅଛି:

```sh
pipx install omi-cli
omi --help
```

ବିକଳ୍ପ ଭାବେ, ସକ୍ରିୟ Python ଭର୍ଚୁଆଲ୍ ପରିବେଶରେ:

```sh
python -m pip install omi-cli
omi --help
```

ଯଦି ଟର୍ମିନାଲ୍ `omi` କମାଣ୍ଡ୍ ଖୋଜି ପାରୁନାହିଁ, ତେବେ ଭର୍ଚୁଆଲ୍ ପରିବେଶ ସକ୍ରିୟ ଅଛି କି ନାହିଁ କିମ୍ବା `pipx` ଡିରେକ୍ଟୋରୀ ଆପଣଙ୍କ `PATH` ରେ ଅଛି କି ନାହିଁ ଯାଞ୍ଚ କରନ୍ତୁ।

## ଆପଣଙ୍କ ଆକାଉଣ୍ଟ୍ ସଂଯୋଗ କରନ୍ତୁ

ଇଣ୍ଟରାକ୍ଟିଭ୍ ଲଗଇନ୍ ଆରମ୍ଭ କରନ୍ତୁ:

```sh
omi auth login
```

ବ୍ରାଉଜର୍ ମାଧ୍ୟମରେ ଲଗଇନ୍ କରନ୍ତୁ କିମ୍ବା Omi ଡେଭଲପର୍ API key ପେଷ୍ଟ୍ କରିବାର ବିକଳ୍ପ ବାଛନ୍ତୁ। ଇଣ୍ଟରାକ୍ଟିଭ୍ ଇନପୁଟ୍ କି (key) କୁ ଲୁଚାଇ ରଖେ; ଟର୍ମିନାଲ୍ ଇତିହାସରେ ରହିଯିବା ଭଳି କମାଣ୍ଡରେ କି ଲେଖନ୍ତୁ ନାହିଁ।

ସିଧାସଳଖ ବ୍ରାଉଜର୍ ପାଇଁ:

```sh
omi auth login --browser
```

ଟର୍ମିନାଲ୍ ଚାଲୁଥିବା କମ୍ପ୍ୟୁଟରରେ ହିଁ ବ୍ରାଉଜର୍ ଲଗଇନ୍ ସମ୍ପୂର୍ଣ୍ଣ କରନ୍ତୁ, କାରଣ ପ୍ରମାଣୀକରଣ ସ୍ଥାନୀୟ ଠିକଣାକୁ ଫେରିଥାଏ। ସ୍କ୍ରିନ୍ ନିର୍ଦ୍ଦେଶାବଳୀ ଅନୁସରଣ କରନ୍ତୁ।

ଏହା ପରେ କନଫିଗରେସନ୍ ଏବଂ API ପ୍ରବେଶ ଯାଞ୍ଚ କରନ୍ତୁ:

```sh
omi auth status
omi auth whoami
```

`status` ସ୍ଥାନୀୟ ସ୍ଥିତି ଦେଖାଏ ଏବଂ ଗୋପନୀୟତା ରକ୍ଷା କରେ, କିନ୍ତୁ ସର୍ଭରରେ ବୈଧତା ଯାଞ୍ଚ କରେ ନାହିଁ। `whoami` ସର୍ଭରକୁ ଏକ ପ୍ରମାଣୀକୃତ ଅନୁରୋଧ ପଠାଏ; ସଫଳ ହେବା ଅର୍ଥ ପରିଚୟପତ୍ର ଠିକ୍ ଭାବେ କାମ କରୁଛି।

କନଫିଗରେସନ୍ ଫାଇଲ୍ ଡିଫଲ୍ଟ ଭାବେ `~/.omi/config.toml` ରେ ସଂରକ୍ଷିତ ହୁଏ। ଏହାକୁ କାହା ସହିତ ସେୟାର୍ କରନ୍ତୁ ନାହିଁ: ଏଥିରେ ଆପଣଙ୍କ ସମ୍ବେଦନଶୀଳ ତଥ୍ୟ ଥାଇପାରେ।

## ଆପଣଙ୍କ ଡାଟା ଦେଖନ୍ତୁ

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ଖାଲି ତାଲିକା କେବଳ ଏହା ସୂଚାଏ ଯେ ସର୍ଚ୍ଚ ସହିତ ମେଳ ଖାଉଥିବା କୌଣସି ଡାଟା ନାହିଁ। କମାଣ୍ଡ୍ ଫିଲ୍ଟର୍ ଜାଣିବା ପାଇଁ help ଦେଖନ୍ତୁ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ଆଉଟପୁଟ୍ ଏବଂ ପେଜିନେସନ୍ (Pagination)

ଗ୍ଲୋବାଲ୍ ବିକଳ୍ପ `--json` କୁ କମାଣ୍ଡ୍ ଗ୍ରୁପ୍ **ପୂର୍ବରୁ** ରଖନ୍ତୁ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ପ୍ରଥମ କମାଣ୍ଡ୍ ପ୍ରଥମ ୨୫ଟି ରେକର୍ଡ ଏବଂ ଦ୍ୱିତୀୟଟି ପରବର୍ତ୍ତୀ ୨୫ଟି ରେକର୍ଡ ଆଣେ। ସମ୍ପୂର୍ଣ୍ଣ ବ୍ୟାକଅପ୍ ପାଇଁ ଏକାଧିକ ପୃଷ୍ଠା ଆବଶ୍ୟକ ହୋଇପାରେ। JSON ଆଉଟପୁଟ୍ ରେ ସମ୍ପୂର୍ଣ୍ଣ ଆଇଡେଣ୍ଟିଫାୟାର୍ ସୁରକ୍ଷିତ ରହେ।

ଏକ ପୃଷ୍ଠାକୁ ଫାଇଲ୍ ରେ ସେଭ୍ କରିବା ପାଇଁ:

```sh
omi --json memory list --limit 25 --offset 0 > smruti-page-1.json
```

ଏହି ରିଡାଇରେକ୍ସନ୍ ସ୍ଥାନୀୟ ଫାଇଲ୍ ତିଆରି କରେ କିମ୍ବା ବଦଳାଏ। ତ୍ରୁଟିଗୁଡ଼ିକ stderr ରେ ଲେଖାଯାଏ; ଖାଲି ଫାଇଲ୍ ଡାଟା ନଥିବାର ନିଶ୍ଚିତ ପ୍ରମାଣ ନୁହେଁ। ରପ୍ତାନି ହୋଇଥିବା ଫାଇଲ୍ ରେ ବ୍ୟକ୍ତିଗତ ସୂଚନା ଥାଇପାରେ, ଏହାକୁ ସୁରକ୍ଷିତ ରଖନ୍ତୁ।

## ଲଗ୍ ଆଉଟ୍ କରନ୍ତୁ

```sh
omi auth logout
```

ଏହି କମାଣ୍ଡ୍ ସ୍ଥାନୀୟ ଭାବେ ସଂରକ୍ଷିତ ପରିଚୟପତ୍ରକୁ ହଟାଇଦିଏ। ସର୍ଭରରେ କି ରଦ୍ଦ କରିବା ପାଇଁ ଆକାଉଣ୍ଟର ଡେଭଲପର୍ ପୋର୍ଟାଲ୍ ବ୍ୟବହାର କରନ୍ତୁ।

ଅନ୍ୟାନ୍ୟ କମାଣ୍ଡ୍ ଏବଂ ଉନ୍ନତ ବିକଳ୍ପ ପାଇଁ ମୁଖ୍ୟ ଇଂରାଜୀ ଗାଇଡ୍ ଦେଖନ୍ତୁ:
[../README.md](../README.md) ଏବଂ `omi --help`.
