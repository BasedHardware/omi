# omi-cli ସହିତ ପ୍ରାରମ୍ଭିକ ମାର୍ଗଦର୍ଶିକା (Odia Quickstart)

ଏହି ମାର୍ଗଦର୍ଶିକା ଓଡ଼ିଆରେ ପ୍ରାରମ୍ଭିକ କମାଣ୍ଡ ବିଷୟରେ ବୁଝାଏ। କମାଣ୍ଡ ନାମ ଏବଂ ପ୍ରୋଗ୍ରାମ ସନ୍ଦେଶ ଇଂରାଜୀରେ ରହିବ। ଏଠାରେ ଦିଆଯାଇଥିବା ଉଦାହରଣଗୁଡ଼ିକ ଆପଣଙ୍କ ସ୍ମୃତି (memories), କଥାବାର୍ତ୍ତା (conversations), କାର୍ଯ୍ୟ (action items) କିମ୍ବା ଲକ୍ଷ୍ୟ (goals) ରେ କୌଣସି ପରିବର୍ତ୍ତନ କରେ ନାହିଁ।

## ପ୍ରୋଗ୍ରାମ ଇନଷ୍ଟଲ୍ କରିବା

ଆବଶ୍ୟକତା: Python 3.10 ବା ତଦୁର୍ଦ୍ଧ୍ୱ ସଂସ୍କରଣ ଏବଂ ଏକ Omi ଆକାଉଣ୍ଟ୍।

ଯଦି ଆପଣଙ୍କ ପାଖରେ `pipx` ଇନଷ୍ଟଲ୍ ଅଛି:

```sh
pipx install omi-cli
omi --help
```

କିମ୍ବା ଏକ ସକ୍ରିୟ Python ଭର୍ଚୁଆଲ୍ ଏନଭାଇରନମେଣ୍ଟ୍ ମଧ୍ୟରେ:

```sh
python -m pip install omi-cli
omi --help
```

ଯଦି ଟର୍ମିନାଲ୍ `omi` ଖୋଜିପାରୁ ନାହିଁ, ତେବେ ଯାଞ୍ଚ କରନ୍ତୁ ଯେ ଭର୍ଚୁଆଲ୍ ଏନଭାଇରନମେଣ୍ଟ୍ ସକ୍ରିୟ ଅଛି କିମ୍ବା `pipx` ର ନିର୍ଦ୍ଦେଶିକା ଆପଣଙ୍କ `PATH` ରେ ଅନ୍ତର୍ଭୁକ୍ତ ଅଛି।

## ଆପଣଙ୍କ ଆକାଉଣ୍ଟ୍ ସଂଯୋଗ କରିବା

ଇଣ୍ଟରାକ୍ଟିଭ୍ ଲଗଇନ୍ ଆରମ୍ଭ କରନ୍ତୁ:

```sh
omi auth login
```

ବ୍ରାଉଜର୍ ମାଧ୍ୟମରେ ଲଗଇନ୍ ବାଛନ୍ତୁ କିମ୍ବା ଆପଣଙ୍କର Omi ଡେଭଲପର୍ API କି (API key) ପେଷ୍ଟ କରନ୍ତୁ। ଇଣ୍ଟରାକ୍ଟିଭ୍ ଇନପୁଟ୍ କି'କୁ ଲୁଚାଇ ରଖେ; ଟର୍ମିନାଲ୍ ଇତିହାସରେ କି' ଲେଖିବାରୁ ଦୂରେଇ ରୁହନ୍ତୁ।

ସିଧାସଳଖ ବ୍ରାଉଜର୍ ବ୍ୟବହାର କରିବାକୁ:

```sh
omi auth login --browser
```

ଟର୍ମିନାଲ୍ ଥିବା କମ୍ପ୍ୟୁଟରରେ ହିଁ ଲଗଇନ୍ କରନ୍ତୁ: ପ୍ରମାଣୀକରଣ ଏକ ଲୋକାଲ୍ ଠିକଣା ବ୍ୟବହାର କରେ। ପରଦାରେ ଦିଆଯାଇଥିବା ନିର୍ଦ୍ଦେଶାବଳୀ ପାଳନ କରନ୍ତୁ।

ଏହା ପରେ, ସଂରଚନା ଏବଂ API ପ୍ରବେଶ ଅଧିକାର ଯାଞ୍ଚ କରନ୍ତୁ:

```sh
omi auth status
omi auth whoami
```

`status` ସ୍ଥାନୀୟ ସ୍ଥିତି ଦେଖାଏ ଏବଂ ଗୋପନୀୟ ସୂଚନା ଲୁଚାଏ, କିନ୍ତୁ ସର୍ଭରରେ ଏହାକୁ ଯାଞ୍ଚ କରେ ନାହିଁ। `whoami` ଏକ ପ୍ରମାଣୀକୃତ ଅନୁରୋଧ ପଠାଏ; ସଫଳ ହେଲେ, ଏହା ପ୍ରମାଣପତ୍ର ସଠିକ୍ ଭାବେ କାମ କରୁଥିବା ନିଶ୍ଚିତ କରେ।

ସଂରଚନା ଡିଫଲ୍ଟ ଭାବରେ `~/.omi/config.toml` ରେ ସଂରକ୍ଷିତ ହୁଏ। ଏହି ଫାଇଲ୍ ଅନ୍ୟ କାହା ସହିତ ସେୟାର୍ କରନ୍ତୁ ନାହିଁ: ଏଥିରେ ଆପଣଙ୍କର ପ୍ରମାଣପତ୍ର ରହିପାରେ।

## ତଥ୍ୟ ଦେଖିବା (Querying Data)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ଏକ ଖାଲି ତାଲିକାର ଅର୍ଥ ହୋଇପାରେ ଯେ ଅନୁରୋଧ ସହିତ ମେଳ ଖାଉଥିବା କୌଣସି ତଥ୍ୟ ନାହିଁ। ପ୍ରତ୍ୟେକ କମାଣ୍ଡର ଫିଲ୍ଟର୍ ବିଷୟରେ ଜାଣିବା ପାଇଁ ସାହାଯ୍ୟ ଦେଖନ୍ତୁ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ଫଳାଫଳ ଏବଂ ପୃଷ୍ଠା ସଞ୍ଚାଳନ (Pagination)

ଗ୍ଲୋବାଲ୍ `--json` ବିକଳ୍ପକୁ କମାଣ୍ଡ୍ ଗ୍ରୁପ୍ ପୂର୍ବରୁ ଲଗାନ୍ତୁ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ପ୍ରଥମ କମାଣ୍ଡ ପ୍ରଥମ ୨୫ଟି ସ୍ମୃତି ଆଣେ; ଦ୍ୱିତୀୟଟି ପରବର୍ତ୍ତୀ ୨୫ଟି ଆଣେ। JSON ଆଉଟପୁଟ୍ ସମ୍ପୂର୍ଣ୍ଣ ଆଇଡି ରଖିଥାଏ, ଯେତେବେଳେ କି ଟେବୁଲ୍ ଗୁଡ଼ିକ ଏହାକୁ ସଂକ୍ଷିପ୍ତ କରିପାରନ୍ତି।

କୌଣସି ପୃଷ୍ଠାକୁ ଏକ ଫାଇଲରେ ସାଇତି ରଖିବାକୁ:

```sh
omi --json memory list --limit 25 --offset 0 > smruti-page-1.json
```

ଏହି ରିଡାଇରେକ୍ସନ୍ ସ୍ଥାନୀୟ ଫାଇଲ୍ ତିଆରି କରେ କିମ୍ବା ବଦଳାଏ। ବ୍ୟବହାର ପୂର୍ବରୁ କମାଣ୍ଡ୍ ସଫଳ ହୋଇଛି କି ନାହିଁ ଯାଞ୍ଚ କରନ୍ତୁ। ଏକ୍ସପୋର୍ଟ ହୋଇଥିବା ଫାଇଲରେ ବ୍ୟକ୍ତିଗତ ତଥ୍ୟ ଥାଇପାରେ: ଏହାକୁ ସୁରକ୍ଷିତ ରଖନ୍ତୁ।

## ଲଗଆଉଟ୍ କରିବା

```sh
omi auth logout
```

ଏହି କମାଣ୍ଡ୍ ସ୍ଥାନୀୟ ଭାବରେ ସଂରକ୍ଷିତ ପ୍ରମାଣପତ୍ରକୁ ହଟାଇଦିଏ। ସର୍ଭରରେ ଏକ କି' ବାତିଲ କରିବା ପାଇଁ, ଆପଣଙ୍କ ଆକାଉଣ୍ଟର ଡେଭଲପର୍ ପୋର୍ଟାଲ୍ ବ୍ୟବହାର କରନ୍ତୁ।

ଅନ୍ୟାନ୍ୟ କମାଣ୍ଡ୍ ଏବଂ ଉନ୍ନତ ବିକଳ୍ପ ପାଇଁ, [ମୂଳ ଇଂରାଜୀ ମାର୍ଗଦର୍ଶିକା](../README.md) ଏବଂ `omi --help` ଦେଖନ୍ତୁ।
