# omi-cli ସହିତ ଶୀଘ୍ର ଆରମ୍ଭ

ଏହି ଗାଇଡ୍ ମୌଳିକ କମାଣ୍ଡଗୁଡ଼ିକୁ ଓଡ଼ିଆରେ ବୁଝାଏ। କମାଣ୍ଡ ନାମ ଏବଂ ପ୍ରୋଗ୍ରାମ୍
ବାର୍ତ୍ତା ଇଂରାଜୀରେ ହିଁ ରୁହନ୍ତି। ନିମ୍ନରେ ଥିବା ଉଦାହରଣ କମାଣ୍ଡ ଆପଣଙ୍କ ସ୍ମୃତି,
କଥାବାର୍ତ୍ତା, କାର୍ଯ୍ୟ ଆଇଟମ୍ କିମ୍ବା ଲକ୍ଷ୍ୟଗୁଡ଼ିକୁ ବଦଳାଏ ନାହିଁ।

## ପ୍ରୋଗ୍ରାମ୍ ଇନଷ୍ଟଲ୍ କରିବା

ଆବଶ୍ୟକତା: Python 3.10 କିମ୍ବା ନୂତନ ଏବଂ Omi ଆକାଉଣ୍ଟ।

ଯଦି `pipx` ଇନଷ୍ଟଲ୍ ଅଛି:

```sh
pipx install omi-cli
omi --help
```

କିମ୍ବା ସକ୍ରିୟ କରାଯାଇଥିବା Python virtual environment ରେ ଇନଷ୍ଟଲ୍ କରନ୍ତୁ:

```sh
python -m pip install omi-cli
omi --help
```

ଟର୍ମିନାଲ `omi` ପାଉ ନ ଥିଲେ, ଦେଖନ୍ତୁ କି virtual environment ସକ୍ରିୟ ଅଛି ବା
`pipx` ଯେଉଁ ଫୋଲ୍ଡରରେ executable ରଖେ ତାହା `PATH` ରେ ଅଛି।

## ଆପଣଙ୍କ ଆକାଉଣ୍ଟ ଯୋଡ଼ିବା

ଇଣ୍ଟରାକ୍ଟିଭ୍ ଗାଇଡ୍ ଚଲାନ୍ତୁ:

```sh
omi auth login
```

ବ୍ରାଉଜର୍ ଲଗିନ୍ ବାଛନ୍ତୁ କିମ୍ବା Omi ଡେଭଲପର୍ API key ପେଷ୍ଟ କରନ୍ତୁ।
ଇଣ୍ଟରାକ୍ଟିଭ୍ ଇନପୁଟ୍ key କୁ ଲୁଚାଏ; ଟର୍ମିନାଲ୍ ଇତିହାସରେ ସଂରକ୍ଷିତ ହେଉଥିବା
କମାଣ୍ଡରେ ଏହାକୁ ସିଧା ଲେଖନ୍ତୁ ନାହିଁ।

ବ୍ରାଉଜର୍ ସିଧା ବ୍ୟବହାର କରିବାକୁ:

```sh
omi auth login --browser
```

ଟର୍ମିନାଲ ଥିବା ସେହି କମ୍ପ୍ୟୁଟରରେ ଲଗିନ୍ କରନ୍ତୁ, କାରଣ ପ୍ରାମାଣିକରଣ ସ୍ଥାନୀୟ
callback ଠିକଣା ବ୍ୟବହାର କରେ। ସ୍କ୍ରିନରେ ଦେଖାଯାଉଥିବା ନିର୍ଦ୍ଦେଶାବଳୀ ପାଳନ କରନ୍ତୁ।

ଲଗିନ୍ ପରେ କନଫିଗରେସନ୍ ଏବଂ API ପ୍ରବେଶ ଯାଞ୍ଚ କରନ୍ତୁ:

```sh
omi auth status
omi auth whoami
```

`status` ସ୍ଥାନୀୟ ସ୍ଥିତି ଦେଖାଏ ଏବଂ ଗୋପନୀୟତାକୁ ମାସ୍କ କରେ, କିନ୍ତୁ ସେଗୁଡ଼ିକ
ସର୍ଭରରେ ବୈଧ କି ନାହିଁ ଯାଞ୍ଚ କରେ ନାହିଁ। `whoami` ପ୍ରାମାଣିକ ଅନୁରୋଧ ପଠାଏ;
ସଫଳ ହେଲେ ଆପଣଙ୍କ credentials କାମ କରୁଛନ୍ତି — ଆପଣଙ୍କ ନାମ ନ ଦେଖାଇ।

କନଫିଗରେସନ୍ ଡିଫଲ୍ଟ ଭାବରେ `~/.omi/config.toml` ରେ ସଂରକ୍ଷିତ ହୁଏ। ଏହି ଫାଇଲ
ସେୟାର କରନ୍ତୁ ନାହିଁ କାରଣ ଏଥିରେ credentials ଥାଇପାରେ।

## ଆପଣଙ୍କ ଡାଟା ପଢ଼ିବା

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ଖାଲି ତାଲିକାର ଅର୍ଥ ହୋଇପାରେ ଫିଲ୍ଟର ସହିତ କୌଣସି ଆଇଟମ ମେଳ ଖାଉନାହିଁ। ପ୍ରତ୍ୟେକ
କମାଣ୍ଡର ବିକଳ୍ପ help ରେ ଦେଖନ୍ତୁ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ପାଇବା ଏବଂ ପୃଷ୍ଠା ଫେରିବା

ଗ୍ଲୋବାଲ `--json` ବିକଳ୍ପକୁ କମାଣ୍ଡ ଗୋଷ୍ଠୀ **ପୂର୍ବରୁ** ରଖନ୍ତୁ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ପ୍ରଥମ କମାଣ୍ଡ ପ୍ରଥମ 25 ଟି ସ୍ମୃତି ମାଗେ; ଦ୍ୱିତୀୟଟି ପରବର୍ତ୍ତୀ 25 ଟି। ଗୋଟିଏ
ପୃଷ୍ଠା ସମ୍ପୂର୍ଣ୍ଣ ବ୍ୟାକଅପ୍ ନୁହେଁ। JSON ଆଉଟପୁଟ୍ ସମ୍ପୂର୍ଣ୍ଣ ID ରଖେ, ଯେତେବେଳେ
ଟେବୁଲ ପ୍ରଦର୍ଶନ ପାଇଁ ID ଛୋଟ କରିପାରେ।

ଗୋଟିଏ ପୃଷ୍ଠାକୁ ଫାଇଲରେ ସଂରକ୍ଷଣ କରିବାକୁ:

```sh
omi --json memory list --limit 25 --offset 0 > memory-page-1.json
```

ରିଡାଇରେକ୍ସନ୍ ସ୍ଥାନୀୟ ଫାଇଲ ତିଆରି କରେ କିମ୍ବା ତାକୁ ଓଭରରାଇଟ କରେ। ବିଷୟବସ୍ତୁ
ବ୍ୟବହାର କରିବା ପୂର୍ବରୁ ନିଶ୍ଚିତ କରନ୍ତୁ କି କମାଣ୍ଡ ସଫଳତାର ସହିତ ଶେଷ ହୋଇଛି।
ଭୁଲଗୁଡ଼ିକ stderr କୁ ଲେଖାଯାଏ; ଖାଲି ଫାଇଲ ଡାଟା ନ ଥିବାର ପ୍ରମାଣ ନୁହେଁ। ଏକ୍ସପୋର୍ଟ
ଫାଇଲରେ ବ୍ୟକ୍ତିଗତ ସୂଚନା ଥାଇପାରେ — ଏହାକୁ ଗୋପନୀୟ ରଖନ୍ତୁ।

## ପ୍ରୋଫାଇଲ ବ୍ୟବହାର କରିବା

ଷ୍ଟେଟ୍ `~/.omi/config.toml` ରେ ସଂରକ୍ଷିତ ହୁଏ (`$OMI_CONFIG` ଦ୍ୱାରା ବଦଳାଯାଇ
ପାରେ)। ପ୍ରତ୍ୟେକ ପ୍ରୋଫାଇଲର ନିଜସ୍ୱ ପ୍ରାମାଣିକରଣ ପଦ୍ଧତି ଏବଂ API ଠିକଣା ଥାଏ।
`--profile` ଦ୍ୱାରା ବଦଳନ୍ତୁ:

```sh
omi config profile use କାମ
omi auth login
omi --profile ବ୍ୟକ୍ତିଗତ memory list
```

ସାଧାରଣ କନଫିଗରେସନ୍ କମାଣ୍ଡ:

```sh
omi config show
omi config path
omi config profile list
```

| ---: | --- | --- |
| 0 | ସଫଳତା | କମାଣ୍ଡ ସମାପ୍ତ ହେଲା |
| 1 | ବ୍ୟବହାର-ତ୍ରୁଟି | ଭୁଲ ଫ୍ଲାଗ୍, ଅଭାପ ଆର୍ଗୁମେଣ୍ଟ କିମ୍ବା ବିଫଳ ବୈଧତା |
| 2 | ପ୍ରାମାଣିକରଣ-ତ୍ରୁଟି | credentials ନାହିଁ, ଟୋକନ୍ ଅବଧି ଶେଷ କିମ୍ବା ଅନୁମତି ଅପର୍ୟାପ୍ତ |
| 3 | ସର୍ଭର-ତ୍ରୁଟି | ସର୍ଭର 5xx କିମ୍ବା ସଂଯୋଗ ବିଫଳ |
| 4 | ହାର-ସୀମା | ସର୍ଭର HTTP 429 ଫେରାଇଲା |

## ଲଗଆଉଟ୍

```sh
omi auth logout
```

ସ୍ଥାନୀୟ ଭାବରେ ସଂରକ୍ଷିତ credentials ହଟାଇଦିଏ। ସର୍ଭରରେ key ରଦ୍ଦ କରିବାକୁ ଆପଣଙ୍କ
ଆକାଉଣ୍ଟର developer key ପରିଚାଳନା ବ୍ୟବହାର କରନ୍ତୁ।

ଅଧିକ କମାଣ୍ଡ ଓ ବିକଳ୍ପ ପାଇଁ [ଇଂରାଜୀ ମୁଖ୍ୟ README](../README.md) ଦେଖନ୍ତୁ
ଏବଂ `omi --help` ଚଲାନ୍ତୁ।
