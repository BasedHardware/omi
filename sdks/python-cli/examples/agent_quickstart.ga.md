# Quickstart Guide for Omi CLI (Irish)

This guide provides a quick start for using the Omi CLI with agent-driven workflows in Irish (Gaeilge).

## Prerequisities

- Install the Omi CLI: `pip install omi-cli`
- Have an OpenAI API key set in the environment: `export OPENAI_API_KEY=...`
