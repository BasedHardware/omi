# एजेंट क्विकस्टार्ट गाइड (डोगरी)

यह गाइड `omi-cli` का उपयोग करके एजेंट‑ड्रिवेन वर्कफ़्लो सेट‑अप करने के लिए डोगरी में अनुवादित है। सभी कोड ब्लॉक्स, कमांड‑आर्ग्युमेंट्स और स्ट्रक्चरल हेडर्स मूल अंग्रेज़ी संस्करण के समान रखे गए हैं।

## पूर्वापेक्षाएँ
```bash
pip install omi-cli
```

## एजेंट बनाना
```bash
omi agent create my-agent --model gpt-4o-mini
```

## एजेंट चलाना
```bash
omi agent run my-agent
```

## इंटरैक्शन
टर्मिनल में प्रश्न टाइप करें और एजेंट का उत्तर देखें।

*यह दस्तावेज़ केवल अनुवाद है; मूल कार्यक्षमता और कोड स्निपेट्स अपरिवर्तित हैं।*
