# एजेंट क्विकस्टार्ट गाइड (डोगरी)

> **नोट:** यह फ़ाइल `agent_quickstart.md` का डोगरी (doi) अनुवाद है। सभी कोड ब्लॉक, कमांड आर्ग्युमेंट और संरचनात्मक हेडर मूल फ़ाइल के समान रखे गये हैं। यदि आप अनुवाद में सुधार करना चाहते हैं, तो कृपया इस फ़ाइल को संपादित करें।

## परिचय

`omi-cli` के साथ एजेंट‑ड्रिवेन वर्कफ़्लो को जल्दी से शुरू करने के लिए इस गाइड का पालन करें। यह गाइड आपको एक बेसिक एजेंट सेट‑अप करने, उसे चलाने और LLM के साथ इंटरैक्ट करने की प्रक्रिया दिखाता है।

## पूर्वापेक्षाएँ

- `omi-cli` स्थापित हो (`npm i -g omi-cli` या `brew install omi-cli` आदि)  
- Python 3.9+ स्थापित हो  
- एक वैध OMI API टोकन (आपके OMI डैशबोर्ड से प्राप्त)
