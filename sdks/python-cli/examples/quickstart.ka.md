# OMI CLI Quickstart (ქართული)

ეს არის **BasedHardware/omi** CLI-ის სწრაფი დაწყების სახელმძღვანელო. გიჩვენებთ, როგორ დააინსტალიროთ, დააწყვილოთ OMI მოწყობილობა და გამოიყენოთ ძირითადი ბრძანებები: რეალურ დროში ტრანსკრიფცია, ჩაწერა, მეხსიერების მართვა და ინტელექტუალური საუბარი.

## წინაპირობები (Prerequisites)

სანამ დაიწყებთ, დარწმუნდით, რომ გაქვთ:

- **Python 3.10+**
- **pip**
- ტერმინალი ან კომანდო სტრიქონი
- OMI მოწყობილობა, რომელიც მზადაა დასაწყვილებლად
- მიკროფონის წვდომა თქვენს სისტემაში
- ინტერნეტკავშირი ავთენტიფიკაციისა და ღრუბლის სერვისებისთვის

შეგიძლიათ შეამოწმოთ Python და pip ვერსიები:

```bash
python --version
pip --version
```

## ინსტალაცია (Installation)

დააინსტალირეთ OMI CLI pip-ის გამოყენებით:

```bash
pip install omi-cli
```

თუ სისტემა ითხოვს მომხმარებლის დონეზე ინსტალაციას, გამოიყენეთ:

```bash
pip install --user omi-cli
```

ინსტალაციის შემდეგ შეამოწმეთ, რომ ბრძანება ხელმისაწვდომია:

```bash
omi --version
```

თუ `omi` ბრძანება ვერ მოიძებნა, შესაძლოა Python-ის `bin` ან `Scripts` გასაღები არ იყოს `PATH`-ში.

## მოწყობილობის დაწყვილება და ავთენტიფიკაცია (Pairing & Auth)

პირველი გაშვებისას გაუშვით `setup` პროცესი:

```bash
omi setup
```

ეს ბრძანება ჩვეულებრივ:

- შეამოწმებს ან შექმნის ავთენტიფიკაციის კონფიგურაციას
- დაგეხმარებათ OMI მოწყობილობის დაწყვილებაში
- შეინახავს აუცილებელ პარამეტრებს ადგილობრივად
- მოგთხოვთ აუცილებელ წვდომებს, მაგალითად მიკროფონის ან Bluetooth-ის

დარწმუნდით, რომ OMI მოწყობილობა ჩართულია, დამუხტულია და მზადაა დასაწყვილებლად.

## ძირითადი ბრძანებები და მაგალითები (Core Commands)

### 1. რეალურ დროში ტრანსკრიფცია და მოსმენა

გაუშვით რეალურ დროში ტრანსკრიფცია:

```bash
omi listen
```

ეს ბრძანება იყენებს მიკროფონს ან დაწყვილებულ OMI მოწყობილობას, რათა აჩვენოს ტრანსკრიფცია რეალურ დროში.

შეგიძლიათ ნახოთ დამატებითი პარამეტრები:

```bash
omi listen --help
```

### 2. მიკროფონით ჩაწერა

გაუშვით აუდიო ჩაწერა:

```bash
omi record
```

ჩაწერის დროს დარწმუნდით, რომ:

- მიკროფონი არ არის დაკავებული სხვა აპლიკაციით
- სისტემას აქვს მიკროფონზე წვდომის ნებართვა
- ჩაწერის პარამეტრები სწორადაა შერჩეული

დამხმარე ინფორმაციისთვის:

```bash
omi record --help
```

### 3. მეხსიერების მართვა

გამოიყენეთ მეხსიერების მართვის ბრძანება:

```bash
omi memories
```

ეს ბრძანება გამოიყენება OMI-ის მეხსიერებებთან სამუშაოდ, მაგალითად:

- მეხსიერებების ნახვა
- ჩანაწერების მართვა
- კონტექსტის გადახედვა

კონკრეტული ქვებრძანებები შეიძლება განსხვავდებოდეს ვერსიის მიხედვით. დახმარებისთვის:

```bash
omi memories --help
```

### 4. ინტელექტუალური საუბარი

გაუშვით საუბრის რეჟიმი:

```bash
omi chat
```

ეს ბრძანება საშუალებას გაძლევთ იყენოთ OMI-ის ინტელექტუალური საუბრის შესაძლებლობები CLI-დან.

დამხმარე ინფორმაციისთვის:

```bash
omi chat --help
```
