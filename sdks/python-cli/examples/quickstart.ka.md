# პირველი ნაბიჯები omi-cli-ით

ეს სახელმძღვანელო ხსნის პირველ ბრძანებებს ქართულ ენაზე. ბრძანებების სახელები
და პროგრამის შეტყობინებები რჩება ინგლისურ ენაზე. აქ მოცემული მოთხოვნის
მაგალითები არ ცვლის თქვენს მოგონებებს, საუბრებს, დავალებებს ან მიზნებს.

## პროგრამის ინსტალაცია

მოთხოვნები: Python 3.10 ან უფრო ახალი ვერსია და Omi ანგარიში.

თუ გაქვთ დაინსტალირებული `pipx`:

```sh
pipx install omi-cli
omi --help
```

ალტერნატივის სახით, შეგიძლიათ დააინსტალიროთ გააქტიურებულ Python ვირტუალურ
გარემოში (virtual environment):

```sh
python -m pip install omi-cli
omi --help
```

თუ ტერმინალი ვერ პოულობს `omi`-ს, შეამოწმეთ, რომ ვირტუალური გარემო გააქტიურებულია
ან დირექტორია, სადაც `pipx` აინსტალირებს შესასრულებელ ფაილებს, არის თქვენს `PATH`-ში.

## თქვენი ანგარიშის დაკავშირება

გაუშვით ინტერაქტიული ასისტენტი:

```sh
omi auth login
```

აირჩიეთ ბრაუზერით შესვლა ან Omi დეველოპერის API გასაღების ჩასმის ოფცია.
ინტერაქტიული შეყვანა მალავს გასაღებს; მოერიდეთ მის ჩაწერას ბრძანებაში,
რომელიც დარჩება ტერმინალის ისტორიაში.

პირდაპირ ბრაუზერში გადასასვლელად:

```sh
omi auth login --browser
```

შედით იმავე კომპიუტერზე, სადაც ტერმინალი მუშაობს: ავთენტიფიკაციის პასუხი
იყენებს ლოკალურ მისამართს. მიჰყევით ეკრანზე მოცემულ ინსტრუქციებს.

ამის შემდეგ, შეამოწმეთ კონფიგურაცია და API-ზე წვდომა:

```sh
omi auth status
omi auth whoami
```

`status` აჩვენებს ლოკალურ მდგომარეობას და მალავს საიდუმლოს, მაგრამ არ ამოწმებს
მის ვალიდურობას სერვერზე. `whoami` აგზავნის ავთენტიფიცირებულ მოთხოვნას;
წარმატების შემთხვევაში, ის ადასტურებს, რომ მონაცემები მუშაობს, თქვენი სახელის
აუცილებლად გამოჩენის გარეშე.

კონფიგურაცია ნაგულისხმევად ინახება `~/.omi/config.toml` ფაილში. არ გაუზიაროთ
ეს ფაილი სხვებს: ის შეიძლება შეიცავდეს თქვენს კონფიდენციალურ მონაცემებს.

## თქვენი მონაცემების ნახვა

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ცარიელი სია შეიძლება უბრალოდ ნიშნავდეს, რომ მოთხოვნის შესაბამისი ელემენტები
არ მოიძებნა. გამოიყენეთ დახმარება თითოეული ბრძანების ფილტრების გასაგებად:

```sh
omi memory list --help
omi action-item list --help
```

## JSON-ის მიღება და გვერდების ნავიგაცია

განათავსეთ გლობალური ოფცია `--json` ბრძანებათა ჯგუფის **წინ**:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

პირველი ბრძანება ითხოვს პირველ 25 მოგონებას; მეორე, შემდეგ 25-ს. ერთი გვერდი
ამიტომ არ წარმოადგენს სრულ სარეზერვო ასლს (backup). JSON გამონატანი ინახავს
სრულ იდენტიფიკატორებს, მაშინ როცა ეკრანის ცხრილებმა შეიძლება შეამოკლონ ისინი
საჩვენებლად.

გვერდის ფაილში შესანახად:

```sh
omi --json memory list --limit 25 --offset 0 > mogonebebi-gverdi-1.json
```

ეს გადამისამართება ქმნის ან ცვლის ლოკალურ ფაილს. დარწმუნდით, რომ ბრძანება
წარმატებით დასრულდა მის შინაარსის გამოყენებამდე. შეცდომები იწერება შეცდომების
გამონატანში (stderr); ცარიელი ფაილი არ იძლევა გარანტიას, რომ მონაცემები არ არსებობს.
ექსპორტირებული ფაილი შეიძლება შეიცავდეს პირად ინფორმაციას: შეინახეთ იგი კონფიდენციალურად.

## ანგარიშიდან გამოსვლა (Logout)

```sh
omi auth logout
```

ეს ბრძანება შლის ლოკალურად შენახულ ავტორიზაციის მონაცემებს. სერვერზე გასაღების
გასაუქმებლად გამოიყენეთ დეველოპერის გასაღებების მართვა თქვენს ანგარიშში.

დამატებითი ბრძანებებისა და გაფართოებული ოფციებისთვის იხილეთ
[ძირითადი სახელმძღვანელო ინგლისურ ენაზე](../README.md) და `omi --help`.
