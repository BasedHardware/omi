# এজেন্ট কুইকস্টার্ট গাইড (বাংলা)

এই গাইডটি আপনাকে **omi-cli** ব্যবহার করে এজেন্ট-চালিত ওয়ার্কফ্লো শুরু করতে সহায়তা করবে। কোড ব্লক, কমান্ড আর্গুমেন্ট এবং কাঠামোগত হেডারগুলো অপরিবর্তিত রাখা হয়েছে।

## ১. প্রয়োজনীয়তা

- পাইথন 3.10 বা তার পরবর্তী সংস্করণ
- `omi-cli` ইনস্টল করা আছে (`pip install omi-cli`)
