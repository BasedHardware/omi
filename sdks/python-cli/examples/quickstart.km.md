# ជំហានដំបូងជាមួយ omi-cli

ការណែនាំនេះពន្យល់អំពីពាក្យបញ្ជាដំបូងជាភាសាខ្មែរ។ ឈ្មោះពាក្យបញ្ជា និងសាររបស់កម្មវិធី
នៅតែជាភាសាអង់គ្លេស។ ឧទាហរណ៍នៃការសាកសួរដែលបង្ហាញនៅទីនេះ មិនកែប្រែការចងចាំ
ការសន្ទនា កិច្ចការ ឬគោលដៅរបស់អ្នកឡើយ។

## ការដំឡើងកម្មវិធី

តម្រូវការ៖ Python 3.10 ឬកំណែថ្មីជាងនេះ និងគណនី Omi មួយ។

ប្រសិនបើអ្នកបានដំឡើង `pipx`៖

```sh
pipx install omi-cli
omi --help
```

ម្យ៉ាងវិញទៀត អ្នកអាចដំឡើងវានៅក្នុង Python virtual environment ដែលបានដំណើរការ៖

```sh
python -m pip install omi-cli
omi --help
```

ប្រសិនបើ terminal រកមិនឃើញ `omi` សូមពិនិត្យមើលថា virtual environment ដំណើរការ
ឬថតដែល `pipx` ដំឡើងឯកសារស្ថិតនៅក្នុង `PATH` របស់អ្នក។

## ការភ្ជាប់គណនីរបស់អ្នក

ចាប់ផ្តើមជំនួយការអន្តរកម្ម៖

```sh
omi auth login
```

ជ្រើសរើសការចូលតាមរយៈកម្មវិធីរុករក (browser) ឬជម្រើសបិទភ្ជាប់ Omi developer API key។
ការបញ្ចូលអន្តរកម្មលាក់សោនេះ សូមជៀសវាងការសរសេរវានៅក្នុងពាក្យបញ្ជាដែលនឹងស្ថិតនៅក្នុងប្រវត្តិ terminal។

ដើម្បីចូលទៅកាន់កម្មវិធីរុករកដោយផ្ទាល់៖

```sh
omi auth login --browser
```

ចូលនៅលើកុំព្យូទ័រតែមួយដែល terminal កំពុងដំណើរការ៖ ការឆ្លើយតបផ្ទៀងផ្ទាត់ប្រើប្រាស់អាសយដ្ឋានមូលដ្ឋាន។
សូមអនុវត្តតាមការណែនាំនៅលើអេក្រង់។

បន្ទាប់ពីនោះ សូមផ្ទៀងផ្ទាត់ការកំណត់រចនាសម្ព័ន្ធ និងការចូលប្រើ API៖

```sh
omi auth status
omi auth whoami
```

`status` បង្ហាញស្ថានភាពមូលដ្ឋាន និងលាក់ការសម្ងាត់ ប៉ុន្តែមិនពិនិត្យមើលសុពលភាពនៅលើ server ទេ។
`whoami` ធ្វើការស្នើសុំផ្ទៀងផ្ទាត់ ប្រសិនបើជោគជ័យ វាបញ្ជាក់ថាព័ត៌មានសម្ងាត់ដំណើរការ ដោយមិនចាំបាច់បង្ហាញឈ្មោះរបស់អ្នកឡើយ។

ការកំណត់រចនាសម្ព័ន្ធត្រូវបានរក្សាទុកតាមលំនាំដើមនៅក្នុង `~/.omi/config.toml`។
កុំចែករំលែកឯកសារនេះ៖ វាអាចផ្ទុកព័ត៌មានសម្ងាត់របស់អ្នក។

## ការមើលទិន្នន័យរបស់អ្នក

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

បញ្ជីទទេអាចមានន័យថាមិនមានធាតុដែលត្រូវគ្នានឹងការសាកសួរនោះទេ។ ប្រើប្រាស់ជំនួយដើម្បីស្វែងយល់អំពីតម្រងនៃពាក្យបញ្ជានីមួយៗ៖

```sh
omi memory list --help
omi action-item list --help
```

## ការទទួលបាន JSON និងការរុករកទំព័រ

ដាក់ជម្រើសសកល `--json` **នៅពីមុខ** ក្រុមពាក្យបញ្ជា៖

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ពាក្យបញ្ជាដំបូងស្នើសុំការចងចាំ ២៥ ដំបូង ពាក្យបញ្ជាទីពីរស្នើសុំ ២៥ បន្ទាប់។ ដូច្នេះទំព័រតែមួយមិនមែនជាការបម្រុងទុកពេញលេញ (backup) ទេ។
លទ្ធផល JSON រក្សាទុកឧបករណ៍សម្គាល់ពេញលេញ ខណៈពេលដែលតារាងនៅលើអេក្រង់អាចកាត់បន្ថយពួកវាសម្រាប់ការបង្ហាញ។

ដើម្បីរក្សាទុកទំព័រទៅក្នុងឯកសារ៖

```sh
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
```

ការបញ្ជូនបន្តនេះបង្កើត ឬជំនួសឯកសារមូលដ្ឋាន។ ត្រូវប្រាកដថាពាក្យបញ្ជាបានបញ្ចប់ដោយជោគជ័យមុនពេលប្រើប្រាស់មាតិការបស់វា។
កំហុសត្រូវបានសរសេរទៅកាន់កំហុសទិន្នផល (stderr) ឯកសារទទេមិនធានាថាមិនមានទិន្នន័យនោះទេ។
ឯកសារដែលបាននាំចេញអាចមានព័ត៌មានផ្ទាល់ខ្លួន៖ សូមរក្សាវាជាការសម្ងាត់។

## ការចាកចេញពីគណនី (Logout)

```sh
omi auth logout
```

ពាក្យបញ្ជានេះលុបព័ត៌មានសម្ងាត់ដែលបានរក្សាទុកក្នុងមូលដ្ឋាន។ ដើម្បីលុបចោលសោនៅលើ server សូមប្រើការគ្រប់គ្រង developer keys នៅក្នុងគណនីរបស់អ្នក។

សម្រាប់ពាក្យបញ្ជាផ្សេងទៀត និងជម្រើសកម្រិតខ្ពស់ សូមមើល [ការណែនាំចម្បងជាភាសាអង់គ្លេស](../README.md) និង `omi --help`។
