# omi-cli తో ప్రారంభ దశలు

ఈ మార్గదర్శిని తెలుగులో ప్రాథమిక ఆదేశాలను (commands) వివరిస్తుంది. ఆదేశాల పేర్లు
మరియు ప్రోగ్రామ్ సందేశాలు ఆంగ్లంలోనే ఉంటాయి. ఇక్కడ చూపిన ప్రశ్నల ఉదాహరణలు మీ
జ్ఞాపకాలను, సంభాషణలను, పనులను లేదా లక్ష్యాలను మార్చవు.

## ప్రోగ్రామ్‌ను ఇన్‌స్టాల్ చేయడం

అవసరాలు: Python 3.10 లేదా అంతకంటే కొత్త వెర్షన్ మరియు ఒక Omi ఖాతా.

మీ వద్ద `pipx` ఇన్‌స్టాల్ చేసి ఉంటే:

```sh
pipx install omi-cli
omi --help
```

ప్రత్యామ్నాయంగా, మీరు దీన్ని యాక్టివేట్ చేసిన Python వర్చువల్ ఎన్విరాన్‌మెంట్‌లో ఇన్‌స్టాల్ చేయవచ్చు:

```sh
python -m pip install omi-cli
omi --help
```

టెర్మినల్ `omi` ని గుర్తించకపోతే, వర్చువల్ ఎన్విరాన్‌మెంట్ యాక్టివ్‌గా ఉందో లేదో లేదా
`pipx` ఎగ్జిక్యూటబుల్స్‌ను ఇన్‌స్టాల్ చేసే డైరెక్టరీ మీ `PATH` లో ఉందో లేదో తనిఖీ చేయండి.

## మీ ఖాతాను కనెక్ట్ చేయడం

ఇంటరాక్టివ్ అసిస్టెంట్‌ను ప్రారంభించండి:

```sh
omi auth login
```

బ్రౌజర్ ద్వారా లాగిన్ అవ్వడాన్ని లేదా Omi డెవలపర్ API కీని పేస్ట్ చేసే ఎంపికను ఎంచుకోండి.
ఇంటరాక్టివ్ ఇన్‌పుట్ కీని దాచిపెడుతుంది; టెర్మినల్ చరిత్రలో మిగిలిపోయేలా కమాండ్‌లో కీని టైప్ చేయవద్దు.

నేరుగా బ్రౌజర్‌కు వెళ్లడానికి:

```sh
omi auth login --browser
```

టెర్మినల్ నడుస్తున్న అదే కంప్యూటర్‌లో లాగిన్ అవ్వండి: ప్రమాణీకరణ ప్రతిస్పందన స్థానిక
చిరునామాను ఉపయోగిస్తుంది. స్క్రీన్‌పై కనిపించే సూచనలను అనుసరించండి.

ఆ తర్వాత, కాన్ఫిగరేషన్ మరియు API యాక్సెస్‌ను ధృవీకరించండి:

```sh
omi auth status
omi auth whoami
```

`status` స్థానిక స్థితిని చూపుతుంది మరియు రహస్య కీని దాచిపెడుతుంది, కానీ సర్వర్‌లో దాని
చెల్లుబాటును తనిఖీ చేయదు. `whoami` ప్రామాణీకరించబడిన అభ్యర్థనను పంపుతుంది; అది విజయవంతమైతే,
మీ పేరును ప్రదర్శించాల్సిన అవసరం లేకుండా మీ ఆధారాలు పనిచేస్తున్నాయని నిర్ధారిస్తుంది.

కాన్ఫిగరేషన్ డిఫాల్ట్‌గా `~/.omi/config.toml` లో భద్రపరచబడుతుంది. ఈ ఫైల్‌ను ఇతరులతో
భాగస్వామ్యం చేయవద్దు: ఇందులో మీ రహస్య లాగిన్ ఆధారాలు ఉండవచ్చు.

## మీ డేటాను చూడటం

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ఖాళీ జాబితా అంటే మీ అభ్యర్థనకు సరిపోయే అంశాలు ఏవీ లేవని అర్థం కావచ్చు.
ప్రతి ఆదేశం యొక్క ఫిల్టర్‌లను తెలుసుకోవడానికి సహాయాన్ని ఉపయోగించండి:

```sh
omi memory list --help
omi action-item list --help
```

## JSON పొందడం మరియు పేజీల ద్వారా నావిగేట్ చేయడం

గ్లోబల్ ఎంపిక `--json` ను కమాండ్ గ్రూప్‌కు **ముందు** ఉంచండి:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

మొదటి ఆదేశం మొదటి 25 జ్ఞాపకాలను అడుగుతుంది; రెండవది, తర్వాతి 25 జ్ఞాపకాలను అడుగుతుంది.
కాబట్టి ఒకే పేజీ పూర్తి బ్యాకప్ కాదు. JSON అవుట్‌పుట్ పూర్తి ఐడెంటిఫైయర్‌లను భద్రపరుస్తుంది,
అయితే డిస్‌ప్లే కోసం పట్టికలు వాటిని కుదించవచ్చు.

ఒక పేజీని ఫైల్‌లో సేవ్ చేయడానికి:

```sh
omi --json memory list --limit 25 --offset 0 > జ్ఞాపకాలు-పేజీ-1.json
```

ఈ దారిమార్పు స్థానిక ఫైల్‌ను సృష్టిస్తుంది లేదా భర్తీ చేస్తుంది. కంటెంట్‌ను ఉపయోగించే ముందు
ఆదేశం విజయవంతంగా పూర్తయిందని నిర్ధారించుకోండి. లోపాలు ఎర్రర్ అవుట్‌పుట్ (stderr) లో
వ్రాయబడతాయి; ఖాళీ ఫైల్ డేటా లేదని హామీ ఇవ్వదు. ఎగుమతి చేయబడిన ఫైల్‌లో వ్యక్తిగత సమాచారం
ఉండవచ్చు: దానిని గోప్యంగా ఉంచండి.

## ఖాతా నుండి లాగౌట్ అవ్వడం (Logout)

```sh
omi auth logout
```

ఈ ఆదేశం స్థానికంగా సేవ్ చేయబడిన ఆధారాలను తొలగిస్తుంది. సర్వర్‌లో కీని రద్దు చేయడానికి,
మీ ఖాతాలోని డెవలపర్ కీ నిర్వహణను ఉపయోగించండి.

మిగిలిన ఆదేశాలు మరియు అధునాతన ఎంపికల కోసం, [ఇంగ్లీషులోని ప్రధాన మార్గదర్శిని](../README.md) మరియు `omi --help` చూడండి.
