# omi-cli এর সাথে পরিচিতি

এই নির্দেশিকাটি বাংলায় প্রথম কয়েকটি কমান্ড ব্যবহারের প্রক্রিয়া দেখায়। কমান্ডের নাম এবং প্রোগ্রামের বার্তাগুলো ইংরেজিতেই থাকবে। এখানে দেওয়া পড়ার উদাহরণগুলো আপনার স্মৃতি, কথোপকথন, কর্মতালিকা বা লক্ষ্য পরিবর্তন করবে না।

## প্রোগ্রাম ইনস্টল করুন

প্রয়োজনীয়তা: Python 3.10 বা তার পরবর্তী সংস্করণ এবং একটি Omi অ্যাকাউন্ট।

> সতর্কতা: PyPI-তে প্যাকেজটির নাম **`omi-cli`**, আর ইনস্টল করার পর কমান্ডটির নাম **`omi`**। PyPI-তে `omi` নামে একটি সম্পর্কহীন প্যাকেজ রয়েছে — সেটি ইনস্টল করবেন না।

যদি `pipx` ইনস্টল থাকে:

```sh
pipx install omi-cli
omi --help
```

বিকল্পভাবে, সক্রিয় Python ভার্চুয়াল এনভায়রনমেন্টে:

```sh
python -m pip install omi-cli
omi --help
```

যদি টার্মিনাল `omi` কমান্ড খুঁজে না পায়, তবে ভার্চুয়াল এনভায়রনমেন্ট সক্রিয় আছে কিনা অথবা `pipx` এর ডিরেক্টরি আপনার `PATH`-এ অন্তর্ভুক্ত আছে কিনা তা নিশ্চিত করুন।

## অ্যাকাউন্ট যুক্ত করুন

ইন্টারেক্টিভ লগইন শুরু করুন:

```sh
omi auth login
```

ব্রাউজারের মাধ্যমে লগইন করুন অথবা Omi ডেভেলপার API key পেস্ট করার বিকল্প বেছে নিন। ইন্টারেক্টিভ ইনপুট key গোপন রাখে; এমন কোনো কমান্ডে key লিখবেন না যা শেল ইতিহাসে সংরক্ষিত হতে পারে।

সরাসরি ব্রাউজারের মাধ্যমে:

```sh
omi auth login --browser
```

যে কম্পিউটারে টার্মিনাল চলছে সেখানেই ব্রাউজার লগইন সম্পন্ন করুন, কারণ প্রমাণীকরণ স্থানীয় ঠিকানায় ফেরত আসে। স্ক্রিনের নির্দেশাবলী অনুসরণ করুন।

এরপর কনফিগারেশন এবং API সংযোগ পরীক্ষা করুন:

```sh
omi auth status
omi auth whoami
```

`status` স্থানীয় কনফিগারেশন দেখায় এবং গোপন তথ্য আড়াল রাখে, তবে সার্ভারে এর বৈধতা যাচাই করে না। `whoami` সার্ভারে একটি প্রমাণীকৃত অনুরোধ পাঠায়; সফল হলে আপনার পরিচয়পত্র সঠিকভাবে কাজ করছে।

কনফিগারেশন ফাইলটি ডিফল্টভাবে `~/.omi/config.toml`-এ সংরক্ষিত হয়। এটি শেয়ার করবেন না: এতে আপনার সংবেদনশীল তথ্য থাকতে পারে।

## আপনার ডেটা দেখুন

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

খালি তালিকা মানে কোয়েরির সাথে মেলে এমন কোনো আইটেম নেই। কোনো কমান্ডের ফিল্টারিং বিকল্প জানতে help দেখুন:

```sh
omi memory list --help
omi action-item list --help
```

## JSON আউটপুট এবং পেজিনেশন

গ্লোবাল অপশন `--json` কমান্ডের **পূর্বে** ব্যবহার করুন:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

প্রথম কমান্ডটি প্রথম ২৫টি রেকর্ড এবং দ্বিতীয়টি পরবর্তী ২৫টি রেকর্ড দেখায়। সম্পূর্ণ ব্যাকআপের জন্য একাধিক পৃষ্ঠা প্রয়োজন। JSON আউটপুটে পূর্ণ আইডেন্টিফায়ার বজায় থাকে।

কোনো পৃষ্ঠা ফাইলে সংরক্ষণ করতে:

```sh
omi --json memory list --limit 25 --offset 0 > smriti-page-1.json
```

এই রিডাইরেকশন ফাইল তৈরি বা প্রতিস্থাপন করে। ত্রুটিগুলো stderr-এ পাঠানো হয়; খালি ফাইল ডেটা না থাকার প্রমাণ নয়। রপ্তানি করা ফাইলে ব্যক্তিগত তথ্য থাকতে পারে, তাই এটি সুরক্ষিত রাখুন।

## লগআউট করুন

```sh
omi auth logout
```

এটি স্থানীয়ভাবে সংরক্ষিত পরিচয়পত্র মুছে ফেলে। সার্ভারে কী বাতিল করতে ওয়েব অ্যাপ্লিকেশনের ডেভেলপার কনসোল ব্যবহার করুন।

অন্যান্য কমান্ড ও বিস্তারিত তথ্যের জন্য মূল ইংরেজি গাইড দেখুন:
[../README.md](../README.md) এবং `omi --help`.
