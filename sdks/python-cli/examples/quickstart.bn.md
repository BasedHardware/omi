# omi-cli দিয়ে শুরু করা

এই নির্দেশিকা বাংলায় প্রথম কমান্ডগুলো ব্যাখ্যা করে। কমান্ডের নাম ও
প্রোগ্রামের বার্তাগুলো ইংরেজিতেই থাকে। এখানকার দেখার (query) উদাহরণগুলো
আপনার স্মৃতি, কথোপকথন, টাস্ক বা লক্ষ্য পরিবর্তন করে না।

## প্রোগ্রাম ইনস্টল করা

প্রয়োজন: Python 3.10 বা তার পরের সংস্করণ এবং একটি Omi অ্যাকাউন্ট।

`pipx` ইনস্টল করা থাকলে:

```sh
pipx install omi-cli
omi --help
```

বিকল্প হিসেবে, চালু থাকা Python ভার্চুয়াল এনভায়রনমেন্টের ভেতরে ইনস্টল
করতে পারেন:

```sh
python -m pip install omi-cli
omi --help
```

টার্মিনাল `omi` খুঁজে না পেলে, যাচাই করুন ভার্চুয়াল এনভায়রনমেন্ট চালু আছে
কিনা অথবা `pipx` যেখানে এক্সিকিউটেবল ইনস্টল করে সেই ডিরেক্টরি আপনার
`PATH`-এ আছে কিনা।

## আপনার অ্যাকাউন্ট সংযুক্ত করা

ইন্টার‌্যাক্টিভ সহকারী চালু করুন:

```sh
omi auth login
```

ব্রাউজারে লগইন করা অথবা Omi ডেভেলপার API কী বসানোর (paste) অপশন বেছে নিন।
ইন্টার‌্যাক্টিভ ইনপুট কীটি লুকিয়ে রাখে; এমন কমান্ডে কীটি লিখবেন না যা
টার্মিনালের হিস্ট্রিতে থেকে যাবে।

সরাসরি ব্রাউজারে যেতে:

```sh
omi auth login --browser
```

টার্মিনাল যে কম্পিউটারে চলছে, সেই কম্পিউটারেই লগইন করুন: অথেনটিকেশনের
উত্তর একটি লোকাল ঠিকানা ব্যবহার করে। স্ক্রিনে দেখানো নির্দেশনা অনুসরণ
করুন।

এরপর কনফিগারেশন ও API অ্যাক্সেস যাচাই করুন:

```sh
omi auth status
omi auth whoami
```

`status` লোকাল অবস্থা দেখায় এবং সিক্রেট লুকিয়ে রাখে, কিন্তু সার্ভারে এর
বৈধতা যাচাই করে না। `whoami` একটি অথেনটিকেটেড অনুরোধ পাঠায়; সফল হলে বোঝা
যায় ক্রেডেনশিয়াল কাজ করছে, যদিও এতে আপনার নাম দেখাতেই হবে এমন নয়।

কনফিগারেশন ডিফল্ট হিসেবে `~/.omi/config.toml`-এ সংরক্ষিত হয়। এই ফাইলটি
শেয়ার করবেন না: এতে আপনার ক্রেডেনশিয়াল থাকতে পারে।

## আপনার ডেটা দেখা

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

খালি তালিকার মানে শুধু এটাই হতে পারে যে কুয়েরির সাথে মিলে এমন কিছু নেই।
প্রতিটি কমান্ডের ফিল্টার জানতে হেল্প ব্যবহার করুন:

```sh
omi memory list --help
omi action-item list --help
```

## JSON নেওয়া ও পেজ ঘোরা

গ্লোবাল `--json` অপশনটি কমান্ড গ্রুপের **আগে** বসান:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

প্রথম কমান্ড প্রথম ২৫টি স্মৃতি চায়; দ্বিতীয়টি, পরের ২৫টি। তাই একটিমাত্র
পেজ সম্পূর্ণ ব্যাকআপ নয়। JSON আউটপুট পূর্ণ আইডেন্টিফায়ার সংরক্ষণ করে,
আর টেবিল দেখানোর সময় সেগুলো ছোট করে দেখাতে পারে।

একটি পেজ ফাইলে সংরক্ষণ করতে:

```sh
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
```

এই রিডাইরেকশন লোকাল ফাইল তৈরি করে বা প্রতিস্থাপন করে। ব্যবহারের আগে
যাচাই করুন কমান্ড ঠিকমতো শেষ হয়েছে কিনা। এররগুলো এরর আউটপুটে লেখা হয়;
খালি ফাইলের মানে এই নয় যে ডেটা নেই। এক্সপোর্ট করা ফাইলে ব্যক্তিগত তথ্য
থাকতে পারে: এটি প্রাইভেট রাখুন।

## লগআউট করা

```sh
omi auth logout
```

এই কমান্ড লোকালি সংরক্ষিত ক্রেডেনশিয়াল মুছে দেয়। সার্ভারে একটি কী বাতিল
করতে, আপনার অ্যাকাউন্টের ডেভেলপার কী ব্যবস্থাপনা ব্যবহার করুন।

বাকি কমান্ড ও অ্যাডভান্সড অপশনের জন্য
[ইংরেজি মূল নির্দেশিকা](../README.md) ও `omi --help` দেখুন।
