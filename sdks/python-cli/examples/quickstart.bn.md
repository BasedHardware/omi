# omi-cli দ্রুত শুরু নির্দেশিকা (Quickstart)

এই নির্দেশিকাটি বাংলায় `omi-cli` ব্যবহারের প্রাথমিক কমান্ডগুলো প্রদর্শন করে। কমান্ডের নাম এবং টার্মিনাল বার্তাগুলো ইংরেজিতে থাকবে। এখানে দেওয়া পড়ার উদাহরণগুলো কেবল আপনার ডেটা প্রদর্শন করে এবং আপনার স্মৃতি (memories), কথোপকথন (conversations), করণীয় তালিকা (action items) বা লক্ষ্যসমূহ (goals) পরিবর্তন করে না।

## প্রোগ্রাম ইনস্টল করুন

প্রয়োজনীয়তা: Python 3.10 বা তার পরবর্তী সংস্করণ এবং একটি Omi অ্যাকাউন্ট।

> **গুরুত্বপূর্ণ দ্রষ্টব্য:** PyPI-তে প্যাকেজটির নাম **`omi-cli`**, কিন্তু ইনস্টলেশনের পর কার্যকর কমান্ডের নাম **`omi`**। PyPI-তে `omi` নামে সম্পূর্ণ আলাদা এবং সম্পর্কহীন একটি প্যাকেজ রয়েছে — সেটি ইনস্টল করবেন না।

যদি আপনার সিস্টেমে `pipx` ইনস্টল করা থাকে (প্রস্তাবিত):

```sh
pipx install omi-cli
omi --help
```

বিকল্পভাবে, আপনার সক্রিয় Python ভার্চুয়াল পরিবেশে (virtual environment):

```sh
python -m pip install omi-cli
omi --help
```

যদি টার্মিনাল `omi` কমান্ড খুঁজে না পায়, তবে নিশ্চিত করুন যে আপনার ভার্চুয়াল পরিবেশ সক্রিয় রয়েছে অথবা `pipx`-এর এক্সিকিউটেবল ডিরেক্টরি আপনার সিস্টেম `PATH`-এ অন্তর্ভুক্ত আছে।

## আপনার অ্যাকাউন্ট লগইন করুন (Login)

ইন্টারেক্টিভ লগইন প্রক্রিয়া শুরু করুন:

```sh
omi auth login
```

ব্রাউজারের মাধ্যমে লগইন নির্বাচন করুন অথবা Omi ডেভেলপার API Key পেস্ট করার বিকল্পটি বেছে নিন। ইন্টারেক্টিভ ইনপুটটি আপনার API Key স্ক্রিনে গোপন রাখে; সরাসরি কমান্ড লাইনে Key লিখবেন না যাতে এটি টার্মিনাল হিস্ট্রিতে সংরক্ষিত না হয়।

সরাসরি ব্রাউজার লগইনের জন্য:

```sh
omi auth login --browser
```

লগইন প্রক্রিয়াটি সেই কম্পিউটারে সম্পন্ন করুন যেখানে টার্মিনাল চলছে, কারণ প্রমাণীকরণ (authentication) স্থানীয় অ্যাড্রেসে (localhost) ফিরে আসে। স্ক্রিনের সহজ নির্দেশাবলী অনুসরণ করুন।

এরপর কনফিগারেশন এবং API সংযোগ পরীক্ষা করুন:

```sh
omi auth status
omi auth whoami
```

- `omi auth status`: স্থানীয় কনফিগারেশন ফাইলের স্থিতি দেখায় এবং সিক্রেট লুকায়।
- `omi auth whoami`: সার্ভারে একটি প্রমাণীকৃত অনুরোধ পাঠায় এবং সফল হলে আপনার ব্যবহারকারী আইডি প্রদর্শন করে।

কনফিগারেশন ডিফল্টভাবে `~/.omi/config.toml` ফাইলে সংরক্ষিত হয়। এই ফাইলটি কারও সাথে শেয়ার করবেন না কারণ এতে আপনার লগইন ক্রেডেনশিয়াল থাকতে পারে।

## আপনার ডেটা দেখুন

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

যদি কোনো ফলাফল না আসে, তবে এর অর্থ হলো অনুসন্ধান মানদণ্ডের সাথে মিলে এমন কোনো ডেটা নেই। অতিরিক্ত ফিল্টার জানতে `--help` ব্যবহার করুন:

```sh
omi memory list --help
omi conversation list --help
omi action-item list --help
```

## JSON আউটপুট এবং পৃষ্ঠা বিভাজন (Pagination)

স্বয়ংক্রিয় প্রক্রিয়া বা প্রোগ্রামিং ব্যবহারের জন্য গ্লোবাল ফ্ল্যাগ `--json` কমান্ড গ্রুপের **পূর্বে** ব্যবহার করুন:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

প্রথম কমান্ডটি প্রথম ২৫টি রেকর্ড নিয়ে আসে; দ্বিতীয় কমান্ডটি পরবর্তী ২৫টি রেকর্ড প্রদর্শন করে। JSON আউটপুটে সম্পূর্ণ আইডেন্টিফায়ার (IDs) সংরক্ষিত থাকে।

ডেটা একটি JSON ফাইলে সংরক্ষণ করতে:

```sh
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
```

## নির্দিষ্ট রেকর্ডের বিস্তারিত বিবরণ দেখুন

```sh
omi memory get <memory-id>
omi conversation get <conversation-id>
```

কথোপকথনের সম্পূর্ণ ট্রান্সক্রিপ্ট সহ দেখতে:

```sh
omi conversation get <conversation-id> --include-transcript
```

## সমস্যা সমাধান (Troubleshooting)

- **কমান্ড পাওয়া যাচ্ছে না (`command not found: omi`)**: নিশ্চিত করুন আপনার Python ভার্চুয়াল পরিবেশ সক্রিয় আছে অথবা `~/.local/bin` আপনার `PATH` এনভায়রনমেন্ট ভেরিয়েবলে অন্তর্ভুক্ত রয়েছে।
- **প্রমাণীকরণ ব্যর্থ (`Authentication failed`)**: `omi auth login` পুনরায় চালিয়ে নতুন সেশন তৈরি করুন অথবা `omi auth status` দিয়ে পরীক্ষা করুন।
- **সাহায্য ও সহায়তা**: যেকোনো কমান্ডের বিস্তারিত নির্দেশিকা জানতে `omi <command> --help` চালান।
