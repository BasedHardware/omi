# คู่มือเริ่มต้นใช้งาน AI Agent (Thai)

นี่คือคู่มือ **เร็ว** สำหรับการสร้างและรัน AI Agent ด้วย `omi-cli` ในภาษาไทย  
เนื้อหาในไฟล์นี้เป็นการแปลจากไฟล์ `agent_quickstart.md` ดั้งเดิม  
โค้ดตัวอย่างและอาร์กิวเมนต์ของคำสั่งจะไม่ถูกแปลเพื่อให้คัดลอกได้โดยตรง

---

## 📋 ความต้องการเบื้องต้น

| สิ่งที่ต้องมี | เวอร์ชันแนะนำ |
|--------------|----------------|
| Python       | ≥ 3.9 |
| `omi-cli`    | ล่าสุด (`pip install omi-cli`) |
| OpenAI API Key (หรือ LLM Provider อื่น) | - |

> **หมายเหตุ**: หากคุณยังไม่มี API Key ของ OpenAI ให้สมัครที่ <https://platform.openai.com/account/api-keys>
