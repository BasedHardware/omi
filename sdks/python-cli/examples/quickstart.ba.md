# omi-cli буйынса ҡыҫҡаса ҡулланма

Был ҡулланма `omi-cli` өсөн башланғыс бойороҡтарҙы башҡорт телендә (Башҡортса) аңлата. Бойороҡ исемдәре һәм программа хәбәрҙәре инглиз телендә ҡала. Бында килтерелгән ҡарап сығыу өлгөләре һеҙҙең иҫтәлектәрегеҙҙе (memories), һөйләшеүҙәрегеҙҙе (conversations), эш пункттарығыҙҙы (action items) йәки маҡсаттарығыҙҙы (goals) үҙгәртмәй.

## Программаны урынлаштырыу

Таләптәр: Python 3.10 йәки яңыраҡ өлгө һәм Omi аккаунты.

Әгәр һеҙҙә `pipx` урынлаштырылған булһа:

```sh
pipx install omi-cli
omi --help
```

Шулай уҡ уны әүҙем Python виртуаль мөхитенә (virtual environment) урынлаштырырға мөмкин:

```sh
python -m pip install omi-cli
omi --help
```

Әгәр терминалда `omi` бойороғо табылмаһа, виртуаль мөхиттең әүҙем булыуын йәки `pipx` урынлаштырыу директорияһының `$PATH` үҙгәреүсәнендә булыуын тикшерегеҙ.

## Аккаунтығыҙҙы тоташтырыу

Интерактив ярҙамсыны башлау:

```sh
omi auth login
```

Браузер аша инеү йәки Omi developer API асҡысын ҡуйыу вариантын һайлағыҙ. Интерактив индереү асҡысты йәшерә; терминал тарихында ҡала торған бойороҡтарҙа уны яҙмағыҙ.

Браузерға туранан-тура күсеү өсөн:

```sh
omi auth login --browser
```

Терминал эшләгән компьютерҙың үҙендә үк инегеҙ: аутентификация яуабы локаль адрес ҡуллана. Экрандағы күрһәтмәләрҙе үтәгеҙ.

Шунан һуң көйләүҙәрҙе һәм API-ға инеү мөмкинлеген тикшерегеҙ:

```sh
omi auth status
omi auth whoami
```

`status` локаль халәтте күрһәтә һәм серҙе йәшерә, ләкин серверҙағы ғәмәлдә булыуын тикшермәй. `whoami` аутентификацияланған һорау ебәрә; әгәр уңышлы булһа, исемегеҙҙе күрһәтмәйенсә генә таныҡлыҡтарҙың эшләүен раҫлай.

Конфигурация ғәҙәттә `~/.omi/config.toml` файлында һаҡлана. Был файл менән уртаҡлашмағыҙ: унда йәшерен таныҡлыҡтар булырға мөмкин.

## Мәғлүмәттәрегеҙҙе ҡарап сығыу

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Буш исемлек бары тик эҙләүгә тура килгән мәғлүмәт булмауын аңлатырға мөмкин. Һәр бойороҡтағы фильтрҙарҙы табыу өсөн ярҙам бүлеген ҡулланығыҙ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON алыу һәм биттәргә бүлеү (Pagination)

Глобаль `--json` опцияһын бойороҡтар төркөмө **алдынан** ҡуйығыҙ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Беренсе бойороҡ тәүге 25 иҫтәлекте һорай; икенсеһе — сираттағы 25 иҫтәлекте. Бер бит тулы резерв күсермә (backup) түгел. JSON сығарылышы тулы идентификаторҙарҙы һаҡлай, ә экрандағы таблицалар уларҙы ҡыҫҡартып күрһәтергә мөмкин.

Битте файлға һаҡлау өсөн:

```sh
omi --json memory list --limit 25 --offset 0 > иҫтәлектәр-бит-1.json
```

Был йүнәлтеү локаль файлды төҙөй йәки алмаштыра. Эстәлеген ҡулланыр алдынан бойороҡтоң уңышлы тамамланыуын тикшерегеҙ. Хаталар хаталар ағымына (stderr) яҙыла; буш файл мәғлүмәт юҡ тигәнде аңлатмай. Экспортланған файлда шәхси мәғлүмәт булырға мөмкин: уны һаҡлағыҙ.

## Аккаунттан сығыу

```sh
omi auth logout
```

Был бойороҡ локаль һаҡланған таныҡлыҡтарҙы бөтөрә. Серверҙағы асҡысты юҡҡа сығарыу өсөн шәхси аккаунтығыҙҙа developer key идараһын ҡулланығыҙ.

Башҡа бойороҡтар һәм өҫтәмә көйләүҙәр өсөн [төп инглизсә ҡулланманы](../README.md) һәм `omi --help` бойороғон ҡарағыҙ.
