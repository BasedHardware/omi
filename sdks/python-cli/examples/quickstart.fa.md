# گام‌های نخست با omi-cli

این راهنما دستورات اولیه را به زبان فارسی توضیح می‌دهد. نام دستورات و پیام‌های
برنامه به زبان انگلیسی باقی می‌مانند. نمونه پرس‌وجوهای ارائه شده در اینجا
تغییری در حافظه‌ها، مکالمات، وظایف یا اهداف شما ایجاد نمی‌کنند.

## نصب برنامه

پیش‌نیازها: پایتون ۳.۱۰ یا بالاتر و یک حساب کاربری Omi.

اگر `pipx` را نصب دارید:

```sh
pipx install omi-cli
omi --help
```

همچنین می‌توانید آن را در یک محیط مجازی فعال پایتون (virtual environment) نصب کنید:

```sh
python -m pip install omi-cli
omi --help
```

اگر ترمینال دستور `omi` را پیدا نکرد، مطمئن شوید محیط مجازی فعال است یا مسیری
که `pipx` فایل‌های اجرایی را در آن نصب می‌کند در متغیر `PATH` شما قرار دارد.

## اتصال حساب کاربری

دستیار تعاملی را اجرا کنید:

```sh
omi auth login
```

ورود از طریق مرورگر یا چسباندن کلید API توسعه‌دهنده Omi را انتخاب کنید.
ورودی تعاملی کلید را پنهان می‌کند؛ از نوشتن آن در دستوری که در تاریخچه ترمینال
باقی می‌ماند خودداری کنید.

برای باز کردن مستقیم مرورگر:

```sh
omi auth login --browser
```

در همان رایانه‌ای که ترمینال اجرا می‌شود وارد شوید: پاسخ احراز هویت از یک
آدرس محلی استفاده می‌کند. دستورالعمل‌های روی صفحه را دنبال کنید.

سپس پیکربندی و دسترسی به API را بررسی کنید:

```sh
omi auth status
omi auth whoami
```

دستور `status` وضعیت محلی را نشان داده و کلید را مخفی می‌کند اما اعتبار آن
را در سرور بررسی نمی‌کند. دستور `whoami` یک درخواست احراز هویت شده ارسال می‌کند؛
در صورت موفقیت، کارکرد صحیح اطلاعات ورود را تأیید می‌کند بدون اینکه لزوماً نام شما را نشان دهد.

پیکربندی به‌صورت پیش‌فرض در مسیر `~/.omi/config.toml` ذخیره می‌شود. این فایل
را با دیگران به اشتراک نگذارید زیرا ممکن است حاوی اطلاعات محرمانه شما باشد.

## مشاهده داده‌های خود

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

یک لیست خالی ممکن است به این معنی باشد که هیچ موردی مطابق با پرس‌وجو یافت نشد.
برای مشاهده فیلترهای هر دستور از راهنما استفاده کنید:

```sh
omi memory list --help
omi action-item list --help
```

## دریافت خروجی JSON و پیمایش بین صفحات

گزینه سراسری `--json` را **قبل** از گروه دستور قرار دهید:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

دستور اول ۲۵ حافظه اول را درخواست می‌کند؛ دستور دوم ۲۵ مورد بعدی را. بنابراین
یک صفحه تکی یک نسخه پشتیبان کامل نیست. خروجی JSON شناسه‌های کامل را حفظ می‌کند،
در حالی که جدول‌های نمایشی ممکن است آن‌ها را کوتاه کنند.

برای ذخیره یک صفحه در یک فایل:

```sh
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
```

این تغییر مسیر فایل محلی را ایجاد یا بازنویسی می‌کند. قبل از استفاده از محتوا،
مطمئن شوید دستور با موفقیت پایان یافته است. خطاها در خروجی خطا (stderr) نوشته می‌شوند؛
فایل خالی تضمین‌کننده نبود داده نیست. فایل صادر شده ممکن است حاوی اطلاعات شخصی باشد: آن را خصوصی نگه دارید.

## خروج از حساب (Logout)

```sh
omi auth logout
```

این دستور اطلاعات ورود ذخیره شده محلی را پاک می‌کند. برای ابطال کلید در سرور،
از بخش مدیریت کلیدهای توسعه‌دهنده در حساب خود استفاده کنید.

برای سایر دستورات و گزینه‌های پیشرفته، به [راهنمای اصلی انگلیسی](../README.md) و `omi --help` مراجعه کنید.
