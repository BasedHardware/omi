# omi-cli உடனான தொடக்க வழிகாட்டி (Tamil Quickstart)

இந்த வழிகாட்டி `omi-cli` இன் அடிப்படை கட்டளைகளைத் (commands) தமிழில் விளக்குகிறது. கட்டளைகளின் பெயர்கள் மற்றும் கணினி செய்திகள் ஆங்கிலத்தில் இருக்கும். இங்குள்ள உதாரணங்கள் உங்களின் நினைவுகள், உரையாடல்கள், செய்யவேண்டிய பணிகள் அல்லது இலக்குகளை மாற்றாமல் தகவல்களை மட்டுமே பார்வையிடுகின்றன.

## 1. நிரலை நிறுவுதல்

**தேவைகள்:** Python 3.10 அல்லது புதிய பதிப்பு மற்றும் ஒரு Omi கணக்கு.

> **முக்கிய குறிப்பு:** PyPI தளத்தில் தொகுப்பின் பெயர் **`omi-cli`** ஆகும், ஆனால் நிறுவிய பிறகு முனையத்தில் (terminal) இயங்கும் கட்டளையின் பெயர் **`omi`** ஆகும். PyPI இல் `omi` என்ற பெயரில் மற்றொரு தொடர்பற்ற தொகுப்பும் உள்ளது — அதை நிறுவ வேண்டாம்.

`pipx` நிறுவப்பட்டிருந்தால்:

```sh
pipx install omi-cli
omi --help
```

அல்லது, இயக்கத்தில் உள்ள Python விர்ச்சுவல் சூழலில் (virtualenv):

```sh
python -m pip install omi-cli
omi --help
```

முனையத்தில் `omi` கட்டளை கிடைக்கவில்லை எனில், விர்ச்சுவல் சூழல் இயக்கத்தில் உள்ளதா அல்லது `pipx` அடைவு உங்கள் `PATH` இல் சேர்க்கப்பட்டுள்ளதா என்பதைச் சரிபார்க்கவும்.

## 2. உங்கள் கணக்கை இணைத்தல் (அங்கீகரிப்பு)

கணக்கு இணைப்பைத் தொடங்க:

```sh
omi auth login
```

உலாவி (browser) மூலம் உள்நுழையவும் அல்லது உங்கள் Omi டெவலப்பர் API சாவியை உள்ளிடவும். நேரடி உலாவி உள்நுழைவுக்கு:

```sh
omi auth login --browser
```

முனையம் இயங்கும் அதே கணினியில் உள்நுழையவும், ஏனெனில் அங்கீகரிப்பு உள்ளூர் முகவரிக்கு (localhost) திரும்பும்.

பின்னர் இணைப்பு நிலை மற்றும் API அணுகலைச் சரிபார்க்கவும்:

```sh
omi auth status
omi auth whoami
```

`status` உள்ளூர் நிலையை வெளிப்படுத்துகிறது மற்றும் ரகசியங்களை மறைக்கிறது. `whoami` சர்வரோடு தொடர்பு கொண்டு சான்றுகள் சரியாகச் செயல்படுவதை உறுதி செய்கிறது.

அமைப்புகள் இயல்பாக `~/.omi/config.toml` இல் சேமிக்கப்படும். இந்த கோப்பில் முக்கியமான சாவிகள் உள்ளதால் இதைப் பாதுகாப்பாக வைத்திருக்கவும்.

## 3. உங்கள் தரவைப் பார்வையிடுதல்

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ஒரு குறிப்பிட்ட உரையாடலின் முழு டிரான்ஸ்கிரிப்டைப் பெற:

```sh
omi conversation get <CONVERSATION_ID> --include-transcript
```

பட்டியல் காலியாக இருந்தால், தேடல் நிபந்தனைகளுக்கு ஏற்ற தரவு இல்லை என்று அர்த்தம். எந்தவொரு கட்டளையின் கூடுதல் விருப்பங்களைப் பார்க்க `--help` ஐப் பயன்படுத்தவும்:

```sh
omi memory list --help
omi conversation list --help
omi goal list --help
```

## 4. JSON வடிவம் மற்றும் பக்கமாக்கம் (Pagination)

உலகளாவிய விருப்பமான `--json` ஐ எப்போதும் கட்டளைக் குழுவிற்கு **முன்பாக** வைக்கவும்:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

முதல் கட்டளை முதல் 25 பதிவுகளைக் கோருகிறது; இரண்டாவது கட்டளை அடுத்த 25 பதிவுகளைக் கோருகிறது.

பக்கக் கோப்பைச் சேமிக்க (Export):

```sh
omi --json memory list --limit 25 --offset 0 > ninaivugal-page-1.json
```

## 5. வெளியேறுதல் (Logout)

உள்ளூர் கணினியிலிருந்து சான்றுகளை நீக்க:

```sh
omi auth logout
```

இது கணினியிலிருந்து மட்டுமே உள்நுழைவுத் தகவலை நீக்கும். சர்வரிலிருந்து சாவியை முழுமையாக ரத்து செய்ய Omi டெவலப்பர் டாஷ்போர்டைப் பயன்படுத்தவும்.

மேலும் விரிவான வழிகாட்டுதலுக்கு ஆங்கில முதன்மை வழிகாட்டியைப் பார்க்கவும்: [../README.md](../README.md) மற்றும் [agent_quickstart.md](agent_quickstart.md).
