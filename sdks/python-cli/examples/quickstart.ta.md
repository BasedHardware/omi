# omi-cli உடன் தொடங்குதல்

இந்த வழிகாட்டி தமிழில் முதல் சில கட்டளைகளை எவ்வாறு பயன்படுத்துவது என்பதை விளக்குகிறது. கட்டளைப் பெயர்களும் கணினிச் செய்திகளும் ஆங்கிலத்திலேயே இருக்கும். இங்கு கொடுக்கப்பட்டுள்ள வாசிப்பு உதாரணங்கள் உங்கள் நினைவுகள், உரையாடல்கள், செய்யவேண்டிய பணிகள் அல்லது இலக்குகளை மாற்றாது.

## நிரலை நிறுவுதல்

தேவைகள்: Python 3.10 அல்லது அதற்குப் பிந்தைய பதிப்பு மற்றும் ஒரு Omi கணக்கு.

> கவனிக்க: PyPI-ல் தொகுப்பின் பெயர் **`omi-cli`**, நிறுவப்பட்ட பின் இயங்கும் கட்டளையின் பெயர் **`omi`**. PyPI-ல் `omi` என்ற பெயரில் தொடர்பில்லாத மற்றொரு தொகுப்பு உள்ளது — அதை நிறுவ வேண்டாம்.

`pipx` நிறுவப்பட்டிருந்தால்:

```sh
pipx install omi-cli
omi --help
```

மாற்றாக, செயலில் உள்ள Python விர்ச்சுவல் சூழலில்:

```sh
python -m pip install omi-cli
omi --help
```

முனையம் (terminal) `omi` கட்டளையைக் கண்டறியவில்லை எனில், விர்ச்சுவல் சூழல் இயக்கத்தில் உள்ளதா அல்லது `pipx` அடைவு உங்கள் `PATH`-ல் உள்ளதா என்பதைச் சரிபார்க்கவும்.

## கணக்கை இணைத்தல்

ஊடாடும் உள்நுழைவைத் தொடங்கவும்:

```sh
omi auth login
```

உலாவி வழியாக உள்நுழையவும் அல்லது Omi டெவலப்பர் API key ஒட்டும் வழியைத் தேர்ந்தெடுக்கவும். ஊடாடும் உள்ளீடு சாவியை மறைக்கும்; முனைய வரலாற்றில் சேமிக்கப்படும்படி சாவியை தட்டச்சு செய்யாதீர்கள்.

நேரடியாக உலாவி மூலம் உள்நுழைய:

```sh
omi auth login --browser
```

முனையம் இயங்கும் அதே கணினியில் உலாவி உள்நுழைவைச் செய்யவும், ஏனெனில் அங்கீகாரம் உள்ளூர் முகவரிக்குத் திரும்பும். திரையில் தோன்றும் வழிமுறைகளைப் பின்பற்றவும்.

அதன்பின் கட்டமைப்பு மற்றும் API இணைப்பைச் சோதிக்கவும்:

```sh
omi auth status
omi auth whoami
```

`status` உள்ளூர் அமைப்பைக் காட்டும் மற்றும் ரகசியங்களை மறைக்கும், ஆனால் சேவையகத்தில் சரிபார்க்காது. `whoami` ஒரு அங்கீகரிக்கப்பட்ட கோரிக்கையை அனுப்புகிறது; வெற்றி பெற்றால் நற்சான்றிதழ்கள் சரியாகச் செயல்படுகின்றன என்று பொருள்.

கட்டமைப்பு கோப்பு இயல்பாக `~/.omi/config.toml` பாதையில் சேமிக்கப்படுகிறது. இதை யாருடனும் பகிர வேண்டாம்: இதில் உங்கள் முக்கியமான சான்றுகள் இருக்கலாம்.

## உங்கள் தரவைப் பார்த்தல்

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

வெற்றுப் பட்டியல் என்பது வினவலுக்குப் பொருந்தும் தகவல்கள் இல்லை என்பதையே குறிக்கும். ஒரு கட்டளையின் வடிகட்டும் விருப்பங்களை அறிய help பார்க்கவும்:

```sh
omi memory list --help
omi action-item list --help
```

## JSON வெளியீடு மற்றும் பக்கமாக்கம் (Pagination)

பொது விருப்பமான `--json` ஐ கட்டளைக் குழுவுக்கு **முன்பு** வைக்கவும்:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

முதல் கட்டளை முதல் 25 பதிவுகளையும், இரண்டாவது அடுத்த 25 பதிவுகளையும் தரும். முழுமையான காப்புப் பிரதிக்கு பல பக்கங்கள் தேவைப்படலாம். JSON வெளியீடு முழு அடையாளங்காட்டிகளையும் தக்கவைக்கும்.

ஒரு பக்கத்தை கோப்பாகச் சேமிக்க:

```sh
omi --json memory list --limit 25 --offset 0 > ninaivukal-page-1.json
```

இந்தத் திருப்பிவிடுதல் உள்ளூர் கோப்பை உருவாக்கும் அல்லது மாற்றியமைக்கும். பிழைகள் stderr இல் எழுதப்படும்; வெற்று கோப்பு என்பது தரவு இல்லை என்பதற்கு முழுமையான ஆதாரமல்ல. ஏற்றுமதி செய்யப்பட்ட கோப்பில் தனிப்பட்ட தகவல்கள் இருக்கலாம், எனவே அதைப் பாதுகாப்பாக வைக்கவும்.

## வெளியேறுதல் (Logout)

```sh
omi auth logout
```

இக்கட்டளை உள்ளூரில் சேமிக்கப்பட்ட சான்றுகளை நீக்கும். சேவையகத்தில் சாவியை ரத்துசெய்ய கணக்கின் டெவலப்பர் தளத்தைப் பயன்படுத்தவும்.

பிற கட்டளைகள் மற்றும் மேம்பட்ட விருப்பங்களுக்கு முதன்மை ஆங்கில வழிகாட்டியைப் பார்க்கவும்:
[../README.md](../README.md) மற்றும் `omi --help`.
