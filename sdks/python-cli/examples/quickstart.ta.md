# omi-cli மூலம் விரைவுத் தொடக்கம்

இந்த வழிகாட்டி அடிப்படை கட்டளைகளை தமிழில் விளக்குகிறது. கட்டளை பெயர்களும்
நிரல் செய்திகளும் ஆங்கிலத்திலேயே இருக்கும். கீழே உள்ள எடுத்துக்காட்டு
கட்டளைகள் உங்கள் நினைவுகள், உரையாடல்கள், செயல் உருப்படிகள் அல்லது
இலக்குகளை மாற்றாது.

## நிரலை நிறுவுதல்

தேவைகள்: Python 3.10 அல்லது புதியது, மற்றும் ஒரு Omi கணக்கு.

`pipx` நிறுவப்பட்டிருந்தால்:

```sh
pipx install omi-cli
omi --help
```

அல்லது இயக்கப்பட்ட Python மெய்நிகர் சூழலில் நிறுவலாம்:

```sh
python -m pip install omi-cli
omi --help
```

டெர்மினலில் `omi` கிடைக்கவில்லை என்றால், மெய்நிகர் சூழல் இயக்கத்தில் உள்ளதா
அல்லது `pipx` நிறுவிய executable கோப்பகம் `PATH` இல் உள்ளதா என சரிபார்க்கவும்.

## உங்கள் கணக்கை இணைத்தல்

ஊடாடும் வழிகாட்டியை இயக்கவும்:

```sh
omi auth login
```

உலாவி உள்நுழைவைத் தேர்ந்தெடுக்கவும் அல்லது Omi டெவலப்பர் API key ஐ ஒட்டவும்.
ஊடாடும் உள்ளீடு key ஐ மறைக்கிறது; டெர்மினல் வரலாற்றில் சேமிக்கப்படும்
கட்டளைகளில் அதை நேரடியாக எழுத வேண்டாம்.

உலாவியை நேரடியாகப் பயன்படுத்த:

```sh
omi auth login --browser
```

அங்கீகாரம் உள்ளூர் callback முகவரியைப் பயன்படுத்துவதால் டெர்மினல் உள்ள அதே
கணினியில் உள்நுழையவும். திரையில் தோன்றும் அறிவுறுத்தல்களைப் பின்பற்றவும்.

உள்நுழைவுக்குப் பிறகு கட்டமைப்பு மற்றும் API அணுகலைச் சரிபார்க்கவும்:

```sh
omi auth status
omi auth whoami
```

`status` உள்ளூர் நிலையைக் காட்டி ரகசியங்களை மறைக்கிறது, ஆனால் சர்வரில் அவை
செல்லுபடியாகும் என சரிபார்க்காது. `whoami` அங்கீகரிக்கப்பட்ட கோரிக்கையை
அனுப்புகிறது; வெற்றியடைந்தால் உங்கள் நினைவுகள் பெயரைக் காட்டாமலேயே credentials
வேலை செய்கின்றன.

கட்டமைப்பு இயல்பாக `~/.omi/config.toml` இல் சேமிக்கப்படுகிறது. இந்தக்
கோப்பில் credentials இருக்கலாம் என்பதால் பகிர வேண்டாம்.

## உங்கள் தரவைப் படித்தல்

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

வெற்று பட்டியல் என்பது எந்த உருப்படியும் வடிகட்டியுடன் பொருந்தவில்லை என்றும்
பொருள். ஒவ்வொரு கட்டளையின் விருப்பங்களையும் உதவியில் காணவும்:

```sh
omi memory list --help
omi action-item list --help
```

## JSON பெறுதல் மற்றும் பக்கங்களைத் தாவல்

உலகளாவிய `--json` விருப்பத்தை கட்டளைக் குழுவிற்கு **முன்** வைக்கவும்:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

முதல் கட்டளை முதல் 25 நினைவுகளையும், இரண்டாம் கட்டளை அடுத்த 25 ஐயும் கேட்கிறது.
ஒரு பக்கம் முழு காப்புப்பிரதி அல்ல. JSON வெளியீடு முழு ID களை தக்க வைக்கிறது,
ஆனால் அட்டவணை காண்பிப்பதற்காக ID களை சுருக்கலாம்.

ஒரு பக்கத்தை கோப்பில் சேமிக்க:

```sh
omi --json memory list --limit 25 --offset 0 > memory-page-1.json
```

மறுவழிசெலுத்தல் உள்ளூர் கோப்பை உருவாக்குகிறது அல்லது மேலெழுதுகிறது. உள்ளடக்கத்தைப்
பயன்படுத்துவதற்கு முன் கட்டளை வெற்றிகரமாக முடிந்ததா என உறுதிப்படுத்தவும். பிழைகள்
stderr க்கு எழுதப்படுகின்றன; வெற்று கோப்பு தரவு இல்லை என நிரூபிக்காது. ஏற்றுமதி
கோப்பில் தனிப்பட்ட தகவல் இருக்கலாம் — தனிப்பட்டதாக வைத்திருங்கள்.

## சுயவிவரங்களைப் பயன்படுத்துதல்

நிலை `~/.omi/config.toml` இல் சேமிக்கப்படுகிறது (`$OMI_CONFIG` மூலம் மாற்றலாம்).
ஒவ்வொரு சுயவிவரமும் தனித்த அங்கீகார முறையும் API முகவரியும் கொண்டது. `--profile`
மூலம் மாற்றவும்:

```sh
omi config profile use வேலை
omi auth login
omi --profile தனிப்பட்ட memory list
```

பொதுவான கட்டமைப்புக் கட்டளைகள்:

```sh
omi config show
omi config path
omi config profile list
```

## வெளியேறு குறியீடுகள்

இந்த வெளியேறு குறியீடுகள் நிலையானவை; ஸ்கிரிப்ட்கள் அல்லது ஏஜெண்டுகளுக்கு
பயனுள்ளவை:

| குறியீடு | பொருள் | எடுத்துக்காட்டு சூழ்நிலை |
| ---: | --- | --- |
| 0 | வெற்றி | கட்டளை முடிந்தது |
| 1 | பயன்பாட்டுப் பிழை | தவறான flag, இல்லாத ஆர்கியூமெண்ட் அல்லது தோற்ற validation |
| 2 | அங்கீகாரப் பிழை | credentials இல்லை, token காலாவதி அல்லது அனுமதி போதாது |
| 3 | சர்வர் பிழை | சர்வர் 5xx அல்லது இணைப்பு தோல்வி |
| 4 | விகித வரம்பு | சர்வர் HTTP 429 திருப்பியது |
| 5 | கண்டறியப்படவில்லை | சர்வர் HTTP 404 திருப்பியது |

## வெளியேறுதல்

```sh
omi auth logout
```

உள்ளூரில் சேமித்த credentials ஐ நீக்குகிறது. சர்வரில் key ஐ திரும்பப் பெற,
உங்கள் கணக்கின் developer key நிர்வாகத்தைப் பயன்படுத்தவும்.

மேலும் கட்டளைகள் மற்றும் விருப்பங்களுக்கு [ஆங்கில முதன்மை README](../README.md)
பார்க்கவும், `omi --help` இயக்கவும்.
