# omi-cli बरे छोट गाइड

ई गाइड अवधी (Awadhi) मा `omi-cli` के सुरुआती कमांड के बारे मा बतावत बा। कमांड के नाँव अउर प्रोग्राम के संदेस अंग्रेजी मा ही रहिहैं। यहिमा दीख उदाहरण आपके याददाश्त (memories), बात-चीत (conversations), करे वाले काम (action items), या लच्छ (goals) मा कौनों बदलाव नाहीं करिहैं।

## प्रोग्राम इनस्टॉल करब (Installation)

जरूरी चीजन: Python 3.10 या नवा वर्जन अउर एक Omi खाता।

अगर आपके पास `pipx` इनस्टॉल बा:

```sh
pipx install omi-cli
omi --help
```

आप यहिका एक चालू Python वर्चुअल एनवायरनमेंट (virtual environment) मा भी इनस्टॉल कइ सकित हो:

```sh
python -m pip install omi-cli
omi --help
```

अगर टर्मिनल मा `omi` कमांड नाहीं मिलत, तौ जाँच लव कि वर्चुअल एनवायरनमेंट चालू बा या `pipx` वाला रस्ता आपके `$PATH` मा शामिल बा।

## आपन खाता जोड़ब (Authentication)

बातचीत वाला सहायक सुरू करा:

```sh
omi auth login
```

ब्राउजर से लॉगिन करब या आपन Omi developer API key पेस्ट करब चुनव। सहायक इनपुट चाबी का छिपाइ देई; टर्मिनल इतिहास मा रहे वाले कौनों कमांड मा चाबी जिन लिखव।

सीधे ब्राउजर पर जाय बरे:

```sh
omi auth login --browser
```

वही कंप्यूटर पर लॉगिन करा जेहिमा टर्मिनल चलत बा: पुष्टि वाला जबाब लोकल पता इस्तेमाल करत है। स्क्रीन पर दीख हिदायत के पालन करा।

ओकरे बाद, सेटिंग्स अउर API पहुँच के जाँच करा:

```sh
omi auth status
omi auth whoami
```

`status` लोकल हाल देखावत बा अउर भेद का छिपावत बा, बाकी सर्वर पर ओकरे चालू होय के जाँच नाहीं करत। `whoami` एक जाँचल बिनती भेजत है; अगर सब ठीक रहा, तौ नाँव देखाय बिना बतावत है कि क्रेडेंशियल काम करत हैं।

सेटिंग्स आमतौर पर `~/.omi/config.toml` मा सँझोई जात हैं। ई फाइल केहू से साझा जिन करव: यहिमा गुप्त क्रेडेंशियल होइ सकत हैं।

## आपन डेटा देखब (Inspection)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

खाली सूची के मतलब बस ई होइ सकत है कि खोज से मिलत-जुलत कछु नाहीं मिला। हर कमांड मा फ़िल्टर खोजय बरे मदद के इस्तेमाल करा:

```sh
omi memory list --help
omi action-item list --help
```

## JSON लेब अउर पन्ना पलटब (Pagination)

कमांड समूह से **पहिले** पूरा सिस्टम वाला `--json` विकल्प लगावा:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

पहिला कमांड पहिला 25 याद मँगिहै; दूसर कमांड अगिला 25 याद मँगिहै। एक पन्ना पूरा बैकअप नाहीं होत। JSON आउटपुट पूरा पहचान सुरक्षित रखत है, जबकि स्क्रीन पर तालिका ओका छोट कइ सकत है।

एक पन्ना फाइल मा सहेजय बरे:

```sh
omi --json memory list --limit 25 --offset 0 > याद-पन्ना-1.json
```

ई तरीका लोकल फाइल बनावत है या बदलत है। अंदर के माल इस्तेमाल करे से पहिले देख लव कि कमांड ठीक से पूर भवा कि नाहीं। खराबी एरर आउटपुट (stderr) मा लिखी जात है; खाली फाइल के मतलब ई नाहीं कि डेटा नाहीं बा। निकारल फाइल मा व्यक्तिगत जानकारी होइ सकत है: एकर जतन करा।

## खाता से बाहर निकलब (Logout)

```sh
omi auth logout
```

ई कमांड लोकल रूप से सँझोये क्रेडेंशियल हटावत है। सर्वर से चाबी रद्द करे बरे, आपन खाता मा developer key प्रबंधन के उपयोग करा।

अउर कमांड अउर जादा विकल्प बरे, [अंग्रेजी के मुख्य गाइड](../README.md) अउर `omi --help` देखा।
