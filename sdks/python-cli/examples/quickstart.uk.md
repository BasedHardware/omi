# Швидкий старт із omi-cli

Цей посібник пояснює базові команди українською. Назви команд і повідомлення
програми лишаються англійською. Приклади команд нижче не змінюють ваші спогади,
розмови, елементи дій чи цілі.

## Встановлення програми

Вимоги: Python 3.10 або новіший та обліковий запис Omi.

Якщо `pipx` уже встановлено:

```sh
pipx install omi-cli
omi --help
```

Або встановіть програму в активоване віртуальне середовище Python:

```sh
python -m pip install omi-cli
omi --help
```

Якщо термінал не знаходить `omi`, переконайтеся, що віртуальне середовище
активне, або що каталог, куди `pipx` встановлює виконувані файли, додано до
`PATH`.

## Підключення облікового запису

Запустіть інтерактивний посібник:

```sh
omi auth login
```

Оберіть вхід через браузер або вставте ключ API розробника Omi. Інтерактивне
введення приховує ключ; не вписуйте його в команди, що зберігаються в історії
термінала.

Щоб одразу використати браузер:

```sh
omi auth login --browser
```

Виконуйте вхід на тому ж комп'ютері, що й термінал, бо результат автентифікації
проходить через локальну callback-адресу. Дотримуйтесь інструкцій на екрані.

Після входу перевірте конфігурацію та доступ до API:

```sh
omi auth status
omi auth whoami
```

`status` показує локальний стан і маскує секрети, але не перевіряє їхню
дійсність на сервері. `whoami` виконує автентифікований запит; якщо він
успішний, ваші облікові дані працюють — без показу вашого імені.

Конфігурація за замовчуванням зберігається у `~/.omi/config.toml`. Не діліться
цим файлом — він може містити облікові дані.

## Читання ваших даних

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Порожній список може означати, що жоден елемент не відповідає фільтру. Опції
кожної команди дивіться у довідці:

```sh
omi memory list --help
omi action-item list --help
```

## Отримання JSON і перегляд сторінок

Глобальну опцію `--json` ставте **перед** групою команд:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Перша команда запитує перші 25 спогадів, друга — наступні 25. Одна сторінка —
це не повна резервна копія. Вивід JSON зберігає повні ідентифікатори, тоді як
таблиця може скорочувати їх для відображення.

Щоб зберегти сторінку у файл:

```sh
omi --json memory list --limit 25 --offset 0 > memory-storinka-1.json
```

Перенаправлення створює або перезаписує локальний файл. Перш ніж користуватися
вмістом, переконайтеся, що команда завершилася успішно. Помилки виводяться у
stderr; порожній файл не доводить відсутність даних. Експортований файл може
містити особисту інформацію — зберігайте його приватно.

## Використання профілів

Стан зберігається у `~/.omi/config.toml` (можна змінити через `$OMI_CONFIG`).
Кожен профіль має власний метод автентифікації та адресу API. Перемикання
профілів — через `--profile`:

```sh
omi config profile use робота
omi auth login
omi --profile особистий memory list
```

Типові команди конфігурації:

```sh
omi config show
omi config path
omi config profile list
```

## Коди виходу

Ці коди виходу стабільні й корисні для скриптів та агентів:

| Код | Значення | Приклад ситуації |
| ---: | --- | --- |
| 0 | успіх | Команду виконано |
| 1 | помилка використання | Неправильний прапорець, брак аргументу або невдала валідація |
| 2 | помилка автентифікації | Немає облікових даних, токен прострочено або бракує дозволів |
| 3 | помилка сервера | Сервер 5xx або збій з'єднання |
| 4 | обмеження частоти | Сервер повернув HTTP 429 |
| 5 | не знайдено | Сервер повернув HTTP 404 |

## Вихід з облікового запису

```sh
omi auth logout
```

Видаляє локально збережені облікові дані. Щоб відкликати ключ на сервері,
скористайтеся керуванням ключами розробника у своєму обліковому записі.

Інші команди й опції — в [англомовному головному README](../README.md) та після
запуску `omi --help`.
