# omi-cli хӀалтӀизе байбихьи

Гьаб нухда-хӀал баян гьабула omi-cli-лъул тӀоцӀебесеб командал магӀарул мацӀалда. Командал цӀарал ва программалъул рагӀал инглис мацӀалда кьола. Кваранисел мисалал дидасул memories, conversations, action items яги goals хисулеб гьечӀо.

## ТӀибитӀи

Дур кварилъи: Python 3.10 яги цӀияб версия, ва Omi аккаунт.

pipx тӀибитӀун бугебу:

```sh
pipx install omi-cli
omi --help
```

Яги активирован гьабунеб Python виртуалияб мохъалда:

```sh
python -m pip install omi-cli
omi --help
```

Балагье: `omi` команда тӀоцӀебесеб рекъон PATH-алда гъвечӀого кьезе бефс — балагье, виртуалияб мохъ активирован букӀунеб яги pipx-лъул папка `$PATH`-алда бугеб.

## БачӀи

ТӀоцӀе коде бачӀине:

```sh
omi auth login
```

Браузералда яги Omi developer API ключаца бачӀунебу. Ключ борхатабизе — терминал-лъул историялде тӀолеб гьечӀо.

Гьаб компьютер алда браузераца бачӀизе:

```sh
omi auth login --browser
```

Терминал цогидал гьечӀеб машинабал: авторизация локалияб адресалда гьабула. Экраналда бихьулел нухмалъулал кӀодо гьабе.

ГӀанчӀияб конфигурация ва API ключ балагье:

```sh
omi auth status
omi auth whoami
```

`status` локалияб хабар бихьизабула, секретал боболе, сервер-щалъе ахӀе гьечӀо. `whoami` аутентификация гьабунеб къотӀи тола; гьелъул кьо гьабулебу, гьелъул магӀна: дудасул credentials хъвалъухӀалъухӀ.

Конфигурация `~/.omi/config.toml`-алда хӀалкъола. Гьаб файл куцалда хисуле гьечӀе — кӀучалъул секретал гьелда буго.

## Memories ва conversations балагьи

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Список гъвечӀо букӀунебу — гьелъул магӀна: щибго гьечӀо. Амма командалъул фильтрал балагьизе:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ва экспортал

Глобалияб `--json` опция команда группаязул ЦОХӀОБА букӀунеб бекен:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ТӀоцӀебесеб команда тӀоцӀебесеб 25 memories тола; кӀицӀебесеб команда кӀудияб 25 тола. JSON бахъсалда тӀубазеб идентификаторал буго, амма таблицаялда кӀижого кьола.

Файлалде хӀалкъизе:

```sh
omi --json memory list --limit 25 --offset 0 > memories-гьумер-1.json
```

Redirect цӀияб локалияб файл гьабула яги цӀика кьола. ТӀоцӀе командалъул бахъс балагье. ХатӀалал stderr-алде тола; гъвечӀо файл — данные гьечӀо магӀна гьечӀо. Экспорт файлабазда лъималияб информация кьезе бефс — рахъалъуцӀидае балагье.

## Бахъи

```sh
omi auth logout
```

Гьаб команда локалиял credentials гьоркье. Сервер бокьарал создатунеб ключал developer key management-алда буго.

ХӀисабалъул: [инглис документал](../README.md) ва `omi --help`.
