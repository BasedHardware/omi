# omi-cli خٲطرٕ تؠز رَہنُمٲیی

یہِ رَہنُمٲیی چھِ کٲشُر زَبانِ (Kashmiri) مَنٛز `omi-cli` کین گۄڈنِکین کَمانٛڈَن ہٕنٛز وَضاحَت کَران۔ کَمانٛڈ ناو تہٕ پروگرام پٲغام چھِ اَنٛگریٖزی مَنٛز روزان۔ ییٚتہِ دِیتمُت مُعاینہٕ نَمونہٕ چھِ نہٕ تُہٕنٛدیٚن یادَن (memories)، کَتھ باتھ (conversations)، کٲم کین نُکتَن (action items)، یا مَقاصَدَن (goals) مَنٛز کانہہ تَبدیٖلی اَنَن۔

## پروگرام تَصدیٖق تہٕ اِنسٹال کَرُن (Installation)

ضَرورِی چیٖز: Python 3.10 یا نٔو تَرین وَرجَن تہٕ اَکھ Omi کھاتہٕ۔

اَگَر تُہَنٛدِس سِسٹَمَس مَنٛز `pipx` چھُ:

```sh
pipx install omi-cli
omi --help
```

تۄہہِ ہؠکِو یہِ اَکِس چالو Python وِرچُوَل ماحَولَس (virtual environment) مَنٛز تہِ اِنسٹال کٔرِتھ:

```sh
python -m pip install omi-cli
omi --help
```

اَگَر ٹَرمنَلَس مَنٛز `omi` کَمانٛڈ نہٕ لَبہٕ، تیٚلہِ کٔرِو یٔقیٖنی زِ وِرچُوَل ماحَول چھُ چالو یا `pipx` پاتھ چھُ تُہٕنٛدِس `$PATH` مَنٛز شامِل۔

## پَنُن کھاتہٕ جوڈُن (Authentication)

باہَم گُفتَگو مَدَتھ گار شروٗع کٔرِو:

```sh
omi auth login
```

براؤزَر ذٔریعہٕ لاگ اِن کَرُن یا پَنُن Omi developer API key درج کَرُن مُنتَخَب کٔرِو۔ اِنٹراؠکٹِو اِنپُٹ چھُ راز کُنٛجی ژھپان؛ ٹَرمنَل توٲریٖخَس مَنٛز روزَن والیٚن کَمانٛڈَن مَنٛز یہِ مَ کٔرِو تَحریٖر۔

براؤزَرَس کُن سِیٖدھے گژھنہٕ خٲطرٕ:

```sh
omi auth login --browser
```

تَتھِی کَمپیوٗٹَرَس پؠٹھ لاگ اِن کٔرِو یَتھ پؠٹھ ٹَرمنَل چھُ چالان: تَصدیٖقی جَواب چھُ مُقامی پَتے اِستِعمال کَران۔ سکرینَس پؠٹھ دِتمٕژ ہِدایاتَن پؠٹھ عَمَل کٔرِو۔

تَمہِ پَتہٕ کٔرِو تَرتِیٖب تہٕ API پَہَنچٕچ تَصدیٖق:

```sh
omi auth status
omi auth whoami
```

`status` چھُ مُقامی حٲلَتھ ہاوَن تہٕ راز ژھپان، مگر سَرور پؠٹھ کٲم کَرنٕچ تَصدیٖق چھُ نہٕ کَران۔ `whoami` چھُ اَکھ تَصدیٖق شُدہ گُزارِش سوزان؛ اَگَر کامِیاب سَپُد، تیٚلہِ چھُ پَنُن ناو ہاونہٕ وَرٲے ثَبوت فَرَہَم کَران زِ کواَف چھِ کٲم کَران۔

تَرتِیٖب چھِ عام طور پٲٹھۍ `~/.omi/config.toml` مَنٛز مَحفوٗظ روزان۔ یہِ فایِل مَ کٔرِو کانٛہہ تہِ باٹِتھ: یَتھ مَنٛز ہؠکَن خُفیَہ کواَف ٲسِتھ۔

## پَنٕنؠ دَیٹا چانٛچ کَرٕنؠ (Inspection)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

خٲلی فِہرِستُک مَطلَب چھُ صِرَف یہِ زِ تَلاشَس مُطابِق کانہہ چیٖز مَوجوٗد چھُ نہٕ۔ پَریتھ کَمانٛڈَس مَنٛز فِلٹَر ژھانٛڈنہٕ خٲطرٕ مَدَتھ اِستِعمال کٔرِو:

```sh
omi memory list --help
omi action-item list --help
```

## JSON حٲصِل کَرُن تہٕ صَفہٕ بَندی (Pagination)

عالَمی اِنتِخاب `--json` کٔرِو کَمانٛڈ گُرۆپَس **بٔروٛنٛہہ** دَرٕج:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

گۄڈنیُک کَمانٛڈ چھُ گۄڈنِک 25 یاد مانٛگان؛ دوٚیِم کَمانٛڈ چھُ پتہٕ کِہ 25 یاد مانٛگان۔ اَکھ صَفہٕ چھُنہٕ پوٗرٕ بؠک اَپ۔ JSON پیٚداوار چھُ تَمام شَناخَتھ دار مَحفوٗظ تھاوان، حالانٛکہِ سکرین ٹیبٕل ہؠکَن نُمٲیِش خٲطرٕ یِم لۄکٕٹ کٔرِتھ۔

صَفہٕ فایِلَس مَنٛز مَحفوٗظ تھاونہٕ خٲطرٕ:

```sh
omi --json memory list --limit 25 --offset 0 > یاد-صفحہ-1.json
```

یہِ رُخ بَدلاو چھُ مُقامی فایِل بَناوان یا بَدلاوان۔ مَواد اِستِعمال کَرنہٕ بٔروٛنٛہہ کٔرِو یٔقیٖنی زِ کَمانٛڈ گوٚو کامِیابِی سان مُکَمَل۔ نَقائِص چھِ خَطا پؠداوارَس (stderr) مَنٛز دَرٕج گَژھان؛ خٲلی فایِلُک مَطلَب چھُ نہٕ زِ دَیٹا چھُ نہٕ۔ بَرآمَد کٔرمٕژ فایِل مَنٛز ہؠکَن ذٲتی مَعلُومات ٲسِتھ: اَتھ تھاوِو مَحفوٗظ۔

## کھاتہٕ پؠٹھٕ نؠبَر نیرُن (Logout)

```sh
omi auth logout
```

یہِ کَمانٛڈ چھُ مُقامی طور پٲٹھۍ مَحفوٗظ کٔرمٕتۍ کواَف ہَٹاوَن۔ سَرور پؠٹھ کُنٛجی رَد کَرنہٕ خٲطرٕ، پَنٕنِس کھاتَس مَنٛز developer key اِنتِظام اِستِعمال کٔرِو۔

باقی کَمانٛڈَن تہٕ مَزیٖد اِنتِخاباتَن خٲطرٕ وُچھِو [اَنٛگریٖزی ہٕنٛز بَڈی رَہنُمٲیی](../README.md) تہٕ `omi --help`۔
