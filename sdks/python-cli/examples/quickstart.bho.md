# omi-cli खातिर त्वरित गाइड

ई गाइड भोजपुरी (Bhojpuri) में `omi-cli` के सुरुआती कमांड के बारे में समझावत बा। कमांड के नाम आ प्रोग्राम के संदेश अंग्रेजी में ही रही। एह में दिहल गइल जांच के उदाहरण रउवा याद (memories), बातचीत (conversations), काम के बात (action items), चाहे लक्ष्य (goals) में कवनो बदलाव ना करी।

## प्रोग्राम इंस्टॉल कइल

जरूरी शर्त: Python 3.10 चाहे ओकरा से नया वर्जन आ एगो Omi खाता।

अगर रउवा लगे `pipx` इंस्टॉल बा:

```sh
pipx install omi-cli
omi --help
```

रउवा एकरा के एगो एक्टिव Python वर्चुअल एनवायरनमेंट (virtual environment) में भी इंस्टॉल कर सकत बानी:

```sh
python -m pip install omi-cli
omi --help
```

अगर टर्मिनल में `omi` कमांड ना मिले, त जांच लीं कि वर्चुअल एनवायरनमेंट एक्टिव बा कि ना चाहे `pipx` के पाथ रउवा `$PATH` में बा कि ना।

## आपन खाता जोड़ल (Authentication)

इंटरैक्टिव सहायक सुरू करीं:

```sh
omi auth login
```

ब्राउजर के माध्यम से लॉगिन करीं चाहे आपन Omi developer API key पेस्ट करीं। इंटरैक्टिव इनपुट में की (key) छिपाल रही; टर्मिनल के इतिहास में दर्ज होखे वाला कवनो कमांड में की मत लिखीं।

सीधे ब्राउजर पर जाए खातिर:

```sh
omi auth login --browser
```

ओही कंप्यूटर पर लॉगिन करीं जवना पर टर्मिनल चलत बा: ऑथेंटिकेशन प्रतिक्रिया लोकल पता के इस्तेमाल करेला। स्क्रीन पर दिहल निर्देश के पालन करीं।

ओकरा बाद, कॉन्फ़िगरेशन आ API पहुंच के जांच करीं:

```sh
omi auth status
omi auth whoami
```

`status` लोकल स्थिति देखावेला आ सीक्रेट के छुपावेला, बाकी सर्वर पर ओकर मान्यता के जांच ना करेला। `whoami` एगो प्रमाणित अनुरोध भेजेला; अगर सफल भइल, त रउवा नाम देखवले बिना पुष्टि करेला कि क्रेडेंशियल काम कर रहल बा।

कॉन्फ़िगरेशन आमतौर पर `~/.omi/config.toml` में सुरक्षित कइल जाला। एह फाइल के कवनो दूसरा से साझा मत करीं: एह में रउवा गुप्त क्रेडेंशियल हो सकत बा।

## आपन डेटा जांचल (Inspection)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

खाली लिस्ट के मतलब ई हो सकत बा कि खोज से मेल खात कवनो डेटा नइखे। हर कमांड में फ़िल्टर खोजे खातिर मदद के इस्तेमाल करीं:

```sh
omi memory list --help
omi action-item list --help
```

## JSON प्राप्त कइल आ पन्ना पलटल (Pagination)

कमांड ग्रुप से **पहिले** ग्लोबल `--json` विकल्प लगाईं:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

पहिला कमांड पहिला 25 याद मांगी; दूसरा कमांड अगिला 25 याद मांगी। एगो पन्ना पूरा बैकअप ना हवे। JSON आउटपुट पूरा पहचानकर्ता (IDs) के सुरक्षित राखेला, जबकि स्क्रीन पर टेबल प्रदर्शन खातिर एकरा के छोट कर सकत बा।

एगो पन्ना के फाइल में सहेजे खातिर:

```sh
omi --json memory list --limit 25 --offset 0 > याद-पन्ना-1.json
```

ई पुनर्निर्देशन लोकल फाइल बनाई चाहे बदल दी। सामग्री के इस्तेमाल करे से पहिले देख लीं कि कमांड सफल भइल कि ना। त्रुटि सभ एरर आउटपुट (stderr) में लिखल जाला; खाली फाइल के मतलब डेटा के अनुपस्थिति ना हवे। एक्सपोर्ट कइल फाइल में व्यक्तिगत जानकारी हो सकत बा: एकरा के सुरक्षित राखीं।

## खाता से बाहर निकलल (Logout)

```sh
omi auth logout
```

ई कमांड लोकल रूप से सुरक्षित क्रेडेंशियल के हटा देला। सर्वर से की (key) के रद्द करे खातिर, आपन खाता में developer key प्रबंधन के इस्तेमाल करीं।

अउरी कमांड आ अतिरिक्त विकल्प खातिर, [अंग्रेजी के मुख्य गाइड](../README.md) आ `omi --help` देखीं।
