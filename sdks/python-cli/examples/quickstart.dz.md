# omi-cli གི་འགོ་ཐོག་ལམ་སྟོན།

ལམ་སྟོན་འདི་གིས་ རྫོང་ཁའི་ཐོག་ལས་ omi-cli གི་འགོ་ཐོག་བཀོད་རྒྱ་ཚུ་གསལ་བཤད་འབདཝ་ཨིན། བཀོད་རྒྱའི་མིང་དང་ ལས་རིམ་གྱི་འཕྲིན་དོན་ཚུ་ དབྱིན་སྐད་ནང་རང་ འཇོག་དགོ། འདི་ནང་བཀོད་མི་ དཔེར་བརྗོད་ཚུ་གིས་ ཁྱོད་རའི་དྲན་ཤེས་ (memories) གསུང་གྲོས་ (conversations) ལས་དོན་ (action items) དང་ དམིགས་ཡུལ་ (goals) ཚུ་ལུ་ འགྱུར་བཅོས་ག་ནི་ཡང་མི་བཟོ།

## ལས་རིམ་གཞི་བཙུགས་འབད་ནི།

དགོས་མཁོ་ཚུ: Python 3.10 ཡང་ན་ དེ་ལས་གསར་ཤོས་དང་ Omi རྩིས་ཁྲ་ཅིག

ཁྱོད་ལུ་ `pipx` གཞི་བཙུགས་ཡོད་པ་ཅིན:

```sh
pipx install omi-cli
omi --help
```

ཡང་ན་ Python གྱི་ virtual environment ནང་ལུ་ཡང་ གཞི་བཙུགས་འབད་ཚུགས:

```sh
python -m pip install omi-cli
omi --help
```

གལ་སྲིད་ ཊར་མི་ནཱལ་ (terminal) གིས་ `omi` མ་ཐོབ་པ་ཅིན་ virtual environment དེ་ ལཱ་འབད་བའི་བསྒང་ཡོདཔ་ཨིནམ་ ཡང་ན་ `pipx` གཞི་བཙུགས་འབད་སའི་ སྣོད་ཐོ་དེ་ ཁྱོད་རའི་ `$PATH` ནང་ཡོདཔ་ཨིནམ་ གཏན་གཏན་བཟོ།

## ཁྱོད་རའི་རྩིས་ཁྲ་མཐུད་ནི།

འབྲེལ་མཐུད་རམ་འདེགས་པ་ འགོ་བཙུགས:

```sh
omi auth login
```

བརྡ་འཚོལ་པ་ (browser) ཐོག་ལས་ ནང་བསྐྱོད་འབད་ནི་ ཡང་ན་ Omi developer API key སྦྱར་ནིའི་གདམ་ཁ་རྐྱབས། ལྡེ་མིག་དེ་ ཊར་མི་ནཱལ་གྱི་ ལོ་རྒྱུས་ནང་མ་ལུས་པར་ གསང་བའི་ཐོག་ལས་ བཙུགས་དགོ།

བརྡ་འཚོལ་པ་ནང་ ཐད་ཀར་དུ་འགྱོ་ནིའི་དོན་ལུ:

```sh
omi auth login --browser
```

ཊར་མི་ནཱལ་ ལག་ལེན་འཐབ་སའི་ གློག་རིག་གཅིག་པའི་ནང་ ནང་བསྐྱོད་འབད། དེ་ལས་ API འཐོབ་ཚུགས་པའི་ བདེན་སྦྱོར་འབད:

```sh
omi auth status
omi auth whoami
```

`status` གིས་ ཉེ་གནས་ཀྱི་གནས་སྟངས་སྟོནམ་ཨིན་རུང་ སར་བར་གྱི་ ནུས་ལྡན་བདེན་སྦྱོར་མི་འབད། `whoami` གིས་ བདེན་སྦྱོར་འབད་ཡོད་པའི་ ཞུ་བ་ཅིག་བཏངམ་ཨིན།

སྒྲིག་བཀོད་དེ་ རང་བཞིན་གྱིས་ `~/.omi/config.toml` ནང་ བསྲུང་བཞག་འབདཝ་ཨིན། ཡིག་སྣོད་འདི་ གཞན་ལུ་མ་བགོ་བཤའ་རྐྱབས།

## ཁྱོད་རའི་གནས་སྡུད་བལྟ་ནི།

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ཐོ་ཡིག་སྟོངམ་ཐོན་པ་ཅིན་ དེ་གིས་ཁྱོད་ལུ་ གནས་སྡུད་དེ་མེདཔ་ཨིནམ་ སྟོནམ་ཨིན། གྲོགས་རམ་ལག་ལེན་འཐབ་སྟེ་ ཚག་མ་ཚུ་བལྟ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ལེན་ནི་དང་ ཤོག་གྲངས་བརྡ་འཚོལ། (Pagination)

སྤྱི་ཁྱབ་གདམ་ཁ་ `--json` དེ་ བཀོད་རྒྱའི་སྡེ་ཚན་གྱི་ **ཧེ་མ་** བཙུགས:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

བཀོད་རྒྱ་དང་པ་གིས་ འགོ་ཐོག་དྲན་ཤེས་ ༢༥ ཞུ་བ་འབདཝ་ཨིནམ་དང་ གཉིས་པ་གིས་ ཤུལ་མའི་ ༢༥ ཞུ་བ་འབདཝ་ཨིན།

ཤོག་གྲངས་དེ་ ཡིག་སྣོད་ཅིག་ནང་ བསྲུང་བཞག་འབད་ནིའི་དོན་ལུ:

```sh
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
```

ཕྱིར་འདྲེན་འབད་ཡོད་པའི་ ཡིག་སྣོད་ནང་ རང་དོན་གྱི་གནས་སྡུད་ཡོདཔ་ལས་ གསང་བ་སྦེ་བཞག

## རྩིས་ཁྲ་ཕྱིར་ཐོན་འབད་ནི།

```sh
omi auth logout
```

བཀོད་རྒྱ་འདི་གིས་ ཉེ་གནས་ནང་ བསྲུང་བཞག་ཡོད་པའི་ ལག་ཁྱེར་ཚུ་ བཏོན་གཏངམ་ཨིན། སར་བར་ལས་ ལྡེ་མིག་ཆ་མེད་གཏང་ནིའི་དོན་ལུ་ developer settings ལག་ལེན་འཐབ།

ཁ་གསལ་གྱི་དོན་ལུ་ [དབྱིན་སྐད་ལམ་སྟོན་གཙོ་བོ](../README.md) དང་ `omi --help` ལུ་བལྟ།
