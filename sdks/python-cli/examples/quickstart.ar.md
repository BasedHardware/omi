# الخطوات الأولى مع omi-cli

يشرح هذا الدليل الأوامر الأولى باللغة العربية. تظل أسماء الأوامر ورسائل
البرنامج باللغة الإنجليزية. أمثلة الاستعلام الموضحة هنا لا تعدل ذكرياتك أو
محادثاتك أو مهامك أو أهدافك.

## تثبيت البرنامج

المتطلبات: Python 3.10 أو إصدار أحدث وحساب Omi.

إذا كان لديك `pipx` مثبتًا:

```sh
pipx install omi-cli
omi --help
```

بدلاً من ذلك، يمكنك تثبيته داخل بيئة بايثون افتراضية مفعلة (virtual environment):

```sh
python -m pip install omi-cli
omi --help
```

إذا لم يعثر الطرفية على أمر `omi`، فتأكد من تفعيل البيئة الافتراضية أو أن
المسار الذي يثبت فيه `pipx` الملفات التنفيذية موجود في متغير `PATH` الخاص بك.

## ربط حسابك

ابدأ المساعد التفاعلي:

```sh
omi auth login
```

اختر تسجيل الدخول عبر المتصفح أو خيار لصق مفتاح API للمطورين من Omi.
يخفي الإدخال التفاعلي المفتاح؛ تجنب كتابته في أمر يبقى في سجل الطرفية.

للانتقال مباشرة إلى المتصفح:

```sh
omi auth login --browser
```

سجل الدخول على نفس الكمبيوتر الذي تعمل عليه الطرفية: تستخدم استجابة المصادقة
عنوانًا محليًا. اتبع التعليمات التي تظهر على الشاشة.

بعد ذلك، تحقق من التكوين والوصول إلى API:

```sh
omi auth status
omi auth whoami
```

يعرض `status` الحالة المحلية ويخفي السر، لكنه لا يتحقق من الصلاحية على الخادم.
يقوم `whoami` بإجراء طلب مصادق عليه؛ وإذا نجح، فإنه يؤكد عمل بيانات الاعتماد دون الحاجة لعرض اسمك.

يتم حفظ التكوين افتراضيًا في `~/.omi/config.toml`. لا تشارك هذا الملف مع الآخرين:
فقد يحتوي على بيانات اعتمادك السرية.

## عرض بياناتك

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

قد تعني القائمة الفارغة ببساطة عدم وجود عناصر تطابق الاستعلام. استخدم المساعدة لاكتشاف مرشحات كل أمر:

```sh
omi memory list --help
omi action-item list --help
```

## الحصول على مخرجات JSON والتنقل بين الصفحات

ضع الخيار العام `--json` **قبل** مجموعة الأوامر:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

يطلب الأمر الأول أول 25 ذكرى؛ والأمر الثاني يطلب الـ 25 التالية. وبالتالي فإن
الصفحة الواحدة لا تمثل نسخة احتياطية كاملة. تحتفظ مخرجات JSON بالمعرفات الكاملة، بينما قد تختصرها الجداول على الشاشة.

لحفظ صفحة في ملف:

```sh
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
```

تؤدي إعادة التوجيه هذه إلى إنشاء الملف المحلي أو استبداله. تأكد من اكتمال الأمر بنجاح قبل استخدام محتواه.
تكتب الأخطاء في مخرجات الأخطاء (stderr)؛ الملف الفارغ لا يضمن عدم وجود بيانات. قد يحتوي الملف المصدر على معلومات شخصية: حافظ على خصوصيته.

## تسجيل الخروج (Logout)

```sh
omi auth logout
```

يحذف هذا الأمر بيانات الاعتماد المحفوظة محليًا. لإلغاء مفتاح على الخادم، استخدم إدارة مفاتيح المطورين في حسابك.

للاطلاع على باقي الأوامر والخيارات المتقدمة، راجع [الدليل الرئيسي باللغة الإنجليزية](../README.md) و `omi --help`.
