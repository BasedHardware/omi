# Example Recipes for the OMI Python CLI

This directory contains small, self‑contained scripts that demonstrate how to
use the OMI Python SDK for common data‑preparation tasks. Each script can be
run directly from the command line.

## Available recipes

- **`conversations_to_jsonl.py`** – Convert plain‑text conversation transcripts
  into JSONL format suitable for LLM fine‑tuning or RAG.
