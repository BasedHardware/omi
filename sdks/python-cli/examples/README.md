# OMI Python CLI Examples

यह डायरेक्टरी `omi-cli` के साथ उपयोग करने योग्य विभिन्न उदाहरण स्क्रिप्ट्स और गाइड्स रखती है।

## उपलब्ध गाइड्स

- **English**: [agent_quickstart.md](agent_quickstart.md)
- **Spanish**: [agent_quickstart.es.md](agent_quickstart.es.md)
- **French**: [agent_quickstart.fr.md](agent_quickstart.fr.md)
- **Dogri (doi)**: [agent_quickstart.doi.md](agent_quickstart.doi.md) ← नया जोड़ दिया गया

## उपयोग

प्रत्येक फ़ाइल में समान संरचना है:
1. परिचय और पूर्वापेक्षाएँ
2. प्रोजेक्ट सेट‑अप
3. एजेंट कोड
4. चलाने के निर्देश
5. आगे की कस्टमाइज़ेशन

उपरोक्त किसी भी गाइड को पढ़ें और अपने स्थानीय वातावरण में चरण‑दर‑चरण पालन करें।
