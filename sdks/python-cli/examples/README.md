### Contribuir

1. Clone el repositorio:
   ```bash
   git clone https://github.com/BasedHardware/omi.git
   ```

2. Navegue al directorio de ejemplos:
   ```bash
   cd sdks/python-cli/examples
   ```

3. Ejecute ejemplos locales:
   ```bash
   python3 -m pip install -e ..
   ```
