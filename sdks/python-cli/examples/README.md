# Example Recipes for the OMI Python CLI

This directory contains small, self‑contained scripts that demonstrate how to
use the OMI Python SDK in real‑world scenarios.  Each script can be executed
directly from the command line and is accompanied by a short markdown
description.

## Available recipes

| Script | Description |
|--------|-------------|
| `memories_to_obsidian.py` | Convert a JSON export of OMI memories into Obsidian‑compatible markdown files with front‑matter and wikilinks. |
| `...` | *(other examples may be listed here)* |
