# Python‑CLI Example Recipes

This directory contains small, self‑contained scripts that demonstrate how to
leverage the OMI Python SDK for everyday automation tasks.  Each example is
intended to be runnable from the command line without any additional setup.

## Available recipes

- **action_items_to_todoist** – Convert a list of action items into a Todoist
  REST API payload with proper priority mapping.
  See the accompanying
  [action_items_todoist.md](action_items_todoist.md) for usage details.

*Add new examples here as they become available.*
