# Python CLI — Examples

This directory contains standalone Python scripts that demonstrate common
workflows with the Omi CLI. Each recipe lives in a `.py` file accompanied by
a `.md` guide.

## Contributing a recipe

1. Add `your_recipe.py` and `your_recipe.md` to this directory.
2. Add a single row to the **Recipes** table above.
3. Open a PR with the prefix `docs(cli):` — e.g. `docs(cli): add your_recipe export`.
