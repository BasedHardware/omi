# OMI Python CLI - Examples

Hapa chini ni orodha ya mifano ya matumizi ya **omi-cli** katika lugha mbalimbali. Kila faili lina mwongozo wa hatua kwa hatua wa jinsi ya kuanzisha na kutumia agizo, wakala, au skripti maalum.

- [English Quickstart – Agent-driven workflows](agent_quickstart.md)
- [Swahili (sw) Quickstart – Agent-driven workflows](agent_quickstart.sw.md)
- [Python SDK Usage Example](python_sdk_example.md)
- [Streaming Completion Example](streaming_completion.md)

## Jinsi ya Kutumia

1. **Chagua lugha** unayotaka (angalia orodha hapo juu).
2. **Fuatilia maelekezo** ndani ya faili husika. Bloki za msimbo hazibadilishi, hivyo unaweza kunakili moja kwa moja kwenye terminal yako.
3. **Fanya majaribio** kwa kuendesha `omi-cli` kulingana na maelekezo yaliyotolewa.

Kama una maswali au unahitaji msaada zaidi, tembelea [Nyaraka Rasmi za OMI](https://github.com/basedhardware/omi/tree/main/sdks/python-cli) au fungua **issue** kwenye GitHub.
