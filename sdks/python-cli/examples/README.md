# Omi CLI Examples

This directory contains example recipes and scripts for working with the Omi CLI.

## Export Recipes

### Conversations to Excel
- **File**: `conversations_xlsx.md`
- **Description**: Convert conversation exports to Excel workbooks
- **Features**: Native datetime cells, AutoFilter, frozen headers

### Action Items to Excel
- **File**: `action_items_xlsx.md`
- **Description**: Convert action-item and task exports to Excel workbooks
- **Features**: Real datetime cells, native boolean status, formula-safe strings, AutoFilter, frozen headers

### CSV Exports
- **File**: `csv_exports.md`
- **Description**: Basic CSV export recipes for various data types
- **Features**: Simple comma-separated value exports

## Data Processing Scripts

### Custom Transformers
- **Directory**: `transformers/`
- **Description**: Custom data processing and transformation utilities
- **Contents**: Python scripts for data manipulation
