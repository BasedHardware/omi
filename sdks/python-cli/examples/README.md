# أمثلة على استخدام omi-cli

في هذا الدليل ستجد أمثلة عملية لكيفية استخدام أداة `omi-cli` لإنشاء وتشغيل الوكلاء (agents) وإدارة سير العمل.

- [البدء السريع للوكيل (English)](agent_quickstart.md)
- [البدء السريع للوكيل (Arabic)](agent_quickstart.ar.md)

> ⚡️ **نصيحة**: تأكد من تثبيت `omi-cli` قبل تشغيل أي مثال. يمكنك تثبيته عبر `pip install omi-cli`.

## دليل الاستخدام

كل مثال يتضمن ملف `omi.yaml` لتكوين الوكيل، بالإضافة إلى سكربتات Python أو أوامر shell. اتبع الخطوات الموضحة في كل ملف README داخل مجلد المثال لتشغيله بنجاح.
