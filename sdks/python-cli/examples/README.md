# omi-cli Examples

Ready-to-run recipes for `omi-cli`. Each file is a self-contained walkthrough
you can follow top-to-bottom in a terminal.

| Recipe | Description |
|---|---|
| [Agent Quickstart](agent_quickstart.md) | Bootstrap and run your first Omi agent. |
| [Agent Quickstart (Malay)](agent_quickstart.ms.md) | Panduan ejen pertama anda (`ms`). |
| [Action Items → HTML Dashboard](action_items_html.md) | Export action items to a self-contained, printable HTML report. |

## Prerequisites

```bash
pipx install omi-cli
export OMI_API_KEY="your_api_key"
```

## Contributing a recipe

1. Add your `.md` file to this directory.
2. Add a row to the table above.
3. Open a PR with the prefix `docs(python-cli):`.
