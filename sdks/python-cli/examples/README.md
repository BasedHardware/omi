# omi-cli — Example Recipes

Step-by-step recipes that combine `omi-cli` with standard shell tools.
Each recipe is self-contained and has zero mandatory dependencies beyond
`omi-cli` itself unless explicitly noted.

## Recipes

| File                                              | What it does                                                          |
|---------------------------------------------------|-----------------------------------------------------------------------|
| [`agent_quickstart.md`](agent_quickstart.md)      | Five-minute end-to-end agent walkthrough                              |
| [`agent_quickstart.ms.md`](agent_quickstart.ms.md) | Agent quickstart — Malay (ms)                                        |
| [`memories_ics.md`](memories_ics.md)              | Export memories to an iCalendar (.ics) file (Google Calendar, Apple Calendar, Outlook) |

## Adding a recipe

1. Drop a `<slug>.md` file in this directory.
2. Add a row to the table above.
3. Open a PR — that's it.
