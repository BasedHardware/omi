# Example Recipes for the Python CLI SDK

This directory contains small, self‑contained scripts that demonstrate common
tasks you might want to perform with the OMI Python CLI SDK. They are meant to
be copied, adapted, or used as a reference.

## Available recipes

- **`conversations_to_jsonl.py`** – Convert plain‑text conversation transcripts
  into a JSONL format suitable for LLM fine‑tuning or Retrieval‑Augmented
  Generation (RAG). See the detailed usage guide in
  [`conversations_jsonl.md`](conversations_jsonl.md).
