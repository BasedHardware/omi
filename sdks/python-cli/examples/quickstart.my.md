# omi-cli ဖြင့် စတင်အသုံးပြုခြင်း

ဤလမ်းညွှန်သည် အခြေခံ command များကို မြန်မာဘာသာဖြင့် ရှင်းပြထားပါသည်။
Command အမည်များနှင့် ပရိုဂရမ် မက်ဆေ့ဂျ်များသည် အင်္ဂလိပ်ဘာသာဖြင့် ဆက်လက်ရှိနေပါမည်။
ဤနေရာတွင် ပြသထားသော ဥပမာများသည် သင်၏ မှတ်ဉာဏ်များ၊ စကားပြောဆိုမှုများ၊
လုပ်ဆောင်ချက်များ သို့မဟုတ် ရည်မှန်းချက်များကို ပြောင်းလဲခြင်း မရှိပါ။

## ပရိုဂရမ် ထည့်သွင်းခြင်း

လိုအပ်ချက်များ - Python 3.10 သို့မဟုတ် အထက်ဗားရှင်း နှင့် Omi အကောင့်တစ်ခု။

သင့်တွင် `pipx` ထည့်သွင်းထားပါက -

```sh
pipx install omi-cli
omi --help
```

အခြားနည်းလမ်းအနေဖြင့် ဖွင့်ထားသော Python virtual environment ထဲတွင် ထည့်သွင်းနိုင်ပါသည် -

```sh
python -m pip install omi-cli
omi --help
```

အကယ်၍ terminal သည် `omi` ကို ရှာမတွေ့ပါက virtual environment ဖွင့်ထားခြင်း ရှိမရှိ သို့မဟုတ်
`pipx` ဖိုင်များ ထည့်သွင်းသည့် လမ်းကြောင်းသည် သင်၏ `PATH` ထဲတွင် ရှိမရှိ စစ်ဆေးပါ။

## သင်၏ အကောင့် ချိတ်ဆက်ခြင်း

အပြန်အလှန် အထောက်အကူပြု စနစ်ကို စတင်ပါ -

```sh
omi auth login
```

Browser မှတစ်ဆင့် ဝင်ရောက်ခြင်း သို့မဟုတ် Omi developer API key ထည့်သွင်းခြင်းကို ရွေးချယ်ပါ။
ဤစနစ်သည် key ကို လျှို့ဝှက်ပေးထားပါသည်၊ terminal မှတ်တမ်းတွင် ကျန်ရှိနေမည့် command အဖြစ် ရေးသားခြင်းကို ရှောင်ကြဉ်ပါ။

Browser သို့ တိုက်ရိုက်သွားရန် -

```sh
omi auth login --browser
```

Terminal အသုံးပြုနေသော ကွန်ပျူတာပေါ်တွင် ဝင်ရောက်ပါ - အတည်ပြုချက်သည် local address ကို အသုံးပြုပါသည်။
မျက်နှာပြင်ပေါ်ရှိ ညွှန်ကြားချက်များကို လိုက်နာပါ။

ထို့နောက် ဖွဲ့စည်းပုံနှင့် API အသုံးပြုခွင့်ကို စစ်ဆေးပါ -

```sh
omi auth status
omi auth whoami
```

`status` သည် local အခြေအနေကို ပြသပြီး လျှို့ဝှက်ချက်ကို ဖုံးကွယ်ထားသော်လည်း server ပေါ်ရှိ တရားဝင်မှုကို မစစ်ဆေးပါ။
`whoami` သည် စစ်ဆေးမှုတောင်းဆိုချက်ကို ပေးပို့ပါသည်၊ အောင်မြင်ပါက သင်၏ အထောက်အထားများ အလုပ်လုပ်ကြောင်း အတည်ပြုပေးပါသည်။

ဖွဲ့စည်းပုံကို ပုံမှန်အားဖြင့် `~/.omi/config.toml` တွင် သိမ်းဆည်းပါသည်။
ဤဖိုင်ကို အခြားသူများနှင့် မျှဝေခြင်း မပြုပါနှင့် - သင်၏ လျှို့ဝှက် အချက်အလက်များ ပါဝင်နေနိုင်ပါသည်။

## သင်၏ ဒေတာများကို ကြည့်ရှုခြင်း

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

စာရင်းအလွတ် ဖြစ်နေပါက ရှာဖွေမှုနှင့် ကိုက်ညီသော အချက်အလက် မရှိခြင်းကြောင့် ဖြစ်နိုင်ပါသည်။
Command တစ်ခုချင်းစီ၏ filter များကို သိရှိရန် help ကို အသုံးပြုပါ -

```sh
omi memory list --help
omi action-item list --help
```

## JSON ရယူခြင်းနှင့် စာမျက်နှာများ ကူးပြောင်းခြင်း

Global option ဖြစ်သော `--json` ကို command အုပ်စု၏ **အရှေ့** တွင် ထားပါ -

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ပထမ command သည် ပထမ မှတ်ဉာဏ် ၂၅ ခုကို တောင်းဆိုပြီး ဒုတိယ command သည် နောက်ထပ် ၂၅ ခုကို တောင်းဆိုပါသည်။
ထို့ကြောင့် စာမျက်နှာတစ်ခုတည်းသည် ပြီးပြည့်စုံသော backup မဟုတ်ပါ။ JSON output သည် ID အပြည့်အစုံကို ထိန်းသိမ်းပေးပါသည်။

စာမျက်နှာကို ဖိုင်အဖြစ် သိမ်းဆည်းရန် -

```sh
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
```

ဤသို့ ပြောင်းလဲခြင်းသည် local ဖိုင်ကို ဖန်တီးပေးခြင်း သို့မဟုတ် အစားထိုးပေးခြင်း ဖြစ်ပါသည်။
အသုံးမပြုမီ command အောင်မြင်စွာ ပြီးဆုံးကြောင်း သေချာပါစေ။ အမှားများကို stderr တွင် ရေးသားပါသည်၊
ဖိုင်အလွတ် ဖြစ်နေခြင်းသည် ဒေတာမရှိကြောင်း အာမမခံပါ။ ထုတ်ယူထားသော ဖိုင်တွင် ကိုယ်ရေးကိုယ်တာ အချက်အလက်များ ပါဝင်နိုင်သဖြင့် လုံခြုံစွာ ထားရှိပါ။

## အကောင့်မှ ထွက်ခြင်း (Logout)

```sh
omi auth logout
```

ဤ command သည် local တွင် သိမ်းဆည်းထားသော အချက်အလက်များကို ဖျက်ပစ်ပါသည်။ Server ပေါ်ရှိ key ကို ပယ်ဖျက်ရန်
သင်၏ အကောင့်ရှိ developer key စီမံခန့်ခွဲမှုကို အသုံးပြုပါ။

ကျန်ရှိသော command များနှင့် အဆင့်မြင့် ရွေးချယ်မှုများအတွက် [အင်္ဂလိပ်ဘာသာ ပင်မလမ်းညွှန်](../README.md) နှင့် `omi --help` ကို ကြည့်ရှုပါ။
