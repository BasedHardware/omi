# Build an Action Items Digest (Completion Rates, Overdue Items, Upcoming Deadlines)

Use this recipe to analyze task completion velocity and upcoming deadlines without parsing individual action
items: it turns one or more `action-item list` JSON exports into a concise Markdown digest featuring overall
completion rates, overdue warnings, upcoming 7-day deadlines, and a calendar schedule matrix. It operates
completely offline, makes zero external network requests, and writes to stdout or standalone Markdown files.

---

## Prerequisites

Ensure you have the `omi` CLI installed and authenticated:

```sh
pip install omi-cli
omi auth login
```

Export your action items (up to 200 items per batch):

```sh
omi --json action-item list --limit 200 > tasks.json
```

Verify that the export file was populated before running the recipe. If you have multiple export batches or
backups, provide them together (e.g. `batch1.json batch2.json`); the converter deduplicates items by their ID.

---

## Quickstart

### 1. Direct Pipeline Stream (Stdout)

Generate a digest directly from the CLI output stream into your terminal:

```sh
omi --json action-item list --limit 200 | python action_items_to_digest.py -
```

### 2. Export to a Dedicated Markdown Report

Generate a standalone digest file:

```sh
python action_items_to_digest.py tasks.json -o digest.md
```

### 3. Apply Local Timezone Offsets

Convert UTC timestamps to your local timezone (e.g. `+09:00` for JST or `-05:00` for EST):

```sh
python action_items_to_digest.py tasks.json -o digest.md --utc-offset +09:00
```

### 4. Filter by Completion Status

Generate a focused digest of pending open items only:

```sh
python action_items_to_digest.py tasks.json --status open -o open_tasks_digest.md
```

## CLI Options

| Option | Flag | Description | Default |
| :--- | :--- | :--- | :--- |
| `inputs` | Positional | One or more JSON export files, or `-` for stdin | *(Required)* |
| `--output` | `-o` | Destination Markdown file path | `stdout` |
| `--status` | `--status` | Filter items: `all`, `open`, or `completed` | `all` |
| `--utc-offset` | `--utc-offset`| Timezone offset in `±HH:MM` format (e.g. `+09:00`, `-05:00`)| UTC (`+00:00`) |
| `--overwrite` | `--overwrite` | Allow overwriting existing destination files | `False` |

## Digest Sections

1. **Executive Summary**: High-level totals, completion velocity rate (%), open counts, and overdue warnings.
2. **Summary Metrics Table**: Structured tabular breakdown with exact task counts and percentage ratios.
3. **⚠️ Overdue Tasks**: Highlights open tasks past their due dates with elapsed duration and unique task IDs.
4. **📅 Upcoming Deadlines**: Chronological listing of open tasks due within the next 7 calendar days.
5. **Due Date Schedule**: Day-by-day table showing workload distribution and completion velocity.

---

## Design Principles

- **Zero Third-Party Dependencies**: Pure Python 3.10+ standard library (`argparse`, `datetime`, `json`, `pathlib`).
- **Safe POSIX File Permissions**: Uses standard umask creation modes (`0644`) rather than restrictive tempfile modes.
- **Atomic File Operations**: Writes to a temporary file before renaming when `--overwrite` is specified.
- **Markdown Metacharacter Escaping**: Automatically sanitizes table and list metacharacters to
  prevent syntax corruption.
- **Pipeline Ready**: Supports piped stdin (`-`) and clean `BrokenPipeError` signal handling for commands like `| head`.
