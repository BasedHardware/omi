# omi-cli ಜತೆ ತ್ವರಿತ ಪ್ರಾರಂಭ

ಈ ಮಾರ್ಗದರ್ಶಿ ಮೂಲಭೂತ ಆಜ್ಞೆಗಳನ್ನು ಕನ್ನಡದಲ್ಲಿ ವಿವರಿಸುತ್ತದೆ. ಆಜ್ಞೆಯ ಹೆಸರುಗಳು ಮತ್ತು
ಪ್ರೋಗ್ರಾಮ್ ಸಂದೇಶಗಳು ಇಂಗ್ಲಿಷ್‌ನಲ್ಲೇ ಇರುತ್ತವೆ. ಕೆಳಗಿನ ಉದಾಹರಣೆ ಆಜ್ಞೆಗಳು ನಿಮ್ಮ
ನೆನಪುಗಳು, ಸಂಭಾಷಣೆಗಳು, ಕ್ರಿಯಾ ಐಟಂಗಳು ಅಥವಾ ಗುರಿಗಳನ್ನು ಬದಲಾಯಿಸುವುದಿಲ್ಲ.

## ಪ್ರೋಗ್ರಾಮ್ ಅನ್ನು ಸ್ಥಾಪಿಸುವುದು

ಅಗತ್ಯಗಳು: Python 3.10 ಅಥವಾ ಹೊಸದು ಮತ್ತು Omi ಖಾತೆ.

`pipx` ಸ್ಥಾಪಿಸಲಾಗಿದ್ದರೆ:

```sh
pipx install omi-cli
omi --help
```

ಅಥವಾ ಸಕ್ರಿಯಗೊಳಿಸಲಾದ Python ವರ್ಚುವಲ್ ಎನ್‌ವಿರಾನ್‌ಮೆಂಟ್‌ನಲ್ಲಿ ಸ್ಥಾಪಿಸಿ:

```sh
python -m pip install omi-cli
omi --help
```

ಟರ್ಮಿನಲ್ `omi` ಅನ್ನು ಹುಡುಕಲಾಗದಿದ್ದರೆ, ವರ್ಚುವಲ್ ಎನ್‌ವಿರಾನ್‌ಮೆಂಟ್ ಸಕ್ರಿಯವಾಗಿದೆಯೇ
ಅಥವಾ `pipx` executable ಗಳನ್ನು ಇಡುವ ಡೈರೆಕ್ಟರಿ `PATH` ನಲ್ಲಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ.

## ನಿಮ್ಮ ಖಾತೆಯನ್ನು ಸಂಪರ್ಕಿಸುವುದು

ಇಂಟರಾಕ್ಟಿವ್ ಮಾರ್ಗದರ್ಶಿಯನ್ನು ಚಲಾಯಿಸಿ:

```sh
omi auth login
```

ಬ್ರೌಸರ್ ಲಾಗಿನ್ ಆಯ್ಕೆಮಾಡಿ ಅಥವಾ Omi ಡೆವಲಪರ್ API key ಅನ್ನು ಅಂಟಿಸಿ. ಇಂಟರಾಕ್ಟಿವ್
ಇನ್‌ಪುಟ್ key ಅನ್ನು ಮರೆಮಾಡುತ್ತದೆ; ಟರ್ಮಿನಲ್ ಇತಿಹಾಸದಲ್ಲಿ ಉಳಿಯುವ ಆಜ್ಞೆಗಳಲ್ಲಿ ಅದನ್ನು
ನೇರವಾಗಿ ಬರೆಯಬೇಡಿ.

ಬ್ರೌಸರ್ ಅನ್ನು ನೇರವಾಗಿ ಬಳಸಲು:

```sh
omi auth login --browser
```

ಟರ್ಮಿನಲ್ ಇರುವ ಅದೇ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಲಾಗಿನ್ ಮಾಡಿ, ಏಕೆಂದರೆ ದೃಢೀಕರಣವು ಸ್ಥಳೀಯ
callback ವಿಳಾಸವನ್ನು ಬಳಸುತ್ತದೆ. ಪರದೆಯ ಮೇಲಿನ ಸೂಚನೆಗಳನ್ನು ಅನುಸರಿಸಿ.

ಲಾಗಿನ್ ಆದ ನಂತರ ಕಾನ್ಫಿಗರೇಶನ್ ಮತ್ತು API ಪ್ರವೇಶವನ್ನು ಪರಿಶೀಲಿಸಿ:

```sh
omi auth status
omi auth whoami
```

`status` ಸ್ಥಳೀಯ ಸ್ಥಿತಿಯನ್ನು ತೋರಿಸಿ ರಹಸ್ಯಗಳನ್ನು ಮರೆಮಾಚುತ್ತದೆ, ಆದರೆ ಅವು ಸರ್ವರ್‌ನಲ್ಲಿ
ಮಾನ್ಯವೆಂದು ಪರಿಶೀಲಿಸುವುದಿಲ್ಲ. `whoami` ದೃಢೀಕರಿಸಿದ ವಿನಂತಿಯನ್ನು ಕಳುಹಿಸುತ್ತದೆ;
ಯಶಸ್ವಿಯಾದರೆ ನಿಮ್ಮ ಹೆಸರನ್ನು ತೋರಿಸದೇ ನಿಮ್ಮ credentials ಕೆಲಸ ಮಾಡುತ್ತವೆ.

ಕಾನ್ಫಿಗರೇಶನ್ ಡೀಫಾಲ್ಟ್ ಆಗಿ `~/.omi/config.toml` ನಲ್ಲಿ ಉಳಿಸಲಾಗುತ್ತದೆ. ಈ ಫೈಲ್
credentials ಹೊಂದಿರಬಹುದು ಆದ್ದರಿಂದ ಹಂಚಿಕೊಳ್ಳಬೇಡಿ.

## ನಿಮ್ಮ ಡೇಟಾವನ್ನು ಓದುವುದು

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ಖಾಲಿ ಪಟ್ಟಿ ಎಂದರೆ ಫಿಲ್ಟರ್‌ಗೆ ಹೊಂದುವ ಐಟಂಗಳಿಲ್ಲ ಎಂದೂ ಇರಬಹುದು. ಪ್ರತಿ ಆಜ್ಞೆಯ
ಆಯ್ಕೆಗಳನ್ನು help ನಲ್ಲಿ ನೋಡಿ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ಪಡೆಯುವುದು ಮತ್ತು ಪುಟಗಳನ್ನು ಹಿಮ್ಮೇಳುವುದು

ಜಾಗತಿಕ `--json` ಆಯ್ಕೆಯನ್ನು ಆಜ್ಞಾ ಗುಂಪಿನ **ಮೊದಲು** ಇರಿಸಿ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ಮೊದಲ ಆಜ್ಞೆ ಮೊದಲ 25 ನೆನಪುಗಳನ್ನು ಕೇಳುತ್ತದೆ; ಎರಡನೆಯದು ಮುಂದಿನ 25. ಒಂದು ಪುಟ ಸಂಪೂರ್ಣ
ಬ್ಯಾಕಪ್ ಅಲ್ಲ. JSON ಔಟ್‌ಪುಟ್ ಪೂರ್ಣ ID ಗಳನ್ನು ಉಳಿಸುತ್ತದೆ, ಆದರೆ ಟೇಬಲ್ ಪ್ರದರ್ಶನಕ್ಕಾಗಿ
ID ಗಳನ್ನು ಸಣ್ಣದಾಗಿಸಬಹುದು.

ಪುಟವನ್ನು ಫೈಲ್‌ಗೆ ಉಳಿಸಲು:

```sh
omi --json memory list --limit 25 --offset 0 > memory-page-1.json
```

ರೀಡೈರೆಕ್ಷನ್ ಸ್ಥಳೀಯ ಫೈಲ್ ಅನ್ನು ರಚಿಸುತ್ತದೆ ಅಥವಾ ಮೇಲೆ ಬರೆಯುತ್ತದೆ. ವಿಷಯವನ್ನು ಬಳಸುವ
ಮೊದಲು ಆಜ್ಞೆ ಯಶಸ್ವಿಯಾಗಿ ಮುಗಿದಿದೆಯೇ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ. ದೋಷಗಳು stderr ಗೆ
ಬರೆಯಲಾಗುತ್ತವೆ; ಖಾಲಿ ಫೈಲ್ ಡೇಟಾ ಇಲ್ಲ ಎಂದು ಸಾಬೀತುಪಡಿಸುವುದಿಲ್ಲ. ಎಕ್ಸ್‌ಪೋರ್ಟ್ ಫೈಲ್
ವೈಯಕ್ತಿಕ ಮಾಹಿತಿಯನ್ನು ಹೊಂದಿರಬಹುದು — ಅದನ್ನು ಖಾಸಗಿಯಾಗಿ ಇರಿಸಿ.

## ಪ್ರೊಫೈಲ್‌ಗಳನ್ನು ಬಳಸುವುದು

ಸ್ಟೇಟ್ `~/.omi/config.toml` ನಲ್ಲಿ ಉಳಿಸಲಾಗುತ್ತದೆ (`$OMI_CONFIG` ಮೂಲಕ
ಬದಲಾಯಿಸಬಹುದು). ಪ್ರತಿ ಪ್ರೊಫೈಲ್ ತನ್ನದೇ ದೃಢೀಕರಣ ವಿಧಾನ ಮತ್ತು API ವಿಳಾಸವನ್ನು ಹೊಂದಿದೆ.
`--profile` ಮೂಲಕ ಬದಲಿಸಿ:

```sh
omi config profile use ಕೆಲಸ
omi auth login
omi --profile ವೈಯಕ್ತಿಕ memory list
```

ಸಾಮಾನ್ಯ ಕಾನ್ಫಿಗರೇಶನ್ ಆಜ್ಞೆಗಳು:

```sh
omi config show
omi config path
omi config profile list
```

## ಎಕ್ಸಿಟ್ ಕೋಡ್‌ಗಳು

ಈ ಎಕ್ಸಿಟ್ ಕೋಡ್‌ಗಳು ಸ್ಥಿರವಾಗಿವೆ ಮತ್ತು ಸ್ಕ್ರಿಪ್ಟ್ ಅಥವಾ ಏಜೆಂಟ್‌ಗಳಿಗೆ ಉಪಯುಕ್ತವಾಗಿವೆ:

| ಕೋಡ್ | ಅರ್ಥ | ಉದಾಹರಣೆ ಸನ್ನಿವೇಶ |
| ---: | --- | --- |
| 0 | ಯಶಸ್ಸು | ಆಜ್ಞೆ ಪೂರ್ಣಗೊಂಡಿದೆ |
| 1 | ಬಳಕೆಯ ದೋಷ | ತಪ್ಪಾದ ಫ್ಲ್ಯಾಗ್, ಕಳಪೆಯಾದ ಆರ್ಗ್ಯುಮೆಂಟ್ ಅಥವಾ ವೈಫಲ್ಯ ಮೌಲ್ಯೀಕರಣ |
| 2 | ದೃಢೀಕರಣ ದೋಷ | credentials ಇಲ್ಲ, ಟೋಕನ್ ಮುಗಿದಿದೆ ಅಥವಾ ಅನುಮತಿ ಕಡಿಮೆ |
| 3 | ಸರ್ವರ್ ದೋಷ | ಸರ್ವರ್ 5xx ಅಥವಾ ಸಂಪರ್ಕ ವಿಫಲ |
| 4 | ದರದ ಮಿತಿ | ಸರ್ವರ್ HTTP 429 ಹಿಂದಿರುಗಿಸಿತು |
| 5 | ಕಂಡುಬಂದಿಲ್ಲ | ಸರ್ವರ್ HTTP 404 ಹಿಂದಿರುಗಿಸಿತು |

## ಲಾಗ್ಔಟ್

```sh
omi auth logout
```

ಸ್ಥಳೀಯವಾಗಿ ಉಳಿಸಿದ credentials ಅನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ. ಸರ್ವರ್‌ನಲ್ಲಿ key ಅನ್ನು
ಹಿಂತೆಗೆದುಕೊಳ್ಳಲು ನಿಮ್ಮ ಖಾತೆಯ developer key ನಿರ್ವಹಣೆಯನ್ನು ಬಳಸಿ.

ಹೆಚ್ಚಿನ ಆಜ್ಞೆಗಳು ಮತ್ತು ಆಯ್ಕೆಗಳಿಗಾಗಿ [ಇಂಗ್ಲಿಷ್ ಮುಖ್ಯ README](../README.md)
ನೋಡಿ ಮತ್ತು `omi --help` ಚಲಾಯಿಸಿ.
