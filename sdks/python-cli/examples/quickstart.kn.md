# omi-cli ನೊಂದಿಗೆ ಪ್ರಾರಂಭಿಸಿ

ಈ ಮಾರ್ಗದರ್ಶಿಯು ಕನ್ನಡದಲ್ಲಿ ಆರಂಭಿಕ ಆದೇಶಗಳನ್ನು ಹೇಗೆ ಬಳಸುವುದು ಎಂಬುದನ್ನು ವಿವರಿಸುತ್ತದೆ. ಆದೇಶಗಳ ಹೆಸರುಗಳು ಮತ್ತು ಸಿಸ್ಟಮ್ ಸಂದೇಶಗಳು ಇಂಗ್ಲಿಷ್‌ನಲ್ಲಿಯೇ ಇರುತ್ತವೆ. ಇಲ್ಲಿ ನೀಡಲಾದ ಓದುವ ಉದಾಹರಣೆಗಳು ನಿಮ್ಮ ನೆನಪುಗಳು, ಸಂಭಾಷಣೆಗಳು, ಕಾರ್ಯಗಳು ಅಥವಾ ಗುರಿಗಳನ್ನು ಬದಲಾಯಿಸುವುದಿಲ್ಲ.

## ಪ್ರೋಗ್ರಾಂ ಅನ್ನು ಸ್ಥಾಪಿಸಿ (Install)

ಅಗತ್ಯತೆಗಳು: Python 3.10 ಅಥವಾ ನಂತರದ ಆವೃತ್ತಿ ಮತ್ತು ಒಂದು Omi ಖಾತೆ.

> ಗಮನಿಸಿ: PyPI ನಲ್ಲಿ ಪ್ಯಾಕೇಜ್ ಹೆಸರು **`omi-cli`**, ಆದರೆ ಸ್ಥಾಪನೆಯ ನಂತರ ಕಾರ್ಯನಿರ್ವಹಿಸುವ ಆದೇಶದ ಹೆಸರು **`omi`**. PyPI ನಲ್ಲಿ `omi` ಹೆಸರಿನ ಅಸಂಬದ್ಧ ಪ್ಯಾಕೇಜ್ ಕೂಡ ಇದೆ — ಅದನ್ನು ಸ್ಥಾಪಿಸಬೇಡಿ.

`pipx` ಸ್ಥಾಪಿತವಾಗಿದ್ದರೆ:

```sh
pipx install omi-cli
omi --help
```

ಪರ್ಯಾಯವಾಗಿ, ಸಕ್ರಿಯ Python ವರ್ಚುವಲ್ ಪರಿಸರದಲ್ಲಿ:

```sh
python -m pip install omi-cli
omi --help
```

ಟರ್ಮಿನಲ್ `omi` ಆದೇಶವನ್ನು ಗುರುತಿಸದಿದ್ದರೆ, ವರ್ಚುವಲ್ ಪರಿಸರ ಸಕ್ರಿಯವಾಗಿದೆಯೇ ಅಥವಾ `pipx` ಡೈರೆಕ್ಟರಿ ನಿಮ್ಮ `PATH` ನಲ್ಲಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ.

## ನಿಮ್ಮ ಖಾತೆಯನ್ನು ಸಂಪರ್ಕಿಸಿ

ಸಂವಾದಾತ್ಮಕ ಲಾಗಿನ್ ಪ್ರಾರಂಭಿಸಿ:

```sh
omi auth login
```

ಬ್ರೌಸರ್ ಮೂಲಕ ಲಾಗಿನ್ ಮಾಡಿ ಅಥವಾ Omi ಡೆವಲಪರ್ API key ಅಂಟಿಸುವ ಆಯ್ಕೆಯನ್ನು ಆರಿಸಿ. ಸಂವಾದಾತ್ಮಕ ಇನ್‌ಪುಟ್ ಕೀಲಿಯನ್ನು ಮರೆಮಾಡುತ್ತದೆ; ಟರ್ಮಿನಲ್ ಇತಿಹಾಸದಲ್ಲಿ ಉಳಿಯುವ ಆಜ್ಞೆಯಲ್ಲಿ ಕೀಲಿಯನ್ನು ಟೈಪ್ ಮಾಡಬೇಡಿ.

ನೇರವಾಗಿ ಬ್ರೌಸರ್ ಮೂಲಕ:

```sh
omi auth login --browser
```

ಟರ್ಮಿನಲ್ ಚಾಲನೆಯಲ್ಲಿರುವ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿಯೇ ಬ್ರೌಸರ್ ಲಾಗಿನ್ ಪೂರ್ಣಗೊಳಿಸಿ, ಏಕೆಂದರೆ ದೃಢೀಕರಣವು ಸ್ಥಳೀಯ ವಿಳಾಸಕ್ಕೆ ಹಿಂತಿರುಗುತ್ತದೆ. ಪರದೆಯ ಮೇಲಿನ ಸೂಚನೆಗಳನ್ನು ಅನುಸರಿಸಿ.

ನಂತರ ಸಂರಚನೆ ಮತ್ತು API ಪ್ರವೇಶವನ್ನು ಪರಿಶೀಲಿಸಿ:

```sh
omi auth status
omi auth whoami
```

`status` ಸ್ಥಳೀಯ ಸ್ಥಿತಿಯನ್ನು ತೋರಿಸುತ್ತದೆ ಮತ್ತು ರಹಸ್ಯಗಳನ್ನು ಮರೆಮಾಡುತ್ತದೆ, ಆದರೆ ಸರ್ವರ್‌ನಲ್ಲಿ ಪರಿಶೀಲಿಸುವುದಿಲ್ಲ. `whoami` ಅಧಿಕೃತ ವಿನಂತಿಯನ್ನು ಕಳುಹಿಸುತ್ತದೆ; ಯಶಸ್ವಿಯಾದರೆ ರುಜುವಾತುಗಳು ಸರಿಯಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಿವೆ ಎಂದರ್ಥ.

ಸಂರಚನಾ ಫೈಲ್ ಅನ್ನು ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ `~/.omi/config.toml` ನಲ್ಲಿ ಉಳಿಸಲಾಗುತ್ತದೆ. ಇದನ್ನು ಯಾರೊಂದಿಗೂ ಹಂಚಿಕೊಳ್ಳಬೇಡಿ: ಇದರಲ್ಲಿ ನಿಮ್ಮ ಸೂಕ್ಷ್ಮ ರುಜುವಾತುಗಳು ಇರಬಹುದು.

## ನಿಮ್ಮ ಡೇಟಾವನ್ನು ವೀಕ್ಷಿಸಿ

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ಖಾಲಿ ಪಟ್ಟಿಯ ಅರ್ಥ ಪ್ರಶ್ನೆಗೆ ಹೊಂದಿಕೆಯಾಗುವ ಯಾವುದೇ ನಮೂದು ಇಲ್ಲದಿರುವುದು ಮಾತ್ರ. ಫಿಲ್ಟರಿಂಗ್ ಆಯ್ಕೆಗಳನ್ನು ತಿಳಿಯಲು help ನೋಡಿ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ಔಟ್‌ಪುಟ್ ಮತ್ತು ಪುಟ ವಿಂಗಡಣೆ (Pagination)

ಜಾಗತಿಕ ಆಯ್ಕೆ `--json` ಅನ್ನು ಆಜ್ಞಾ ಗುಂಪಿನ **ಮೊದಲು** ಇರಿಸಿ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ಮೊದಲ ಆಜ್ಞೆಯು ಮೊದಲ 25 ದಾಖಲೆಗಳನ್ನು ಮತ್ತು ಎರಡನೆಯದು ಮುಂದಿನ 25 ದಾಖಲೆಗಳನ್ನು ಪಡೆಯುತ್ತದೆ. ಸಂಪೂರ್ಣ ಬ್ಯಾಕಪ್‌ಗಾಗಿ ಬಹು ಪುಟಗಳು ಬೇಕಾಗಬಹುದು. JSON ಔಟ್‌ಪುಟ್‌ನಲ್ಲಿ ಪೂರ್ಣ ಗುರುತಿಸುವಿಕೆಗಳು ಸುರಕ್ಷಿತವಾಗಿರುತ್ತವೆ.

ಪುಟವನ್ನು ಫೈಲ್‌ನಲ್ಲಿ ಉಳಿಸಲು:

```sh
omi --json memory list --limit 25 --offset 0 > nenapugalu-page-1.json
```

ಈ ಮರುನಿರ್ದೇಶನವು ಸ್ಥಳೀಯ ಫೈಲ್ ಅನ್ನು ರಚಿಸುತ್ತದೆ ಅಥವಾ ಬದಲಾಯಿಸುತ್ತದೆ. ದೋಷಗಳನ್ನು stderr ಗೆ ಬರೆಯಲಾಗುತ್ತದೆ; ಖಾಲಿ ಫೈಲ್ ಡೇಟಾ ಇಲ್ಲದಿರುವುದಕ್ಕೆ ಅಂತಿಮ ಪುರಾವೆಯಲ್ಲ. ರಫ್ತು ಮಾಡಿದ ಫೈಲ್ ಖಾಸಗಿ ಮಾಹಿತಿಯನ್ನು ಹೊಂದಿರಬಹುದು, ಅದನ್ನು ಸುರಕ್ಷಿತವಾಗಿರಿಸಿ.

## ಲಾಗ್‌ಔಟ್ ಮಾಡಿ

```sh
omi auth logout
```

ಈ ಆಜ್ಞೆಯು ಸ್ಥಳೀಯವಾಗಿ ಉಳಿಸಲಾದ ರುಜುವಾತುಗಳನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ. ಸರ್ವರ್‌ನಲ್ಲಿ ಕೀಲಿಯನ್ನು ಹಿಂಪಡೆಯಲು ಖಾತೆಯ ಡೆವಲಪರ್ ಪೋರ್ಟಲ್ ಬಳಸಿ.

ಇತರ ಆಜ್ಞೆಗಳು ಮತ್ತು ಸುಧಾರಿತ ಆಯ್ಕೆಗಳಿಗಾಗಿ ಮುಖ್ಯ ಇಂಗ್ಲಿಷ್ ಮಾರ್ಗದರ್ಶಿಯನ್ನು ನೋಡಿ:
[../README.md](../README.md) ಮತ್ತು `omi --help`.
