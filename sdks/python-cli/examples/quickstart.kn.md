# omi-cli ನೊಂದಿಗೆ ಪ್ರಾರಂಭಿಕ ಮಾರ್ಗದರ್ಶಿ (Kannada Quickstart)

ಈ ಮಾರ್ಗದರ್ಶಿಯು ಕನ್ನಡದಲ್ಲಿ `omi-cli` ನ ಮೂಲಭೂತ ಆಜ್ಞೆಗಳನ್ನು (commands) ಪರಿಚಯಿಸುತ್ತದೆ. ಆಜ್ಞೆಗಳ ಹೆಸರುಗಳು ಮತ್ತು ಸಿಸ್ಟಮ್ ಸಂದೇಶಗಳು ಇಂಗ್ಲಿಷ್‌ನಲ್ಲಿರುತ್ತವೆ. ಇಲ್ಲಿ ನೀಡಿರುವ ಓದುವ ಉದಾಹರಣೆಗಳು ನಿಮ್ಮ ನೆನಪುಗಳು, ಸಂಭಾಷಣೆಗಳು, ಕಾರ್ಯಗಳು ಅಥವಾ ಗುರಿಗಳನ್ನು ಬದಲಾಯಿಸುವುದಿಲ್ಲ.

## ೧. ಪ್ರೋಗ್ರಾಂ ಅನ್ನು ಸ್ಥಾಪಿಸಿ (Installation)

**ಅಗತ್ಯತೆಗಳು:** Python 3.10 ಅಥವಾ ನಂತರದ ಆವೃತ್ತಿ ಮತ್ತು ಒಂದು Omi ಖಾತೆ.

> **ಪ್ರಮುಖ ಸೂಚನೆ:** PyPI ನಲ್ಲಿ ಪ್ಯಾಕೇಜ್ ಹೆಸರು **`omi-cli`** ಆಗಿದೆ, ಆದರೆ ಸ್ಥಾಪನೆಯ ನಂತರ ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ ಚಲಿಸುವ ಆಜ್ಞೆಯ ಹೆಸರು **`omi`** ಆಗಿದೆ. PyPI ನಲ್ಲಿ `omi` ಹೆಸರಿನ ಬೇರೆ ಪ್ಯಾಕೇಜ್ ಇದೆ — ಅದನ್ನು ಸ್ಥಾಪಿಸಬೇಡಿ.

`pipx` ಸ್ಥಾಪಿತವಾಗಿದ್ದರೆ:

```sh
pipx install omi-cli
omi --help
```

ಅಥವಾ, ಸಕ್ರಿಯ Python ವರ್ಚುವಲ್ ಎನ್ವಿರಾನ್ಮೆಂಟ್‌ನಲ್ಲಿ:

```sh
python -m pip install omi-cli
omi --help
```

ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ `omi` ಆಜ್ಞೆ ಕಂಡುಬರದಿದ್ದರೆ, ವರ್ಚುವಲ್ ಎನ್ವಿರಾನ್ಮೆಂಟ್ ಸಕ್ರಿಯವಾಗಿದೆಯೇ ಅಥವಾ `pipx` ಡೈರೆಕ್ಟರಿಯು ನಿಮ್ಮ `PATH` ನಲ್ಲಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ.

## ೨. ನಿಮ್ಮ ಖಾತೆಯನ್ನು ಸಂಪರ್ಕಿಸಿ (Authentication)

ಸಂವಾದಾತ್ಮಕ ಲಾಗಿನ್ ಪ್ರಾರಂಭಿಸಿ:

```sh
omi auth login
```

ಬ್ರೌಸರ್ ಮೂಲಕ ಲಾಗಿನ್ ಆಯ್ಕೆಮಾಡಿ ಅಥವಾ Omi ಡೆವಲಪರ್ API ಕೀಲಿಯನ್ನು ನಮೂದಿಸಿ. ನೇರ ಬ್ರೌಸರ್ ಲಾಗಿನ್‌ಗಾಗಿ:

```sh
omi auth login --browser
```

ಟರ್ಮಿನಲ್ ಚಾಲನೆಯಲ್ಲಿರುವ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿಯೇ ಲಾಗಿನ್ ಮಾಡಿ, ಏಕೆಂದರೆ ದೃಢೀಕರಣವು ಸ್ಥಳೀಯ ವಿಳಾಸಕ್ಕೆ (localhost) ಹಿಂತಿರುಗುತ್ತದೆ.

ನಂತರ ಸಂರಚನೆ ಮತ್ತು API ಸಂಪರ್ಕವನ್ನು ಪರಿಶೀಲಿಸಿ:

```sh
omi auth status
omi auth whoami
```

`status` ಸ್ಥಳೀಯ ಸ್ಥಿತಿಯನ್ನು ತೋರಿಸುತ್ತದೆ ಮತ್ತು ರಹಸ್ಯಗಳನ್ನು ಮರೆಮಾಡುತ್ತದೆ. `whoami` ಸರ್ವರ್‌ಗೆ ದೃಢೀಕರಣ ವಿನಂತಿಯನ್ನು ಕಳುಹಿಸಿ ಸರಿಯಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಿದೆಯೇ ಎಂದು ಖಚಿತಪಡಿಸುತ್ತದೆ.

ಸಂರಚನೆಯನ್ನು ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ `~/.omi/config.toml` ನಲ್ಲಿ ಉಳಿಸಲಾಗುತ್ತದೆ. ಈ ಫೈಲ್‌ನಲ್ಲಿ ನಿಮ್ಮ ರುಜುವಾತುಗಳು ಇರುವುದರಿಂದ ಇದನ್ನು ಸುರಕ್ಷಿತವಾಗಿರಿಸಿ.

## ೩. ನಿಮ್ಮ ಡೇಟಾವನ್ನು ವೀಕ್ಷಿಸಿ

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ನಿರ್ದಿಷ್ಟ ಸಂಭಾಷಣೆಯ ಸಂಪೂರ್ಣ ಪ್ರತಿಲೇಖನವನ್ನು (transcript) ಪಡೆಯಲು:

```sh
omi conversation get <CONVERSATION_ID> --include-transcript
```

ಯಾವುದೇ ಆಜ್ಞೆಯ ಫಿಲ್ಟರ್‌ಗಳು ಮತ್ತು ಆಯ್ಕೆಗಳನ್ನು ತಿಳಿಯಲು `--help` ಬಳಸಿ:

```sh
omi memory list --help
omi conversation list --help
omi goal list --help
```

## ೪. JSON ಔಟ್‌ಪುಟ್ ಮತ್ತು ಪುಟೀಕರಣ (Pagination)

ಜಾಗತಿಕ ಆಯ್ಕೆ `--json` ಅನ್ನು ಯಾವಾಗಲೂ ಆಜ್ಞಾ ಗುಂಪಿನ **ಮೊದಲು** ಇರಿಸಿ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ಮೊದಲ ಆಜ್ಞೆಯು ಮೊದಲ 25 ದಾಖಲೆಗಳನ್ನು ವಿನಂತಿಸುತ್ತದೆ; ಎರಡನೆಯದು ಮುಂದಿನ 25 ದಾಖಲೆಗಳನ್ನು ವಿನಂತಿಸುತ್ತದೆ.

ಪುಟವನ್ನು ಫೈಲ್‌ಗೆ ರಫ್ತು ಮಾಡಲು (Export):

```sh
omi --json memory list --limit 25 --offset 0 > nenapugalu-page-1.json
```

## ೫. ಲಾಗ್‌ಔಟ್ ಮಾಡಿ

ಸ್ಥಳೀಯ ರುಜುವಾತುಗಳನ್ನು ತೆಗೆದುಹಾಕಲು:

```sh
omi auth logout
```

ಇದು ಸ್ಥಳೀಯ ಕಂಪ್ಯೂಟರ್‌ನಿಂದ ಲಾಗಿನ್ ಮಾಹಿತಿಯನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ. ಸರ್ವರ್‌ನಿಂದ ಕೀಲಿಯನ್ನು ರದ್ದುಗೊಳಿಸಲು Omi ಡೆವಲಪರ್ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಬಳಸಿ.

ಹೆಚ್ಚಿನ ವಿವರಗಳಿಗಾಗಿ ಇಂಗ್ಲಿಷ್ ಮುಖ್ಯ ಮಾರ್ಗದರ್ಶಿಯನ್ನು ನೋಡಿ: [../README.md](../README.md) ಮತ್ತು [agent_quickstart.md](agent_quickstart.md).
