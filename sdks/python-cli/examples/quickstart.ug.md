# omi-cli بىلەن تۇنجى قەدەملەر

بۇ قوللانما omi-cli نىڭ تۇنجى بۇيرۇقلىرىنى (commands) ئۇيغۇرچە چۈشەندۈرىدۇ. بۇيرۇق ئىسىملىرى ۋە پروگرامما ئۇچۇرلىرى ئىنگلىزچە قالىدۇ. بۇ يەردە كۆرسىتىلگەن ئىزدەش مىساللىرى سىزنىڭ ئەسلىمىلىرىڭىز (memories)، سۆھبەتلىرىڭىز (conversations)، ۋەزىپىلىرىڭىز (action items) ياكى مەقسەتلىرىڭىز (goals) نى ئۆزگەرتمەيدۇ.

## قاچىلاش

تەلەپلەر: Python 3.10 ياكى ئۇنىڭدىن يېڭى نەشرى، ۋە بىر Omi ھېساباتى.

ئەگەر `pipx` بار بولسا:

```sh
pipx install omi-cli
omi --help
```

بۇنى ھەرەكتىكى Python مۇھىتى ئىچىگەمۇ قاچىلىيالايسىز:

```sh
python -m pip install omi-cli
omi --help
```

ئەگەر تېرمىنال `omi` نى تاپالمىسا، مۇھىتنىڭ ھەرەكتە ئىكەنلىكىنى ياكى `pipx` قىسقۇچىنىڭ `$PATH` ئىچىدە ئىكەنلىكىنى جەزملەڭ.

## ھېساباتىڭىزنى باغلاش

ئۆز-ئارا تەسىرلىك ياردەمچىنى باشلاڭ:

```sh
omi auth login
```

توركۆرگۈ ئارقىلىق كىرىشنى ياكى Omi تەرەققىياتچى API ئاچقۇچىنى چاپلاشنى تاللاڭ. ئۆز-ئارا كىرگۈزۈش ئاچقۇچنى يوشۇرىدۇ؛ ئاچقۇچنى تېرمىنال تارىخىغا ساقلىنىدىغان بۇيرۇققا يازماڭ.

توركۆرگۈگە بىۋاسىتە مېڭىش ئۈچۈن:

```sh
omi auth login --browser
```

تېرمىنال بىلەن ئوخشاش كومپيۇتېردا كىرىڭ: دەلىللەش جاۋابى يەرلىك ئادرېسقا كېتىدۇ. ئېكراندىكى كۆرسەتمىلەرگە ئەمەل قىلىڭ.

شۇنىڭدىن كېيىن، سەپلىمە ۋە API زىيارىتىنى دەلىللەڭ:

```sh
omi auth status
omi auth whoami
```

`status` يەرلىك ھالەتنى كۆرسىتىدۇ ۋە مەخپىي نەرسىنى يوشۇرىدۇ، ئەمما مۇلازىمېتەردىكى ئىناۋەتلىكلىكنى دەلىللىمەيدۇ. `whoami` دەلىللەنگەن تەلەپ قىلىدۇ؛ ئۇتۇشلۇق بولسا، ئىسپاتنىڭ ئىشلەيدىغانلىقى ئېنىق، ئىسمىڭىزنى كۆرسەتمەي.

سەپلىمە سۈكۈتتە `~/.omi/config.toml` غا ساقلىنىدۇ. بۇ ھۆججەتنى ھەمبەھىرلىمەڭ: ئۇ مەخپىي ئىسپاتلارنى ئۆز ئىچىگە ئېلىشى مۇمكىن.

## سانلىق مەلۇماتلىرىڭىزنى كۆرۈش

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

قۇرۇق تىزىملىك كۆپىنچە ئىزدەشكە ماس كېلىدىغان نەرسە يوقلۇقىنى بىلدۈرىدۇ. ھەر بىر بۇيرۇقنىڭ سۈزگۈچلىرىنى تېپىش ئۈچۈن ياردەمنى ئىشلىتىڭ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ۋە بەتلەش

ئومۇمىي تاللانما `--json` نى بۇيرۇق گۇرۇپپىسىدىن **ئىلگىرى** قويۇڭ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

بىرىنچى بۇيرۇق ئالدىنقى 25 ئەسلىمىنى سورايدۇ؛ ئىككىنچىسى كېيىنكى 25 نى. بىر بەت تولۇق زاپاس ئەمەس. JSON چىقىرىش پۈتۈن سانلارنى ساقلايدۇ، ئېكراندىكى جەدۋەللەر ئۇلارنى قىسقارتىشى مۇمكىن.

بىر بەتنى ھۆججەتكە ساقلاش ئۈچۈن:

```sh
omi --json memory list --limit 25 --offset 0 > ئەسلىمە-بەت-1.json
```

بۇ قايتا يۆتكەش يەرلىك ھۆججەت قۇرىدۇ ياكى ئۈستىگە يازىدۇ. مەزمۇننى ئىشلىتىشتىن بۇرۇن بۇيرۇقنىڭ تاماملانغانلىقىنى جەزملەڭ. خاتالىقلار خاتالىق چىقىرىشىغا (stderr) يېزىلىدۇ؛ قۇرۇق ھۆججەت سانلىق مەلۇمات يوقلۇقىنىڭ ئىسپاتى ئەمەس. چىقىرىلغان ھۆججەت شەخسىي ئۇچۇرلارنى ئۆز ئىچىگە ئېلىشى مۇمكىن: ئۇنى شەخسىي ساقلاڭ.

## چىقىش

```sh
omi auth logout
```

بۇ بۇيرۇق يەرلىك ساقلانغان ئىسپاتلارنى ئۆچۈرىدۇ. مۇلازىمېتەردىكى ئاچقۇچنى بىكار قىلىش ئۈچۈن، ئۆز ھېساباتىڭىزدىكى تەرەققىياتچى ئاچقۇچ باشقۇرۇشىنى ئىشلىتىڭ.

تېخىمۇ كۆپ بۇيرۇق ۋە تاللانمىلار ئۈچۈن، [ئىنگلىزچە ئاساسىي قوللانمىنى](../README.md) ۋە `omi --help` نى كۆرۈڭ.
