# omi-cli بىلەن باشلاش

بۇ قوللانما ئۇيغۇرچە تۇنجى بىر قانچە بۇيرۇقنى كۆرسىتىدۇ. بۇيرۇق ناملىرى ۋە سىستېما ئۇچۇرلىرى ئىنگلىزچە بويىچە قالىدۇ. بۇ يەردە كۆرسىتىلگەن ئوقۇش مىساللىرى خاتىرىلىرىڭىز، سۆھبەتلىرىڭىز، مەشغۇلات تىزىملىكلىرىڭىز ياكى نىشانلىرىڭىزنى ئۆزگەرتمەيدۇ.

## پروگراممىنى ئورنىتىش

تەلەپلەر: Python 3.10 ياكى تېخىمۇ يېڭى نەشرى ۋە Omi ھېساباتى.

> دىققەت: PyPI دىكى بوغچا نامى **`omi-cli`**, ئورنىتىلغاندىن كېيىن ئىجرا قىلىنىدىغان بۇيرۇق بولسا **`omi`**. PyPI دا مۇناسىۋەتسىز `omi` ناملىق باشقا بىر بوغچا بار — ئۇنى ئورناتماڭ.

ئەگەر `pipx` ئورنىتىلغان بولسا:

```sh
pipx install omi-cli
omi --help
```

باشقا بىر ئۇسۇلدا، ئاكتىپ بولغان Python مەۋھۇم مۇھىتىدا:

```sh
python -m pip install omi-cli
omi --help
```

ئەگەر تېرمىنال `omi` نى تاپالمىسا، مەۋھۇم مۇھىتنىڭ ئاكتىپلىقىنى ياكى `pipx` مۇندەرىجىسىنىڭ `PATH` ئىچىدە بار-يوقلۇقىنى تەكشۈرۈڭ.

## ھېساباتىڭىزنى ئۇلاش

ئۆزئارا ياردەمچىنى قوزغىتىڭ:

```sh
omi auth login
```

تور كۆرگۈچ ئارقىلىق كىرىشنى تاللاڭ، ياكى Omi ئاچقۇچى API ئاچقۇچىنى چاپلاشنى تاللاڭ. ئۆزئارا كىرگۈزۈش ئاچقۇچنى يوشۇرىدۇ؛ ئاچقۇچنى تېرمىنال خاتىرىسىدە قالىدىغان بۇيرۇقلارغا يازماڭ.

تور كۆرگۈچ ئارقىلىق بىۋاسىتە كىرىش ئۈچۈن:

```sh
omi auth login --browser
```

تېرمىنال ئىجرا قىلىنىۋاتقان كومپيۇتېردا كىرىشنى تاماملاڭ، چۈنكى دەلىللەش يەرلىك ئادرېسقا قايتىدۇ. ئېكراندىكى كۆرسەتمىلەرگە ئەمەل قىلىڭ.

ئۇنىڭدىن كېيىن تەڭشەك ۋە API زىيارەت ھوقۇقىنى تەكشۈرۈڭ:

```sh
omi auth status
omi auth whoami
```

`status` يەرلىك ھالەتنى كۆرسىتىدۇ ۋە مەخپىيەتلەرنى يوشۇرىدۇ، ئەمما مۇلازىمېتىر بىلەن دەلىللىمەيدۇ. `whoami` ھوقۇق بېرىلگەن تەلەپنى ئەۋەتىدۇ؛ مۇۋەپپەقىيەت سالاھىيەت گۇۋاھنامىلىرىڭىزنىڭ نورمال ئىشلەۋاتقانلىقىنى كۆرسىتىدۇ.

تەڭشەك ئادەتتە `~/.omi/config.toml` ئىچىدە ساقلىنىدۇ. بۇ ھۆججەتنى باشقىلار بىلەن ھەمبەھىرلىمەڭ، چۈنكى ئۇنىڭدا شەخسىي ئۇچۇرلىرىڭىز بار.

## سانلىق مەلۇماتلىرىڭىزنى كۆرۈش

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

بوش تىزىملىك پەقەت تەلەپكە ماس كېلىدىغان تۈرنىڭ يوقلۇقىنى بىلدۈرۈشى مۇمكىن. بىر بۇيرۇقنىڭ سۈزگۈچلىرىنى چۈشىنىش ئۈچۈن ياردەمنى كۆرۈڭ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ئېلىش ۋە بەتلەرنى ئايلاندۇرۇش

ئومۇمىي تاللانما `--json` نى بۇيرۇق گۇرۇپپىسىنىڭ **ئالدىغا** قويۇڭ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

بىرىنچى بۇيرۇق دەسلەپكى 25 خاتىرىنى سورايدۇ؛ ئىككىنچىسى كېيىنكى 25 نى سورايدۇ. شۇڭا بىر بەت تولۇق زاپاس نۇسخا ئەمەس. JSON چىقىرىش تولۇق كىملىكنى ساقلاپ قالىدۇ، جەدۋەللەر ئۇلارنى قىسقارتىشى مۇمكىن.

بىر بەتنى ھۆججەتكە ساقلاش ئۈچۈن:

```sh
omi --json memory list --limit 25 --offset 0 > xatire-bet-1.json
```

بۇ قايتا نىشانلاش يەرلىك ھۆججەت قۇرىدۇ ياكى ئالماشتۇرىدۇ. مەزمۇننى ئىشلىتىشتىن بۇرۇن، بۇيرۇقنىڭ مۇۋەپپەقىيەتلىك بولغانلىقىنى جەزملەشتۈرۈڭ. خاتالىقلار stderr غا يېزىلىدۇ؛ بوش ھۆججەت سانلىق مەلۇمات يوق دېگەنلىك ئەمەس. بۇ ھۆججەت شەخسىي ئۇچۇرلارنى ئۆز ئىچىگە ئېلىشى مۇمكىن: ئۇنى بىخەتەر ساقلاڭ.

## چىقىش (Log out)

```sh
omi auth logout
```

بۇ بۇيرۇق يەرلىكتە ساقلانغان سالاھىيەت گۇۋاھنامىلىرىنى چىقىرىپ تاشلايدۇ. مۇلازىمېتىردىكى ئاچقۇچنى بىكار قىلىش ئۈچۈن، ھېساباتىڭىزدىكى ئاچقۇچى باشقۇرۇشنى ئىشلىتىڭ.

باشقا بۇيرۇقلار ۋە ئىلغار تاللانمىلار ئۈچۈن ئىنگلىزچە ئاساسىي قوللانمىنى كۆرۈڭ:
[../README.md](../README.md) ۋە `omi --help`.
