# omi-cli بىلەن تۇنجى قەدەم

بۇ قوللانما ئۇيغۇرچىدە omi-cli نىڭ تۇنجى بۇيرۇقلىرىنى تونۇشتۇرىدۇ. بۇيرۇق ئىسىملىرى ۋە پروگرامما ئۇچۇرلىرى ئىنگلىزچە قالىدۇ. بۇ قوللانمىدىكى مىساللار سىزنىڭ ئەسلىمىلىرىڭىز، سۆھبەتلىرىڭىز، ھەرىكەت تۈرلىرىڭىز ياكى نىشانلىرىڭىزنى ئۆزگەرتمەيدۇ.

## قاچىلاش

سىزگە Python 3.10 ياكى ئۇنىڭدىن يېڭىراق، ۋە بىر Omi ھېساباتى كېرەك.

ئەگەر `pipx` ئاللىقاچان قاچىلانغان بولسا:

```sh
pipx install omi-cli
omi --help
```

ئۇنداق بولمىسا، ئۇنى ئاكتىپ Python خىيالىي مۇھىتتا قاچىلاڭ:

```sh
python -m pip install omi-cli
omi --help
```

ئەگەر تېرمىنال `omi` نى تاپالمىسا، خىيالىي مۇھىتنىڭ ئاكتىپلىقىنى ياكى pipx مۇندەرىجىسىنىڭ `$PATH` دا بارلىقىنى تەكشۈرۈڭ.

## ھېساباتىڭىزنى ئۇلاش

ئۆزئارا كىرىش يېتەكچىسىنى باشلاڭ:

```sh
omi auth login
```

سىز توركۆرگۈچ بىلەن كىرىشنى ياكى Omi تەرەققىياتچى API ئاچقۇچىنى قويۇشنى تاللىيالايسىز. ئۆزئارا كىرىش ئاچقۇچىڭىزنى يوشۇرىدۇ؛ ئېھتىيات قىلىڭ، ئۇنى تېرمىنال تارىخىغا قالدۇرماڭ.

توركۆرگۈچ بىلەن بىۋاسىتە كىرىش ئۈچۈن:

```sh
omi auth login --browser
```

تېرمىنال ئىجرا بولىدىغان ئوخشاش كومپيۇتېردا كىرىڭ: ئىجازەت جاۋابى يەرلىك ئادرېسنى ئىشلىتىدۇ. ئېكراندىكى كۆرسەتمىلەرگە ئەمەل قىلىڭ.

ھازىر سەپلىمە ۋە API ئاچقۇچىنى تەكشۈرۈڭ:

```sh
omi auth status
omi auth whoami
```

`status` يەرلىك ھالەتنى كۆرسىتىدۇ ۋە مەخپىيلەرنى يوشۇرىدۇ، ئەمما مۇلازىمېتەر بىلەن تەكشۈرمەيدۇ. `whoami` ئىجازەتلەنگەن تەلەپ قىلىدۇ؛ مۇۋەپپەقىيەت قازانسا، ئىجازىتىڭىزنىڭ ئىشلەيدىغانلىقىنى جەزملەيدۇ، ئەمما ئىسمىڭىزنى كۆرسەتمەيدۇ.

سەپلىمە `~/.omi/config.toml` دا ساقلىنىدۇ. بۇ ھۆججەتنى ھەمبەھرىلىمەڭ: ئۇنىڭدا كىرىش مەخپىيەتلىكى بولۇشى مۇمكىن.

## سانلىق مەلۇماتلارنى كۆرۈش

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

قۇرۇق تىزىملىك پەقەت تەلەپكە ماس كېلىدىغان سانلىق مەلۇمات يوقلۇقىنى بىلدۈرۈشى مۇمكىن. ھەر بىر بۇيرۇقنىڭ سۈزگۈچلىرىنى ئۆگىنىش ئۈچۈن ياردەمنى كۆرۈڭ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON چىقىرىشى ۋە بەت ئايرىش

ئومۇمىي `--json` تاللانمىسىنى بۇيرۇق گۇرۇپپىسىدىن **بۇرۇن** قويۇڭ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

بىرىنچى بۇيرۇق تۇنجى 25 ئەسلىمىنى ئالىدۇ؛ ئىككىنچىسى كېيىنكى 25 نى ئالىدۇ. بىر بەت كۆپىنچە تولۇق بولمايدۇ. JSON چىقىرىشى بارلىق شناسىتۇرلارنى ساقلايدۇ، ئېكراندىكى جەدۋەللەر ئۇلارنى كۆپىنچە قىسقارتىدۇ.

بىر بەتنى ھۆججەتكە يېزىش ئۈچۈن:

```sh
omi --json memory list --limit 25 --offset 0 > ئەسلىمە-بەت-1.json
```

قايتا يۆتكەش يەرلىك ھۆججەت يارىتىدۇ ياكى ئۈستىگە يازىدۇ. مەزمۇننى ئىشلىتىشتىن بۇرۇن بۇيرۇقنىڭ مۇۋەپپەقىيەتلىك بولغانلىقىنى تەكشۈرۈڭ. خاتالىقلار stderr غا كېتىدۇ؛ قۇرۇق ھۆججەت سانلىق مەلۇمات يوقلۇقىنى بىلدۈرمەيدۇ. چىقىرىلغان ھۆججەتلەردە شەخسىي ئۇچۇر بولۇشى مۇمكىن: ئۇلارنى بىخەتەر ساقلاڭ.

## چېكىنىش

```sh
omi auth logout
```

بۇ بۇيرۇق ساقلانغان يەرلىك ئىجازەتنى ئۆچۈرىدۇ. ئاچقۇچنى مۇلازىمېتەردە بىكار قىلىش ئۈچۈن ھېساباتىڭىزدىكى تەرەققىياتچى ئاچقۇچ باشقۇرۇشىنى ئىشلىتىڭ.

باشقا بۇيرۇقلار ۋە ئىلغار تاللانمىلار ئۈچۈن [ئىنگلىزچە ئاساسىي قوللانما](../README.md) ۋە `omi --help` نى كۆرۈڭ.
