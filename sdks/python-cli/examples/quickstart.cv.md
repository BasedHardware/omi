# omi-cli валли кӗске ҫулкӑтартмӑш

Ку ҫулкӑтартмӑш `omi-cli` валли малтанхи командӑсене чӑвашла (Chuvash) ӑнлантарать. Командӑсен ячӗсемпе программа пӗлтерӗвӗсем акӑлчанла юлаҫҫӗ. Кунта кӑтартнӑ тӗрӗслев тӗслӗхӗсем сирӗн асӑнмалӑхсене (memories), калаҫусене (conversations), ӗҫ пункчӗсене (action items) е тӗллевсене (goals) улӑштармаҫҫӗ.

## Программӑна лартасси (Installation)

Кирлӗ япаласем: Python 3.10 е ҫӗнӗрех версийӗ тата Omi аккаунт.

Эхер те сирӗн `pipx` лартиҫҫӗ пулсан:

```sh
pipx install omi-cli
omi --help
```

Ҫавӑн пекех ӑна ӗҫлекен Python виртуаллӑ хутлӑхне (virtual environment) лартма пулать:

```sh
python -m pip install omi-cli
omi --help
```

Эхер те терминалта `omi` команди тупӑнмасан, виртуаллӑ хутлӑх хастар пулнине е `pipx` лартнӑ ҫулӗ сирӗн `$PATH` хушшинче пулнине тӗрӗслӗр.

## Аккаунтӑра ҫыхӑнтарасси (Authentication)

Интерактивлӑ пулӑшакана пуҫлӑр:

```sh
omi auth login
```

Браузер урлӑ кӗрессине е Omi developer API key ҫыпӑҫтарассине суйлӑр. Интерактивлӑ кӗртни ҫӑлҫӑна пытарать; терминал историйӗнче юлакан командӑсенче ҫӑлҫӑна ан ҫырӑр.

Тӳррӗн браузера куҫас тесен:

```sh
omi auth login --browser
```

Терминал ӗҫлекен компьютертах кӗрӗр: аутентификаци хуравӗ вырӑнти адреспа усӑ курать. Экран ҫинчи кӑтартӑвене пӑхӑнӑр.

Ун хыҫҫӑн ӗҫ йӗркисемпе API-на кӗрес майсене тӗрӗслӗр:

```sh
omi auth status
omi auth whoami
```

`status` вырӑнти лару-тӑрӑва кӑтартать тата вӑрттӑнлӑха пытарать, анчах та сервер ҫинчи чӑн пулнине тӗрӗслемест. `whoami` тӗрӗсленӗ ыйту ярать; ӑнӑҫлӑ пулсан, сирӗн ята кӑтартмасӑрах креденциалсем ӗҫленине ҫирӗплетет.

Ӗҫ йӗркисем яланхилле `~/.omi/config.toml` файлта упранаҫҫӗ. Ку файла урӑх ҫынсене ан парӑр: унта вӑрттӑн креденциалсем пулма пултараҫҫӗ.

## Сирӗн даннӑйсене тӗрӗслесси (Inspection)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

Пушӑ список шыравпа пӗр килекен нимӗн те тупӑнманнине кӑна пӗлтерме пултарать. Кашни командӑри фильтрсене тупас тесен пулӑшӑва усӑ курӑр:

```sh
omi memory list --help
omi action-item list --help
```

## JSON илесси тата страницӑсене пайласси (Pagination)

Глобаллӑ `--json` опцине командӑсен ушкӑнӗ **умӗн** лартӑр:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

Пӗрремӗш команда малтанхи 25 асӑнмалӑха ыйтать; иккӗмӗшӗ — черетлӗ 25 асӑнмалӑха. Пӗр страница тулли резервлӑ копи (backup) мар. JSON кӑтартӑвӗ тулли идентификаторсене упрать, экран ҫинчи таблицӑсем вӗсене кӑтартма кӗскетме пултараҫҫӗ.

Страницӑна файла упрас тесен:

```sh
omi --json memory list --limit 25 --offset 0 > асанмалахсем-страница-1.json
```

Ку мел вырӑнти файла тӑвать е улӑштарать. Ӑшлӑхӗпе усӑ курас умӗн команда ӑнӑҫлӑ вӗҫленнине тӗрӗслӗр. Йӑнӑшсем йӑнӑшсен юхӑмне (stderr) ҫырӑнаҫҫӗ; пушӑ файл даннӑйсем ҫуккине пӗлтермест. Экспортланӑ файлта сирӗн хӑвӑр информаци пулма пултарать: ӑна асӑрханӑр.

## Аккаунтран тухасси (Logout)

```sh
omi auth logout
```

Ку команда вырӑнта упраннӑ креденциалсене кӑларса пӑрахать. Сервер ҫинчи ҫӑлҫӑна пӑрахӑҫлас тесен, хӑвӑр аккаунтӑрти developer key ертсе пырӑвӗпе усӑ курӑр.

Ытти командӑсемпе хушма майсем валли [акӑлчанла тӗп ҫулкӑтартмӑша](../README.md) тата `omi --help` пӑхӑр.
