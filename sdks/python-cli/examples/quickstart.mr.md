# omi-cli सह सुरुवातीची पावले

ही मार्गदर्शिका मराठीत सुरुवातीच्या आज्ञा (commands) स्पष्ट करते. आज्ञांची
नावे आणि प्रोग्रॅमचे संदेश इंग्रजीतच राहतील. येथे दिलेली उदाहरणे तुमच्या आठवणी,
संभाषणे, कार्ये किंवा उद्दिष्टांमध्ये कोणताही बदल करत नाहीत.

## प्रोग्रॅम इन्स्टॉल करणे

आवश्यकता: Python 3.10 किंवा नवीन आवृत्ती आणि एक Omi खाते.

तुमच्याकडे `pipx` इन्स्टॉल असल्यास:

```sh
pipx install omi-cli
omi --help
```

पर्याय म्हणून, तुम्ही एका सक्रिय Python व्हर्च्युअल एन्व्हायरनमेंटमध्ये हे इन्स्टॉल करू शकता:

```sh
python -m pip install omi-cli
omi --help
```

जर टर्मिनलला `omi` सापडले नाही, तर व्हर्च्युअल एन्व्हायरनमेंट सक्रिय असल्याची किंवा
`pipx` ज्या डिरेक्टरीमध्ये एक्झिक्युटेबल्स इन्स्टॉल करते ती तुमच्या `PATH` मध्ये असल्याची खात्री करा.

## तुमचे खाते कनेक्ट करणे

संवादी सहाय्यक (interactive assistant) सुरू करा:

```sh
omi auth login
```

ब्राउझरद्वारे लॉग इन करण्याचा पर्याय किंवा Omi डेव्हलपर API की पेस्ट करण्याचा पर्याय निवडा.
संवादी इनपुट की लपवून ठेवते; टर्मिनलच्या इतिहासात राहील अशा आज्ञेमध्ये की टाइप करणे टाळा.

थेट ब्राउझरवर जाण्यासाठी:

```sh
omi auth login --browser
```

टर्मिनल ज्या कॉम्प्युटरवर चालू आहे त्याच कॉम्प्युटरवर लॉग इन करा: प्रमाणीकरण
स्थानिक पत्ता वापरते. स्क्रीनवरील सूचनांचे पालन करा.

त्यानंतर, कॉन्फिगरेशन आणि API ऍक्सेस तपासा:

```sh
omi auth status
omi auth whoami
```

`status` स्थानिक स्थिती दर्शवते आणि गुप्त की लपवते, परंतु सर्व्हरवर तिची वैधता तपासत नाही.
`whoami` एक प्रमाणीकृत विनंती पाठवते; ती यशस्वी झाल्यास, तुमचे नाव न दाखवता तुमचे क्रेडेंशियल्स
कार्यरत असल्याची पुष्टी करते.

कॉन्फिगरेशन डीफॉल्टनुसार `~/.omi/config.toml` मध्ये सेव्ह केले जाते. ही फाइल इतरांशी शेअर करू नका:
यामध्ये तुमचे गुप्त क्रेडेंशियल्स असू शकतात.

## तुमचा डेटा पाहणे

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

रिकामी यादी म्हणजे फक्त विनंतीशी जुळणारे कोणतेही घटक उपलब्ध नाहीत असा असू शकतो.
प्रत्येक आज्ञेचे फिल्टर्स जाणून घेण्यासाठी मदतीचा वापर करा:

```sh
omi memory list --help
omi action-item list --help
```

## JSON मिळवणे आणि पेजेस नेव्हिगेट करणे

ग्लोबल पर्याय `--json` आज्ञा समूहाच्या **आधी** ठेवा:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

पहिली आज्ञा पहिल्या २५ आठवणींची विनंती करते; दुसरी, पुढील २५ आठवणींची.
त्यामुळे एकच पेज हा संपूर्ण बॅकअप नसतो. JSON आउटपुट संपूर्ण आयडेंटिफायर्स टिकवून ठेवते,
तर डिस्प्लेसाठी टेबल्स ते लहान करू शकतात.

एका फाइलमध्ये पेज सेव्ह करण्यासाठी:

```sh
omi --json memory list --limit 25 --offset 0 > आठवणी-पेज-१.json
```

हे पुनर्निर्देशन स्थानिक फाइल तयार करते किंवा पुनर्स्थित करते. सामग्री वापरण्यापूर्वी
आज्ञा यशस्वीरीत्या पूर्ण झाल्याची खात्री करा. त्रुटी एरर आउटपुटवर (stderr) लिहिल्या जातात;
रिकामी फाइल म्हणजे डेटा नाहीच अशी खात्री देत नाही. निर्यात केलेल्या फाइलमध्ये वैयक्तिक
माहिती असू शकते: ती सुरक्षित ठेवा.

## खात्यातून बाहेर पडणे (Logout)

```sh
omi auth logout
```

ही आज्ञा स्थानिक पातळीवर सेव्ह केलेले क्रेडेंशियल्स काढून टाकते. सर्व्हरवरून की रद्द करण्यासाठी,
तुमच्या खात्यातील डेव्हलपर की व्यवस्थापनाचा वापर करा.

इतर आज्ञा आणि प्रगत पर्यायांसाठी, [इंग्रजीतील मुख्य मार्गदर्शिका](../README.md) आणि `omi --help` पहा.
