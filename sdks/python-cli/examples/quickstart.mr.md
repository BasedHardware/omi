# omi-cli सोबत सुरुवात

हे मार्गदर्शक मराठीत सुरुवातीच्या काही आज्ञा कशा वापरायच्या हे दाखवते. आज्ञांची नावे आणि सिस्टीमचे संदेश इंग्रजीतच राहतील. येथे दिलेली वाचनाची उदाहरणे तुमच्या आठवणी, संभाषणे, कार्यसूची किंवा उद्दिष्टांमध्ये कोणताही बदल करत नाहीत.

## प्रोग्राम स्थापित (Install) करा

आवश्यकता: Python 3.10 किंवा नवीन आवृत्ती आणि एक Omi खाते.

> टीप: PyPI वर पॅकेजचे नाव **`omi-cli`** आहे, तर इन्स्टॉल केल्यानंतर चालणाऱ्या आज्ञेचे नाव **`omi`** आहे. PyPI वर `omi` नावाचे असंबद्ध पॅकेज देखील आहे — ते इन्स्टॉल करू नका.

जर `pipx` इन्स्टॉल असेल तर:

```sh
pipx install omi-cli
omi --help
```

किंवा, सक्रिय Python व्हर्च्युअल वातावरणात:

```sh
python -m pip install omi-cli
omi --help
```

टर्मिनलला `omi` आज्ञा सापडत नसल्यास, व्हर्च्युअल वातावरण सक्रिय आहे का किंवा `pipx` डिरेक्टरी तुमच्या `PATH` मध्ये समाविष्ट आहे का ते तपासा.

## आपले खाते जोडा

संवादी लॉगिन सुरू करा:

```sh
omi auth login
```

ब्राउझरद्वारे लॉगिन करा किंवा Omi डेव्हलपर API key पेस्ट करण्याचा पर्याय निवडा. संवादी इनपुट की लपवून ठेवते; टर्मिनल इतिहासात राहील अशा आज्ञेत की लिहू नका.

थेट ब्राउझरसाठी:

```sh
omi auth login --browser
```

ज्या संगणकावर टर्मिनल चालू आहे त्याच संगणकावर ब्राउझर लॉगिन पूर्ण करा, कारण प्रमाणीकरण स्थानिक पत्त्यावर परत येते. स्क्रीनवरील सूचनांचे पालन करा.

त्यानंतर कॉन्फिगरेशन आणि API प्रवेश तपासा:

```sh
omi auth status
omi auth whoami
```

`status` स्थानिक स्थिती दर्शवतो आणि गुप्त माहिती लपवतो, परंतु सर्व्हरवर पडताळणी करत नाही. `whoami` सर्व्हरला प्रमाणित विनंती पाठवतो; यशस्वी झाल्यास क्रेडेंशियल्स व्यवस्थित काम करत आहेत.

कॉन्फिगरेशन फाइल डीफॉल्टनुसार `~/.omi/config.toml` मध्ये जतन केली जाते. ही फाइल कोणाशीही शेअर करू नका: यात संवेदनशील माहिती असू शकते.

## आपला डेटा पहा

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

रिक्त सूचीचा अर्थ केवळ असा असू शकतो की क्वेरीशी जुळणारी कोणतीही नोंद नाही. एखाद्या आज्ञेचे फिल्टर जाणून घेण्यासाठी help पहा:

```sh
omi memory list --help
omi action-item list --help
```

## JSON आउटपुट आणि पेजिनेशन

ग्लोबल पर्याय `--json` आज्ञा समूहाच्या **आधी** ठेवा:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

पहिली आज्ञा पहिले २५ रेकॉर्ड आणि दुसरी पुढील २५ रेकॉर्ड मागवते. पूर्ण बॅकअपसाठी एकापेक्षा जास्त पाने आवश्यक असू शकतात. JSON आउटपुटमध्ये संपूर्ण अभिज्ञापक (identifiers) सुरक्षित राहतात.

एखादे पान फाइलमध्ये जतन करण्यासाठी:

```sh
omi --json memory list --limit 25 --offset 0 > aathvani-page-1.json
```

हे पुनर्निर्देशन स्थानिक फाइल तयार करते किंवा बदलते. त्रुटी stderr वर लिहिल्या जातात; रिक्त फाइल डेटा नसल्याचा अंतिम पुरावा नाही. निर्यात केलेल्या फाइलमध्ये वैयक्तिक माहिती असू शकते, म्हणून ती सुरक्षित ठेवा.

## लॉग आउट करा

```sh
omi auth logout
```

ही आज्ञा स्थानिक पातळीवर जतन केलेली क्रेडेंशियल्स काढून टाकते. सर्व्हरवर की रद्द करण्यासाठी वेब ॲपमधील डेव्हलपर कन्सोल वापरा.

इतर आज्ञा आणि प्रगत पर्यायांसाठी इंग्रजी मुख्य मार्गदर्शक पहा:
[../README.md](../README.md) आणि `omi --help`.
