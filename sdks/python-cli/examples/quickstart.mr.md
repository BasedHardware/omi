# omi-cli — मराठी क्विकस्टार्ट मार्गदर्शक

> टर्मिनलवरून Omi सोबत काम करण्यासाठी एक व्यावहारिक मार्गदर्शक. मानव आणि AI एजंट दोघांसाठीही योग्य.

`omi-cli` हा [Omi](https://omi.me) डेव्हलपर API चा अधिकृत कमांड-लाइन क्लायंट आहे.
तो Omi च्या चार मुख्य संस्थांसाठी — आठवणी, संभाषणे, कृती घटक आणि उद्दिष्टे — जलद आणि स्क्रिप्ट-योग्य प्रवेश देतो.

* **PyPI:** [pypi.org/project/omi-cli](https://pypi.org/project/omi-cli/)
* **दस्तऐवजीकरण:** [docs.omi.me/doc/developer/cli/introduction](https://docs.omi.me/doc/developer/cli/introduction)
* **स्रोत कोड:** [github.com/BasedHardware/omi/tree/main/sdks/python-cli](https://github.com/BasedHardware/omi/tree/main/sdks/python-cli)

---

## 1. इन्स्टॉलेशन

शिफारस केलेली पद्धत `pipx` आहे: ती साधन एका विलग वातावरणात इन्स्टॉल करते,
जेणेकरून त्याच्या अवलंबित्वाचा तुमच्या प्रकल्पांशी संघर्ष होत नाही.

```bash
# शिफारस: pipx ने इन्स्टॉल करा
pipx install omi-cli

# किंवा pip ने
pip install omi-cli
```

> **महत्त्वाचे: पॅकेजचे नाव आणि कमांडचे नाव वेगळे आहे.**
> * इन्स्टॉल होणारे पॅकेज **`omi-cli`** आहे (वेगळे पॅकेज `omi` हा दुसरा, असंबंधित प्रकल्प आहे).
> * इन्स्टॉलेशननंतर चालवली जाणारी कमांड **`omi`** आहे.

सर्व काही चालू आहे याची खात्री करा:

```bash
omi --version
omi --help
```

## 2. प्रमाणीकरण

`omi-cli` लॉग इनच्या दोन पद्धती समर्थित करते.

| पद्धत | योग्य | कमांड |
| :--- | :--- | :--- |
| **डेव्हलपर की (`omi_dev_*`)** | CI/CD, स्क्रिप्ट, AI एजंट | `omi auth login --api-key ...` किंवा पर्यावरण चल |
| **ब्राउझर लॉग इन (Google/Apple)** | स्वतःच्या संगणकावर काम | `omi auth login --browser` |

### इंटरॲक्टिव्ह लॉग इन

कोणतेही पर्याय न देता चालवा — कोणती पद्धत वापरायची ते विचारेल.

```bash
omi auth login
# 1) Browser — Google किंवा Apple ने लॉग इन (मानवांसाठी)
# 2) API key — app.omi.me वरून डेव्हलपर की पेस्ट करा (एजंट/CI साठी)
```

की निवडल्यास इनपुट लपविले जाते, त्यामुळे की टर्मिनलच्या इतिहासात राहात नाही.

### थेट ब्राउझरने लॉग इन

```bash
omi auth login --browser
```

### डेव्हलपर कीने लॉग इन

की [app.omi.me](https://app.omi.me) वर **Developer → API Keys** मध्ये मिळवा.

```bash
# की कॉन्फिगरेशनमध्ये जतन करा
omi auth login --api-key omi_dev_...

# किंवा पर्यावरणाद्वारे द्या — CI/CD आणि कंटेनरसाठी चांगले
export OMI_API_KEY=omi_dev_...
```

`OMI_API_KEY` पर्यावरण चल तेव्हा वापरला जातो जेव्हा सक्रिय प्रोफाइलमध्ये कोणतीही की
जतन केलेली नसते, म्हणून कंटेनरमध्ये डिस्कवर काही लिहिण्याची गरज नाही. प्रोफाइलमध्ये
आधीच की असल्यास ती पर्यावरण चलाच्या वर प्राधान्य घेते.

### प्रवेश सत्यापित करा

दोन कमांड वेगवेगळ्या प्रश्नांची उत्तरे देतात — त्या गोंधळात टाकू नका:

* `omi auth status` — **स्थानिक** काय जतन आहे: प्रोफाइल, मास्क केलेली की, कालबाह्यता तारीख.
  नेटवर्कशिवाय चालते.
* `omi auth whoami` — **Omi सर्व्हरवर** विनंती: की खरोखर स्वीकारली जाते हे सत्यापित करते.
  नेटवर्क आवश्यक.

```bash
omi auth status    # स्थानिक तपासणी, ऑफलाइन
omi auth whoami    # सर्व्हर तपासणी
```

कालबाह्य होणारा टोकन पुन्हा लॉग इन न करता रिन्यू करा — ही कमांड केवळ
**ब्राउझर/OAuth सत्रांसाठी** आहे. API की (`omi_dev_*`) ने प्रमाणित केलेल्या प्रोफाइलसाठी
`omi auth refresh` वापर त्रुटीने (कोड 1) अयशस्वी होते: रिन्यू करण्यासाठी टोकन नाही —
गरज असल्यास Omi वेब ॲपमध्ये की बदला:

```bash
omi auth refresh
```

लॉग आउट:

```bash
omi auth logout
```

## 3. मूलभूत कमांड

### आठवणी (memories)

सिस्टीमने तुमच्याबद्दल लक्षात ठेवलेली तथ्ये आणि ज्ञान.

```bash
# आठवणींची यादी
omi memory list

# नवीन तयार करा
omi memory create "वापरकर्त्याला गडद थीम आवडते" --category lifestyle

# एक विशिष्ट पहा
omi memory get <MEMORY_ID>
```

### संभाषणे (conversations)

उपकरण किंवा ॲपवरून आवाज आणि मजकूर इतिहास.

```bash
# अलीकडील 5 संभाषणे
omi conversation list --limit 5

# ट्रान्सक्रिप्टसह संपूर्ण संभाषण
omi conversation get <CONVERSATION_ID> --include-transcript
```

### कृती घटक (action items)

Omi ने संभाषणांमधून काढलेली कामे.

```bash
# फक्त उघडेले
omi action-item list --open

# पूर्ण म्हणून चिन्हांकित करा
omi action-item complete <ACTION_ITEM_ID>
```

### उद्दिष्टे (goals)

```bash
# उद्दिष्टांची यादी
omi goal list

# नवीन प्रगती मूल्य नोंदवा (दोन्ही आर्ग्युमेंट आवश्यक: उद्दिष्ट आणि मूल्य)
omi goal progress <GOAL_ID> 25

# बदलांचा इतिहास
omi goal history <GOAL_ID>
```

## नैसर्गिक भाषेत विचारा (`ask`)

एक वेगळी टॉप-लेव्हल कमांड: ती नैसर्गिक भाषेतील प्रश्न घेते,
आणि उत्तर तुमच्या संभाषणांमधून तयार होते.

```bash
omi ask "स्थानांतराबद्दल मी काय ठरवले"
omi --json ask "या आठवड्यात कोणते कृती घटक पूर्ण करण्याचे वचन दिले"
```

## 4. JSON आणि स्क्रिप्ट (`--json`)

`omi-cli` मशीन-वाचनीय JSON तयार करू शकते. `--json` पर्याय **ग्लोबल** आहे
त्यामुळे तो सबकमांडच्या **आधी** ठेवावा लागतो.

```bash
# आठवणी: id, मजकूर आणि श्रेणी काढा
omi --json memory list | jq '.[] | {id, content, category}'

# अलीकडील संभाषणांचे शीर्षके
omi --json conversation list --limit 5 | jq '.[] | {id, title: .structured.title, started_at}'

# उघडेले कृती घटक
omi --json action-item list --open | jq '.'
```

> **सामान्य चूक.** `--json` सबकमांडच्या आधी येते, नंतर नाही.
> * योग्य: `omi --json memory list`
> * चुकीचे: `omi memory list --json`

`--json` मोडमध्ये मानवांसाठीचे प्रगती संदेश आणि स्पिनर नाहीसे होतात —
stdout मध्ये फक्त एक वैध JSON दस्तऐवज असतो. त्रुटी
`{"error": "...", "detail": "..."}` स्वरूपात stderr वर जातात.

## 5. एक्झिट कोड

स्क्रिप्टमध्ये निर्णय घेण्यासाठी स्थिर एक्झिट कोड.

| कोड | अर्थ |
| :--- | :--- |
| `0` | यशस्वी |
| `1` | वापर त्रुटी (चुकीचा फ्लॅग, आवश्यक आर्ग्युमेंट गहाळ) |
| `2` | प्रमाणीकरण अयशस्वी — लॉग इन आवश्यक |
| `3` | सर्व्हर/नेटवर्क त्रुटी |
| `4` | दर मर्यादा — नंतर पुन्हा प्रयत्न करा |
| `5` | संसाधन सापडले नाही |

```bash
if ! omi memory get "$MEMO_ID" --json > /tmp/m.json; then
  code=$?
  case $code in
    2) omi auth login --browser ;;
    5) echo "त्या आठवणी अस्तित्वात नाही" ;;
    *) echo "त्रुटी $code" ;;
  esac
fi
```

## 6. प्रोफाइल आणि कॉन्फिगरेशन

अनेक खाती किंवा वातावरण असल्यास ती प्रोफाइलने विभक्त करा.
सेटिंग्ज `~/.omi/config.toml` मध्ये जतन होतात.

```bash
# वैयक्तिक प्रोफाइलमध्ये लॉग इन
omi --profile personal auth login

# कार्य प्रोफाइलमध्ये लॉग इन
omi --profile work auth login

# विशिष्ट प्रोफाइलमध्ये कमांड चालवा
omi --profile work memory list
```

वापरला जाणारा प्रोफाइल या क्रमाने ठरतो: `--profile` पर्याय (किंवा `-p`)
सर्वांवर प्राधान्य घेतो; मग `OMI_PROFILE` पर्यावरण चल; मग `~/.omi/config.toml`
मधील सक्रिय प्रोफाइल; आणि शेवटी `default` प्रोफाइल राखीव म्हणून.

स्वतःचे कॉन्फिगरेशन पहा आणि बदला:

```bash
# आत्ता काय सेट आहे
omi config show

# कॉन्फिगरेशन फाइल कुठे आहे
omi config path

# मूल्य बदला
omi config set api_base https://api.omi.me
```
