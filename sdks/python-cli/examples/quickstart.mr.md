# omi-cli सह झटपट सुरुवात

हा मार्गदर्शक मराठीत मूलभूत आज्ञा समजावतो. आज्ञांची नावे आणि प्रोग्राम संदेश
इंग्रजीतच राहतात. खालील उदाहरणांच्या आज्ञा तुमच्या आठवणी, संभाषणे, कृती
तुकडे किंवा ध्येये बदलत नाहीत.

## प्रोग्राम स्थापित करणे

आवश्यकता: Python 3.10 किंवा नवीन आणि Omi खाते.

`pipx` स्थापित असल्यास:

```sh
pipx install omi-cli
omi --help
```

किंवा सक्रिय केलेल्या Python virtual environment मध्ये स्थापित करा:

```sh
python -m pip install omi-cli
omi --help
```

टर्मिनलला `omi` सापडत नसेल तर virtual environment सक्रिय आहे का किंवा `pipx`
ने executable ज्या फोल्डरमध्ये ठेवले ते `PATH` मध्ये आहे का, ते तपासा.

## खाते जोडणे

इंटरॲक्टिव्ह मार्गदर्शक चालवा:

```sh
omi auth login
```

ब्राउझर लॉगिन निवडा किंवा Omi डेव्हलपर API key पेस्ट करा. इंटरॲक्टिव्ह इनपुट
key लपवते; ती टर्मिनल इतिहासात साठवल्या जाणाऱ्या आज्ञांत टाइप करू नका.

ब्राउझर थेट वापरण्यासाठी:

```sh
omi auth login --browser
```

टर्मिनल असलेल्या त्याच संगणकावर लॉगिन करा, कारण प्रमाणीकरण स्थानिक callback
पत्ता वापरते. स्क्रीनवरील सूचना पाळा.

लॉगिननंतर कॉन्फिगरेशन आणि API प्रवेश तपासा:

```sh
omi auth status
omi auth whoami
```

`status` स्थानिक स्थिती दाखवते आणि गुप्त मूल्ये लपवते, पण त्यांची सर्व्हरवरील
वैधता तपासत नाही. `whoami` प्रमाणित विनंती पाठवते; यशस्वी झाल्यास तुमच्या
credentials कार्यरत आहेत — तुमचे नाव न दाखवता.

कॉन्फिगरेशन डीफॉल्टनुसार `~/.omi/config.toml` मध्ये साठवते. ही फाईल शेअर करू
नका कारण त्यात credentials असू शकतात.

## तुमचा डेटा वाचणे

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

रिकामी यादी म्हणजे फिल्टरशी जुळणारे घटक नाहीत असेही होऊ शकते. प्रत्येक
आज्ञेचे पर्याय help मध्ये पाहा:

```sh
omi memory list --help
omi action-item list --help
```

## JSON मिळवणे आणि पृष्ठे मागवणे

ग्लोबल `--json` पर्याय कमांड गटाच्या **आधी** ठेवा:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

पहिली आज्ञा पहिल्या 25 आठवणी मागवते; दुसरी पुढील 25. एक पृष्ठ पूर्ण बॅकअप
नाही. JSON आउटपुट संपूर्ण ID ठेवते, तर टेबल दर्शनासाठी ID छोटे करू शकते.

एक पृष्ठ फाइलमध्ये साठवण्यासाठी:

```sh
omi --json memory list --limit 25 --offset 0 > memory-pan-1.json
```

रीडायरेक्शन स्थानिक फाइल बनवते किंवा तिच्यावर लिहिते. मजकूर वापरण्यापूर्वी
आज्ञा यशस्वीरीत्या पूर्ण झाली का ते तपासा. एरर्स stderr वर लिहिल्या जातात;
रिकामी फाइल म्हणजे डेटा नाहीच असे सिद्ध होत नाही. एक्सपोर्ट फाइलमध्ये वैयक्तिक
माहिती असू शकते — ती खाजगी ठेवा.

## प्रोफाइल वापरणे

स्टेट `~/.omi/config.toml` मध्ये साठवते (`$OMI_CONFIG` ने बदलता येते). प्रत्येक
प्रोफाइलला स्वतःची प्रमाणीकरण पद्धत आणि API पत्ता असतो. `--profile` ने बदला:

```sh
omi config profile use काम
omi auth login
omi --profile वैयक्तिक memory list
```

सामान्य कॉन्फिगरेशन आज्ञा:

```sh
omi config show
omi config path
omi config profile list
```

## एक्झिट कोड

हे एक्झिट कोड स्थिर असून स्क्रिप्ट किंवा एजंट्ससाठी उपयोगी आहेत:

| कोड | अर्थ | उदाहरण स्थिती |
| ---: | --- | --- |
| 0 | यशस्वी | आज्ञा पूर्ण झाली |
| 1 | वापर-चूक | चुकीचा फ्लॅग, अर्ग्युमेंट कमी किंवा व्हॅलिडेशन अयशस्वी |
| 2 | प्रमाणीकरण-चूक | credentials नाहीत, टोकन कालबाह्य किंवा परवानग्या कमी |
| 3 | सर्व्हर-चूक | सर्व्हर 5xx किंवा कनेक्शन अयशस्वी |
| 4 | दर-मर्यादा | सर्व्हरने HTTP 429 परत केला |
| 5 | सापडले नाही | सर्व्हरने HTTP 404 परत केला |

## लॉगआउट

```sh
omi auth logout
```

स्थानिक साठवलेली credentials काढून टाकते. सर्व्हरवर key मागे घेण्यासाठी
तुमच्या खात्यातील developer key व्यवस्थापन वापरा.

अधिक आज्ञा व पर्यायांसाठी [इंग्रजी मुख्य README](../README.md) पाहा आणि
`omi --help` चालवा.
