# omi-cli सोबत सुरुवात (Marathi Quickstart)

हे मार्गदर्शक मराठीमध्ये `omi-cli` च्या मूलभूत आज्ञा (commands) समजावून सांगते. आज्ञांची नावे आणि संगणकाचे संदेश इंग्रजीत राहतात. येथे दिलेली उदाहरणे तुमच्या आठवणी, संभाषणे, कार्य-सूची किंवा ध्येयांमध्ये कोणताही बदल न करता फक्त माहिती वाचतात.

## १. प्रोग्रॅम इन्स्टॉल करा

**आवश्यकता:** Python 3.10 किंवा त्याहून नवीन आवृत्ती आणि एक Omi खाते.

> **महत्त्वाची सूचना:** PyPI वर पॅकेजचे नाव **`omi-cli`** आहे, परंतु इन्स्टॉलेशननंतर टर्मिनलवर चालणाऱ्या आज्ञेचे नाव **`omi`** आहे. PyPI वर `omi` नावाचे एक वेगळे, असंबंधित पॅकेजही उपलब्ध आहे — ते चुकूनही इन्स्टॉल करू नका.

जर तुमच्याकडे `pipx` इन्स्टॉल असेल:

```sh
pipx install omi-cli
omi --help
```

किंवा, सक्रिय Python व्हर्च्युअल एन्व्हायरनमेंट (virtualenv) मध्ये:

```sh
python -m pip install omi-cli
omi --help
```

जर टर्मिनलला `omi` आज्ञा सापडत नसेल, तर व्हर्च्युअल एन्व्हायरनमेंट सक्रिय असल्याची किंवा `pipx` ची डायरेक्टरी तुमच्या `PATH` मध्ये समाविष्ट असल्याची खात्री करा.

## २. आपले खाते जोडा (प्रमाणीकरण)

खाते जोडण्यासाठी संवाद सुरू करा:

```sh
omi auth login
```

ब्राउझरद्वारे लॉगिन निवडा किंवा तुमची Omi डेव्हलपर API key पेस्ट करा. थेट ब्राउझर लॉगिनसाठी:

```sh
omi auth login --browser
```

लॉगिन त्याच संगणकावर करा ज्यावर टर्मिनल चालू आहे, कारण प्रमाणीकरण स्थानिक पत्त्यावर (localhost) परत फिरते.

त्यानंतर जोडणीची स्थिती आणि API प्रवेश तपासा:

```sh
omi auth status
omi auth whoami
```

`status` स्थानिक स्थिती दाखवते आणि गुपिते (secrets) लपवते. `whoami` हे थेट सर्व्हरला विनंती पाठवून क्रेडेन्शियल्स व्यवस्थित काम करत असल्याची खात्री करते.

कॉन्फिगरेशन डीफॉल्टनुसार `~/.omi/config.toml` मध्ये साठवले जाते. ही फाईल सुरक्षित ठेवा, कारण यामध्ये तुमच्या खात्याच्या चाव्या असतात.

## ३. तुमचा डेटा पहा

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

एखाद्या संभाषणाचा संपूर्ण ट्रान्सक्रिप्ट पाहण्यासाठी:

```sh
omi conversation get <CONVERSATION_ID> --include-transcript
```

रिक्त यादीचा अर्थ केवळ असा असू शकतो की शोधलेल्या निकषांशी जुळणारी माहिती नाही. कोणत्याही आज्ञेचे पर्याय पाहण्यासाठी `--help` वापरा:

```sh
omi memory list --help
omi conversation list --help
omi goal list --help
```

## ४. JSON स्वरूप आणि पृष्ठांकन (Pagination)

जागतिक पर्याय `--json` नेहमी आज्ञा समूहाच्या **आधी** लिहा:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

पहिली आज्ञा पहिली २५ नोंदणी मागवते; दुसरी आज्ञा पुढील २५ नोंदणी मागवते.

माहिती फाईलमध्ये साठवण्यासाठी (Export):

```sh
omi --json memory list --limit 25 --offset 0 > athavani-page-1.json
```

## ५. लॉग आउट करा

स्थानिक प्रणालीवरून तुमचे क्रेडेन्शियल्स काढण्यासाठी:

```sh
omi auth logout
```

हे केवळ स्थानिक संगणकावरून क्रेडेन्शियल्स काढून टाकते. सर्व्हरवरून की पूर्णपणे रद्द करण्यासाठी Omi डेव्हलपर डॅशबोर्ड वापरा.

अधिक माहिती आणि प्रगत पर्यायांसाठी मुख्य इंग्रजी संदर्भ मार्गदर्शक पहा: [../README.md](../README.md) आणि [agent_quickstart.md](agent_quickstart.md).
