# omi-cli සමඟ මූලික පියවර

මෙම මාර්ගෝපදේශය මඟින් මූලික විධානයන් සිංහලෙන් පැහැදිලි කරයි. විධාන නාම සහ
වැඩසටහන් පණිවිඩ ඉංග්‍රීසි භාෂාවෙන් පවතී. මෙහි දැක්වෙන විමසුම් උදාහරණ මඟින්
ඔබගේ මතකයන්, සංවාද, කාර්යයන් හෝ ඉලක්ක වෙනස් නොවේ.

## වැඩසටහන ස්ථාපනය කිරීම

අවශ්‍යතා: Python 3.10 හෝ ඊට පසු අනුවාදයක් සහ Omi ගිණුමක්.

ඔබ සතුව `pipx` ස්ථාපනය කර ඇත්නම්:

```sh
pipx install omi-cli
omi --help
```

විකල්පයක් ලෙස, සක්‍රිය කරන ලද Python virtual environment එකක් තුළ ස්ථාපනය කළ හැක:

```sh
python -m pip install omi-cli
omi --help
```

ටර්මිනලයට `omi` විධානය සොයාගත නොහැකි නම්, virtual environment එක සක්‍රියද යන්න
හෝ `pipx` මඟින් ගොනු ස්ථාපනය කරන බහලුම ඔබගේ `PATH` හි ඇත්දැයි පරීක්ෂා කරන්න.

## ඔබගේ ගිණුම සම්බන්ධ කිරීම

අන්තර්ක්‍රියාකාරී සහායකයා ආරම්භ කරන්න:

```sh
omi auth login
```

බ්‍රව්සරය හරහා පිවිසීම හෝ Omi developer API key එකක් ඇතුළත් කිරීමේ විකල්පය තෝරන්න.
මෙමඟින් key එක සඟවා තබයි; ටර්මිනල් ඉතිහාසයේ රැඳෙන පරිදි එය විධානයක් ලෙස ලිවීමෙන් වළකින්න.

සෘජුවම බ්‍රව්සරයට යාමට:

```sh
omi auth login --browser
```

ටර්මිනලය ක්‍රියාත්මක වන පරිගණකයෙන්ම පිවිසෙන්න: සත්‍යාපන ප්‍රතිචාරය දේශීය ලිපිනයක් භාවිතා කරයි.
තිරයේ ඇති උපදෙස් අනුගමනය කරන්න.

ඉන්පසු වින්‍යාසය සහ API ප්‍රවේශය තහවුරු කරන්න:

```sh
omi auth status
omi auth whoami
```

`status` මඟින් දේශීය තත්ත්වය පෙන්වන අතර රහස්‍ය තොරතුරු සඟවයි, නමුත් සේවාදායකයේ වලංගුභාවය පරීක්ෂා නොකරයි.
`whoami` සත්‍යාපිත ඉල්ලීමක් යවයි; එය සාර්ථක වුවහොත්, ඔබගේ නම ප්‍රදර්ශනය කිරීමකින් තොරව ඔබගේ පිවිසුම් තොරතුරු ක්‍රියා කරන බව තහවුරු කරයි.

වින්‍යාසය පෙරනිමියෙන් `~/.omi/config.toml` හි සුරැකේ. මෙම ගොනුව අන් අය සමඟ බෙදා නොගන්න:
එහි ඔබගේ රහස්‍ය පිවිසුම් තොරතුරු අඩංගු විය හැක.

## ඔබගේ දත්ත පරීක්ෂා කිරීම

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

හිස් ලැයිස්තුවකින් අදහස් විය හැක්කේ විමසුමට ගැලපෙන අයිතම නොමැති බවයි.
එක් එක් විධානයේ පෙරහන් දැන ගැනීමට උදවු භාවිතා කරන්න:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ලබා ගැනීම සහ පිටු අතර සැරිසැරීම

ගෝලීය විකල්පය වන `--json` විධාන සමූහයට **පෙර** යොදන්න:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

පළමු විධානය මඟින් පළමු මතකයන් 25 ඉල්ලා සිටින අතර දෙවැන්න මඟින් ඊළඟ 25 ඉල්ලා සිටී.
එබැවින් එක් පිටුවක් සම්පූර්ණ උපස්ථයක් නොවේ. JSON ප්‍රතිදානය සම්පූර්ණ හැඳුනුම්කාරක රඳවා තබා ගනී.

පිටුවක් ගොනුවක සුරැකීමට:

```sh
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
```

මෙමඟින් දේශීය ගොනුව නිර්මාණය කිරීම හෝ ප්‍රතිස්ථාපනය කිරීම සිදු කරයි. අන්තර්ගතය භාවිතා කිරීමට පෙර විධානය සාර්ථකව අවසන් වූ බවට සහතික වන්න.
දෝෂ stderr වෙත ලියනු ලැබේ; හිස් ගොනුවක් දත්ත නොමැති බවට සහතික නොවේ.
අපනයනය කරන ලද ගොනුවේ පුද්ගලික තොරතුරු අඩංගු විය හැක: එය පුද්ගලිකව තබා ගන්න.

## ගිණුමෙන් ඉවත් වීම (Logout)

```sh
omi auth logout
```

මෙම විධානය දේශීයව සුරකින ලද පිවිසුම් තොරතුරු මකා දමයි. සේවාදායකයේ key එකක් අවලංගු කිරීමට
ඔබගේ ගිණුමේ developer keys කළමනාකරණය භාවිතා කරන්න.

අනෙකුත් විධාන සහ උසස් විකල්ප සඳහා [ප්‍රධාන ඉංග්‍රීසි මාර්ගෝපදේශය](../README.md) සහ `omi --help` බලන්න.
