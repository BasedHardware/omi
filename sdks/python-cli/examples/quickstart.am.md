# ከ omi-cli ጋር መጀመር

ይህ መመሪያ በአማርኛ የመጀመሪያዎቹን ጥቂት ትዕዛዞች ያሳያል። የትዕዛዝ ስሞች እና የስርዓት መልዕክቶች በእንግሊዝኛ ይቆያሉ። እዚህ የተሰጡት የንባብ ምሳሌዎች የእርስዎን ትውስታዎች፣ ንግግሮች፣ የተግባር ዝርዝሮች ወይም ግቦች አይለውጡም።

## ፕሮግራሙን ይጫኑ

መስፈርቶች፡ Python 3.10 ወይም ከዚያ በላይ እና የ Omi መለያ።

> ማስታወሻ፡ በ PyPI ላይ የጥቅሉ ስም **`omi-cli`** ነው፤ ከተጫነ በኋላ የሚሠራው ትዕዛዝ ግን **`omi`** ነው። በ PyPI ላይ `omi` የሚባል ያልተዛመደ የተለየ ጥቅል አለ — እርሱን አይጫኑ።

`pipx` ከተጫነ፡

```sh
pipx install omi-cli
omi --help
```

በአማራጭ፣ በነቃ የ Python ቨርቹዋል አካባቢ ውስጥ፡

```sh
python -m pip install omi-cli
omi --help
```

ተርሚናሉ `omi` ማግኘት ካልቻለ፣ ቨርቹዋል አካባቢው ንቁ መሆኑን ወይም የ `pipx` ዳይሬክቶሪ በ `PATH` ውስጥ መኖሩን ያረጋግጡ።

## መለያዎን ያገናኙ

ተደጋጋፊ ረዳቱን ያስጀምሩ፡

```sh
omi auth login
```

በድር አሳሽ መግባት ይምረጡ፣ ወይም የ Omi ገንቢ የኤፒአይ ቁልፍ (API key) የመለጠፍ አማራጭ ይምረጡ። ረዳቱ ቁልፉን ይደብቃል፤ በተርሚናል ታሪክ ውስጥ በሚቀመጡ ትዕዛዞች ውስጥ ቁልፉን አይተይቡ።

በቀጥታ በድር አሳሽ ለመግባት፡

```sh
omi auth login --browser
```

ማረጋገጫው ወደ አካባቢያዊ አድራሻ ስለሚመለስ ተርሚናሉ በሚሠራበት ኮምፒውተር ላይ ይግቡ። በማያ ገጹ ላይ የሚታዩትን መመሪያዎች ይከተሉ።

ከዚያ በኋላ ውቅረቱን እና የኤፒአይ መዳረሻን ይፈትሹ፡

```sh
omi auth status
omi auth whoami
```

`status` የአካባቢውን ሁኔታ ያሳያል እና ሚስጥሮችን ይደብቃል፣ ነገር ግን ከአገልጋዩ ጋር አያረጋግጥም። `whoami` የተፈቀደ ጥያቄ ይልካል፤ ስኬታማ መሆኑ ምስክርነቶች በትክክል እየሠሩ መሆናቸውን ያረጋግጣል።

ውቅረቱ በነባሪነት በ `~/.omi/config.toml` ውስጥ ይቀመጣል። ይህ ፋይል የግል ምስክርነቶችዎን ስለሚይዝ ለሌሎች አያጋሩት።

## የእርስዎን ውሂብ ይመልከቱ

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ባዶ ዝርዝር ማለት ከጥያቄው ጋር የሚዛመድ ንጥል አልተገኘም ማለት ብቻ ሊሆን ይችላል። የትዕዛዞቹን ማጣሪያዎች ለማየት እገዛን ይመልከቱ፡

```sh
omi memory list --help
omi action-item list --help
```

## JSON ማግኘት እና ገጾችን ማሰስ

አጠቃላይ አማራጩን `--json` ከትዕዛዝ ቡድኑ **በፊት** ያስቀምጡ፡

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

የመጀመሪያው ትዕዛዝ የመጀመሪያዎቹን 25 መዝገቦች ይጠይቃል፤ ሁለተኛው ደግሞ ቀጣዮቹን 25 ይጠይቃል። ስለዚህ አንድ ገጽ ሙሉ ምትኬ አይደለም። የ JSON ውፅዓት ሙሉ መለያዎችን ይይዛል፤ ሰንጠረዦች ግን ሊያሳጥሯቸው ይችላሉ።

አንድን ገጽ ወደ ፋይል ለማስቀመጥ፡

```sh
omi --json memory list --limit 25 --offset 0 > tiwistawot-gets-1.json
```

ይህ አቅጣጫ መቀየር የአካባቢ ፋይል ይፈጥራል ወይም ይተካል። ይዘቱን ከመጠቀምዎ በፊት ትዕዛዙ በተሳካ ሁኔታ መከናወኑን ያረጋግጡ። ስህተቶች በ stderr ላይ ይጻፋሉ፤ ባዶ ፋይል ውሂብ የለም የሚል ማረጋገጫ አይደለም። የተቀመጠው ፋይል የግል መረጃ ሊይዝ ስለሚችል ሚስጥራዊነቱን ይጠብቁ።

## ውጣ (Log out)

```sh
omi auth logout
```

ይህ ትዕዛዝ በአካባቢው የተቀመጡትን ምስክርነቶች ያስወግዳል። በአገልጋዩ ላይ ያለውን ቁልፍ ለመሰረዝ በመለያዎ ውስጥ ያለውን የገንቢ ቁልፍ አስተዳደር ይጠቀሙ።

ለሌሎች ትዕዛዞች እና ተጨማሪ አማራጮች፣ እባክዎን ዋናውን የእንግሊዝኛ መመሪያ ይመልከቱ፡
