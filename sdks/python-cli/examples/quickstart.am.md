# በ omi-cli የመጀመሪያ እርምጃዎች

ይህ መመሪያ የመጀመሪያዎቹን ትዕዛዞች በአማርኛ ያብራራል። የትዕዛዝ ስሞች እና የፕሮግራሙ
መልዕክቶች በእንግሊዝኛ ይቆያሉ። እዚህ የሚታዩት የጥያቄ ምሳሌዎች የእርስዎን ትውስታዎች፣
ውይይቶች፣ ተግባራት ወይም ግቦች አይለውጡም።

## ፕሮግራሙን መጫን

መስፈርቶች፡ Python 3.10 ወይም ከዚያ በላይ እና የ Omi መለያ።

`pipx` ከተጫነዎት፡

```sh
pipx install omi-cli
omi --help
```

በአማራጭ፣ በተሰራ የ Python ቨርቹዋል አካባቢ (virtual environment) ውስጥ መጫን ይችላሉ፡

```sh
python -m pip install omi-cli
omi --help
```

ተርሚናሉ `omi`ን ካላገኘው፣ ቨርቹዋል አካባቢው መስራቱን ወይም `pipx` ፋይሎችን የሚጭንበት
አድራሻ በ `PATH` ውስጥ መኖሩን ያረጋግጡ።

## መለያዎን ማገናኘት

የመስተጋብር ረዳቱን ይጀምሩ፡

```sh
omi auth login
```

በብሮውዘር በኩል መግባትን ወይም የ Omi ገንቢ API ቁልፍን የመለጠፍ አማራጭን ይምረጡ።
የመስተጋብር ማስገቢያው ቁልፉን ይደብቃል፤ በተርሚናል ታሪክ ውስጥ በሚቀረው ትዕዛዝ ላይ እንዳይጽፉት ይጠንቀቁ።

በቀጥታ ወደ ብሮውዘር ለመሄድ፡

```sh
omi auth login --browser
```

ተርሚናሉ በሚሰራበት ኮምፒውተር ላይ ይግቡ፡ የማረጋገጫ ምላሹ የአካባቢ አድራሻን ይጠቀማል።
በስክሪኑ ላይ የሚታዩትን መመሪያዎች ይከተሉ።

ከዚያ በኋላ ውቅረቱን እና የ API መዳረሻን ያረጋግጡ፡

```sh
omi auth status
omi auth whoami
```

`status` የአካባቢውን ሁኔታ ያሳያል እንዲሁም ምስጢሩን ይደብቃል፣ ነገር ግን በሰርቨሩ ላይ
ትክክለኛነቱን አያረጋግጥም። `whoami` የተረጋገጠ ጥያቄ ይልካል፤ ከተሳካ፣ ስምዎ የግድ ሳይታይ
ማስረጃዎችዎ እየሰሩ መሆናቸውን ያረጋግጣል።

ውቅረቱ በነባሪነት በ `~/.omi/config.toml` ውስጥ ይቀመጣል። ይህንን ፋይል ለሌሎች አያጋሩ፡
የእርስዎን ሚስጥራዊ መረጃዎች ሊይዝ ይችላል።

## ውሂብዎን መመልከት

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ባዶ ዝርዝር በቀላሉ ከጥያቄው ጋር የሚዛመዱ ነገሮች አለመኖራቸውን ሊያመለክት ይችላል።
የእያንዳንዱን ትዕዛዝ ማጣሪያዎች ለማወቅ እገዛን ይጠቀሙ፡

```sh
omi memory list --help
omi action-item list --help
```

## JSON ማግኘት እና ገጾችን ማሰስ

ዓለም አቀፋዊውን `--json` ምርጫ ከትዕዛዝ ቡድኑ **በፊት** ያስቀምጡ፡

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

የመጀመሪያው ትዕዛዝ የመጀመሪያዎቹን 25 ትውስታዎች ይጠይቃል፤ ሁለተኛው ቀጣዮቹን 25።
ስለዚህ አንድ ገጽ የተሟላ መጠባበቂያ (backup) አይደለም። የ JSON ውጤት ሙሉ መለያዎችን
ይጠብቃል፣ የስክሪን ሠንጠረዦች ግን ለማሳየት ሊያሳጥሯቸው ይችላሉ።

አንድን ገጽ በፋይል ውስጥ ለማስቀመጥ፡

```sh
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
```

ይህ አቅጣጫ መቀየር የአካባቢውን ፋይል ይፈጥራል ወይም ይተካል። ይዘቱን ከመጠቀምዎ በፊት
ትዕዛዙ በተሳካ ሁኔታ መጠናቀቁን ያረጋግጡ። ስህተቶች በስህተት ውጤት (stderr) ላይ ይፃፋሉ፤
ባዶ ፋይል ውሂብ አለመኖሩን አያረጋግጥም። የወጣው ፋይል የግል መረጃ ሊይዝ ይችላል፡ በሚስጥር ይያዙት።

## ከመለያ መውጣት (Logout)

```sh
omi auth logout
```

ይህ ትዕዛዝ በአካባቢው የተቀመጡ ማስረጃዎችን ይሰርዛል። በሰርቨሩ ላይ ቁልፍን ለመሰረዝ
በመለያዎ ውስጥ የገንቢ ቁልፎች አስተዳደርን ይጠቀሙ።

ለተቀሩት ትዕዛዞች እና የላቁ አማራጮች፣ [ዋናውን የእንግሊዝኛ መመሪያ](../README.md) እና `omi --help` ይመልከቱ።
