# omi-cli ਨਾਲ ਸ਼ੁਰੂਆਤ (Punjabi Quickstart)

ਇਹ ਗਾਈਡ ਪੰਜਾਬੀ ਵਿੱਚ `omi-cli` ਦੀਆਂ ਮੁੱਖ ਕਮਾਂਡਾਂ ਬਾਰੇ ਦੱਸਦੀ ਹੈ। ਕਮਾਂਡਾਂ ਦੇ ਨਾਮ ਅਤੇ ਸਿਸਟਮ ਸੁਨੇਹੇ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਹੀ ਰਹਿਣਗੇ। ਇੱਥੇ ਦਿੱਤੀਆਂ ਉਦਾਹਰਣਾਂ ਤੁਹਾਡੀਆਂ ਯਾਦਾਂ, ਗੱਲਬਾਤ, ਕੰਮਾਂ ਜਾਂ ਟੀਚਿਆਂ ਵਿੱਚ ਬਿਨਾਂ ਕੋਈ ਬਦਲਾਅ ਕੀਤੇ ਸਿਰਫ਼ ਡਾਟਾ ਪੜ੍ਹਦੀਆਂ ਹਨ।

## 1. ਪ੍ਰੋਗਰਾਮ ਇੰਸਟਾਲ ਕਰੋ (Installation)

**ਲੋੜਾਂ:** Python 3.10 ਜਾਂ ਨਵਾਂ ਸੰਸਕਰਣ ਅਤੇ ਇੱਕ Omi ਖਾਤਾ।

> **ਮਹੱਤਵਪੂਰਨ ਨੋਟ:** PyPI 'ਤੇ ਪੈਕੇਜ ਦਾ ਨਾਮ **`omi-cli`** ਹੈ, ਪਰ ਇੰਸਟਾਲੇਸ਼ਨ ਤੋਂ ਬਾਅਦ ਟਰਮੀਨਲ ਵਿੱਚ ਚੱਲਣ ਵਾਲੀ ਕਮਾਂਡ ਦਾ ਨਾਮ **`omi`** ਹੈ। PyPI 'ਤੇ `omi` ਨਾਮ ਦਾ ਇੱਕ ਵੱਖਰਾ ਪੈਕੇਜ ਵੀ ਹੈ — ਉਸਨੂੰ ਇੰਸਟਾਲ ਨਾ ਕਰੋ।

ਜੇਕਰ `pipx` ਇੰਸਟਾਲ ਹੈ:

```sh
pipx install omi-cli
omi --help
```

ਜਾਂ, ਇੱਕ ਸਰਗਰਮ Python ਵਰਚੁਅਲ ਵਾਤਾਵਰਣ (virtualenv) ਵਿੱਚ:

```sh
python -m pip install omi-cli
omi --help
```

ਜੇਕਰ ਟਰਮੀਨਲ ਨੂੰ `omi` ਕਮਾਂਡ ਨਹੀਂ ਮਿਲਦੀ, ਤਾਂ ਜਾਂਚ ਕਰੋ ਕਿ ਵਰਚੁਅਲ ਵਾਤਾਵਰਣ ਸਰਗਰਮ ਹੈ ਜਾਂ `pipx` ਡਾਇਰੈਕਟਰੀ ਤੁਹਾਡੇ `PATH` ਵਿੱਚ ਸ਼ਾਮਲ ਹੈ।

## 2. ਆਪਣਾ ਖਾਤਾ ਜੋੜੋ (Authentication)

ਇੰਟਰਐਕਟਿਵ ਲੌਗਇਨ ਸ਼ੁਰੂ ਕਰੋ:

```sh
omi auth login
```

ਬ੍ਰਾਊਜ਼ਰ ਰਾਹੀਂ ਲੌਗਇਨ ਚੁਣੋ ਜਾਂ ਆਪਣੀ Omi ਡਿਵੈਲਪਰ API ਕੁੰਜੀ ਦਰਜ ਕਰੋ। ਸਿੱਧੇ ਬ੍ਰਾਊਜ਼ਰ ਲੌਗਇਨ ਲਈ:

```sh
omi auth login --browser
```

ਲੌਗਇਨ ਉਸੇ ਕੰਪਿਊਟਰ 'ਤੇ ਕਰੋ ਜਿਸ 'ਤੇ ਟਰਮੀਨਲ ਚੱਲ ਰਿਹਾ ਹੈ, ਕਿਉਂਕਿ ਪ੍ਰਮਾਣੀਕਰਨ ਲੋਕਲ ਐਡਰੈੱਸ (localhost) 'ਤੇ ਵਾਪਸ ਆਉਂਦਾ ਹੈ।

ਇਸ ਤੋਂ ਬਾਅਦ ਕਨੈਕਸ਼ਨ ਸਥਿਤੀ ਅਤੇ API ਪਹੁੰਚ ਦੀ ਜਾਂਚ ਕਰੋ:

```sh
omi auth status
omi auth whoami
```

`status` ਲੋਕਲ ਸਥਿਤੀ ਦਿਖਾਉਂਦਾ ਹੈ ਅਤੇ ਗੁਪਤ ਜਾਣਕਾਰੀ ਨੂੰ ਲੁਕਾਉਂਦਾ ਹੈ। `whoami` ਸਰਵਰ ਨੂੰ ਬੇਨਤੀ ਭੇਜ ਕੇ ਜਾਂਚਦਾ ਹੈ ਕਿ ਪ੍ਰਮਾਣ ਪੱਤਰ ਸਹੀ ਢੰਗ ਨਾਲ ਕੰਮ ਕਰ ਰਹੇ ਹਨ।

ਸੰਰਚਨਾ ਡਿਫੌਲਟ ਰੂਪ ਵਿੱਚ `~/.omi/config.toml` ਵਿੱਚ ਸੁਰੱਖਿਅਤ ਕੀਤੀ ਜਾਂਦੀ ਹੈ। ਇਸ ਫ਼ਾਈਲ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖੋ।

## 3. ਆਪਣਾ ਡਾਟਾ ਦੇਖੋ

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ਕਿਸੇ ਖਾਸ ਗੱਲਬਾਤ ਦਾ ਪੂਰਾ ਟ੍ਰਾਂਸਕ੍ਰਿਪਟ ਪ੍ਰਾਪਤ ਕਰਨ ਲਈ:

```sh
omi conversation get <CONVERSATION_ID> --include-transcript
```

ਕਿਸੇ ਵੀ ਕਮਾਂਡ ਦੇ ਵਾਧੂ ਵਿਕਲਪਾਂ ਨੂੰ ਸਮਝਣ ਲਈ `--help` ਦੀ ਵਰਤੋਂ ਕਰੋ:

```sh
omi memory list --help
omi conversation list --help
omi goal list --help
```

## 4. JSON ਫਾਰਮੈਟ ਅਤੇ ਪੰਨਾਬੰਦੀ (Pagination)

ਗਲੋਬਲ ਵਿਕਲਪ `--json` ਨੂੰ ਹਮੇਸ਼ਾ ਕਮਾਂਡ ਗਰੁੱਪ ਤੋਂ **ਪਹਿਲਾਂ** ਲਿਖੋ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ਪਹਿਲੀ ਕਮਾਂਡ ਪਹਿਲੇ 25 ਰਿਕਾਰਡ ਮੰਗਦੀ ਹੈ; ਦੂਜੀ ਕਮਾਂਡ ਅਗਲੇ 25 ਰਿਕਾਰਡ ਮੰਗਦੀ ਹੈ।

ਡਾਟਾ ਫ਼ਾਈਲ ਵਿੱਚ ਸੁਰੱਖਿਅਤ ਕਰਨ ਲਈ (Export):

```sh
omi --json memory list --limit 25 --offset 0 > yaadan-page-1.json
```

## 5. ਲੌਗ ਆਉਟ ਕਰੋ (Logout)

ਲੋਕਲ ਸਿਸਟਮ ਤੋਂ ਪ੍ਰਮਾਣ ਪੱਤਰ ਹਟਾਉਣ ਲਈ:

```sh
omi auth logout
```

ਇਹ ਕੇਵਲ ਲੋਕਲ ਕੰਪਿਊਟਰ ਤੋਂ ਲੌਗਇਨ ਜਾਣਕਾਰੀ ਹਟਾਉਂਦਾ ਹੈ। ਸਰਵਰ ਤੋਂ ਕੁੰਜੀ ਰੱਦ ਕਰਨ ਲਈ Omi ਡਿਵੈਲਪਰ ਡੈਸ਼ਬੋਰਡ ਦੀ ਵਰਤੋਂ ਕਰੋ।

ਵਧੇਰੇ ਜਾਣਕਾਰੀ ਅਤੇ ਉੱਨਤ ਵਿਕਲਪਾਂ ਲਈ ਮੁੱਖ ਅੰਗਰੇਜ਼ੀ ਗਾਈਡ ਵੇਖੋ: [../README.md](../README.md) ਅਤੇ [agent_quickstart.md](agent_quickstart.md).
