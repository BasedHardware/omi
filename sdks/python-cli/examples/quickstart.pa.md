# omi-cli ਨਾਲ ਸ਼ੁਰੂਆਤ (Punjabi Quickstart)

ਇਹ ਗਾਈਡ ਪੰਜਾਬੀ ਵਿੱਚ ਸ਼ੁਰੂਆਤੀ ਕਮਾਂਡਾਂ ਬਾਰੇ ਜਾਣਕਾਰੀ ਦਿੰਦੀ ਹੈ। ਕਮਾਂਡਾਂ ਦੇ ਨਾਮ ਅਤੇ ਪ੍ਰੋਗਰਾਮ ਸੁਨੇਹੇ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਹੀ ਰਹਿਣਗੇ। ਇੱਥੇ ਦਿੱਤੇ ਗਏ ਉਦਾਹਰਨ ਤੁਹਾਡੀਆਂ ਯਾਦਾਂ (memories), ਗੱਲਬਾਤਾਂ (conversations), ਕੰਮਾਂ (tasks/action items) ਜਾਂ ਟੀਚਿਆਂ (goals) ਵਿੱਚ ਕੋਈ ਤਬਦੀਲੀ ਨਹੀਂ ਕਰਦੇ।

## ਪ੍ਰੋਗਰਾਮ ਇੰਸਟਾਲ ਕਰਨਾ

ਜ਼ਰੂਰਤਾਂ: Python 3.10 ਜਾਂ ਇਸ ਤੋਂ ਨਵਾਂ ਵਰਜਨ ਅਤੇ ਇੱਕ Omi ਖਾਤਾ।

ਜੇਕਰ ਤੁਹਾਡੇ ਸਿਸਟਮ ਵਿੱਚ `pipx` ਇੰਸਟਾਲ ਹੈ:

```sh
pipx install omi-cli
omi --help
```

ਜਾਂ ਐਕਟਿਵ ਕੀਤੇ Python ਵਰਚੁਅਲ ਐਨਵਾਇਰਨਮੈਂਟ ਦੇ ਅੰਦਰ:

```sh
python -m pip install omi-cli
omi --help
```

ਜੇਕਰ ਟਰਮੀਨਲ `omi` ਨੂੰ ਨਹੀਂ ਲੱਭ ਪਾਉਂਦਾ, ਤਾਂ ਜਾਂਚ ਕਰੋ ਕਿ ਵਰਚੁਅਲ ਐਨਵਾਇਰਨਮੈਂਟ ਐਕਟਿਵ ਹੈ ਜਾਂ `pipx` ਡਾਇਰੈਕਟਰੀ ਤੁਹਾਡੇ `PATH` ਵਿੱਚ ਸ਼ਾਮਲ ਹੈ।

## ਆਪਣਾ ਖਾਤਾ ਕਨੈਕਟ ਕਰਨਾ

ਇੰਟਰਐਕਟਿਵ ਲੌਗਇਨ ਸ਼ੁਰੂ ਕਰੋ:

```sh
omi auth login
```

ਬ੍ਰਾਊਜ਼ਰ ਰਾਹੀਂ ਲੌਗਇਨ ਚੁਣੋ ਜਾਂ ਆਪਣੀ Omi ਡਿਵੈਲਪਰ API ਕੁੰਜੀ (API key) ਪੇਸਟ ਕਰੋ। ਇੰਟਰਐਕਟਿਵ ਇਨਪੁਟ ਕੁੰਜੀ ਨੂੰ ਲੁਕਾਉਂਦਾ ਹੈ; ਟਰਮੀਨਲ ਹਿਸਟਰੀ ਵਿੱਚ ਕੁੰਜੀ ਲਿਖਣ ਤੋਂ ਬਚੋ।

ਸਿੱਧਾ ਬ੍ਰਾਊਜ਼ਰ ਰਾਹੀਂ ਲੌਗਇਨ ਕਰਨ ਲਈ:

```sh
omi auth login --browser
```

ਉਸੇ ਕੰਪਿਊਟਰ 'ਤੇ ਲੌਗਇਨ ਕਰੋ ਜਿੱਥੇ ਟਰਮੀਨਲ ਹੈ: ਪ੍ਰਮਾਣੀਕਰਨ ਇੱਕ ਸਥਾਨਕ ਪਤੇ ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ। ਸਕ੍ਰੀਨ 'ਤੇ ਦਿੱਤੀਆਂ ਹਦਾਇਤਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ।

ਇਸ ਤੋਂ ਬਾਅਦ, ਸੰਰਚਨਾ ਅਤੇ API ਪਹੁੰਚ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ:

```sh
omi auth status
omi auth whoami
```

`status` ਸਥਾਨਕ ਸਥਿਤੀ ਦਿਖਾਉਂਦਾ ਹੈ ਅਤੇ ਗੁਪਤ ਜਾਣਕਾਰੀ ਨੂੰ ਲੁਕਾਉਂਦਾ ਹੈ, ਪਰ ਸਰਵਰ 'ਤੇ ਇਸ ਦੀ ਜਾਂਚ ਨਹੀਂ ਕਰਦਾ। `whoami` ਇੱਕ ਪ੍ਰਮਾਣਿਤ ਬੇਨਤੀ ਕਰਦਾ ਹੈ; ਜੇਕਰ ਸਫਲ ਹੁੰਦਾ ਹੈ, ਤਾਂ ਇਹ ਪੁਸ਼ਟੀ ਕਰਦਾ ਹੈ ਕਿ ਪ੍ਰਮਾਣ ਪੱਤਰ ਕੰਮ ਕਰ ਰਹੇ ਹਨ।

ਸੰਰਚਨਾ ਮੂਲ ਰੂਪ ਵਿੱਚ `~/.omi/config.toml` ਵਿੱਚ ਸੁਰੱਖਿਅਤ ਕੀਤੀ ਜਾਂਦੀ ਹੈ। ਇਹ ਫ਼ਾਈਲ ਕਿਸੇ ਨਾਲ ਸਾਂਝੀ ਨਾ ਕਰੋ: ਇਸ ਵਿੱਚ ਤੁਹਾਡੇ ਪ੍ਰਮਾਣ ਪੱਤਰ ਹੋ ਸਕਦੇ ਹਨ।

## ਆਪਣਾ ਡਾਟਾ ਵੇਖਣਾ

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ਇੱਕ ਖਾਲੀ ਸੂਚੀ ਦਾ ਮਤਲਬ ਇਹ ਹੋ ਸਕਦਾ ਹੈ ਕਿ ਬੇਨਤੀ ਨਾਲ ਮੇਲ ਖਾਂਦਾ ਕੋਈ ਡਾਟਾ ਨਹੀਂ ਹੈ। ਹਰੇਕ ਕਮਾਂਡ ਦੇ ਫਿਲਟਰਾਂ ਬਾਰੇ ਜਾਣਨ ਲਈ ਮਦਦ ਵੇਖੋ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ਪ੍ਰਾਪਤ ਕਰਨਾ ਅਤੇ ਪੰਨੇ ਬਦਲਣਾ

ਗਲੋਬਲ `--json` ਵਿਕਲਪ ਨੂੰ ਕਮਾਂਡ ਗਰੁੱਪ ਤੋਂ **ਪਹਿਲਾਂ** ਲਗਾਓ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ਪਹਿਲੀ ਕਮਾਂਡ ਪਹਿਲੀਆਂ 25 ਯਾਦਾਂ ਲਿਆਉਂਦੀ ਹੈ; ਦੂਜੀ ਕਮਾਂਡ ਅਗਲੀਆਂ 25 ਯਾਦਾਂ ਲਿਆਉਂਦੀ ਹੈ। ਇਸ ਲਈ ਇੱਕ ਪੰਨਾ ਪੂਰਾ ਬੈਕਅੱਪ ਨਹੀਂ ਹੈ। JSON ਆਉਟਪੁੱਟ ਪੂਰੀਆਂ ਆਈਡੀਜ਼ ਰੱਖਦਾ ਹੈ, ਜਦਕਿ ਟੇਬਲ ਉਹਨਾਂ ਨੂੰ ਛੋਟਾ ਕਰਕੇ ਦਿਖਾ ਸਕਦੇ ਹਨ।

ਕਿਸੇ ਪੰਨੇ ਨੂੰ ਫ਼ਾਈਲ ਵਿੱਚ ਸੁਰੱਖਿਅਤ ਕਰਨ ਲਈ:

```sh
omi --json memory list --limit 25 --offset 0 > yaadan-page-1.json
```

ਇਹ ਰੀਡਾਇਰੈਕਸ਼ਨ ਲੋਕਲ ਫ਼ਾਈਲ ਬਣਾਉਂਦੀ ਹੈ ਜਾਂ ਬਦਲਦੀ ਹੈ। ਵਰਤੋਂ ਤੋਂ ਪਹਿਲਾਂ ਜਾਂਚ ਕਰੋ ਕਿ ਕਮਾਂਡ ਸਫਲਤਾਪੂਰਵਕ ਪੂਰੀ ਹੋਈ ਹੈ। ਐਕਸਪੋਰਟ ਕੀਤੀ ਫ਼ਾਈਲ ਵਿੱਚ ਨਿੱਜੀ ਜਾਣਕਾਰੀ ਹੋ ਸਕਦੀ ਹੈ: ਇਸਨੂੰ ਨਿੱਜੀ ਰੱਖੋ।

## ਲੌਗਆਉਟ ਕਰਨਾ

```sh
omi auth logout
```

ਇਹ ਕਮਾਂਡ ਸਥਾਨਕ ਤੌਰ 'ਤੇ ਸੁਰੱਖਿਅਤ ਕੀਤੇ ਪ੍ਰਮਾਣ ਪੱਤਰ ਹਟਾ ਦਿੰਦੀ ਹੈ। ਸਰਵਰ 'ਤੇ ਕੁੰਜੀ ਰੱਦ ਕਰਨ ਲਈ, ਆਪਣੇ ਖਾਤੇ ਦੇ ਡਿਵੈਲਪਰ ਪ੍ਰਬੰਧਨ ਦੀ ਵਰਤੋਂ ਕਰੋ।

ਹੋਰ ਕਮਾਂਡਾਂ ਅਤੇ ਉੱਨਤ ਵਿਕਲਪਾਂ ਲਈ, [ਮੁੱਖ ਅੰਗਰੇਜ਼ੀ ਗਾਈਡ](../README.md) ਅਤੇ `omi --help` ਵੇਖੋ।
