# omi-cli बर संक्षेप मार्गदर्शिका

ए मार्गदर्शिका छत्तीसगढ़ी (Chhattisgarhi) भाखा म `omi-cli` के सुरुआती कमांड के बारे म समझावत हे। कमांड के नांव अउ प्रोग्राम के संदेस अंग्रेजी म ही रहिही। इहां दे गे उदाहरण मन तुंहर सुरता (memories), गोठ-बात (conversations), करे बर काम (action items), या लछ (goals) म कोनो बदलाव नइ करही।

## प्रोग्राम इंस्टॉल करब (Installation)

जरूरी जिनिस: Python 3.10 या नवा संस्करण अउ एक Omi खाता।

अगर तुंहर कोति `pipx` इंस्टॉल हे:

```sh
pipx install omi-cli
omi --help
```

तुमन एकर ले चालू Python वर्चुअल एनवायरनमेंट (virtual environment) म घलो इंस्टॉल कर सकथो:

```sh
python -m pip install omi-cli
omi --help
```

अगर टर्मिनल म `omi` कमांड नइ मिलय, त जांच लेव कि वर्चुअल एनवायरनमेंट चालू हे कि नइ या `pipx` के रद्दा तुंहर `$PATH` म सामिल हे कि नइ।

## अपन खाता जोड़ब (Authentication)

गोठ-बात करे वाला सहायक सुरू करव:

```sh
omi auth login
```

ब्राउजर ले लॉगिन करब या अपन Omi developer API key चिपकाए के रद्दा चुनव। सहायक इनपुट चाबी ला लुका देही; टर्मिनल के इतिहास म रहे वाला कोनो कमांड म चाबी ला झन लिखव।

सोझे ब्राउजर म जाए बर:

```sh
omi auth login --browser
```

उहचे कंप्यूटर म लॉगिन करव जेमा टर्मिनल चलत हे: परमानित जबाब लोकल पता के उपयोग करथे। पर्दा म दिखे निर्देश के पालन करव।

ओकर बाद, सेटिंग्स अउ API पहुंच के जांच करव:

```sh
omi auth status
omi auth whoami
```

`status` लोकल हाल ला देखावत हे अउ भेद ला लुकावत हे, पर सर्वर म ओकर चले के जांच नइ करय। `whoami` एक जांचे अरजी भेजथे; अगर बने होगे, त नांव देखाय बिना बताथे कि क्रेडेंशियल्स काम करत हे।

सेटिंग्स बहुधा `~/.omi/config.toml` म सुरक्षित रहिथे। ए फाइल ला कोनो ले साझा झन करव: एमा गुप्त क्रेडेंशियल्स हो सकत हे।

## अपन डेटा देखब (Inspection)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

खाली सूची के मतलब सिर्फ ए हो सकत हे कि खोज के मुताबिक कोनो डेटा नइ मिलिस। हर कमांड म फ़िल्टर खोजे बर मदद के उपयोग करव:

```sh
omi memory list --help
omi action-item list --help
```

## JSON प्राप्त करब अउ पन्ना पलटब (Pagination)

कमांड समूह ले **पहिली** पूरा सिस्टम वाला `--json` विकल्प लगालव:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

पहिला कमांड पहिली 25 सुरता मंगही; दूसर कमांड आगू के 25 सुरता मंगही। एक पन्ना पूरा बैकअप नइ होवय। JSON आउटपुट पूरा पहचानी कोड ला सुरक्षित राखथे, जबकि स्क्रीन के तालिका ओला छोट कर सकत हे।

एक पन्ना ला फाइल म सहेजे बर:

```sh
omi --json memory list --limit 25 --offset 0 > सुरता-पन्ना-1.json
```

ए रद्दा लोकल फाइल बनाथे या बदलथे। सामग्री उपयोग करे ले पहिली देख लेव कि कमांड बने पूरा होइस कि नइ। गड़बड़ी एरर आउटपुट (stderr) म लिखे जाथे; खाली फाइल के मतलब ए नइ हे कि डेटा नइ हे। निकाले फाइल म निजी जानकारी हो सकत हे: ओला संभाल के राखव।

## खाता ले बाहिर निकलना (Logout)

```sh
omi auth logout
```

ए कमांड लोकल रूप ले सहेजे क्रेडेंशियल्स ला मेटा देथे। सर्वर ले चाबी रद्द करे बर, अपन खाता म developer key प्रबंधन के उपयोग करव।

अउ दूसर कमांड अउ जादा विकल्प बर, [अंग्रेजी के मुख्य मार्गदर्शिका](../README.md) अउ `omi --help` देखव।
