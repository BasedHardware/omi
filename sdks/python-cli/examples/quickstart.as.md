# omi-cli ক্ষিপ্ৰ আৰম্ভণি নিৰ্দেশিকা (Assamese Quickstart)

> টাৰ্মিনেলৰ পৰা পোনপটীয়াকৈ Omi ব্যৱহাৰ কৰাৰ বাবে ব্যৱহাৰিক নিৰ্দেশনা — ডেভেলপাৰ আৰু স্বায়ত্তশাসিত AI এজেণ্টসকলৰ বাবে নিৰ্মিত।

`omi-cli` হৈছে [Omi](https://omi.me) ডেভেলপাৰ API-ৰ বাবে অফিচিয়েল কমাণ্ড-লাইন ইণ্টাৰফেচ (CLI)। ই Omi-ৰ ৪টা প্ৰধান সম্পদত সুসংগঠিত প্ৰৱেশাধিকাৰ প্ৰদান কৰে: স্মৃতি (memories), বাৰ্তালাপ (conversations), কাৰ্য্যসূচী (action items), আৰু লক্ষ্য (goals)।

* **PyPI:** [pypi.org/project/omi-cli](https://pypi.org/project/omi-cli/)
* **অফিচিয়েল নথি-পত্ৰ:** [docs.omi.me/doc/developer/cli/introduction](https://docs.omi.me/doc/developer/cli/introduction)
* **উৎস ক'ড:** [github.com/BasedHardware/omi/tree/main/sdks/python-cli](https://github.com/BasedHardware/omi/tree/main/sdks/python-cli)

## ১. ইনষ্টলেশ্বন (Installation)

চিষ্টেম নিৰ্ভৰশীলতাসমূহৰ মাজত সংঘাত পৰিহাৰ কৰিবলৈ আৰু এটা পৃথক পৰিৱেশ বজাই ৰাখিবলৈ, `pipx` ব্যৱহাৰ কৰাৰ দৃঢ় পৰামৰ্শ দিয়া হয়:

```bash
# পৰামৰ্শিত পদ্ধতি: pipx-ৰ জৰিয়তে পৃথক ইনষ্টলেশ্বন
pipx install omi-cli

# বিকল্প পদ্ধতি: মানক pip-ৰ দ্বাৰা ইনষ্টলেশ্বন (উদাহৰণস্বৰূপে ভাৰ্চুৱেল পৰিৱেশত)
pip install omi-cli
```

> **গুৰুত্বপূৰ্ণ স্পষ্টীকৰণ: পেকেজ নাম বনাম কমাণ্ড নাম**
> * PyPI-ত অফিচিয়েল পেকেজৰ নাম হৈছে **`omi-cli`** (মন কৰিব যে `omi` নামৰ পেকেজটো এটা পৃথক আৰু অসম্পৰ্কিত প্ৰকল্প)।
> * টাৰ্মিনেলত কাৰ্যকৰী কৰা প্ৰকৃত কমাণ্ডটো হৈছে কেৱল **`omi`**।

ইনষ্টলেশ্বন সফল হৈছে নে নাই সেয়া পৰীক্ষা কৰিবলৈ সংস্কৰণ আৰু সহায় মেনু চাওক:

```bash
omi --version
omi --help
```

## ২. প্ৰমাণীকৰণ (Authentication)

`omi-cli`-য়ে প্ৰমাণীকৰণৰ দুটা প্ৰধান পদ্ধতি সমৰ্থন কৰে:

| পদ্ধতি | উদ্দেশ্য | কমাণ্ডৰ উদাহৰণ |
| :--- | :--- | :--- |
| **ডেভেলপাৰ API কী (`omi_dev_*`)** | স্বয়ংক্ৰিয়কৰণ, CI/CD, হেডলেছ চাৰ্ভাৰ, AI এজেণ্ট | `omi auth login --api-key ...` বা `OMI_API_KEY` |
| **ব্ৰাউজাৰ OAuth লগইন (Google/Apple)** | ব্যক্তিগত কম্পিউটাৰত স্থানীয় বিকাশ | `omi auth login --browser` (Google) / `--provider apple` |

### ইণ্টাৰেক্টিভ লগইন
কোনো অতিৰিক্ত পেৰামিটাৰ অবিহনে কমাণ্ড চলালে এটা ইণ্টাৰেক্টিভ প্ৰম্পট আৰম্ভ হয়, যিয়ে ইনপুটৰ সময়ত আপোনাৰ গোপনীয় কী সুৰক্ষিতভাৱে লুকুৱাই ৰাখে:

```bash
omi auth login
# 1) Browser — ব্ৰাউজাৰৰ জৰিয়তে Google-ৰে লগইন কৰক (Apple-ৰ বাবে `--provider apple` ফ্লেগ যোগ কৰক)
# 2) API key — app.omi.me-ৰ পৰা প্ৰাপ্ত ডেভেলপাৰ API কী পেষ্ট কৰক
```

### পোনপটীয়া ব্ৰাউজাৰ লগইন
```bash
# সাধাৰণ Google একাউণ্টৰ সৈতে লগইন কৰক
omi auth login --browser

# Apple একাউণ্টৰ সৈতে লগইন কৰক
omi auth login --browser --provider apple
```

### API কীৰ জৰিয়তে স্বয়ংক্ৰিয় লগইন
হেডলেছ পৰিৱেশ আৰু স্ক্ৰিপ্টৰ বাবে, আপুনি পোনপটীয়াকৈ কমাণ্ড-লাইন ফ্লেগ বা পৰিৱেশ চলক (environment variable) ব্যৱহাৰ কৰিব পাৰে:

```bash
# ফ্লেগৰ জৰিয়তে পোনপটীয়াকৈ কী প্ৰদান কৰক
omi auth login --api-key "omi_dev_xxxxxxxxxxxxxxxxxxxxxxxx"

# অথবা পৰিৱেশ চলক সংহতি কৰক (অধিবেশন জুৰি স্বয়ংক্ৰিয়ভাৱে চিনাক্ত কৰা হয়)
export OMI_API_KEY="omi_dev_xxxxxxxxxxxxxxxxxxxxxxxx"
```

### প্ৰমাণীকৰণ স্থিতি পৰীক্ষণ
```bash
# স্থানীয় ক্ৰেডেনচিয়েলৰ স্থিতি আৰু প্ৰফাইল পৰীক্ষা কৰক (অফলাইনতো কাৰ্যক্ষম)
omi auth status

# সক্ৰিয় টোকেন বা API কী চাৰ্ভাৰত পৰীক্ষা কৰক আৰু ব্যৱহাৰকাৰীৰ তথ্য প্ৰাপ্ত কৰক
omi auth whoami

# সুৰক্ষিতভাৱে লগআউট কৰক আৰু স্থানীয় টোকেন বিলোপ কৰক
omi auth logout
```

## ৩. মূল সম্পদ আৰু কমাণ্ডসমূহ

`omi-cli`-য়ে Omi প্ৰণালীৰ ৪টা প্ৰধান সম্পদ পৰিচালনা কৰে:

### ক) স্মৃতিসমূহ (Memories)
বাৰ্তালাপৰ পৰা স্বয়ংক্ৰিয়ভাৱে আহৰণ কৰা মূল তথ্য আৰু প্ৰসংগ।

```bash
# সকলো স্মৃতিৰ তালিকা চাওক
omi memory list

# পৃষ্ঠাৰ সীমা নিৰ্ধাৰণ কৰি তালিকা চাওক
omi memory list --limit 10

# নিৰ্দিষ্ট স্মৃতিৰ বিশদ বিৱৰণ আইডিৰে প্ৰাপ্ত কৰক
omi memory get <memory-id>
```

### খ) বাৰ্তালাপ (Conversations)
Omi হাৰ্ডৱেৰ বা এপৰ দ্বাৰা ৰেকৰ্ড কৰা সম্পূৰ্ণ কথোপকথন।

```bash
# শেহতীয়া বাৰ্তালাপৰ তালিকা প্ৰাপ্ত কৰক
omi conversation list

# কোনো নিৰ্দিষ্ট বাৰ্তালাপৰ সম্পূৰ্ণ বিৱৰণ আৰু ট্ৰান্সক্ৰিপ্ট চাওক
omi conversation get <conversation-id>
```

### গ) কাৰ্য্যসূচী (Action Items)
বাৰ্তালাপৰ পৰা চিনাক্ত কৰা কৰণীয় কাম আৰু দায়িত্ব।

```bash
# সকলো বাকী থকা আৰু সম্পূৰ্ণ কাৰ্য্যসূচী চাওক
omi action-item list

# নিৰ্দিষ্ট কাৰ্য্যসূচীৰ বিৱৰণ চাওক
omi action-item get <item-id>
```

### ঘ) লক্ষ্য (Goals)
ব্যৱহাৰকাৰীৰ দীৰ্ঘম্যাদী লক্ষ্য আৰু উদ্দেশ্য।

```bash
# নিৰ্ধাৰিত লক্ষ্যসমূহৰ তালিকা প্ৰাপ্ত কৰক
omi goal list

# কোনো নিৰ্দিষ্ট লক্ষ্যৰ অগ্ৰগতি আৰু বিৱৰণ চাওক
omi goal get <goal-id>
```

## ৪. স্বয়ংক্ৰিয়কৰণ আৰু JSON স্ক্ৰিপ্টিং (JSON & jq)

AI এজেণ্ট, পাইপলাইন, আৰু শ্বেল স্ক্ৰিপ্টত একত্ৰীকৰণৰ বাবে, `omi-cli`-য়ে সকলো ফলাফল মেচিন-পঠনযোগ্য JSON বিন্যাসত প্ৰদান কৰে।

### সুবৰ্ণ নিয়ম: `--json` ফ্লেগৰ স্থান
> **অত্যন্ত গুৰুত্বপূৰ্ণ:** `--json` ফ্লেগটো মূল কমাণ্ড `omi`-ৰ ঠিক পিছত আৰু উপ-কমাণ্ডৰ আগত ৰখাটো বাধ্যতামূলক:

```bash
# শুদ্ধ বিন্যাস:
omi --json memory list
omi --json conversation list

# অশুদ্ধ বিন্যাস (ত্ৰুটি হ'ব পাৰে):
omi memory list --json
```

### ব্যৱহাৰিক `jq` পাইপলাইনৰ উদাহৰণ

```bash
# ১. সকলো স্মৃতিৰ চমু বিষয়বস্তু আৰু সময় উলিয়াওক
omi --json memory list | jq '.[] | {id: .id, content: .content, created_at: .created_at}'

# ২. আটাইতকৈ শেহতীয়া বাৰ্তালাপৰ আইডি সংগ্ৰহ কৰক
RECENT_ID=$(omi --json conversation list --limit 1 | jq -r '.[0].id')
echo "শেহতীয়া বাৰ্তালাপৰ আইডি: $RECENT_ID"

# ৩. অসম্পূৰ্ণ কাৰ্য্যসূচীসমূহৰ বিৱৰণ ফিল্টাৰ কৰক
omi --json action-item list | jq -r '.[] | select(.completed == false) | .description'
```

### পৃষ্ঠাকৰণ (Pagination)
ডাঙৰ তথ্যসমষ্টিৰ বাবে, `--limit` আৰু `--offset` পেৰামিটাৰ ব্যৱহাৰ কৰক:

```bash
# প্ৰথম ২০টা ফলাফল প্ৰাপ্ত কৰক
omi --json memory list --limit 20 --offset 0

# পৰৱৰ্তী ২০টা ফলাফল প্ৰাপ্ত কৰক
omi --json memory list --limit 20 --offset 20
```

## ৫. এক্সিট ক'ড চুক্তি (Exit Codes Contract)

`omi-cli`-য়ে [omi_cli/errors.py](https://github.com/BasedHardware/omi/blob/main/sdks/python-cli/omi_cli/errors.py)-ত সংজ্ঞায়িত মানক এক্সিট ক'ড অনুসৰণ কৰে, যাৰ দ্বাৰা স্ক্ৰিপ্টসমূহত ত্ৰুটি নিয়ন্ত্ৰণ সহজ হৈ পৰে:

| এক্সিট ক'ড | প্ৰতীকী নাম | অৰ্থ আৰু প্ৰতিকাৰ |
| :---: | :--- | :--- |
| **0** | `EXIT_OK` | অপাৰেচন সম্পূৰ্ণৰূপে সফল হ'ল। |
| **1** | `EXIT_USAGE` | অশুদ্ধ কমাণ্ড ছিনটেক্স, অজ্ঞাত তৰ্ক, বা প্ৰয়োজনীয় ফ্লেগৰ অনুপস্থিতি। |
| **2** | `EXIT_AUTH` | প্ৰমাণীকৰণ তথ্য নাই, অকাৰ্যকৰী API কী, বা ম্যাদ উকলি যোৱা অধিবেশন। |
| **3** | `EXIT_SERVER` | চাৰ্ভাৰ ত্ৰুটি (5xx) বা সংযোগ ব্যৰ্থতা। |
| **4** | `EXIT_RATE_LIMITED` | অনুৰোধৰ সীমা (Rate limit 429) অতিক্ৰম কৰা হৈছে। |
| **5** | `EXIT_NOT_FOUND` | অনুৰোধ কৰা সম্পদ (আইডি) পোৱা নগ'ল (404)। |

### বাশ্ব স্ক্ৰিপ্টত ত্ৰুটি নিয়ন্ত্ৰণৰ উদাহৰণ:
```bash
if ! omi --json memory list > /dev/null 2>&1; then
  EXIT_CODE=$?
  case $EXIT_CODE in
    1) echo "ত্ৰুটি: অশুদ্ধ ব্যৱহাৰ বা ফ্লেগ।" ;;
    2) echo "ত্ৰুটি: প্ৰমাণীকৰণ ব্যৰ্থ হ'ল। অনুগ্ৰহ কৰি 'omi auth login' চলাওক।" ;;
    3) echo "ত্ৰুটি: চাৰ্ভাৰ ত্ৰুটি বা সংযোগ ব্যৰ্থতা হৈছে।" ;;
    4) echo "ত্ৰুটি: অনুৰোধৰ সীমা (Rate limit) অতিক্ৰম হৈছে। কিছু সময় পিছত পুনৰ চেষ্টা কৰক।" ;;
    5) echo "ত্ৰুটি: সম্পদ পোৱা নগ'ল।" ;;
    *) echo "ত্ৰুটি: ক'ড $EXIT_CODE-ৰ সৈতে অপ্ৰত্যাশিত সমস্যা হৈছে।" ;;
  esac
  exit $EXIT_CODE
fi
```

## ৬. উন্নত ব্যৱহাৰ: স্থানীয় API আৰু একাধিক প্ৰফাইল

### স্থানীয় ডেস্কটপ API একত্ৰীকৰণ
যেতিয়া Omi ডেস্কটপ এপ আপোনাৰ কম্পিউটাৰত চলি থাকে, আপুনি ক্লাউডৰ পৰিৱৰ্তে স্থানীয় ইনষ্টান্সৰ সৈতে পোনপটীয়াকৈ সংযোগ কৰিব পাৰে:

```bash
# স্থানীয় ডেস্কটপ API এণ্ডপইণ্ট নিৰ্ধাৰণ কৰক
export OMI_LOCAL_API_URL="http://127.0.0.1:47778"

# স্থানীয় টোকেন ছেট কৰক
export OMI_LOCAL_TOKEN="your_local_desktop_token"

# স্থানীয় চাৰ্ভাৰৰ পৰা স্থিতি পৰীক্ষা কৰক
omi auth status
```

### একাধিক প্ৰফাইল ব্যৱস্থাপনা
আপুনি বিভিন্ন পৰিৱেশৰ বাবে (যেনে ব্যক্তিগত, কৰ্মক্ষেত্ৰ, ষ্টেজিং) পৃথকে ক্ৰেডেনচিয়েল সংৰক্ষণ কৰিব পাৰে:

```bash
# ষ্টেজিং প্ৰফাইলত লগইন কৰক
omi --profile staging auth login --api-key "omi_dev_staging_key"

# ষ্টেজিং প্ৰফাইলৰ পৰা কমাণ্ড চলাওক
omi --profile staging memory list
```

## ৭. সামৰণি

`omi-cli`-য়ে ডেভেলপাৰসকলক টাৰ্মিনেলত Omi তথ্য প্লেটফৰ্মৰ সম্পূৰ্ণ ক্ষমতা প্ৰদান কৰে। অধিক বিৱৰণ আৰু পাইথন SDK নথি-পত্ৰৰ বাবে [docs.omi.me](https://docs.omi.me) চাওক।
