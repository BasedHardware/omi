# omi-cli ৰ সৈতে আৰম্ভণি

এই গাইডখন অসমীয়া ভাষাত omi-cli ৰ প্ৰথম পদক্ষেপসমূহ বৰ্ণনা কৰে। ক'মাণ্ডৰ নাম আৰু প্ৰ'গ্ৰামৰ বাৰ্তাসমূহ ইংৰাজীতে থাকে। ইয়াত থকা কুয়েৰী উদাহৰণসমূহে আপোনাৰ স্মৃতি, কথোপকথন, কাৰ্যসূচী বা লক্ষ্যসমূহ সাল-সলনি নকৰে।

## ইনষ্টল কৰা

চৰ্ত: Python 3.10 বা তাতকৈ নতুন সংস্কৰণ, আৰু এটা Omi একাউণ্ট।

যদি আপোনাৰ `pipx` ইনষ্টল হৈ আছে:

```sh
pipx install omi-cli
omi --help
```

বিকল্পভাৱে, সক্ৰিয় Python virtual environment ৰ ভিতৰত ইনষ্টল কৰিব পাৰি:

```sh
python -m pip install omi-cli
omi --help
```

যদি টাৰ্মিনালে `omi` বিচাৰি নাপায়, চাওক যে virtual environment সক্ৰিয় আছে, নে `pipx` ত ইনষ্টল হোৱা এক্সিকিউটেবল থকা ডাইৰেক্টৰীটো আপোনাৰ `PATH` ত আছে।

## একাউণ্ট সংযোগ

ইণ্টাৰেক্টিভ উইজাৰ্ড আৰম্ভ কৰক:

```sh
omi auth login
```

ব্ৰাউজাৰত লগ-ইন কৰা বা Omi ডেভেলপাৰ API কী পেষ্ট কৰা — দুয়োটাৰে এটা বাছি লওক। ইণ্টাৰেক্টিভ ইনপুটে কী লুকুৱাই ৰাখে; টাৰ্মিনেল ইতিহাসত থাকি যোৱা ক'মাণ্ডত এনে কী টাইপ কৰাটো এৰক।

সৰাসৰি ব্ৰাউজাৰলৈ যাবলৈ:

```sh
omi auth login --browser
```

টাৰ্মিনেলটো চলি থকা একেটা কম্পিউটাৰতে লগ-ইন কৰক: অথেন্টিকেচন সঁহাৰিটোৱে এটা লোকেল ঠিকনা ব্যৱহাৰ কৰে। পৰ্দাত দিয়া নিৰ্দেশনা অনুসৰণ কৰক।

তাৰ পিছত ছেটিং আৰু API এপ্ৰ'চ ভেৰিফাই কৰক:

```sh
omi auth status
omi auth whoami
```

`status` য়ে লোকেল অৱস্থা দেখুৱায় আৰু গোপন তথ্য লুকুৱাই, কিন্তু ই চাৰ্ভাৰত সেই তথ্য বৈধ নে নাই পৰীক্ষা নকৰে। `whoami` য়ে এটা অথেন্টিকেটেড অনুৰোধ কৰে; যদি সেয়া সফল হয়, তেন্তে ক্ৰেডেন্সিয়েলসমূহে কাম কৰে বুলি নিশ্চিত হয় — আৰু ই আপোনাৰ নাম দেখুৱাবও নালাগে।

কনফিগাৰেচনটো অবিকল্পিতভাৱে `~/.omi/config.toml` ত সংৰক্ষিত হয় (ইচ্ছা হ'লে `$OMI_CONFIG` ৰে অন্য ঠিকনালৈ পৰিৱৰ্তন কৰিব পাৰি)। এই ফাইলটো আন কাৰো সৈতে ভাগ নকৰিব: ইয়াত আপোনাৰ ক্ৰেডেন্সিয়েল থাকিব পাৰে।

## তথ্য চোৱা

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

এখন খালী তালিকাই কেৱল বুজাব পাৰে যে অনুৰোধৰ লগত মিলা বস্তু নাই। প্ৰতিটো ক'মাণ্ডৰ ফিল্টাৰ আৱিষ্কাৰ কৰিবলৈ সহায় ব্যৱহাৰ কৰক:

```sh
omi memory list --help
omi action-item list --help
```

## JSON আৰু পৃষ্ঠা-পেজিনেচন

গ্ল'বেল `--json` বিকল্পটো ক'মাণ্ড গোটৰ **আগত** ৰাখক:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

প্ৰথম ক'মাণ্ডে প্ৰথম ২৫টা স্মৃতি বিচাৰে; দ্বিতীয়টোৱে পৰৱৰ্তী ২৫টা। গতিকে এটা পৃষ্ঠা সম্পূৰ্ণ বেকআপ নহয়। JSON আউটপুটত সম্পূৰ্ণ আইডিসমূহ থাকে, যেতিয়া টেবুলে প্ৰদৰ্শনৰ বাবে সেয়া চমু কৰিব পাৰে।

এটা পৃষ্ঠা ফাইলত সাঁচিবলৈ:

```sh
omi --json memory list --limit 25 --offset 0 > smriti-patha-1.json
```

এই ৰিডাইৰেক্সনে লোকেল ফাইলটো সৃষ্টি বা প্ৰতিস্থাপন কৰে। ব্যৱহাৰৰ আগত নিশ্চিত হওক যে ক'মাণ্ডটো সফলভাৱে শেষ হৈছে। ত্ৰুটিসমূহ stderr ত লিখা হয়; এটা খালী ফাইলেই নিশ্চিত নহয় যে তথ্য নাই। ৰপ্তানি কৰা ফাইলটোত ব্যক্তিগত তথ্য থাকিব পাৰে: ইয়াক ব্যক্তিগতভাৱে ৰাখক।

## লগ-আউট

```sh
omi auth logout
```

এই ক'মাণ্ডে লোকেলভাৱে সংৰক্ষিত ক্ৰেডেন্সিয়েলসমূহ মচি পেলায়। চাৰ্ভাৰত এটা কী ৰিভ'ক কৰিবলৈ, আপোনাৰ একাউণ্টৰ ডেভেলপাৰ-কী ব্যৱস্থাপনা ব্যৱহাৰ কৰক।

বাকী ক'মাণ্ড আৰু উন্নত বিকল্পৰ বাবে, মূল [ইংৰাজী গাইড](../README.md) আৰু `omi --help` চাওক।
