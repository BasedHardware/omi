# omi-cli ৰ সৈতে আৰম্ভণি (Assamese Quickstart)

এই নিৰ্দেশিকাখনত অসমীয়াত প্ৰাৰম্ভিক কমাণ্ডসমূহৰ বিষয়ে ব্যাখ্যা কৰা হৈছে। কমাণ্ডৰ নাম আৰু প্ৰগ্ৰাম বাৰ্তাসমূহ ইংৰাজীতেই থাকিব। ইয়াত দিয়া উদাহৰণসমূহে আপোনাৰ স্মৃতি (memories), বাৰ্তালাপ (conversations), কাম (action items) বা লক্ষ্যসমূহ (goals) পৰিৱৰ্তন নকৰে।

## প্ৰগ্ৰাম ইনষ্টল কৰা

প্ৰয়োজনীয়তা: Python 3.10 বা ততোধিক নতুন সংস্কৰণ আৰু এটা Omi একাউণ্ট।

যদি আপোনাৰ ওচৰত `pipx` ইনষ্টল আছে:

```sh
pipx install omi-cli
omi --help
```

বা এটা সক্ৰিয় Python ভাৰ্চুৱেল পৰিৱেশৰ ভিতৰত:

```sh
python -m pip install omi-cli
omi --help
```

যদি টাৰ্মিনেলে `omi` বিচাৰি নাপায়, তেন্তে পৰীক্ষা কৰক যে ভাৰ্চুৱেল পৰিৱেশ সক্ৰিয় আছে নে নাই বা `pipx` ৰ ডিৰেক্টৰি আপোনাৰ `PATH` ত আছে নে নাই।

## আপোনাৰ একাউণ্ট সংযোগ কৰা

ইণ্টাৰেক্টিভ লগইন আৰম্ভ কৰক:

```sh
omi auth login
```

ব্ৰাউজাৰৰ জৰিয়তে লগইন বাছনি কৰক বা আপোনাৰ Omi ডেভেলপাৰ API কি (API key) পেষ্ট কৰক। ইণ্টাৰেক্টিভ ইনপুটে কি'টো লুকুৱাই ৰাখে; টাৰ্মিনেল হিষ্ট্ৰীত কি' লিখাৰ পৰা বিৰত থাকক।

পোনপটীয়াকৈ ব্ৰাউজাৰ ব্যৱহাৰ কৰিবলৈ:

```sh
omi auth login --browser
```

টাৰ্মিনেল থকা কম্পিউটাৰতে লগইন কৰক: প্ৰমাণীকৰণে এটা স্থানীয় ঠিকনা ব্যৱহাৰ কৰে। পৰ্দাত দিয়া নিৰ্দেশনা অনুসৰণ কৰক।

ইয়াৰ পিছত, কনফিগাৰেচন আৰু API প্ৰৱেশাধিকাৰ পৰীক্ষা কৰক:

```sh
omi auth status
omi auth whoami
```

`status` য়ে স্থানীয় স্থিতি দেখুৱায় আৰু গোপন তথ্য লুকুৱাই ৰাখে, কিন্তু চাৰ্ভাৰত ইয়াৰ বৈধতা পৰীক্ষা নকৰে। `whoami` য়ে এটা প্ৰমাণীকৃত অনুৰোধ কৰে; সফল হ'লে, ই নিশ্চিত কৰে যে ক্ৰেডেনচিয়েলসমূহ সঠিকভাৱে কাম কৰি আছে।

কনফিগাৰেচন ডিফল্টভাৱে `~/.omi/config.toml` ত সংৰক্ষণ কৰা হয়। এই ফাইলটো কাৰো সৈতে শ্বেয়াৰ নকৰিব: ইয়াত আপোনাৰ গোপন ক্ৰেডেনচিয়েল থাকিব পাৰে।

## তথ্য অনুসন্ধান কৰা (Querying Data)

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

এটা খালী তালিকাই বুজাব পাৰে যে অনুৰোধৰ সৈতে মিল থকা কোনো তথ্য নাই। প্ৰতিটো কমাণ্ডৰ ফিল্টাৰসমূহ জানিবলৈ সহায় চাওক:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ফলাফল আৰু পৃষ্ঠা সলনি কৰা (Pagination)

গ্ল'বেল `--json` বিকল্পটো কমাণ্ড গোটৰ **আগত** ব্যৱহাৰ কৰক:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

প্ৰথম কমাণ্ডে প্ৰথম ২৫ টা স্মৃতি আনে; দ্বিতীয় কমাণ্ডে পৰৱৰ্তী ২৫ টা আনে। গতিকে এটা পৃষ্ঠা সম্পূৰ্ণ বেকআপ নহয়। JSON ফলাফলে সম্পূৰ্ণ আইডিসমূহ ৰাখে, যেতিয়নে তালিকাসমূহে প্ৰদৰ্শনৰ বাবে ইয়াক চুটি কৰিব পাৰে।

কোনো পৃষ্ঠা ফাইলত সংৰক্ষণ কৰিবলৈ:

```sh
omi --json memory list --limit 25 --offset 0 > memories-page-1.json
```

এই ৰিডাইৰেকচনে এটা স্থানীয় ফাইল সৃষ্টি কৰে বা সলনি কৰে। ব্যৱহাৰ কৰাৰ আগতে কমাণ্ডটো সফল হৈছে নে নাই পৰীক্ষা কৰক। ৰপ্তানি কৰা ফাইলত ব্যক্তিগত তথ্য থাকিব পাৰে: ইয়াক সুৰক্ষিত ৰাখক।

## লগআউট কৰা

```sh
omi auth logout
```

এই কমাণ্ডে স্থানীয়ভাৱে সংৰক্ষিত ক্ৰেডেনচিয়েল আঁতৰাই পেলায়। চাৰ্ভাৰত কোনো কি' বাতিল কৰিবলৈ, আপোনাৰ একাউণ্টৰ ডেভেলপাৰ পৰ্টেল ব্যৱহাৰ কৰক।

অন্যান্য কমাণ্ড আৰু উন্নত বিকল্পসমূহৰ বাবে, [মূল ইংৰাজী নিৰ্দেশিকা](../README.md) আৰু `omi --help` চাওক।
