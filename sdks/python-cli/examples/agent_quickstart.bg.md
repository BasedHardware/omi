# Оперативен старт за агенти (Bulgarian)

Този ръководство ще ви покаже как да стартирате бърз старт за агенти с `omi-cli`.  
Кодовете и командите остават същите като в английската версия, но всички описания са преведени на български.

## Предварителни изисквания

- **Python 3.10+**  
- **omi-cli** – инсталирайте с `pip install omi-cli`
