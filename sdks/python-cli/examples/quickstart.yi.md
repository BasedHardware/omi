# ערשטע טריט מיט omi-cli

דער פֿירער דערקלערט די ערשטע באַפֿעלן (commands) פֿון omi-cli אויף ייִדיש. די נעמען פֿון די באַפֿעלן און די מעלדונגען פֿון דעם פּראָגראַם בלײַבן אויף ענגליש. די זוך-בײַשפּילן וואָס ווערן געוויזן דאָ טוישן נישט אײַערע זכרונות (memories), שמועסן (conversations), אויפֿגאַבן (action items) אָדער צילן (goals).

## אינסטאַלאַציע

פֿאַרלענגערט: Python 3.10 אָדער נײַער, און אַן Omi קאָנטע.

אויב איר האָט `pipx`:

```sh
pipx install omi-cli
omi --help
```

איר קענט עס אויך אינסטאַלירן אין אַן אַקטיוון Python ווירטועלן סבֿיבֿה:

```sh
python -m pip install omi-cli
omi --help
```

אויב דער טערמינאַל געפֿינט נישט `omi`, פֿאַרזיכערט זיך אַז די ווירטועלע סבֿיבֿה איז אַקטיוו אָדער אַז דער `pipx` טעקע איז אין `$PATH`.

## פֿאַרבינדן אײַער קאָנטע

אָנהייבט דעם אינטעראַקטיוון אַסיסטענט:

```sh
omi auth login
```

קלייבט אַרײַנצוגיין דורך דעם בלעטערער אָדער אַרײַנקלעפּן אַן Omi דעוועלאָפּער API שליסל. די אינטעראַקטיווע אײַנגאַבע באַהאַלט דעם שליסל; פֿאַרמיידט עס צו שרײַבן אין אַ באַפֿעל וואָס ווערט געהיט אין דער טערמינאַל געשיכטע.

צו גיין גלײַך צום בלעטערער:

```sh
omi auth login --browser
```

לאָגט זיך אַרײַן אויף דעם זעלבן קאָמפּיוטער ווי דער טערמינאַל: דער אויטענטיפֿיקאַציע ענטפֿער גייט צו דער לאָקאַלער אַדרעס. פֿאָלגט די אַנווײַזונגען אויף דעם עקראַן.

דערנאָך, באַשטעטיקט די קאָנפֿיגוראַציע און API צוטריט:

```sh
omi auth status
omi auth whoami
```

`status` ווײַזט דעם לאָקאַלן צושטאַנד און באַהאַלט דעם סוד, אָבער באַשטעטיקט נישט די גילטיקייט אויף דעם סערווער. `whoami` מאַכט אַן אויטענטיפֿיצירטע בקשה; אויב עס געלינגט, איז קלאָר אַז די באַשטעטיקונגען אַרבעטן, אָן ווײַזן אײַער נאָמען.

די קאָנפֿיגוראַציע ווערט געהיט דורך פֿאַרשטעלונג אין `~/.omi/config.toml`. טיילט נישט די טעקע: זי קען האַלטן פּריוואַטע באַשטעטיקונגען.

## דערקענען אײַערע דאַטן

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

אַן ליידיקע רשימה מיינט אָפֿט נאָר אַז גאָרנישט שטימט מיט דער זוך. ניצט די הילף צו געפֿינען די פֿילטערס פֿון יעדער באַפֿעל:

```sh
omi memory list --help
omi action-item list --help
```

## JSON און בלעטער

שטעלט די וועלטלעכע אָפּציע `--json` **פֿאַר** דער באַפֿעל-גרופּע:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

די ערשטע באַפֿעל בעט די ערשטע 25 זכרונות; די צווייטע די ווײַטערדיקע 25. איין בלאַט איז נישט אַ פֿולשטענדיקע קאָפּיע. דער JSON אויסגאַבע היט די גאַנצע נומערן, בשעת די טאַבעלן אויף דעם עקראַן קענען זיי פֿאַרקירצן.

צו היטן אַ בלאַט אין אַ טעקע:

```sh
omi --json memory list --limit 25 --offset 0 > זכרונות-בלאַט-1.json
```

די איבערפֿירונג שאַפֿט אָדער איבערשרײַבט אַ לאָקאַלע טעקע. פֿאַרזיכערט זיך אַז די באַפֿעל איז פֿאַרטיק איידער איר ניצט דעם אינהאַלט. טעותים ווערן געשריבן צום טעות-אויסגאַבע (stderr); אַן ליידיקע טעקע איז נישט קיין באַווײַז אַז עס איז נישטאָ קיין דאַטן. אַן עקספּאָרטירטע טעקע קען האַלטן פּערזענלעכע אינפֿאָרמאַציע: היט זי פּריוואַט.

## אַרויסלאָגן

```sh
omi auth logout
```

די באַפֿעל פֿאַרלאָשט די לאָקאַל געהיטענע באַשטעטיקונגען. צו פֿאַרומגילטן אַ שליסל אויף דעם סערווער, ניצט די פֿאַרוואַלטונג פֿון דעוועלאָפּער שליסלען אין אײַער אייגענער קאָנטע.

פֿאַר מער באַפֿעלן און אָפּציעס, זעט דעם [הויפּט פֿירער אויף ענגליש](../README.md) און `omi --help`.
