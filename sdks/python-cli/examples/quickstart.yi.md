# אָנהייבן מיט omi-cli

דער מדריך ווײַזט די ערשטע פּאָר באַפֿעלן אויף ייִדיש. די נעמען פֿון די באַפֿעלן און סיסטעם מעלדונגען בלײַבן אויף ענגליש. די לייענען בײַשפּילן דאָ וועלן נישט ענדערן אײַערע זכרונות, שמועסן, אַקציע רשימות אָדער צילן.

## אינסטאַלירן די פּראָגראַם

באַדערפֿנישן: Python 3.10 אָדער נײַער און אַן Omi קאָנטאָ.

> באַמערקונג: דער פּעקל נאָמען אויף PyPI איז **`omi-cli`**, בשעת דער באַפֿעל וואָס לויפֿט נאָך אינסטאַלירונג איז **`omi`**. עס איז פֿאַראַן אַן אַנדער ניט-פֿאַרבונדענער פּעקל מיטן נאָמען `omi` אויף PyPI — אינסטאַלירט נישט יענעם פּעקל.

אויב `pipx` איז אינסטאַלירט:

```sh
pipx install omi-cli
omi --help
```

אַנדערש, אין אַן אַקטיווע ווירטועלע סבֿיבֿה פֿון Python:

```sh
python -m pip install omi-cli
omi --help
```

אויב דער טערמינאַל געפֿינט נישט `omi`, פֿאַרזיכערט אַז די ווירטועלע סבֿיבֿה אַרבעט אָדער דער `pipx` אָפּטיילונג איז אין אײַער `PATH`.

## פֿאַרבינדן אײַער קאָנטאָ

הייבט אָן דעם אינטעראַקטיוון געהילף:

```sh
omi auth login
```

קלײַבט אויס זיך צו פֿאַרבינדן דורכן בראַוזער, אָדער קלײַבט די ברירה אַרײַנצוקלעפּן אַן Omi דעוועלאָפּער API שליסל. דער אינטעראַקטיווער אַרײַנגאַנג באַהאַלט דעם שליסל; שרײַבט נישט דעם שליסל אין באַפֿעלן וואָס בלײַבן אין דער טערמינאַל היסטאָריע.

פֿאַר דירעקטן אַרײַנגאַנג דורכן בראַוזער:

```sh
omi auth login --browser
```

ענדיקט דעם אַרײַנגאַנג אויפֿן זעלבן קאָמפּיוטער וווּ דער טערמינאַל לויפֿט, ווײַל די באַשטעטיקונג קערט זיך אום צו אַ לאָקאַלער אַדרעס. פֿאָלגט די אָנווײַזונגען אויפֿן עקראַן.

נאָך דעם, קאָנטראָלירט די קאָנפֿיגוראַציע און API צוטריט:

```sh
omi auth status
omi auth whoami
```

`status` ווײַזט דעם לאָקאַלן מצבֿ און באַהאַלט סודות, אָבער פּרוֿווט עס נישט מיטן סערווער. `whoami` שיקט אַ באַשטעטיקטע בקשה; הצלחה מיינט אַז אײַערע קראַדענשאַלז אַרבעטן געהעריק.

די קאָנפֿיגוראַציע ווערט געהיט נאָרמאַל אין `~/.omi/config.toml`. טיילט נישט דעם פֿײַל ווײַל ער ענטהאַלט אײַערע פּריוואַטע אינפֿאָרמאַציע.

## זען אײַערע דאַטן

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

אַ ליידיקע רשימה קען פּשוט מיינען אַז קיין זאַך שטימט נישט מיט דער בקשה. כּדי צו פֿאַרשטיין די פֿילטערס פֿון אַ באַפֿעל, קוקט אין דער הילף:

```sh
omi memory list --help
omi action-item list --help
```

## באַקומען JSON און בלאַטערן דורך די בלעטער

לייגט די גלאָבאַלע ברירה `--json` **פֿאַר** דער באַפֿעלן גרופּע:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

דער ערשטער באַפֿעל בעט די ערשטע 25 רעקאָרדס; דער צווייטער בעט די קומענדיקע 25. דעריבער איז איין בלאַט נישט קיין פֿולע זיכערהייט קאָפּיע. דער JSON אַרויסגאַנג האַלט די פֿולע אידענטיפֿיקאַטאָרן, בשעת טאַבעלעס קענען זיי פֿאַרקירצן.

צו ראַטעווען אַ בלאַט אין אַ פֿײַל:

```sh
omi --json memory list --limit 25 --offset 0 > זכרונות-בלאט-1.json
```

די איבערפֿירונג שאַפֿט אָדער פֿאַרבײַט אַ לאָקאַלן פֿײַל. איידער איר ניצט דעם אינהאַלט, פֿאַרזיכערט אַז דער באַפֿעל איז געווען מצליח. גרײַזן ווערן געשריבן אויף stderr; אַ ליידיקער פֿײַל איז נישט קיין באַווײַז אַז עס זענען נישטאָ קיין דאַטן. היט דעם פֿײַל זיכער ווײַל ער קען ענטהאַלטן פּערזענלעכע אינפֿאָרמאַציע.

## אַרויסגיין (Log out)

```sh
omi auth logout
```

דער באַפֿעל נעמט אַראָפּ לאָקאַל געהיטע קראַדענשאַלז. כּדי צו בטל מאַכן אַ שליסל אויפֿן סערווער, ניצט די דעוועלאָפּער שליסל פֿאַרוואַלטונג אין אײַער קאָנטאָ.

פֿאַר אַנדערע באַפֿעלן און מער ברירות, קוקט ביטע אינעם הויפּט מדריך אויף ענגליש:
[../README.md](../README.md) און `omi --help`.
