# omi-cli އާއެކު އަވަސް ފަށައިގަތުން

މި ގައިޑަކީ ދިވެހި ބަހުން މުހިންމު ކޮމާންޑްތައް ކިޔާދޭ ފޮޓެއް. ކޮމާންޑްގެ
ނަންނަން އަދި ޕްރޮގްރާމްގެ މެސެޖުތައް އިނގިރޭސި ބަހުން ދެއްވާނެ. ތިރީސް
ވާ މިސާލު ކޮމާންޑްތަކުން ތިބާ މީހުންގެ ހަނދާންތައް، ވާހަކަތައް، އެކްޝަން
އައިޓަމް ނުވަތަ މަޤްސަދުތައް ބަދަލު ނުވާނެ.

## ޕްރޮގްރާމް އިންސްޓޯލް ކުރުން

މުހިންމު ތަންތަން: Python 3.10 ނުވަތަ އަލީ އަދި Omi އެކައުންޓެއް.

`pipx` އިންސްޓޯލް ކޮށްފައިވާ ނަމަ:

```sh
pipx install omi-cli
omi --help
```

ނުވަތަ ފާއިތުވެފައިވާ Python virtual environment އަށް އިންސްޓޯލް ކުރުން:

```sh
python -m pip install omi-cli
omi --help
```

ޓާމިނަލު `omi` ނުފެންނަ ނަމަ، virtual environment ފާއިތުވެފައި ހުރިތޯ ނުވަތަ
`pipx` executable ބެހެއްޓި ފޯލްޑަރ `PATH` ގައި ހުރިތޯ ބަލާށެވެ.

## އެކައުންޓް ބައިންދާލުން

އިންޓަރެކްޓިވް ގައިޑް ރަން ކުރުން:

```sh
omi auth login
```

ބްރަވުޒަރް ލޮގިން ނުވަތަ Omi ޑިވެލަޕަރ API key ބައިންދާލާށެވެ. އިންޓަރެކްޓިވް
އިންޕުޓުން key ފޮރުވައިދެއެ; ޓާމިނަލް ހިސްޓަރީގައި ރައްކާވާ ކޮމާންޑްތަކަށް
ސީދާ ލިޔުން ނުވާނެ.

ބްރަވުޒަރ ސީދާކޮށް ބޭނުން ކުރުމަށް:

```sh
omi auth login --browser
```

ޓާމިނަލު އޮތް އެ ކޮމްޕިއުޓަރުގައި ލޮގިން ކުރާށެ — އޮތެންޓިކޭޝަނަކީ ލޯކަލް
callback އެޑްރެހަކު ބޭނުންކުރާ ތަންތަން. ސްކްރީންގައި ދެއްވާ އިރުޝާދުތައް
ފާލަމްކުރާށެ.

ލޮގިން ވުމަށް ފަހު، ކޮންފިގުރޭޝަން އަދި API އެކްސެސް ޗެކް ކުރާށެ:

```sh
omi auth status
omi auth whoami
```

`status` ލޯކަލް ހާލަތް ދައްކައި ސިރްތައް ފޮރުވައިދެއެ، އެހެނަސް ސަރވަރުގައި
އެ ސާދިރު ހުރިތޯ ޗެކް ނުކުރެ. `whoami` އޮތެންޓިކޭޓިޑް ރިކުއެސްޓެއް ފޮނުވީ;
ކާމިޔާބު ވެއްޖެ ނަމަ ތިބާގެ credentials މަސައްކަތް ކުރާނެ — ތިބާގެ ނަން
ނުދައްކައިގެން.

ކޮންފިގުރޭޝަން ޑިފޯލްޓްކޮށް `~/.omi/config.toml` ގައި ސޭވް ވާނެ. މި ފައިލް
ޝެއަރ ނުކުރާށެ — އޭގައި credentials ހިމެނިދާނެ.

## ތިބާ ޑޭޓާ ކިޔަވައިގަތުން

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ހުސް ލިސްޓަކީ ފިލްޓަރާ މެޗްވާ އައިޓަމް ނެތް ކަމުގެ މަޢުނަކީ. ކޮންމެ ކޮމާންޑެއްގެ
އޮޕްޝަންތައް help ގައި ބަލާށެ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON ހޯދުމާއި ސަފުހާ ފޮނުވާލުން

ގްލޯބަލް `--json` އޮޕްޝަން ކޮމާންޑް ގްރޫޕަށް **ކުރީން** ބަހައްޓާށެ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ފުރަތަމަ ކޮމާންޑުން ފުރަތަމަ 25 ހަނދާން ސުވާލު ކުރެވެ; ދެވަނަ ކޮމާންޑުން
ދެން އޮތް 25. އެއް ސަފުހާއަކީ ފުރިހަމަ ބެކްއަޕެއް ނޫން. JSON އައުޓްޕުޓްގައި
ފުރިހަމަ ID ތައް ރައްކާވާނެ، އެހެނަސް ޓޭބަލްގައި ދައްކަވަން ID ތައް ކުޑަކޮށް
ކުރެވިދާނެ.

ސަފުހާއެއް ފައިލަކަށް ސޭވް ކުރުން:

```sh
omi --json memory list --limit 25 --offset 0 > memory-page-1.json
```

ރީޑައިރެކްޝަން ލޯކަލް ފައިލެއް އުފެއްދުމެއް ނުވަތަ އޯވަރރައިޓް ކުރެވޭނެ.
މުހިންމުތައް ބޭނުންކުރުން ކުރިން ކޮމާންޑް ކާމިޔާބުކޮށް ނިމުނުތޯ ޔަޤީން
ކުރާށެ. އެރަރުތައް stderr އަށް ލިޔެވޭނެ; ހުސް ފައިލަކީ ޑޭޓާ ނެތްކަމުގެ
ހެއްކެއް ނޫން. އެކްސްޕޯޓް ފައިލްގައި ޝަހްސީ މަޢުލޫމާތު ހިމެނިދާނެ — ޕްރައިވަޓްކޮށް
ބަހައްޓާށެ.

## ޕްރޮފައިލް ބޭނުން ކުރުން

ސްޓޭޓް `~/.omi/config.toml` ގައި ސޭވްވެއް (`$OMI_CONFIG` އިން ބަދަލު
ކުރެވޭނެ). ކޮންމެ ޕްރޮފައިލަކަށް އެގެ އޮތެންޓިކޭޝަން މެތަޑާއި API އެޑްރެސް
ވެއް. `--profile` އިން ބަދަލު ކުރާށެ:

```sh
omi config profile use މަސައްކަތް
omi auth login
omi --profile ޝަހްސީ memory list
```

އާންމު ކޮންފިގުރޭޝަން ކޮމާންޑްތައް:

```sh
omi config show
omi config path
omi config profile list
```

## އެގްޒިޓް ކޯޑްތައް

މި އެގްޒިޓް ކޯޑްތައް ސްޓޭބަލް އަދި ސްކްރިޕްޓް ނުވަތަ މުންރަކީއަށް ފުއްދިވޭ:

| ކޯޑް | މާނަ | މިސާލު ހާލަތް |
| ---: | --- | --- |
| 0 | ކާމިޔާބު | ކޮމާންޑް ނިމުނު |
| 1 | ބޭނުން ކުރުމުގެ އެރަރ | ނުބައި flag، ކުޑަ އަރގިއުމެންޓް ނުވަތަ ފޭލް validation |
| 2 | އޮތެންޓިކޭޝަން އެރަރ | credentials ނެތް، ޓޯކަން އެކްސްޕަޔަރ ނުވަތަ ހުކުމް ކުޑަ |
| 3 | ސަރވަރ އެރަރ | ސަރވަރ 5xx ނުވަތަ ކަނެކްޝަން ފޭލް |
| 4 | ރޭޓް ލިމިޓް | ސަރވަރ HTTP 429 އަށް ރިޓާން |
| 5 | ނުފެންނަ | ސަރވަރ HTTP 404 އަށް ރިޓާން |

## ލޮގައުޓް

```sh
omi auth logout
```

ލޯކަލްކޮށް ސޭވް ކޮށްފައިވާ credentials ފޮހެދޭ. ސަރވަރުގައި key ރިވޯކް
ކުރުމަށް ތިބާ އެކައުންޓްގެ developer key މޭނޭޖްމަންޓް ބޭނުން ކުރާށެ.

އިތުރު ކޮމާންޑްތަކާއި އޮޕްޝަންތަކަށް [އިނގިރޭސި މުހިންމު README](../README.md)
ބަލާށެ އަދި `omi --help` ރަން ކުރާށެ.
