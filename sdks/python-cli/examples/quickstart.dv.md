# omi-cli ބޭނުންކުރަން ފަށާށެވެ

މި ގައިޑްގައި ބުނެދެނީ omi-cli ގެ ފުރަތަމަ ކަމަންޑްތައް ދިވެހި ބަހުންނެވެ. ކަމަންޑްތަކުގެ ނަންތަކާއި ޕްރޮގްރާމްގެ މެސޭޖްތައް އިނގިރޭސި ބަހުން ދެވޭނެއެވެ. މި ސާމްޕަލް ކުއެރީތަކުން ތިބާގެ މެމޮރީސް، ކޮންވަރސޭޝަންސް، އެކްޝަން އައިޓަމްސް، ނުވަތަ ގޯލްސް ބަދަލު ނުކުރާނެއެވެ.

## އިންސްޓޯލް ކުރުން

ބޭނުންވާނީ: Python 3.10 ނުވަތަ އާ ވާޝަނެއް، އަދި Omi އެކައުންޓެކެވެ.

pipx އިންސްޓޯލް ކޮށްފައިވާނަމަ:

```sh
pipx install omi-cli
omi --help
```

ނުވަތަ އެކްޓިވޭޓް ކޮށްފައިވާ Python virtual environment އެއްގައި:

```sh
python -m pip install omi-cli
omi --help
```

ނޯޓު: `omi` ކަމަންޑް ވަގުތުން PATH ގައި ނުހުރެވިދާނެ — virtual environment އެކްޓިވޭޓް ވެގެންވާ ކަމުގެ އަދި pipx ގެ ފޯލްޑަރ `$PATH` ގައި ހުރި ކަމުގެ ޔަޤީންކުރައްވާށެވެ.

## ލޮގިން

ފުރަތަމަ ލޮގިން ވާށެވެ:

```sh
omi auth login
```

ބްރައުޒަރަކުން ނުވަތަ Omi developer API key އަކުން ލޮގިން ކުރެވޭނެއެވެ. ކީ ޕޭސްޓް ކުރާށެވެ — ޓާމިނަލް ހިސްޓަރީއަށް ނުވަންނާނެއެވެ.

މި ކޮމްޕިއުޓަރުގައި ބްރައުޒަރުން ލޮގިން ކުރުމަށް:

```sh
omi auth login --browser
```

ޓާމިނަލް އެކަނި ހުރި މެޝިންތަކަށް: އޮތޯރައިޒޭޝަން ވާނީ ލޯކަލް އެޑްރެހެއްގައެވެ. ސްކްރީންގައި ދައްކާ އިރުޝާދުތައް ފޮލޯ ކުރާށެވެ.

މިހާރުގެ ކޮންފިގުރޭޝަނާއި API key ޗެކް ކުރާށެވެ:

```sh
omi auth status
omi auth whoami
```

`status` އިން ދައްކާނީ ލޯކަލް މަޢުލޫމާތު، ސީކްރެޓްތައް ފޮރުވައިގެން، ސާވަރަށް އެއްވެސް އެއްޗެއް ނުއެހެއެވެ. `whoami` އިން ފޮނުވާނީ އޮތެންޓިކޭޓްކޮށްފައިވާ ރިކުއެސްޓެއް؛ އެ މަސައްކަތް ކުރިނަމަ، ތިބާގެ credentials ރަނގަޅުކަން ޔަޤީނެވެ.

ކޮންފިގުރޭޝަން ހުރީ `~/.omi/config.toml` ގައެވެ. މި ފައިލަށް އަތުން ބަދަލު ނުގެންނަވާށެވެ — ކީ ސީކްރެޓްތައް އެތެރޭގައި އެބަހުއްޓެވެ.

## މެމޮރީސް އަދި ކޮންވަރސޭޝަންސް ލިސްޓް

```sh
omi memory list --limit 5
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

ލިސްޓް ހުވާވެފައިވާނަމަ، އެއްވެސް އެއްޗެއް އަދި ނެތް ކަން ދައްކަނީ އެއްޗެކެވެ. ކޮންމެ ކަމަންޑެއްގެ ފިލްޓަރތައް ބައްލަވާށެވެ:

```sh
omi memory list --help
omi action-item list --help
```

## JSON އަދި އެކްސްޕޯޓްތައް

ގްލޯބަލް `--json` އޮޕްޝަން އަބަދުވެސް ކަމަންޑް ގުރޫޕަށް ކުރިން އަންނަން ޖެހޭނެއެވެ:

```sh
omi --json memory list --limit 25 --offset 0
omi --json memory list --limit 25 --offset 25
```

ފުރަތަމަ ކަމަންޑަށް ގެނެވޭނީ ފުރަތަމަ 25 މެމޮރީސް؛ ދެވަނަ ކަމަންޑަށް ގެނެވޭނީ ދެން ހިނގާ 25 އެވެ. JSON އައުޓްޕުޓްގައި ފުރިހަމަ އައިޑެންޓިފަޔަރތައް ހުރެއެވެ، އެހެނަސް ޓޭބަލް ވިއުގައި އެއްޗެސް ކުރުކޮށް ދައްކައެވެ.

ފައިލެއްގައި ސޭވް ކުރުމަށް:

```sh
omi --json memory list --limit 25 --offset 0 > މެމޮރީސް-ޞަފްޙާ-1.json
```

މި ރީޑައިރެކްޓަށް އާ ލޯކަލް ފައިލެއް ބައްދަލު ކުރާނެ ނުވަތަ ކުރީގެ ފައިލް އޮވަރައިޓް ކުރާނެއެވެ. ފުރަތަމަ ކަމަންޑްގެ އައުޓްޕުޓް ޗެކް ކުރާށެވެ. އެރަރތައް ވާނީ stderr އަށް؛ ހުވާ ފައިލަކަށް ޑޭޓާ ނެތް ކަމުގެ މާނަ ނުވެއެވެ. އެކްސްޕޯޓް ފައިލްތަކުގައި ޕަރސަނަލް އިންފޯމޭޝަން ހުރެވިދާނެ — ރަނގަޅަށް ބެލެހެއްޓުމަށް.

## ލޮގައުޓް

```sh
omi auth logout
```

މި ކަމަންޑަށް ލޯކަލް credentials ފޮހެލާނެއެވެ. ސާވަރ ސައިޑުން ބައްދަލުކޮށްފައިވާ ކީތައް ވާނީ developer key management ގެ ދަށުންނެވެ.

އިތުރަށް: [އިނގިރޭސި ޑޮކްސް](../README.md) އަދި `omi --help`.
