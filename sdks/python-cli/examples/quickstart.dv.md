# omi-cli — ދިވެހި ކުއިކްސްޓާޓް ގައިޑް

> ޓަރުމިނަލުން Omi އާއެކު މަސައްކަތް ކުރުމަށްޓަކައި ޢަމަލީ ގައިޑެއް. މީހުންނަށާއި AI އޭޖެންޓުންނަށް ވެސް.

`omi-cli` އަކީ [Omi](https://omi.me) ޑިވެލޮޕާ API ގެ ރަސްމީ ކޮމަންޑް-ލައިން ކްލައަންޓެވެ.
އެއިން Omi ގެ ހަައަސީލީ ހަަތަރު މުއްސަނދި ވަސީލަތްތަކަށް — މެމޮރީޒް، ވާހަކަތައް، އެކްޝަން އައިޓަމްތައް، އަދި ލަނޑުދަނޑިތައް — އަވަސް އަދި ސްކްރިޕްޓް ކުރެވޭނެ ނިޒާމް ލިބިގެން ވެއެވެ.

* **PyPI:** [pypi.org/project/omi-cli](https://pypi.org/project/omi-cli/)
* **ޑޮކިއުމެންޓޭޝަން:** [docs.omi.me/doc/developer/cli/introduction](https://docs.omi.me/doc/developer/cli/introduction)
* **ސޯސް ކޯޑް:** [github.com/BasedHardware/omi/tree/main/sdks/python-cli](https://github.com/BasedHardware/omi/tree/main/sdks/python-cli)

## 1. އިންސްޓޯލް

ރިކޮމެންޑް ކުރެވޭ ގޮތަކީ `pipx`: ޓޫލް އެކަނި އިން އިސްތަރީ މާހައުލަކަށް އިންސްޓޯލްކުރާ،
އެހެންކަމުން އޭގެ ޑިޕެންޑެންސީތައް ތިޔަ ޕްރޮޖެކްޓުތަކާއި ނުކޮޅިލޭނެއެވެ.

```bash
# ރިކޮމެންޑް: pipx އިން އިންސްޓޯލްކުރޭ
pipx install omi-cli

# ނުވަތަ pip އިން
pip install omi-cli
```

> **މުހިއްމު: ޕެކޭޖް ނަނާއި ކޮމަންޑް ނަން ތަފާތު.**
> * އިންސްޓޯލްވާ ޕެކޭޖަކީ **`omi-cli`** (ވަކި ޕެކޭޖް `omi` އަކީ އެހެން، ގުޅުންނެތް ޕްރޮޖެކްޓެކެ).
> * އިންސްޓޯލް ކުރުމަށްފަހު ރަންކުރާ ކޮމަންޑަކީ **`omi`**.

ހުރިހާ ކަމެއް މަސައްކަތްކުރާކަން ޔަގީންކުރޭ:

```bash
omi --version
omi --help
```

## 2. އޮތެންޓިކޭޝަން

`omi-cli` ލޮގިން ކުރުމުގެ ދެ ގޮތަކަށް ސަޕޯޓްކުރެއެވެ.

| ގޮތް | ރަނގަޅު | ކޮމަންޑް |
| :--- | :--- | :--- |
| **ޑިވެލޮޕާ ކީ (`omi_dev_*`)** | CI/CD، ސްކްރިޕްޓް، AI އޭޖެންޓްތައް | `omi auth login --api-key ...` ނުވަތަ މާހައުލު ވޭރިއަބަލް |
| **ބްރަވުޒަރ ލޮގިން (Google/Apple)** | އަމިއްލަ ކޮމްޕިއުޓަރުގައި މަސައްކަތް | `omi auth login --browser` |

### އިންޓަރެކްޓިވް ލޮގިން

އިޚްތިޔާރެއް ނުދީ ރަންކުރޭ — ކޮން ގޮތަކަށް ބޭނުންކުރަނީ ސުވާލުކުރާނެއެ.

```bash
omi auth login
# 1) Browser — Google ނުވަތަ Apple އިން ލޮގިންކުރޭ (މީހުންނަށް)
# 2) API key — app.omi.me އިން ޑިވެލޮޕާ ކީ ޕޭސްޓްކުރޭ (އޭޖެންޓް/CI އަށް)
```

ކީ ނަގާނަމަ، އިންޕުޓް ފޮރުވޭނެވެ އެހެންކަމުން ކީ އެއް ޓަރުމިނަލް ހިސްޓރީގައި ނުބަހައްޓާނެއެވެ.

### ބްރަވުޒަރުން ސީދާ ލޮގިންކުރޭ

```bash
omi auth login --browser
```

### ޑިވެލޮޕާ ކީއިން ލޮގިންކުރޭ

ކީއެއް [app.omi.me](https://app.omi.me) ގެ **Developer → API Keys** ދަށުން ހޯދޭ.

```bash
# ކީއެއް ކޮންފިގަރޭޝަންގައި ސޭވްކުރޭ
omi auth login --api-key omi_dev_...

# ނުވަތަ މާހައުލުން ފޮނުވޭ — CI/CD އާއި ކޮންޓެއިނަރަށް ރަނގަޅު
export OMI_API_KEY=omi_dev_...
```

`OMI_API_KEY` މާހައުލު ވޭރިއަބަލް ބޭނުންވާނީ އެކްޓިވް ޕްރޮފައިލްގައި ކީއެއް ސޭވް
ނުކޮށްފައި ހުރިހިނދު، އެހެންކަމުން ކޮންޓެއިނަރުގައި ޑިސްކަށް އެއްވެސް ކަމެއް ލިޔެން
ނުޖެހޭނެއެވެ. ޕްރޮފައިލުގައި ކުރިން ކީއެއް އެބަ ހުރެއްޖެނަމަ އެ ކީ އެއް މާހައުލު
ވޭރިއަބަލަށް ވުރެ މުގުރާނޭނެއެވެ.

### އެކްސެސް ޔަގީންކުރޭ

ދެ ކޮމަންޑް ތަފާތު ސުވާލުތަކަށް ޖަވާބު ދެއެ — އެތައް ގޯސްނުކުރާށެވެ:

* `omi auth status` — **ލޯކަލް** ސޭވްކޮށްފައިވާ ކަންތައް: ޕްރޮފައިލް، މާސްކްކޮށްފައިވާ ކީ، ކަމިން ފުރުމުގެ ތާރީޚު.
  ނެޓްވަރކް ނުޖެހޭ.
* `omi auth whoami` — **Omi ސަރވަރަށް** ހުށަހެޅުމެއް: ކީއެއް ހަގީގަތުގައި ގަބޫލުކުރާކަން ޔަގީންކުރެއެ.
  ނެޓްވަރކް ބޭނުން.

```bash
omi auth status    # ލޯކަލް ޗެކް، އޮފްލައިން
omi auth whoami    # ސަރވަރ ޗެކް
```

ކަމިން ފުރަންދިމާވާ ޓޮކަން އަލުން ލޮގިން ނުކޮށް ރިނޫކުރޭ — މި ކޮމަންޑަކީ ހަމައެކަނި
**ބްރަވުޒަރ/OAuth ސެޝަންތަކަށް**. API ކީ (`omi_dev_*`) އިން ސަބިތުވާ ޕްރޮފައިލަކަށް
`omi auth refresh` ބޭނުންކުރުމުގެ ގޯސްތަކަކުން (ކޯޑް 1) ފޭލްވާނެއެ: ރިނޫކުރެވޭނެ
ޓޮކަނެއް ނެތް — ބޭނުންވަނަމަ Omi ވެބް އޭޕްގައި ކީ ބަދަލުކުރޭ:

```bash
omi auth refresh
```

ލޮގްއައުޓް:

```bash
omi auth logout
```

## 3. މުއާސިލީ ކޮމަންޑްތައް

### މެމޮރީޒް (memories)

ސިސްޓަމަށް ތިޔަގާބެލު ހަގީގަތް އަދި ޢިލްމު ރަކިވާ ކަންތައް.

```bash
# މެމޮރީޒްތަކުގެ ލިސްޓު
omi memory list

# އައު އެއް ބުނާށެވެ
omi memory create "ޔޫޒަރަކު ޑާކް ތީމް ކަމަށް ކަނޑައެޅޭ" --category lifestyle

# ވަކިވަކި އެއް ބަލާށެވެ
omi memory get <MEMORY_ID>
```

### ވާހަކަތައް (conversations)

ޑިވައިސް ނުވަތަ އޭޕްގެ އަޑު އަދި މަތްސޫރު ތާރީޚު.

```bash
# ފަހުގެ 5 ވާހަކަ
omi conversation list --limit 5

# ޓްރާންސްކްރިޕްޓާއެކު ފުރިހަމަ ވާހަކަ
omi conversation get <CONVERSATION_ID> --include-transcript
```

### އެކްޝަން އައިޓަމްތައް (action items)

Omi އިން ވާހަކަތަކުން ނިސްބަތް ކުރީމާ މަސައްކަތްތައް.

```bash
# ހަމައެކަނި ހުޅުވާ އެއްޗެއް
omi action-item list --open

# ފުރިހަމަކޮށްފައިވާގޮތަށް ޝާއިރުކުރޭ
omi action-item complete <ACTION_ITEM_ID>
```

### ލަނޑުދަނޑިތައް (goals)

```bash
# ލަނޑުދަނޑިތަކުގެ ލިސްޓު
omi goal list

# އައު ޕްރޮގްރެސް ވެލިޔު ރެކޮޑްކުރޭ (ދެ އާގިޔުމެންޓްވެސް ބޭނުން: ލަނޑުދަނޑި އަދި ވެލިޔު)
omi goal progress <GOAL_ID> 25

# ބަދަލުތަކުގެ ތާރީޚު
omi goal history <GOAL_ID>
```

## ކުދިންނާހިސާބު ސުވާލުކުރޭ (`ask`)

ވަކި އަވަސް ކޮމަންޑެއް: ކުދިންނާހިސާބު ސުވާލެއް ގަބޫލުކުރޭ،
އަދި ޖަވާބު ތިޔަ ވާހަކަތަކުން ބިނާވާނެއެ.

```bash
omi ask "ގެއަށް ބަދަލުކުރުމާއި ބެހޭ ގޮތުން ތި ނިންމީވައިސް"
omi --json ask "މި ހަފްތާގައި ތި ނިންމާނެ އެކްޝަން އައިޓަމްތައް ކޮންބާވައި ވޭ"
```

## 4. JSON އާއި ސްކްރިޕްޓް (`--json`)

`omi-cli` އިން މަޝިން-ރީޑަބަލް JSON ނެރެވޭނެއެ. `--json` އިޚްތިޔާރަކީ **ގްލޯބަލް**
އެހެންކަމުން އެ ސަބްކޮމަންޑަށް **ކުރިން** ލިޔެން ޖެހޭނެއެ.

```bash
# މެމޮރީޒް: id، މަތްސޫރު އަދި ކެޓަގަރީ ނަގާ
omi --json memory list | jq '.[] | {id, content, category}'

# ފަހުގެ ވާހަކަތަކުގެ ސުރުޚީ
omi --json conversation list --limit 5 | jq '.[] | {id, title: .structured.title, started_at}'

# ހުޅުވާ އެކްޝަން އައިޓަމްތައް
omi --json action-item list --open | jq '.'
```

> **އާންމު ގޯސް.** `--json` ސަބްކޮމަންޑަށް ކުރިން އަންނަނީ، ފަހުން ނޫން.
> * ރަނގަޅު: `omi --json memory list`
> * ގޯސް: `omi memory list --json`

`--json` މޯޑުގައި މީހުންނަށް ޕްރޮގްރެސް މެސޭޖް އަދި ސްޕިނަރ ފާޭރިވާނެއެ —
stdout ގައި ހަމައެކަނި ރަނގަޅު JSON ޑޮކިއުމެންޓެއް ހުންނާނެއެ. ގޯސްތައް stderr އަށް
`{"error": "...", "detail": "..."}` ގެ ސިފަޔަށް ދާނެއެ.

## 5. ނިކުންމުމުގެ ކޯޑްތައް

ސްކްރިޕްޓްގައި ފަރުމަން ކުރަންވީ ސްޓޭބަލް ނިކުންމުމުގެ ކޯޑްތައް.

| ކޯޑް | މާނަ |
| :--- | :--- |
| `0` | ކާމިޔާބު |
| `1` | ބޭނުންކުރުމުގެ ގޯސް (ގޯސް ފްލޭގް، ބޭނުންވާ އާގިޔުމެންޓް ނެތް) |
| `2` | އޮތެންޓިކޭޝަން ފޭލްވިއްޖެ — ލޮގިން ބޭނުން |
| `3` | ސަރވަރ/ނެޓްވަރކް ގޯސް |
| `4` | ރޭޓް ލިމިޓް — ފަހުން އަލުން މަސައްކަތްކުރޭ |
| `5` | ވަސީލަތް ނުލިބުނު |

```bash
if ! omi memory get "$MEMO_ID" --json > /tmp/m.json; then
  code=$?
  case $code in
    2) omi auth login --browser ;;
    5) echo "އެ މެމޮރީ ނެތް" ;;
    *) echo "ގޯސް $code" ;;
  esac
fi
```

## 6. ޕްރޮފައިލްތައް އަދި ކޮންފިގަރޭޝަން

ތިޔަ ގިނަ އެކާއުންޓް ނުވަތަ މާހައުލު އެބަހުރެއްޖެނަމަ ޕްރޮފައިލްތަކުން ވަކިކުރޭ.
ސެޓިންގްސް `~/.omi/config.toml` ގައި ސޭވްވާނެއެ.

```bash
# ޕަރސަނަލް ޕްރޮފައިލަށް ލޮގިންކުރޭ
omi --profile personal auth login

# ވަރކް ޕްރޮފައިލަށް ލޮގިންކުރޭ
omi --profile work auth login

# ވަކި ޕްރޮފައިލަކަށް ކޮމަންޑް ރަންކުރޭ
omi --profile work memory list
```

ބޭނުންކުރާ ޕްރޮފައިލް މި ތަރުތީބުން ކަނޑައަޅާ: `--profile` އިޚްތިޔާރު (ނުވަތަ `-p`)
ހުރިހާ ކަމެއްގެ މަތީން މުގުރާނޭ; ދެން `OMI_PROFILE` މާހައުލު ވޭރިއަބަލް; ދެން
`~/.omi/config.toml` ގެ އެކްޓިވް ޕްރޮފައިލް; އަދި ފަހުން `default` ޕްރޮފައިލް ފޯލްބެކްގެ ގޮތުން.

އަމިއްލަ ކޮންފިގަރޭޝަން ބަލާ އަދި ބަދަލުކުރޭ:

```bash
# މިހާރު ކޮން ސެޓްވެފައިވަނީ
omi config show

# ކޮންފިގަރޭޝަން ފައިލް ކޮބާއީ
omi config path

# ވެލިޔުއެއް ބަދަލުކުރޭ
omi config set api_base https://api.omi.me
```
