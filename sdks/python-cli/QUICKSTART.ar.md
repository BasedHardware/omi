# البدء باستخدام omi-cli

[English reference](README.md) · [التوثيق الكامل](https://docs.omi.me/doc/developer/cli/introduction)

تتيح أداة `omi-cli` الوصول من الطرفية إلى الذكريات والمحادثات والمهام والأهداف
المحفوظة في حساب Omi. هذا دليل بدء مختصر، وليس ترجمة لكل خيارات الأداة.
تبقى أسماء الأوامر والخيارات باللغة الإنجليزية؛ انسخها كما هي.

## التثبيت

تحتاج إلى Python 3.10 أو أحدث. إذا كانت أداة `pipx` مثبتة لديك، استخدم:

```shell
pipx install omi-cli
```

أو ثبّت الحزمة في بيئة Python الافتراضية التي تعمل بها:

```shell
python -m pip install omi-cli
```

اسم الحزمة هو `omi-cli`، لكن اسم الأمر بعد التثبيت هو `omi`.
لا تثبّت الحزمة المسماة `omi` بدلًا منها؛ فهي مشروع آخر.

```shell
omi --version
omi --help
```

إذا لم تتعرف الطرفية على `omi`، تأكد من تفعيل بيئة Python الصحيحة،
أو من إضافة مجلد البرامج الذي تستخدمه `pipx` إلى `PATH`، ثم افتح طرفية جديدة.

## تسجيل الدخول

شغّل الاختيار التفاعلي:

```shell
omi auth login
```

اختر تسجيل الدخول بالمتصفح باستخدام Google أو Apple، أو اختر مفتاح المطوّر
من حسابك في [app.omi.me](https://app.omi.me). لتحديد المتصفح مباشرة:

```shell
omi auth login --browser
```

لا تلصق المفتاح في تذكرة دعم أو مستودع عام. عند استخدام مفتاح يدويًا،
يتيح إدخاله في السؤال التفاعلي تجنب كتابته ضمن الأمر المحفوظ في سجل الطرفية.

```shell
omi auth status
omi auth whoami
```

يعرض `status` الحالة المحلية وبيانات اعتماد مقنّعة. أما `whoami` فيرسل طلبًا
إلى الخدمة للتحقق من بيانات الاعتماد؛ ظهور حالة محلية وحده لا يثبت نجاح الاتصال.

## قراءة بيانات الحساب

الأوامر التالية تقرأ البيانات، ولا تنشئ سجلات أو تحذفها:

```shell
omi memory list
omi conversation list --limit 5
omi action-item list --open
omi goal list
```

قد تكون القائمة فارغة إذا لم توجد بيانات مطابقة. استخدم المساعدة الخاصة
بالأمر لمعرفة خيارات التصفية المتاحة في إصدارك:

```shell
omi memory list --help
omi conversation list --help
```

## إخراج JSON للبرامج

ضع الخيار العام `--json` **قبل** اسم المجموعة، مثل `memory`:

```shell
omi --json memory list
```

لنسخ قائمة الذكريات التي يعيدها هذا الطلب إلى ملف، يمكنك استخدام إعادة التوجيه:

```shell
omi --json memory list > memories.json
```

قد يحتوي الملف على بيانات شخصية. هذا يحفظ نتيجة طلب واحد، ولا يضمن تصدير
جميع صفحات البيانات. تحقق من نجاح الأمر ومن محتوى الملف قبل الاعتماد عليه.
عند وقوع خطأ، يكتب وضع JSON تفاصيل الخطأ إلى `stderr` بدلًا من ملف النتيجة.

## الإعدادات والخروج

تُحفظ الإعدادات عادةً في `~/.omi/config.toml`. لمعرفة المسار الفعلي، بما في
ذلك أي تخصيص بواسطة `OMI_CONFIG`، شغّل:

```shell
omi config path
```

يمكن حفظ أكثر من ملف إعدادات مسمّى داخل هذا الملف. يشرح
[قسم Profiles](README.md#profiles) كيفية اختيار الحساب المناسب.
لا تشارك ملف الإعدادات؛ قد يحتوي على بيانات اعتماد.

```shell
omi auth logout
```

يمسح الأمر بيانات الاعتماد المحفوظة للملف الشخصي المختار. إذا كنت توفر
`OMI_API_KEY` كمتغير بيئة، فأزله أيضًا من بيئتك عند الرغبة في إيقاف استخدامه.

هذا الدليل يستخدم واجهة Omi السحابية. أوامر `omi local` لها إعداد منفصل
وتحتاج إلى تطبيق Omi Desktop يعمل ويوفر واجهته المحلية؛ راجع
[Local Omi Desktop API](README.md#local-omi-desktop-api).
