# OMI Python SDK

The OMI Python SDK provides a convenient interface for interacting with the OMI platform.

## Localized Guides

The SDK includes quickstart guides in multiple languages:

- English (`examples/quickstart.md`)
- Spanish (`examples/quickstart.es.md`)
- French (`examples/quickstart.fr.md`)
- German (`examples/quickstart.de.md`)
- Bengali (`examples/quickstart.bn.md`)

For more information, see the [documentation](https://github.com/basedhardware/omi/tree/main/sdks/python-cli).
