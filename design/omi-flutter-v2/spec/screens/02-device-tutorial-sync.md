## Pairing — Connect Omi

`Pairing.dc.html` · plan IDs **D01** · stage **S04** · presented as **sheet (large) over Home** · theme: always dark

Reference: `renders/{se,mini,iphone16,max}/{dark,light}/Pairing.webp`, `specs/geometry/<device>/Pairing.json`.

**Purpose.** Pair the nearest Omi pendant in one tap.

**Reached from.** `Discover`.

**Data (existing contracts only).** CoreBluetooth scan (single scan owner), GATT connect, battery `performRetrieveBatteryLevel`, codec `performGetAudioCodec`; firmware info for Device. Device record as Flutter does.

**States.**

- scanning: pendant art with LED breathing, “Looking for your Omi…”
- found one: name + battery + Connect
- several found: go to Discover (never guess)
- connecting: spinner in button
- connected: success haptic, Done
- Bluetooth off / denied: explain + Settings
- timeout 20 s: “Can't find it” + tips + Scan again

- empty per tab
- pendant disconnected: rows still listed from the local journal
