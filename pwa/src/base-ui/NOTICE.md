# Preview component sources

Locally owned adaptations of shadcn/ui's **Base Nova** Button, Card, Input,
Checkbox and Tabs, retrieved from https://ui.shadcn.com/r/styles/base-nova/
on 2026-09-20. Styles are reduced to the variants used by this Omi preview;
headings/sections use semantic HTML. The runtime primitives are Base UI,
not Radix. Dependencies are pinned in `pwa/package.json` and `bun.lock`.
